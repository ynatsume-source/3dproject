# R-009 住人ごとの「道のり」：科学班のたたき台（2026-10-25、main 7c8214e、未採択・リハのあとの作業）

本体の案（①状態の文に「何のため」の1行、②住人ごとの道のりを 済んだ・いま・次 で見せる）に、科学の流れを合わせる。

## 決め方

- 道のりの軸は ADR 0006 の役目（`islandlang.ts` の ROLE）にそろえる：ドット＝世界を広げる（作る・渡る）、ランタン＝火と灯りの
  研究、ラッコ＝貝殻の収集、カメマル＝位置の測量。役目と道のりが食い違うと、視聴者には余計にわからなくなる。
- 段階は「すでにある世界の事実」で済んだかを決める（節目 FIRSTS、`village` の値、工程の済み `labDone`）。まだない段階は
  「次」としてだけ見せ、済んだ判定は実装されてから足す。
- 画面は言葉だけ（数・残りの量は出さない、視聴者設計の決まり）。

## 「何のため」の1行

- LLM を使わず、作業の種類 → その作業の出来たものが入る次の段階、の表から作る（例：縄を撚る → 「筏を縛る縄のため」、
  殻を叩く → 「縄にする繊維のため」、芯を比べる → 「一晩じゅう消えない灯りのため」）。科学の工程は、工程表の入力と
  出力のつながり（process-catalog の input / also）から引ける。
- 段階の言葉と同じ言葉を使う（「いま：帆」なら「帆の筏のための縄」）。

## 本体の確認（10/25）

- chart（見える島を地図に記す）はドットの仕事。ドットの役目（地図の作成）に合うので、担い手は移さずドットの道のりに置く
  （科学班の案。カメマルの道のりからは外した）。

## オーナー決定（2026-10-25）

1. 道のりの軸は ADR 0006 の役目にそろえる。潮の記録はカメマルの道のり。
2. 炭と石灰はランタン（火の研究）の道のりに入れる（ドットには入れない）。
