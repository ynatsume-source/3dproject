# B. サンゴ・貝殻を焼いて石灰にする：仕様案 v1（2026-10-25、科学班、未採択）

## v2 の修正（Codex レビュー 10/25。本文より優先する）

1. **56 %** は反応した純 CaCO3 から CaO になる比。lot 全体には掛けない。質の値（`calcined_ppm`、`ash_mixed_ppm` など）は
   それぞれ分母（lot の乾いた重さ、など）を定義する。
2. 焼け残り（半焼け）、消化されなかった CaO、余った水は、返して**もう一度使える** lot にする。
3. 貝殻：ラッコのいまの「集めた数」の統計を材料の残りにしない。実物の item と mg の lot を1度だけ対応づけ、
   二重に使えないようにする。
4. **大きさと時間**：焼け目が一定の速さで進む式なので、芯まで届く時間は**半径に比例**（v0 概要の「2乗」は誤り）。
   焼け始めは式どおり約 **795 °C**（p_eq が山の中の 0.2 atm を超える温度）。
5. **反応熱**は main の値（焼成 191.59 kJ/mol、消化 −64.47 kJ/mol、`S-thermo`）を使う。試算の 178／65.2 は使わない。
   共有の値は変えない。熱の釣り合いの試算もこの値で直す（サンゴ 1 kg の焼成は 1.91 MJ、温めと合わせて約 2.8 MJ）。
6. **消化**は既存の定数をつなぐだけでは足りない：水の蒸発、水が足りないとき、器の熱容量、途中で止めたときを設計する。
   置いておくあいだも世界時計で進める（水をかけたら住民がいなくても反応と冷えは進む）。
7. **サンゴ拾い**の潮の条件は、世界時計の海面と島の `tideK` を受け取る形にする（ADR 0001、住民の海と同じ）。
8. PR は 3 本（①材料の codec と積み焼き、②消化、③拾うことと世界側の接続）。C0 のあと、12/1 以降。


main 6a3b0fc を元にした。C0（火の温度の天井）が入ってから実装する（12/1 以降）。試算は `lime.mts`。

## 1. すでにあるもの

- 物質：`calcite`（CaCO3）、`lime`（CaO）、`portlandite`（Ca(OH)2）、`co2`、`water`、`ash`、`inert_mineral`。
- 反応：焼成 CaCO3 → CaO + CO2、消化 CaO + H2O → Ca(OH)2（`chem.ts` の REACTIONS）。
- 値：焼成の吸熱 dHCalcination、消化の発熱、`kinHydrationTref`（消化の速さ、仮定）。
- `kinCalcTref`（800 °C で半減期 15 分）は粘土の中の細かい方解石用。こぶし大の石には使わない（§3）。
- 足りないもの：原料の lot、石の大きさによる焼け方、積み焼きの炉、消化の工程、漆喰が固まる反応（炭酸化）。

  v2 で雨ざらし・真水洗いで塩が抜ける仕組みを入れる。

## 3. 焼ける速さ（石の外側から殻のように焼け、芯が残る）

```
CO2 の釣り合いの圧力   log10 p_eq[atm] = 7.079 − 8308 / T[K]      （1 atm になるのが約 900 °C）
焼け目が進む速さ        v = V0 × clamp(1 − p_heap / p_eq(T), 0, 1)   [mm/時]
  V0     = 4 mm/時   サンゴは穴が多く焼けやすい（仮定。出典で詰める）
  p_heap = 0.2 atm  積んだ山の中の CO2（燃えた薪の煙と、サンゴから出る CO2。仮定）
石の残り（球）          芯の割合 = (1 − 焼け目の深さ / 半径)³
```

| 温度 | p_eq | 焼け目の速さ |
|---|---|---|
| 750 °C | 0.09 atm | 0（山の中の CO2 のほうが濃いので進まない） |
| 800 °C | 0.22 atm | 0.3 mm/時 |
| 850 °C | 0.48 atm | 2.3 mm/時 |
| 900 °C | 0.99 atm | 3.2 mm/時 |
| 950 °C | 1.9 atm | 3.6 mm/時 |

| 石の大きさ | 900 °C で芯まで | 850 °C で芯まで |
|---|---|---|
| 2 cm | 3.1 時間 | 4.3 時間 |
| 6 cm | 9.4 時間 | 12.8 時間 |
| 10 cm | 15.7 時間 | 21.4 時間 |

- 照らし合わせ：スリランカのサンゴの石灰窯（薪とサンゴを交互に積む）は、サンゴ 1.5〜3 t と薪 0.75〜1.5 t で
  約 48 時間燃やし、生石灰 0.75〜1.5 t が取れる（Practical Action の事例）。大きい石を温めて焼くのに丸2日、という
  桁は上の表と合う。取れる重さ（およそ半分）は理論の 56 % より少し少ない（焼け残り・こぼれ）。
- 熱の釣り合い：サンゴ 1 kg を 900 °C まで温めて焼くのに 2.65 MJ（焼成 1.78 MJ ＋ 温め 0.87 MJ）。
  スリランカの薪の量（サンゴ 1 kg に薪 0.5 kg ≈ 7.5 MJ）だと効率は約 35 %。島の小さな山はもっと熱が逃げるので、
  サンゴと同じくらいの重さの薪が要る見込み（C0 の式で決まる）。
- 焼きすぎ：1100 °C を長く超えると生石灰が締まって水と反応しにくくなる。積み焼きの天井は 900〜950 °C（C0）
  なので、ふつうは起きない。v1 では温度の最高値を質に残すだけ。

## 4. 積み焼き（新しい工程 `p_lime_heap_burn`、島の時間）

- 焚き火台とは別の場所（浜の近くの開けた所）に、薪とサンゴを交互に積む。1回の山はサンゴ 5〜20 kg。
- 住民が始めに決めること（1回）：サンゴの量、薪の量、石を大きさで選り分けるか（選ると焼けむらが減る）。
- 火は A の火から移す（熾が生きていれば持っていく。消えていればおこす）。
- 山は燃料を最初に全部積む（あとから足さない）。温度は C0 の式（F 0.85、λ は C0 で合わせる）で上がり、
  薪が尽きると冷める。冷めるまで崩さない（`UNLOAD_C` 60 °C）。
- 台帳：サンゴ（calcite）→ 生石灰（lime）＋ CO2（空気へ）。有機物は O2 を引いて燃える。薪は灰になり、
  **灰は生石灰に混ざる**（質 `ash_mixed_ppm`）。焼け残りの芯は calcite のまま残る（質 `calcined_ppm`）。
- 天気：雨が降ると山が冷える（pit-fire の雨の扱いに合わせる）。天気がわからない区間は 'stopped'。
- 出てくるもの：`quicklime`（lot。中身は lime ＋ 焼け残りの calcite ＋ 灰 ＋ inert_mineral）。56 % は**反応した純 CaCO3 → CaO の比**で、
  芯・灰・不純物・水を含む lot 全体の重さには固定で掛けない（各成分を台帳で足し合わせる）。

## 5. 消化（新しい工程 `p_lime_slake`、世界の時間）

- 既存の `slake.ts` はそのまま。新しいファイルは `lime-hydrate.ts`、工程 ID は `p_lime_slake`（衝突しない）。
- 生石灰に水をかけると、CaO + H2O → Ca(OH)2 で強く熱が出る（生石灰 1 kg で 1.16 MJ）。最低限の水は生石灰の
  32 %。熱で水が湯気になって逃げるので、実際はその 1.5〜2 倍かける。
- 決めること：水の量。少なめ → 粉の消石灰（`hydrated_lime`）、多め → 練った石灰（`lime_putty`、水が残る）。
- 器が要る（水を張る土器、既存）。湯気の分の水は空気へ（台帳に出す）。
- 速さは既存の `kinHydrationTref`。焼けが甘い（calcite が多い）ほど消化される量が減るだけ。

## 6. その先（B の次の段、ここでは仕様にしない）

- 漆喰：消石灰＋砂＋水を塗ると、空気の CO2 を吸って Ca(OH)2 + CO2 → CaCO3 + H2O で数週間かけて固まる
  （炭酸化。反応を chem に足す）。かまど・炉の内張り・壁に使う → 囲った炉ができ、天井が上がる。
- 金属への道：囲った炉＋竹のふいご（C）＋炭＋るつぼ。石灰は銅を溶かすときの融剤にもなる。

## 7. 保存

- 新しい lot が4種（coral_rubble、shell、quicklime、hydrated_lime / lime_putty）。1回の山で数件。
- 灰を混ぜて持つので、灰の lot は増えない。CO2・湯気は台帳の「空気へ」に出すだけ。

## 8. 実装されたら科学班が確かめること

1. 質量が mg で釣り合う（CaCO3 → CaO ＋ CO2、有機物の燃え、薪 → 灰 ＋ CO2 ＋ 水）。重さ 56 %。
2. §3 の表が params から再現される。800 °C 未満では焼けない。石が大きいほど芯が残る。
3. 薪が少ない山は温度が上がりきらず、焼け残りが多い。雨で焼けが悪くなる。
4. 消化で熱が出て水が減る。焼けが甘い石灰ほど消化される量が少ない。
5. 早回し・チャンクで結果が変わらない。
