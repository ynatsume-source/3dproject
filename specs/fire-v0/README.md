# 火の科学の見直し（下書き v0、2026-10-24、科学班）

main 6a3b0fc 時点の調査と、Codex に渡す前の仕様の下書き。**未採択**。リハーサル（10/31）のあとに Codex と詰める。
順番の提案：A 火をおこす → C0 火の温度の天井 → B 石灰を焼く → C 竹のふいご。金属はその後。

## 0. いまどうなっているか（調査）

### 火はどこから来るか
- **誰もおこしていない。** 焚き火の会（`src/robots/residents.ts` の fireCircle）は、集いの時間に2体以上が焚き火台
  （PIT、小屋のそば）に座ると成立する社交の出来事。炎は円錐のメッシュで、毎晩 19:24〜21:06 と土器焼き・油煮の間に描かれる（燃料・天気・誰がつけたかとは無関係。
  v0 で「いつも描かれている」と書いたのは誤り、10/24 訂正）。
- 科学のステップ（wood-fire / pit-fire / charcoal / coconut）は「`open_fire_pit` がある＝もう燃えている」が前提で、
  予約した薪の lot を燃やすところから始まる。`wood-fire.ts` の冒頭に「未実装：空気が足りない燃え方、煙、火の粉、
  湿った木に火がつかないこと、流木の塩」とある。火をおこす・火種を保つ・雨で消える、はどこにもない。

### 炉ごとの温度の天井（params から計算、定常で 気温＋ΔT）
天井 ΔT ≈ 最大の燃やす速さ × 薪の正味の発熱 × 残る割合 ÷ 逃げ（UA）。薪は乾いた分 18 MJ/kg、水の蒸発を引く。

| 炉 | 燃やす速さ上限 | 残る割合 | UA | 薪の水 12 % | 20 % | 28 % |
|---|---|---|---|---|---|---|
| 焚き火（料理・試験タイル wood-fire、process-catalog の OPEN_FIRE） | 3 kg/h | 0.2 | 8 W/K | +324 K | +291 K | +257 K |
| 野焼き（pit-fire、params の pit*） | 40 kg/h | 0.35 | 25 W/K | 約 +2000 K | — | — |

- 焚き火の上に置いたタイルは 300 °C 台で頭打ち。赤く光る（680 °C）には届かず `peak_not_reached` になる。
  実際の熾火の中なら 600〜800 °C にはなるので、低すぎる側。
- 野焼きは計画しだいで黄色（1130 °C）まで届く。実際の野焼きは 600〜900 °C、短く 1000 °C 前後で、高すぎる側。
- 原因は共通：温度の天井が「燃やす速さの上限」と「直線の逃げ（UA）」だけで決まり、**空気（酸素の入り方）と放射の
  逃げ（温度の4乗）が入っていない**。このままだと「ふいごで風を送ると熱くなる」を表せない。

### 石灰の土台はもうある
- `chem.ts` に CaCO3 → CaO + CO2（焼成）と CaO + H2O → Ca(OH)2（消化）の反応、`lime`（CaO）の物質がある。
- `params.ts` に焼成の吸熱 dHCalcination、消化の発熱、`kinCalcTref` 800 °C（半減期15分）、`kinHydrationTref`。
  ただし kinCalc は **粘土の中の細かい方解石** 用に合わせた値で、こぶし大のサンゴ石には使えない（中まで熱と CO2 の
  出入りが届くのに時間がかかる）。
- 島の貝殻はラッコが集める「数」（物語・言葉の側）で、科学の lot ではない。サンゴ石もまだ無い。
- `slake.ts` は粘土を水でほぐす工程で、石灰の消化ではない（名前が紛らわしいので新しい工程は lime_slake などにする）。

## A. 火をおこす（最初・小さい・見て楽しい）

> 詳しい仕様は [A-fire-making.md](A-fire-making.md)（v1、試算つき）。以下は v0 の概要。

**世界の事実として、焚き火台の火に状態を持たせる**：`out`（消えている）／`embers`（熾・灰に埋めた火種）／`burning`。
台帳に記録し、世界の時間で変わる（ADR 0001：観賞用の早回しでは変わらない）。

- おこし方：火溝式（ひみぞ、柔らかい乾いた木の溝を棒でこする。太平洋の島々で広く使われた）か、きりもみ式。
  どちらにするかはオーナー判断（下の「決めてほしいこと」）。
- 要るもの：乾いた木（台木と棒）、火口（ほくち）＝**乾いた**ヤシの繊維や殻のくず。いま島にある husk は浸けて
  湿っているので、乾かした別の lot が要る（既存の drying で乾く）。
- 成功の決め方（仮定値、すべて assumed で params に置く）：1回の試み＝数分のつらい作業（手の仕事の offer、
  50〜100 W 程度）。成功の確率は木と火口の水分、湿度、雨、風で下がる。seed 付きの抽選（チャンクで変わらない）。
  失敗しても試み直せる。LLM は要らない（ルールで暮らしが続く）。
- 火種を保つ：灰に埋めた熾は数時間〜一晩もつ（仮定 8〜12 時間、雨ざらしなら短い）。朝の最初の仕事が
  「熾をかき起こす／消えていたらおこし直す」になる。のちに、ヤシの殻に入れた火種を運ぶ（ほかの場所・島へ）。
- 何が変わるか：焚き火の会は `burning` のときだけ成立。火を使う科学の工程は、始めるときに `burning` を要する
  （または工程の最初に火をおこす）。描画の炎は状態に従う（見た目の変更は別 PR、本体か自然班）。
- 保存：状態と最後におこした時刻だけ。数バイト。

## C0. 火の温度の天井を作り直す（B・C の前提）

> 下調べと式の案は [C0-fire-ceiling.md](C0-fire-ceiling.md)（10/25）。以下は v0 の概要。

- 炉の温度の釣り合いを「入る熱 ＝ 壁から逃げる熱（UA）＋ 放射で逃げる熱（ε σ A T⁴）＋ 物を温める熱」にする。
  高温ほど放射が効くので、燃料を増やしても温度は伸びにくくなる（実際の焚き火の 900 °C 前後の頭打ち）。
- 燃える速さは空気で縛る：自然の通風で入る空気の上限 → 酸素 → 燃やせる薪・炭の速さ。ふいごはこの上限を上げる。
- 焚き火（置いたもの）と野焼き（囲んだもの）を同じ式で、形の違い（覆う薪の量・地面への逃げ）だけで分ける。
- 変更は processVersion を上げ、進行中の run は旧版のまま終わらせる。**12月の潮が固まるまで（12/1 まで）は触らない。**
  住民の結果（土器が焼けるか）が変わるので、リハーサル・潮の観察と重ねない。

## B. 石灰を焼く

> 仕様案は [B-lime.md](B-lime.md)（v1、10/25）。以下は v0 の概要。

- 原料：浜の死んだサンゴのかけら・貝殻（CaCO3 が 9 割台、数 % の Mg、塩、有機物）。生きたサンゴは採らない
  （オーナー確認したい）。新しい lot：`coral_rubble` / `shell`（質量 mg、大きさ mm、水、塩）。
- 焼き方：薪とサンゴ石を交互に積んで燃やす積み焼き（沖縄・太平洋の石灰焼きの形）。C0 の野焼き型の炉を使う。
- 化学：CaCO3（100.09）→ CaO（56.08）＋ CO2。重さは **56 %** になる。CO2 は空気へ（台帳で釣り合う）。
  分解は空気中なら 700 °C 台から遅く、850〜900 °C を超えると速い（CO2 が 1 気圧で釣り合う温度は約 900 °C）。
- 大きさの効き方：外側から殻が焼けて芯が残る（収縮核）。芯まで届く時間は半径に比例（10/25 訂正、v0 は「2乗」と誤記）、900 °C で
  こぶし大（5〜8 cm）なら数時間（仮定、出典を探す）。芯が残ったものは「焼けが甘い石灰」として品質に出す。
  1100 °C を長く超えると焼きすぎ（消化が遅い）。
- 消化（lime_slake）：CaO＋H2O → Ca(OH)2、強い発熱で湯気が立つ。最低でも CaO の 32 % の水、練るならもっと。
  できるのは消石灰（粉・練り）。住民が素手で触らないルール（道具で扱う）。けがは模型にしない。
- 使い道（あとの段）：消石灰＋砂の漆喰は空気の CO2 を吸ってゆっくり固まる（数週間）→ かまど・壁・炉。
  囲った炉ができると天井が上がり、金属への道（ふいご＋炭＋るつぼ）につながる。
- 保存：原料と生成物の lot が増えるだけ。副産物（燃え殻・灰）は 12 月以降の副産物の扱いの決まりに従う。

## C. 竹のふいご（ピストン式）

> 下調べと骨組みは [C-bellows.md](C-bellows.md)（10/25）。島のいまの竹（内径 6〜12 mm）では作れないことがわかった。以下は v0 の概要。

- 形：太い竹の筒を2本立て、繊維（ヤシ・羽根）を巻いたピストンを交互に上下する。空気は粘土の管（羽口）で
  炭の床の底へ。東南アジア・マダガスカルの鍛冶で使われた形。
- 物理（仮定、出典を探す）：1人で毎分 0.2〜0.5 m³ の空気。0.3 m³/分なら酸素 約 0.08 kg/分 → 炭（炭素）
  約 1.9 kg/時 → 約 17 kW を小さな炉に集める → 炭の床で 1100〜1300 °C。人の仕事は 50〜100 W、空気に
  渡るのはその一部（圧力 1〜2 kPa × 流量）。
- 要るもの：竹（島に生えているか、地点ごとに確認が要る）、ヤシの繊維（coir はある）、羽口（土器の技術はある）、
  炭（炭焼きの retort はあるが量が少ない。炭の量産が別に要る）。
- 世界側：送風の設備（`bamboo_bellows`）と、それを動かす手の仕事。炉の工程は「送られた空気」を受け取り、
  C0 の式で燃える速さの上限が上がる。
- 最初の確かめ（初点灯の前の段）：同じ炭で、送風なしは橙（950 °C）止まり、送風ありは黄色（1130 °C）以上。
  その先が銅（遠くの島の鉱石、1085 °C で溶ける）と還元（炭の CO）。

## オーナー決定（2026-10-24）

1. 火のおこし方は**火溝式**。地点ごとの違いは今は作らない（必要になったら改めて相談）。
2. 夜は**熾を灰に埋めて、たいてい朝までもつ**。雨ざらし・長い放置では消え、そのときはおこし直す。
3. サンゴは**浜の死んだかけらと貝殻だけ**。生きたサンゴは採らない。
4. 順番 A → C0 → B → C。C0 以降は 12/1 以降。
5.（10/25）ふいごの筒は最初は木をくり抜き、のちに遠くの島の太い竹。炭の量産（伏せ焼き）をふいごの前に入れる：A → C0 → B → 炭の量産 → C。

## 確かめ方（実装されたら科学班が見ること）

  火の状態が変わらない／旧セーブは「燃えている」として読める。
- C0：既存の土器・タイル・炭焼き・ココナツ油の結果が、版を上げた run でどれだけ変わるかの表（前後比較）。

- C：送風の有無で天井が変わる／人の仕事の J が台帳に出る。
