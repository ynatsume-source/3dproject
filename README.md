# Seaglass

実在の海を再現した海中を、ドローンでゆっくり巡る Web アプリ。
現地の太陽・月・潮の位置に合わせて光と流れが変わり、作業中の環境映像として流しっぱなしにできます。

## 開発

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ に出力
npm run typecheck
npm run sim -- miyako   # 生態系だけをヘッドレスで早回しし、昼・夕方・夜・朝の行動を確認
npx tsx --import ./scripts/node-assets.mjs scripts/director-check.ts miyako   # カメラ監督が何を撮りに行くかを確認
npx tsx --import ./scripts/node-assets.mjs scripts/clip-check.ts   # ウミガメが岩やサンゴにめり込んでいないか
```

`?debug` を付けて開くと、コンソールから `seaglass.cur.eco.env` などを覗けます。

`main` への push で GitHub Actions がビルドし、GitHub Pages に公開します
（リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく）。

## 構成

| パス | 役割 |

| `src/eco/` | 生態系：環境（光・潮流・プランクトン場・脅威・出来事ログ）、魚の群れ行動、捕食、ウミガメとマンタの一日 |

## 操作

- 図鑑の「会いに行く」：その生き物のいちばん近い個体のところへ自動カメラが連れて行き、観察する。宮古島では「洞窟へ行く」で海底洞窟を通り抜ける。ザトウクジラは季節中なら呼ぶと通り過ぎてくれる（季節外は案内が出る）
- ログ（SEA LOG）に出た出来事は、画面上のその場所に淡い輪で示す（画面の外なら端に矢印）。輪かログをタップするとそこへ向かう
- 海を選ぶと、あなたのいる場所（位置情報。許可しなければタイムゾーンから推定）から実際の地球の上を飛んで、その海の本物の衛星写真へ降下し、着水して潜る。`スキップ` で省略でき、「視差効果を減らす」設定では従来どおり直接切り替わる
- 「今日の海」かつ実時刻のときは、現地の今の天気（雲量・雨・雷・風・波高・海水温）が海に反映される。雲が厚いと光芒が弱まり、雨の日は水面に雨粒の輪が、雷の日は稲光が走る。時刻パネルに現地の天気を表示
- 「空へ」（`U`）でドローンが水面を抜けて空へ出る。海面の上を高さ120mまでゆっくり巡り、昼は上から礁を見下ろし、夕方は沈む陽の方を、夜は星空を見上げる。手動操縦なら `E` で浮上してそのまま水面を抜け、`Q` で潜れる
  - 空は現地の実際の空：太陽と月（満ち欠けの向きまで）の位置、約5000個の実在の恒星（その場所・時刻の恒星時で配置）、天の川、朝焼け夕焼け、今日の雲量。雷の日は雲の中が光り、落雷が見え、音が距離に応じて遅れて届く。雨の日は雨粒が落ちる
  - 海面は風で立つ波が空と太陽・月を映し、真上に近いほど透けて礁が見える。モデル化した礁の外は深い青に沈む
  - オーロラは高緯度の海でだけ現れる（`?aurora=1` でどこでも試せる）
- 図鑑には生き物ごとにモデルの絵を出す（まだ会っていない生き物は影だけ）。「行き先」から洞窟や根などの場所へも行ける
- スマホ・タブレットでは画面がスリープしないようにしている（Screen Wake Lock と、無音の小さな動画をループさせる NoSleep.js の方法）

## 描画

- シーンを HDR（半精度）で描き、後処理でまとめる：水中の体積光（波で集まった日光が光の筋になり、深さと距離で色が抜ける）→ ブルーム → ドローンカメラのホワイトバランス（水深に応じて赤と緑を戻す）→ ACES トーンマッピング → 周辺減光・わずかな色収差・粒状感
- 海底と岩は Poly Haven の写真計測テクスチャ（CC0：砂紋 aerial_beach_01、サンゴ石灰岩 coral_fort_wall_03、サンゴ礫 coral_mud_01）を三方向から投影し、リーフの被度・傾き・ノイズで混ぜ、サンゴモ・芝状藻・カイメンの色を重ねる。地形の高さから求めた遮蔽（AO）で窪みを暗くし、リーフには1m規模の凹凸（ルゴシティ）を加える。サンゴにも同じスキャンから細かな凹凸と質感を載せる
- 砂紋は各海の潮流の向きに直交するよう回転し、場所ごとに少し揺らぐ。砂の上にはサンゴ礫・二枚貝・イモガイ、クロナマコ、リーフ縁にはアオヒトデを散らす（リーフ近くほど多い）
- サンゴは近くだけ高精細モデルに切り替わる（高画質22m／標準13m／軽量6m、頂点シェーダーで距離ごとに出し分け）。スギノキミドリイシ型の長い枝、コユビミドリイシ型の指状の群体、縁の反り上がったテーブル、コブ状のハマサンゴ型を追加。表面にはポリプの突起・莢の細かな凹凸を法線で描く
- 岩は6系統12種の原型（丸い岩・平面で削った角岩・板状の岩・尖塔・穴だらけの死サンゴ塊・瓦礫）から約2,200個を配置
- 深度バッファからの画面空間アンビエントオクルージョン（SSAO）で、サンゴと岩の根元や隙間に接地の陰を落とす（標準・高画質）
- 遠景：太陽側と上方ほど明るく光る水のかすみ（遠景と背景で共通）と、手前十数mで効きはじめる淡いベールで形をやわらげ、体積光は95m先まで光の筋を描く
- ウミウチワは扇形のシートを網目と放射状の枝で切り抜いたレース状（遠くでは面として描き、ちらつきを防ぐ）。ソフトコーラルはウミキノコ（深いひだの傘）・ウネタケ（太い指状の群体）・トゲトサカ（光に透ける樹状、モルディブのティラに多い）の3種
- 根の縁にはひさし状に張り出す岩、壁の足元には立てかかった岩を置き、オーバーハングと割れ目の陰をつくる
- 海底洞窟（宮古島）：砂地に立つ石灰岩の根を符号付き距離場で作り、曲がりくねったトンネル・中央の広間・天井の3つの天窓をくり抜いて Surface Nets でメッシュ化。同じ距離場から「日光（太陽の向きに合わせて数フレームずつ焼き直す）」と「空の明るさ」の3Dテクスチャを焼き、全マテリアルと体積光がそれを参照するので、トンネルは暗く、天窓からは光の柱が床に落ちる。暗い壁にはオレンジ色のイボヤギ（Tubastraea）が群れ、中ではカメラの露出が上がり、自動でライトが点く。自動航行中は近くを通ると入口から出口まで通り抜ける
- 朝夕の低い太陽（高度0〜12°前後）では光の筋が琥珀色になり、太く少ない筋として斜めに差し込む。水の色は青いまま、色は直接光と光芒だけに乗る
- 夜は「月明かりの見える夜」として描く：月が銀青色の主光源になり（光芒とコースティクスも月で）、水はくすんだ青緑のまま遠くまで見え、海面の窓には星が揺れる。月のない夜だけライトが自動で点く。生き物の行動は現実の暗さのまま
- 季節：時刻パネルで「今の季節／春／夏／秋／冬」を選べる。時刻はそのままその季節の日付になり、日の長さ・太陽の高さ・月・潮・水温（例：宮古島は2月に約21°C、8月に約29°C）・季節の生き物が変わる。南半球のグレートバリアリーフでは季節が逆になる。選んだ季節は次回も保たれる
- サメは実際の体形から作ったモデル（円錐形の吻、5本のエラ、鎌形の胸びれ、上葉が長い異尾）。ツマグロは黒い、ネムリブカは白いヒレ先
- 水の色は波長ごとの吸収（赤が最初に消え、青が最も遠くまで届く）で計算
- 画質は「軽量（スマホ）／標準（ノートPC）／高画質（ゲーミングPC）」の3段階。起動時にGPUから自動で選び、フレームレートが足りなければ一段下げる。`?tier=high` のように指定も可能

## 生態系のしくみ

- **活動時間**：種類ごとに昼行性・夜行性・薄明薄暮性（`diel`）を持ち、現地の空の明るさで活動度が決まる。休む時間になると群れは寝床（サンゴの中・岩陰・イソギンチャク）へ縮こまる
- **食性**：プランクトン食の魚は潮上に顔を向けて餌をついばみ、プランクトンが濃いと高く上がる。藻食の魚はリーフをかじる（ブダイの近くではかじる音がする）
- **捕食**：肉食魚は空腹が溜まると群れを狙い、主に夕暮れと夜明けに狩りをする。成功率は低く、狙われた群れは散って岩陰へ逃げる。イソギンチャクの中のクマノミは狙われない
- **個体数**：捕食で減った分は、しばらくして外から別の個体が入ってくる形で補われ、流しっぱなしでも崩れない
- **プランクトン場**：潮流に運ばれ、昼は光で、夜は動物プランクトンの浮上で濃くなる。マンタは夜、濃い場所へ食べに上がってくる
- **ウミガメ**：昼は海草やリーフで食事、夜は岩陰で眠り、ときどき息継ぎに浮上する
- **チンアナゴ**：流れがある昼は体を伸ばして流れに身を傾け、夜は巣穴に引っ込む
- **ウメイロモドキ**（宮古島）：数百匹の群れがボイド（群れのアルゴリズム）で泳ぎ、ドローンの周りでは割れ、捕食者が来ると弾けるように散る。夜はリーフ近くで群れをほどいて休む
- **ワモンダコ**（宮古島）：昼に巣穴から出て岩の上を歩き、模様を波のように変えながら餌を探す。近づきすぎると体色を変えてジェット噴射で逃げ、夕方には巣穴へ戻る
- **ヒブダイ**（宮古島）：夜は自分で出した粘液の膜にくるまって眠る
- **ヤライイシモチ**（宮古島）：昼は枝サンゴの間でじっと群れ、夜に散らばって餌をとる
- **ネムリブカ**（宮古島）：泳がなくてもえらに水を送れるので、昼は洞窟の奥の床に並んでじっと休む。夕方にトンネルを通って出ていき、夜のリーフで狩りをする
- **ザトウクジラ**（宮古島、12月下旬〜4月上旬だけ）：数分おきに、親子（ときどきオスの付き添い）や1頭のオスが水面近くを通り過ぎ、子どもはときどき息継ぎに上がる。季節中は遠くからクジラの歌が聞こえ、近くを通るときは大きくなる。時刻パネルの「季節」で冬を選ぶといつでも見られる
- **ナンヨウマンタ**（宮古島にも1枚）：昼はリーフの上を回り、夜はプランクトンを食べに浅場へ上がる

移動の速さは実時間のまま、活動のリズムだけがシミュレーション時計（早回し含む）に従います。
