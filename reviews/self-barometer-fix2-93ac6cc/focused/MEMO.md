# 93ac6cc：保持気圧による読みの軽い確認

対象は FX-SB-A1 の修正部分だけ。SB-C3 など次の全面レビューに回した項目は再監査していません。

`focused.mjs` を対象の分離作業場所で実行：81 要求、57 判定すべて成功、`validateResult` 違反 0。追加の A/B/C 指摘はありません。

## 確かめた形

- 本物の p16x 0.1.4 の出力を `potToEquipmentParams` で設備にして使用。自作の漏れ係数や非公開状態を直接作っていません。
- run 開始を 1007 ms にし、30 秒セルの原点を世界の 0 ms と区別。
- contract 0.1.0 / 0.1.7 / 0.2.0 / 0.2.1 の4通り。
- 気圧不明で始まったセルの途中で現在の気圧が戻っても、次のセルまでは数値なし。次のセルの境界では数値が戻る。この境界で要求を分割しても、状態の小数と読みが完全一致。
- 直前のセルは気圧既知でも、現在の要求が気圧欠測なら数値なし（既存の慎重な扱いを保持）。
- 欠測・復帰・通常の各段階で、セルの途中と境界の読みを入れた実行と、読みを省いた実行の物理・精算が完全一致。
- 状態 `/2` を JSON 保存・復元し、格子外の要求から再開しても直接渡した状態と結果が一致。
- processVersion `0.1.1` は状態が `/2` でも `unknown processVersion 0.1.1` で拒否。消費・生成・放出なし、受け取った状態を変えない。古い `/1` も `unsupported-state-schema` で拒否。
- セル途中・境界の `take_out` は同じ時刻の operator 停止と物理・精算が一致。
- 0.2.x の drawn は空配列、0.1.x には drawn なし。

結果は `result.json`。この検査は読みの内部実装を写さず、公開入口・公開組み立て換算と結果の比較で上記を確認します。根の算術・流出量や過去の広い境界条件は親レビューで前回診断をそのまま再実行した記録を参照してください。
