# 手順書：自作の気圧計（p16x 0.1.4 で管を通して封じる → 換算表 /4 → m03x_air_barometer_pot 0.1.1）

2026-10-09 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

設計案 [SELF_BAROMETER_DESIGN.md](SELF_BAROMETER_DESIGN.md)（オーナー決定済み）の実装。ランタンの「節目」：試験用の気圧計の器を、住人がタールで封じた器に置き換える。台風の予報は試験用の気圧計で先に始めていて、こちらは「借り物を自分の手で作り直した」区切り。

```
gauge_tube_test ─┐
住人の壺（fired_pot）─┼→ p16x 0.1.3（管を栓に通して封じる）→ 管つきの封じた壺 → 本体が組み立て（換算表 /4 ＋ markMm）
wood_tar ────────┘                                                              ↓
                                     m03x 自作の気圧計（島の時計：管の水を入れ、read_gauge、take_out）
```

## 1. 管を栓に通して封じる（p16x 0.1.3）

- 入力：器・`wood_tar`・（温めるなら）`firewood` に、`gauge_tube_test`（quality `bore_mm`・`length_mm`）を足す。`seal` の params に `jointTarG`（継ぎ目に盛るタールの g）。管があるのに `seal` しなければ拒否。
- タールは、栓に 5 g、継ぎ目に `jointTarG`、残りを内側に塗る。継ぎ目の覆い＝1 − e^(−g × 0.3)（冷たい）／e^(−g × 1.0)（温めた）。
- 管の質量は器のロットに入る（`x_tube_ppm`、`tube_bore_mm`・`tube_length_mm`・`joint_cover_ppm`）。栓が足りず封じられなければ、管はそのまま返る。割れたら管は破片の中（`pot_sherds` の `x_tube_ppm`）。
- 空気を保つ時間（`air_leak_tau_min`、換算表 /4 と p17x 0.1.4 も同じ式）：
  `τ = 2 時間 × (容量 / 500 mL) / (壁の漏れやすさ × 壁の面積 / 500 mL の器の面積 + 継ぎ目)`
  継ぎ目＝1.0 ×（1 − 覆い）＋ 0.005（どれだけ丁寧でも残る漏れ）。管のない 500 mL の試験用の器は今までと同じ値（140 通りの比較で一致）。

| 封じ方（500 mL の試験用の器、壁のタール 30 g） | 空気を保つ時間 |
|---|---:|
| 継ぎ目に何も盛らない（冷たい） | 95 分 |
| 温めて継ぎ目に 1 g | 311 分 |
| 温めて継ぎ目に 6 g | 3,096 分（約 2 日） |
| 壁 90 g・継ぎ目 60 g（温めた） | 7,756 分（約 5.4 日） |
| （管なし、壁 90 g） | 1,200,000 分（式の上限） |

管を通すと完璧にはならない：壁を塗り込んでも、継ぎ目から少し漏れる。住人は「壁は十分なのに戻る、漏れているのは別の所だ」と気づける。

## 2. 組み立て（換算表 civ-sci.pot-assembly/4）

管つきの器の `potToEquipmentParams` は、今までの params に `tubeBoreMm`・`tubeLengthMm`・`bulbTauS`（器の空気が気温に追いつく時定数＝素地の熱容量 ÷（表面積 × 20 W/(m²·K))、仮定）を足す。本体は浮かべる棒の目盛り `markMm` を足して `assembled_pot` にする。

## 3. 自作の気圧計（m03x_air_barometer_pot 0.1.0）

- 島の時計、接続仕様 0.1.x / 0.2.x。設備 `assembled_pot`（封じてあり、空気を保つことが分かっていて、管つき）。ロット：管の水 `process_water`（両方の脚の真ん中まで入る量以上：8 mm・600 mm なら 15.1 mL）。エネルギーは使わない。
- 操作：`read_gauge`（目盛り）、`take_out`（終わり：水を返す）。`stop` でも終わる。合わせ直しは住人のノートの仕事（世界は何もしない）。日陰に置く前提。
- 物理：試験用の気圧計（m02x）の釣り合い式に、器の空気の漏れを足す。`d(nR)/dt = −(V0/(T0·τ))·2ρg x`。読みの戻る時間は約 1.5 τ（水柱も動く）。
- 分からないもの：気温が分からない間は器の温度、気圧が分からない間は器の空気の量も幅で持つ（水が管のどこにあってもよいとして、漏れうるだけ広げる）。両端が同じ目盛りのときだけ読みを返す。管の端を越えたかもしれないなら、何も言わない。
- 時間：run の始まりからの 30 秒のセル。漏れの速さはセルの頭で決めて保ち、途中の値は式で出す（灯りの学び）。要求の端や読みは何も決めない。読みは状態を変えない（あふれはセルの境目で記録）。
- あふれ：開いた口から水があふれたら、その分は地面（`released`、`to: 'ground'`）。底まで下がったら器の空気が泡で抜ける。どちらも「置いたときの印と合わない」と言い続ける（置き直すまで）。

## 4. 住人が試して分かること（気圧が 24 時間で 30 hPa 下がって止まる、28 °C、6 時間ごと）

| 器 | 読み（目盛り、5 mm） |
|---|---|
| 試験用の気圧計（漏れない） | 4, 9, 14, 19, 20, 20, 20, 20 |
| 壁も継ぎ目もよく封じた壺（約 5.4 日） | 4, 9, 14, 18, 19, 18, 17, 17 |
| 継ぎ目に何も盛らない壺（95 分） | 1, 2, 2, 2, 0, 0, 0, 0 |

漏れる壺は、下がり続ける間だけ少し上がり、止まると 0 に戻る：**気圧の高さではなく、変わる速さ**を示す。並べて置けば、2 つの差から器の漏れが分かる。

## 5. 本体へ

- 管は試験用の既製品 `gauge_tube_test` から（後で竹・粘土の管に置き換える）。
- `assembled_pot` の params は換算表 /4 の `potToEquipmentParams` に `markMm` を足す。管のない器・`airtightKnown` 0 の器は m03x が断る。
- 終わりに返る水は、元の場所に戻す。あふれた分は地面へ（記帳）。
- 版：p16x 0.1.2・p17x 0.1.3 の run は版で拒否（中止して予約を解放）。換算表 /4 を記録する。

## 6. 検査

`scripts/science-barometer-pot-check.ts` 24件：管を通す（継ぎ目の漏れ、上限に届かない、大きさ、読み戻し、破片、水の試験）、読み（試験用と比べる、漏れる器は変わる速さ）、区切り（1 h・30 s・7.2 min・2 h・30 min で状態の小数まで一致）、読みは何も変えない、分からない天気で空気の量の幅、あふれ、拒否。

## 7. 修正（Codex の全面レビュー 7f4d1e3：SB-A1〜A4）

| 指摘 | 変更 |
|---|---|
| SB-A1 継ぎ目のタールが状態に残らず、最後の要求や届かなかった操作で決まる | 届いた最初の `seal` の時刻と `jointTarG` を状態に残し、精算はその値だけで行う（p16x 0.1.4、状態 `vessel-seal/3`） |
| SB-A2 最初の要求に `seal` がないと拒否 | 管は後の要求の `seal` を待てる。封じずに終われば管はそのまま返る |
| SB-A3 セルの中であふれた水が記帳されない、次の天気で消える | あふれはそのセルを決めた気圧で、セルの始まりから終わり（または run の終わり）まで 1 秒ごとに調べて記帳する。口から出た水は、口を越えてから最も高かった水位までの分を一度だけ地面へ。読みも同じ調べ方をするが、状態は変えない（m03x 0.1.1、状態 `air-barometer-pot/2`） |
| SB-A4 欠測の終わりまで進めていない値で、過去のあふれを否定する | 欠測の間の器の温度と空気の量の端を、欠測の終わりの時刻まで進めた値で集め、戻ったときの判定に使う。否定できなければ「分からない」のまま |
| FX-SB-A1（7318506 の修正確認）あふれの判定はセルの気圧、返す目盛りは要求の気圧で、管の口を越えた 101 目盛りや保持軌道と違う目盛りが出る | 返す目盛りも、あふれ・漏れ・精算と同じセルの気圧の軌道で出す。セルの気圧が分からないときは読めない。読む・読まないで物理は変わらない（m03x 0.1.2、状態は `air-barometer-pot/2` のまま、0.1.1 の run は版で拒否） |

**近似として残すもの**：水柱の釣り合い（読み・あふれ・漏れ・精算のすべて）に使う気圧は、そのセル（30 秒）を決めたときのもの。セルの途中で気圧が変わる要求の区切りでは、変化は次のセルから効く（灯りの「セルの頭の天気を保つ」と同じ）。仮定の上限 20 hPa/h では、30 秒で最大 0.17 hPa、水位のずれは 500 mL・8 mm・水位 50 mm の例で約 0.56 mm（5 mm 目盛りの約 0.11 目盛り）。小さくても、丸めの境目や管の口の近くでは目盛りやあふれの有無が変わりうる。これは 30 秒保持のモデルの適用範囲で、実物の管の口での連続した安全を保証するものではない（Codex 7318506 の判断）。
旧い run（p16x 0.1.3・m03x 0.1.0・0.1.1）は版で拒否される（本体は中止して予約を解放）。検査は 35 件（5 節が SB-A1〜A4、6 節が FX-SB-A1 の回帰）。
