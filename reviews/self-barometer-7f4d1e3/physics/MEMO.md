# 自作の気圧計・物理の独立確認 — 7f4d1e3

対象：`7f4d1e3c50e29f1ecde7382219f13f19c32777d4`、`m03x_air_barometer_pot 0.1.0`。対象ソース・全ブランチ・前回 ZIP は変更せず、作成したのはこのディレクトリのメモ・診断・結果のみ。

## 結論

**釣り合いの根、単位、漏れの符号、標準の500 mL・8 mmで約1.5τという説明は正しい。** 正常な長いτで、連続の漏れ式に対する30秒刻みの誤差は小さい。この担当では追加のA・Bを出していない。短いτへの入口防御と近似の精度はCとして次の全面レビューへ残す。

これは理想気体・静水圧・線形の漏れという仮定同士の一致の確認である。タールを塗った実際の器の漏れ量や時間を実測で校正した結果ではない。

## 1. 根の選び方と桁

釣り合い式は `F(x) = (Pa + 2ρg x)(V0 + A x) − s Tb = 0`。物理的に両方が正になる `x > max(−Pa/(2ρg), −V0/A)` では `F` は増加し、正の空気量に対応する根は1つである。

実装は `(-2c)/(b + sqrt(b² − 4ac))` を使い、近い2数を引く桁落ちを避けている。独立の二分法で、容量1–1,000,000 mL、管径1/8/30 mm、気温−60/0/28/70°C、気圧800/990/1010/1100 hPa、空気量の係数0.6–1.4の**1,440条件**を照合した。

- 最大の根の差：`2.22 × 10⁻¹⁵ m`
- 元の釣り合い式へ戻した最大の相対残差：`2.94 × 10⁻¹⁶`
- 非有限・違う物理的根：0

容量をm³、管面積をm²、圧力をPa、温度をKとして扱う単位も整っている。

## 2. leakK と読みの時定数

`s = nR` の単位は `Pa·m³/K`。`leakK = V0/(T0 τ) · 2ρg` の単位は `Pa·m²/(K·s)` なので、`ds/dt = −leakK x` の単位・方向は正しい。水位が高いと器内の圧力が高いため空気が抜け、水位が低いと入る。

温度・外気圧が一定なら、元の式を微分すると次になる。

```
dx/dt = − x / {τ [1 + Pa A/(2ρg V0) + 2A x/V0]}
```

小さい変化の読みの時定数は

```
τ_eff = τ [1 + Pa A/(2ρg V0)]
```

で、**1.5は器と管の標準寸法に依存する**。1010 hPaで：

| 容量・内径 | τ_eff / τ |
|---|---:|
| 100 mL・8 mm | 3.5876 |
| 500 mL・8 mm | 1.5175 |
| 2 L・8 mm | 1.1294 |
| 500 mL・1 mm | 1.0081 |
| 500 mL・30 mm | 8.2775 |

設計案§2には500 mL・8 mmという条件が明記されているので、ここは誤った物理として指摘していない。手順書§3だけ読む人にもこの条件を付けると分かりやすい。

## 3. 連続の漏れ式に対する30秒セルの精度

一定の気温・気圧では、上のODEを厳密に積分できる。

```
a = 1 + Pa A/(2ρg V0), b = 2A/V0
a ln(x0/x) + b(x0 − x) = elapsed/τ
```

この独立した式を対数域で二分法により解き、実装の30秒セルと比較した。圧力が1010→1000 hPaへ変わった後の、500 mL・8 mm・28°Cでの比較（25サンプル）では：

| τ | 連続式で約1/eまで戻る時点の差 |
|---|---:|
| 95分（標準の裸の継ぎ目） | −0.02151 mm |
| 3,096分 | −0.0006594 mm |
| 7,756分 | −0.0002632 mm |

別に、気温28→29°C・気圧1010 hPa・τ95分をRK4で参照計算した。1秒刻みと0.5秒刻みの参照の差は `2.05 × 10⁻¹¹ mm` 以下。実装との差は最大 **0.01382 mm**（600/1,800/7,200秒の3点）である。器の温度の時定数そのものを資料で校正した検査ではない。

## C：短いτでは、30秒で保持する漏れ率の精度・安定性を保証しない

`at()` の空気量は `s + ds × elapsed` なので、漏れは陽的Eulerに相当する。連続式では水位は0へ単調に近づくが、τ_effに比べて30秒が長いと、過剰な減衰、符号反転、数値計算だけのあふれ・泡が起こりうる。

ただし **`airLeakTauMin()` は分単位を `Math.round` して返す**。換算表を通って正値として使えるτの最小は1分で、数秒のτは正規の換算表からは出ない。この区別を診断結果で分けている。

1. **換算表が読み取れる品質の端**：20 mL・内径1 mm・割れ指標1・吸水率40%の「既知」品質の試験ロットは、表からτ1分が返る。30/60/120秒で連続式との差は−3.206/−3.992/−3.101 mmで、5 mm目盛りの1目盛り違いを生む。これは表で受理する端の品質の診断で、実際に壊れた器からこの「既知」品質が戻ってくるという主張ではない。傷みを本体から返す正規経路では `airtight_known:0` になる。
2. **直接渡した小数分の設備params**：m03x自体はτ1秒・6秒・12秒を受け付ける。τ6秒では30秒後に−77.87 mm、60秒後に+177.87 mmへ振れ、120秒後には泡が抜けた扱いになる。連続式はそれぞれ+1.238 mm、+0.0454 mm、ほぼ0へ単調に戻る。τ1秒は30秒で−662.47 mmとなり、架空の泡の観察を返す。これらは**手作りの直接paramsの試験**であり、現在の表が生成する正常な器の例ではない。

標準の95–7,756分での精度は良好であり、通常の組み立ての統合をこの端の入力だけで止めない。次に、受け付けるτ・寸法に応じた安定な積分、または入口での適用範囲の制限と明記を検討してほしい。区切り同士の完全一致は、元の連続ODEへの精度を別途保証するものではない。
