## seed 2 の新しい止まり（stall2.log・stall2y.log）
- 野焼き（p13y）は labReady に出ている（乾いた薪 38.35 kg の山、乾いた封じる壺）。でも始まらない。
- ランタンが流れ着いたもの（drift）を持ったまま、252〜330 h のあいだ、起きているときはずっと「棚に置く（shelve）」を繰り返し、
  一度も置けていない（「棚に飾った」が日記にない）。手がふさがっているので、野焼きに取りかからない。
- shelve の行き先は棚の位置から固定で（+0.6, +0.6）。そこに行けない（進めなかった）まま繰り返しているとみる。
  薪棚・乾かし棚・焚き火などが棚のそばに建つと、その点がふさがる島がある。
- 直し案：(1) 行き先を、ほかの棚の仕事と同じ立ち位置（shelfStand()）にする。(2) 同じ行き先で何度も進めなかったら、持ち物を
  棚の脇の地面に置いて手を空ける（世界の事実として、置いた場所に残す）。
