# Claude への引き継ぎ

ユーザー依頼: 既存の海域と重複しない新しい海を Codex で試作し、最終確認と本実装は Claude に任せる。

まず [README と画像](README.md) を確認し、採用・調整する範囲を判断してください。進行中の変更を保護し、これを完成済みの実測景観として公開しないでください。

## 実装の境界

| ファイル | 役割 |
|---|---|
| `src/data/monterey.ts` | 地域、地形、ケルプ分布、魚 4 種、解説 |
| `src/data/locations.ts` | `Sea.kelp` の型と新海域の登録。既存の熱帯用補正を新海域に適用しないため最後に追加 |
| `src/ocean/kelp.ts` | ケルプのバッチ生成と材質、温帯の海底材質。独自の seeded RNG |
| `src/ocean/build.ts` | ケルプの追加、サンゴ重みゼロの扱い、熱帯の海底小物を出さない分岐、温帯用材質の選択 |
| `src/main.ts` | ケルプ海域の時間帯ログ・図鑑見出し（サンゴの説明を混ぜない） |
| `src/ui/places.ts` | 実際に生成された株と砂地から 3 つの行き先を探す |
| `src/ui/minimap.ts` | 地図未収録の場合の位置図。前の海域の画像を残さない |
| `scripts/kelp-check.ts` | モデル・配置・熱帯要素の混入防止の検査 |
| `docs/ARCHITECTURE.md` | 追加モジュールと時間の持ち主を記録 |

`TERR.reef` は既存の魚・岩の配置判定にも使われます。この海では「硬い岩の基盤」のマスクとして利用し、サンゴの重みはすべてゼロです。基盤の名前や生態系全体は今回リファクタしていません。

`tot <= 0` の場合にサンゴ生成を skip する修正は重要です。これがないと全重みゼロでも最初のサンゴ種が生成されてしまいます。

## 開き方

```sh
npm ci
npm run typecheck
npm run build
npm run preview -- --host 0.0.0.0
```

起動 URL に `/?debug&tier=low&at=2026-06-20T20:00:00Z#monterey` を付けるか、地球儀の一覧でモントレー湾を選びます。既存サーバーとポートを分けてください。

図鑑の「ケルプの森」「水面の葉の層」「森の間の砂地」から観賞できます。既存の自動撮影も有効です。

### 検査

```sh
npx tsx --import ./scripts/node-assets.mjs scripts/kelp-check.ts
npm run sim -- monterey
```

ブラウザでは昼／夜、森の中層・水面・海底、モントレー→宮古島→モントレーを確認してください。地図の説明が新海域では座標、宮古島では国土地理院に戻ることも対象です。

## 取り込み

ブランチ: `codex/monterey-kelp-prototype`。レビュー差分は `git diff 7124cc6...origin/codex/monterey-kelp-prototype`。

main のファイルを一括置換せず、作業中の変更と突き合わせてこのブランチの差分を取り込んでください。終盤に確認した main `00e7a4d` は住民のモデル・動作だけの更新で、この案のソースとは重なりませんでした。取り込み時点の最新状態は改めて確認してください。

沈船ブランチも採用する場合、`build.ts` と `places.ts` に双方の差分がありますが、編集箇所は異なります。両方を取り込んだ後に Carnatic / Monterey / 既存の Miyako を開いて確認してください。

## 次の調整で優先すること

1. 現地の写真・生物資料と照合し、葉の長さ・密度・水の色、種の体形・模様を詰める。
2. 実 GPU・Windows・スマートフォンで負荷を計測。必要なら距離 LOD / 画質ごとの葉の簡略化を追加（魚の個体数や同一性は画質で変更しない）。
3. 葉が波面から突き出る頻度と、光線が密な葉を突き抜ける見え方を確認。潮汐追従や遮蔽は次の独立した改善候補。
4. セニョリータの砂潜りやケルプへの避難を加えるなら、見た目だけの制御にせず、生態系側の行動として別途検討。

ラッコ・アザラシ・海鳥・ウニの追加は、今回の最低限の海が成立した後に、生息資料と見た目の予算を確認してから行うと進めやすいです。

## 最終ブラウザ確認の結果

production build / Chromium 151 / SwiftShader / low tier で、モントレーの昼→夜→地球儀→宮古島→地球儀→モントレーを実行し、成功しました。[結果 JSON](browser-result.json)、[夜間の画面](images/night.png)。

- モントレー 211 株 / 魚 4 系統。再訪時も同じ株数。
- 宮古島ではケルプなし、魚 26 系統 / イソギンチャク 11 個を確認。
- 地図はモントレーの位置図→宮古島の国土地理院→モントレーの位置図へ切り替わる。
- 自動的に候補になる熱帯の rare event はモントレーで 0。
- JS・shader エラー、ローカルのアセット取得失敗、WebGL エラー・context loss・safe mode への退避なし。

ブラウザ自動操作では、地球儀へ戻る際、暗幕が消えてもカメラの移動中は既存の `busy` フラグが残るため、海域カードを押す前に約 2 秒の移動完了を待つ必要があります。早く押した場合は入力が無視されます（今回の変更ではない）。
