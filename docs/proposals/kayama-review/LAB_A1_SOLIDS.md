# LAB A1 — 固い物の共通登録、身体の大きさ、接近位置、経路失敗を直進にしない

対象: 香山レビュー NAVIGATION_REVIEW.md N1–N3, N5（0f93991）。

## 再現条件
`npx tsx --import ./scripts/node-assets.mjs scripts/nav-check.ts`（実 `makeResidents()`、制御地形（平らな陸 / 水深2 m）、乱数固定 2601003、20 Hz、2026-10-03 17:00 JST）。毎フレーム、住人の体が固い物に食い込んだ深さを測る。

## before（レビュー evidence/navigation-diagnostics.json）

- 泳ぐカメマル: サンゴ障害物を見ず、中を 33 フレーム通過。
- 経路が見つからないと `?? [[tx,tz]]` で目的地へ直進。blocked は減らない累積値。

## 変更
- `src/robots/solids.ts`: 固い物を一つの登録に。各物は直立円柱（位置・半径・下端・上端）。浜の岩・モクマオウとアダンの幹・流木（丸太に沿った円の列）・森の幹（森のセルから都度）・建てた物（小屋の柱と柵、作業台、棚、桟橋の杭/台石、焚き火）。描画の LOD・カメラ位置とは無関係。
- 身体: 各住人のモデルの見えている形から測った円柱（平均幅の半分×0.85、高さ）。またげる高さは高さの 1/3（動物は 1/4）。丸太を抱えたドットは丸太の幅。
  ドット r0.19 h1.18 またぎ0.39 / カメマル r0.49 h0.54 またぎ0.14 / ランタン r0.37 h0.83 またぎ0.28 / ラッコ r0.38 h0.43 またぎ0.11（m）。
- 移動: 経路のコストに固い物（体の半径＋格子の半分）を通行不可として入れる。2 m 以内でも直線が塞がっていれば経路を探す。道がなければ直進せず `went='no way'` で作業をやめる。
- 一歩ごと: 次の位置が固い物に食い込むなら、目的地に近づく側へ回り込む（±0.5/1.0/1.5 rad）。回れなければ止まって再計画（`went='blocked'`）。すでに中にいる場合は外へ出る一歩だけ許す。
- 接近位置: 目的地が固い物の中なら、近い側の外周（体の半径＋余白）に立つ。立てる所がなければ `went='nowhere to stand'`。
- blocked は進めている間は減る（累積でなく、続けて止まっている時間に近い）。
- 泳ぐカメマルはサンゴの上（T.top）を越える。海底に降りる場所はサンゴのない所。
- 最初の更新で、固い物の中に置かれた住人（古いセーブ・家の位置）を外へ出す。
