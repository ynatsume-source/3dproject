# 大型の魚の作り込み（2026-10-08、オーナー依頼）

依頼：「1 m や 50 cm くらいの魚の作り込みを。代表はナポレオンフィッシュ。大きさの割に作りが甘く、せっかく大きくて迫力のある魚に出会えているのに感動が薄い」

## 前の作り

- 体：球（16×12 分割）を引き伸ばしただけ。近くで見ると角ばっていた。
- ヒレ：三角形 1〜5 枚の板。
- 目：模様として塗った黒い点。
- 模様：種ごとの簡単な色分け。ナポレオンは、白い波線と、細かい凹凸を描いただけ。
- 動き：体の波と旋回だけ。胸びれ・口・えらは動かなかった。

## いまの作り（`src/ocean/bony.ts`、`fishMaterial` の BONY）

### 体の作り方

- サメと同じ方式。実際の体形から、横から見た輪郭（背・腹・幅）を体の前後に並べ、その間を断面の輪（73 × 36）でつなぐ。
- 断面は涙形（背側が細い）。
- 唇：分厚い 2 本のふくらみ。間に口の切れ目があり、口角まで続く。
- えらぶた：後ろの縁が少し張り出す。
- 目：皮膚から盛り上がったドーム。瞳・虹彩・周りの皮膚を描き分け、濡れた艶をつける。

### ヒレ

ヒレは外形から作り、筋（鰭条）を入れる。

- 尾びれと胸びれは、付け根から扇形に広げる。
- 背びれと臀びれは、後ろに傾いた筋の列。
- 背びれのとげの部分は、とげの間の膜がくぼむ。

### 皮膚

- 鱗：瓦のように重なり、見えるのは後ろの縁。光の当たり方で鱗が丸くふくらんで見える。
- 細かすぎて画面でちらつく大きさになると、細部は消える。

### 動き

- 胸びれで漕ぐ（ナポレオン・ハタ・ブダイ・モンガラ）。
- えらぶたと口で呼吸する。
- 柔らかいヒレが波打つ。モンガラはこれで泳ぐ。

### その他

- 群れで数百匹いる魚（`low`）は、前の作りのまま。

## 種ごとの形と模様

| 種 | 形（`model`） | 特徴 |
|---|---|---|
| メガネモチノウオ（ナポレオン） | napoleon | 額のこぶ。厚い唇。頭はオレンジの迷路模様。目から後ろへ 2 本の黒線。鱗ごとに縦の暗い線。胸びれで漕ぐ |
| タマカイ | tamakai | 大きな頭と口。暗い地に淡いまだら模様。ヒレは黄色に黒い点 |
| スジアラ | sujiara | 突き出た下あご。赤地に、縁の暗い青い点 |
| カンムリブダイ | kanmuri | 壁のような額。淡いくちばし（歯）。大きな鱗 |
| ロウニンアジ・カスミアジ | jack | 急な額。鎌形の胸びれ・第 2 背びれ。尾の付け根に稜鱗。深く二叉した尾。銀色 |
| オニカマス | barracuda | 細長い円筒形。牙。離れた 2 つの背びれ。背の斜めの帯と黒い斑点 |
| イソマグロ | tuna | 紡錘形。小離鰭（しょうりき）。三日月形の尾。暗い背と銀の腹 |
| ゴマモンガラ | trigger | 長い吻。高い位置の目。トリガーのとげ。鱗の中心が暗いモザイク。目から口への帯 |

## 確かめたこと

- 道具：
  - `tools/lab/fishstudio.cjs`：魚だけを明るい所で、横・斜め前・正面・上・頭のアップから撮る。`TS`・`SWIM` を指定すると、動きのコマを撮る。
  - `tools/lab/fishscene.cjs`：図鑑から向かい、海の中で出会う姿を撮る。
- ナポレオン：
  - 作り直す前後を比べた。
  - 海の中で撮った（PC と スマホ縦、1.7〜2.2 m）。
  - 胸びれの漕ぎを上から 4 コマで確認した（開く・たたむ）。
- タマカイ・カンムリブダイ・ロウニンアジ：海の中で撮った（モルディブ、2〜2.6 m）。
- ほかの種：魚だけで撮った。
- 形のデータ：8 種とも NaN がないことを確かめた（イソマグロの吻の先で 1 点見つかり、直した）。

## 引き換え

- 1 匹あたりの頂点が増えた。前は数百だったのが、約 4 千頂点・約 7.5 千三角形になった。
- 大型の魚は 1 つの海に十数匹、捕食者の群れを入れても 20〜30 匹。
- ソフトウェア描画では GPU の重さは測れていない。
- 遅い端末で重く感じたら、輪の数を減らす。`RINGS`・`RAD`・ヒレの段数 `T` で調整できる。
