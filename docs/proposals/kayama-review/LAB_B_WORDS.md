# LAB B — 状態表示を実行状態から、日記に作った数値を書かない

対象: 香山レビュー CLOCK_DIARY_DIAGNOSTICS.md §2–3（0f93991）。

## 再現条件
`npx tsx --import ./scripts/node-assets.mjs scripts/words-check.ts`（実 `makeResidents()` と `makeDiaryBook()`、制御地形、乱数固定、2026-10-03 17:00 JST）。

## before（レビューの fixture）
- ラッコ: `task=float, arrived=false, act=walk` で「沖で仰向けに浮かんでいる」。ランタンも think へ移動中に「丘の上で星を見て考えごとをしている」。
- カメマルの日記: 入力に測定値がなくても「（水温 27.2℃・透明度 24m・見えた数 10）」が日付の乱数で付く。「見た魚」も乱数で選んだ名前。
- ラッコの絵日記: 天気の入力がなくても「てんき：はれ」。ランタンの星図は乱数の星（観測の星図ではない）。

## 変更
- 状態表示: 着く前は「向かっている」（float/think/sleep/look/watch/rest/nap/crack/charge/build/idle に向かう途中の文）、着いてから「している」。道がふさがれて止まっていれば「行く手がふさがっていて、回り道を探している」（A1 の `went`）。
- カメマル: 日記の「見た魚」は `T.nearFish`（目の前、その時と海草を食べている間に実際に見分けた魚）だけ。いなければ「目にとまる魚はいなかった」。数値は `Entry.obs`（見分けた魚の種数）があるときだけ表示。水温・透明度は測っていないので出さない。余白の書き込みから、測定や数日の観察を主張する3つを外した。
- ラッコ: 天気は夜（記録からわかる）だけ。昼の天気を推測で書かない。
- ランタン: 星図に「（思い出して描いた空）」と添える。

## after
| 項目 | 結果 |
|---|---|
| ラッコ float へ移動中 | 「静かな水面へ向かっている（あと30m）」 |
| ランタン think へ移動中 | 「丘の上へ歩いている（あと30m）」 |
| カメマル 測定なし | 数値なし |
| カメマル 見分けた魚あり | 「（見分けた魚 1種）」のみ |
| ラッコ 天気の入力なし | 天気の表示なし |
