# LAB A2 — 住人の目線をモデルの目に戻す

対象: 香山レビュー（Codex, 2026-10-03, 0f93991）優先A2。

## 再現条件
build: main（本コミット） / URL: `?tier=low&debug&lab&time=noon&wx=clear#kayama` / 390×844 / residentMode: lab /
操作: `seaglass.startWatch(id); seaglass.setPov(true)` → 4 s 後に測定。

## before（0f93991）
- かめまる: 目 y≈1.95 に対してカメラ y≈5.68（地面からの床クランプ・林冠リングの押し上げが、目の位置を写した後に掛かっていた）。
- 視線は体の向き＋行動ごとの固定の俯角で、頭の動き（見回し・注視）は映らない。
- 目線でも、巡航カメラの上下の揺れ・波乗り・水面すれすれの補正が重なっていた。

## 変更
- 4体のモデルに目の位置（`Robot.eye`、頭の子ノード）を追加。`sense()` が目のワールド位置と頭の前方向（`look`）を返す。
- 目線中は、幹・林冠・床・洞窟・水面の補正、揺れ・波乗りを掛けない。住人の更新後にカメラを目へ置き直す。
- 視線は頭の前方向に追従。視聴者のドラッグは別（`look.yaw/pitch`、離すと戻る）。三人称の見守りは従来通り。

## 受け入れ条件
- カメラと目の距離 < 0.01 m、落ち着いた後の視線と頭の前方向 < 2°（4体とも）。
- 三人称の見守り・巡航は変化なし（目線中のみ補正を外す）。

## 実機確認が必要な点
- 体が地面・岩に接する低い目線で、近くの地形や葉がカメラの近接面で切れて見えないか。
- 頭の見回しがそのまま画面の揺れになるので、酔わないか（必要なら視線の追従を緩める）。
