# 巡航から自動撮影へ（2026-10-06、オーナー指摘）

## 指摘

- 潜った直後の挙動が悪い。目の前に魚がたくさんいるので、5秒くらいはその光景を味わいたい。
- 潜った瞬間がまぶしすぎる。リアルな泡がほしいだけで、真っ白で何も見えなくなることは求めていない。
- カメをやたら撮りに行く。一度きちんと見たら、しばらく見に行かなくてよい。
- 小魚が過小評価されている。小魚の群れやクマノミも撮る対象にする。大物ばかり追う巡航はやめる。バリエーションが大事。
- SEA LOG の内容が乏しい。ウミガメやマンタの報告ばかり。
- 巡航中は、20〜30秒も同じ対象を追わなくてよい。せいぜい10秒くらい。
- 最初の間のあとは、視界にいる生き物（特に手前）から撮り始め、自然な流れで撮影を続ける。巡航ではなく「自動撮影」へ、考えの根本を切り替えたい。

## 変えたこと

### 潜った直後

- **到着の間**（`main.ts` `arrive`）：海に入ってから 5.5 秒は、その場でほぼ止まり（前へ 0.18 m/s）、視線をゆっくり少し左右に振る。この間は撮影監督が何も選ばない。何かを頼めば、そこで終わる。
  - 入り方の演出があるときは、演出の終わりから数える。ないとき（同じ日の2回目・共有リンクなど）は海に入った時から数える。
- **間のあと**：すぐ撮影を始める（`director.start()`）。演出のあとの「海のおすすめ3つ巡り」（`tourQ`）はやめた。間のあとは、見えている近くのものから撮る。
- **まぶしさ**：入水の白い膜は、不透明度 1 の白から、最大 0.35 の淡い水色にした。1.2 秒で消える（`opening.ts`）。
  - 代わりに、レンズの前と周りに泡の雲を出す（`splash.ts` `diveBubbles`）：入った瞬間に 340 個、その後 1.6 秒は減りながら追加する。大きさは数 mm〜数 cm で、近い泡は画面で大きく写る。
  - 近くて大きく写る泡は、縁が光る輪と上のハイライトにした（中が白い円盤にならない）。
  - 撮影で確認：泡の向こうに礁が見える。

### 撮る対象の選び方（`director.ts`・`persona.ts`）

- **自動撮影の流れ**：18 m 以内の正面にあるものほど選ばれやすい（最大 2.4 倍）。撮り終えてから次を探すまでの間（程よく）は、20〜40 秒から 4〜10 秒にした。
- **1つの対象は約10秒**：
  - 自分で選んだものは、撮る時間 8〜12 秒（大物 10〜14 秒）。近づく時間も含めて、およそ 15 秒で次へ。
  - 近づくのに 14 秒かかっても着かないものは諦め、近くの別のものにする。
  - 頼んだもの・ジャンプ・洞窟・めったにない光景・続いている狩りは、これまでどおり。
- **一度見た種類は 7 分見に行かない**（`REST_KIND`）：カメに限らず全種類。頼めばいつでも見られる。
- **小魚の群れを撮る対象に**：礁の小魚の群れ（5匹以上、活動している時間）を被写体にした。タップしたときと同じ撮り方で、核を囲む。
- **大物優先をやめる**：
  - 撮影監督の「大物補正」を弱めた（ジンベエザメなど 1.4 → 1.15、マンタ 1.3 → 1.1、大型魚 1.15 → 1）。
  - 程よくの好みを変えた：クマノミ 1.0 → 1.6、小魚の群れ 0.75 → 1.3、小さな生き物 1.1 → 1.4、マンタ・大物 1.6 → 1.2、カメ 1.4 → 1.0。

### SEA LOG

- **礁の魚の本当の変化を報告に足した**（`fish.ts` `tellReef`）：
  - 群れが休みに入る／動き出す（活動が状態表示の境目をまたいだとき）。
  - クマノミがイソギンチャクの奥へ／から出てくる。
  - 捕食者の気配で小魚の群れが礁へ身を寄せる。
  - どれも、カメラから 40〜45 m 以内のその群れで実際に起きたときだけ出る。
- **偏りを減らした**：
  - 待っている報告の中から、その種類を最後に見せてからいちばん時間がたったものを選ぶ。カメの息継ぎと休みは「カメ」で1種類、マンタの採餌とジャンプは「マンタ」で1種類と数える。
  - カメ・マンタは、同じ種類の報告の間隔を 4〜5 分から 7〜8 分にした。
  - 1分以上待った報告は捨てる。
- **案内（「↗ 30m 先に」）**：同じ種類（マンタ・大物など）は 6 分に1回にした。

## 見直すとき

- 7分の「同じ種類は見ない」は、生き物の種類が少ない海（外洋・ケルプ）で、撮るものがなくなる時間が長すぎないか見る。
- ほかの性格（おだやか・水面と空など）は、好みはそのままで、撮影時間の上限と同じ種類の休みだけ共通にした。
