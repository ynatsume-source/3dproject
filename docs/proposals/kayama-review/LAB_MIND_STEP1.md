ブラウザ: `?tier=low&debug&lab&time=noon&wx=clear#kayama`、ドットを目線で。キーなしなら習慣で動く。キーがあれば `agent/config.ts` のモデルで考える（ドット：深い思考 1日200回、軽い判断 1日400回、間隔20秒）。

## 作ったもの
- `src/robots/agent/types.ts`：観察・選択肢・結果・知識・目的・思考の型。
- `src/robots/agent/agent.ts`：一人の循環。節目（何も決めていない／目的が終わった／うまくいかなかった／はじめて見るもの）でだけ考え、その間は計画どおり進む。考えている間は「どうするか考えている」。答えが来なければ（`ponderMaxS`）習慣で進む。
- `src/robots/agent/brain.ts`：モデルへの入力（見ているもの・覚えているもの・持ち物・知識・最近の結果・選択肢だけ）と、返答の検査（選択肢にない id、座標、長すぎる文、根拠のない判定を受け付けない）。呼び出しごとの使用量・遅延・推定費用を `mindLog` に記録。
- `src/robots/agent/config.ts`：運用設定（モデル・上限・間隔・単価の仮定）。
- `src/robots/mind.ts`：モデルの指定、住人ごとの1日の枠（会話の枠と別）、API の使用量の受け取り。
- `residents.ts`：`observe`（前方150°・昼40 m/夜12 m・地面と背の高い固い物で遮られる）、`optionsFor`（見て知っている物だけ。将来できる手順は ready=false と必要条件付き）、`taskFor`（世界が受け付けなければ unavailable）、結果の報告（拾いに行ったら先に取られていた＝gone、道がない、眠る時間で中断…）。働いている間も1秒ごとに見て、はじめて見るものがあれば歩いている途中で立ち止まって考える。目的・仮説・やりとげた・うまくいかなかったを日記に書く。目線の「いまの目的」に本人の目的と残りの手順を出す。LAB の再現情報に目的・理由・呼び出し回数・最近の結果と知識。
- ドットは、見て知っている流木しか拾いに行かない（以前は 220 m 以内の流木を全部知っていた）。

## 結果（mind-check.ts、全項目 PASS）
1. 前の流木は見える／後ろの流木と、背の高い岩の陰の流木は見えない。
2. 本人の目的「小屋を建てる」が、拾う→削る→取りつけるの順で実行され、小屋に部材が1本付く。日記に「目的」と「やりとげた」。目的が終わると次を考える。
3. 拾いに行く途中で他の誰かが流木を取る → 世界が gone と判定 → 「試した」知識として残る → 次に考えるときは失敗の理由つきで、取られた流木はもう選択肢にない → もう1本の流木を拾う。
4. はじめて見る種類の物（石）が視界に入る → 深い思考で考え直す。
5. 選択肢にない手順（存在しない流木、座標）を含む計画は採らない。仮説「流木は作業台で削れば部材になる」は、作り話の根拠では確定せず、仮説の後に起きた本物の結果（削った done）でだけ確定する。
6. 脳なし、答えない脳：習慣で進み、小屋に部材が付く。

既存の nav-check / words-check / lantern-residents-check も PASS。
