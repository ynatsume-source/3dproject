# 帆の作業場の見た目：窓口に何を載せるか（提案、自然班 → 本体、2026-10-19）

本体の相談（2026-10-19）：帆の作業場（`site:sail-tree-0/1`・`site:sail-dry`・`site:sail-work`）と、筏のそばの帆の材料（`site:raft`）は main に入った（f9e19a6）。窓口（`src/world/worksite-look.ts`）の fixture で何を描くか。

この資料は**未採択の提案**。殻と縄と同じ決まりで考えた：

- 窓口に載っている物だけ描く。数（長さ・重さ・水分・枚数・出来の割合）は載せず、見て分かる状態だけ。
- 見た目の乱数は物の id から（`draw(seed, id, 'look')`）。

## 工程（main の `robots/sail-host.ts` で読んだ）

1. 刈る：浜のアダン 2 本（`site:sail-tree-0/1`）から葉を刈る。1 本に 3 回ぶん。
2. 干す：刈った葉を、小屋の裏の軒下（`site:sail-dry`、屋根ができてから）に並べて干す。取り込む。
3. 裂く：干した葉を、作業台の反対側（`site:sail-work`）で細く裂く。とげと縁の切りくず（`pandanus_leaf_scrap`）が出る。
4. 編む：裂いた葉で帆のむしろ（`sail_mat`）を編む。
5. 帆柱：棚の竹を切ってマスト（`bamboo_mast`）にする。
6. 筏のそば（`site:raft`）に帆の材料が運ばれる。

## 提案：品物（`WorksiteThingKind` に足す）

| 種類 | 材料 | 見た目の状態（`look`） | 描き方 |
|---|---|---|---|
| `pandanus-leaves` | `pandanus_leaves` | `fresh`（刈ったばかり）／`drying`（干している途中）／`dry`（干し上がり） | 長い帯状の葉の束。緑 → 黄緑で少ししおれる → 麦わら色で平ら。とげの縁は近くだけ |
| `pandanus-strips` | `pandanus_strips` | `dry` | 細く裂いた葉を、ゆるく束ねて置く |
| `leaf-scrap` | `pandanus_leaf_scrap` | `dry` | とげの縁と切れ端の小さな山 |
| `sail-mat` | `sail_mat` | `weaving`（編みかけ）／`done`（編み上がり） | 編みかけは、片側が編み目で、反対側に裂いた葉の端が並ぶ。編み上がりは丸めて置く。編み目は画素より細くなる所で溶かす（ちらつき対策）。点や穴の模様にしない |
| `bamboo-mast` | `bamboo_mast` | `cut` | 節のある竹の竿を地面に寝かせる。長さはどれも同じ（長さは隠れた値） |

- 編みかけの「どこまで編めたか」は数なので載せない。`weaving` と `done` の 2 つだけ。
- 干している途中の `drying` は、科学側が「乾いた」と判定するまでの見た目。判定は科学側（数は渡さない）。

## 提案：設備（`WorksiteFixtureKind`）

- 新しい設備は**足さない**のをおすすめ。
  - 干す：今の工程は「軒下に並べて干す」なので、葉は軒下の地面に並べて描く（`on` なし）。竿や棚に掛けるなら、本体の工程に設備が要る。
  - 裂く・編む：地面か作業台の脇で足りる。むしろは地面に広げて編む（八重山の伝統のやり方に近い）。
- 筏の上の帆柱と帆（立てた姿）は、本体の筏の描画の側。`site:raft` の窓口には、筏のそばに置かれた物だけを載せる。

## 提案：アダンの木そのもの（`site:sail-tree-0/1`）

- 立っている葉（`pandanus_standing_leaves`）は、刈ると減る。見て分かる。
- 案：アダンの木の見た目の状態を窓口に載せる：`full`（刈る前）／`thinned`（1〜2 回刈った）／`stripped`（3 回とも刈った）。正確な回数は載せない。
- 描くのは自然班（浜の植物 `ocean/shore.ts`）。刈った葉の付け根が残り、葉の房が小さくなる。
- 葉がまた伸びるかどうか（世界の在庫が戻るか）は本体と科学側。戻らないなら、`stripped` のまま。

## 決めてほしいこと

1. 上の品物の種類と状態でよいか。
2. 設備を足さない（干すのは軒下の地面に並べる）でよいか。
3. アダンの木の状態（`full`／`thinned`／`stripped`）を窓口に載せるか。載せるなら、どの作業場の窓口に入れるか（`site:sail-tree-0/1` の `fixtures` に `pandanus-tree` として、など）。
4. 筏の上の帆と帆柱を誰が描くか（本体の筏の描画か、自然班か）。

自然班は、決まった種類から、試験用の値（`WORKSITE_LOOK_FIXTURES` と同じ形）で描き始める。
