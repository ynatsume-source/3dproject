## 乱数を変えないやり方

- 元の形は、海の共有の乱数列（`core/math` の `R`/`rr`）を使って形を作っていた。その乱数列は、このあと岩などの配置にも使われる。three.js も物を作るたびに `Math.random` を引く。
- 形は `fineGeos()` の中で作る。そのあいだだけ、形専用の乱数列を `R`/`rr` と `Math.random` に貸し、終わったら元に戻す。
- そのうえで、丸い形が作るときに引いていた世界の `Math.random` の回数を、同じ場所で同じだけ引く（浜 52 回、林 300 回）。
- 若木と倒れる木は、前の形が作っていた物の数と同じ数の id を引く（`sameDraws`）。three.js で数えて、どちらも同じ回数になることを確かめた（倒れる木 52 回、若木 48 回）。
