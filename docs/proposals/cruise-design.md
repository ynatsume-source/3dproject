# 提案：自動巡航と「性格」を土台から作り直す

2026-10-01。まだ実装していない。どの形にするかを決めるための叩き台。

## 1. いまの仕組みと、感じている違和感の原因

いまの自動巡航は、ひとつの「撮影監督（director）」が、近くにいる生きものに点数をつけて一番高いものを撮りに行く、というだけの仕組み。

- 点数 ＝ 生きものごとの固定の優先度 × 距離 × 「最近見たか」の割引 × 性格の好み
- 性格の違いは、ほぼ数字だけ（速さ、眺める長さ、空へ行く間隔、寄る距離、好きな生きものの重み）。撮り方や動き方の「型」は全員同じ

このせいで、違和感がそれぞれ次のように生まれている。

| 感じていること | 原因 |
|---|---|
| タコばかり見に行く／ウミガメはもういい | 優先度が固定で、「飽き」がない。同じ種類を何度見ても、数分たてば点数が元に戻る |
| あの魚群が気になるのに、何も言ってくれない | 監督は「カメラに何が映っているか」を見ていない。撮らないものは存在しないのと同じ |
| 遠くの魚を追っているが、目の前を横切った魚の方が見栄えした | 一度決めたら撮り終えるまで変えない。途中で良いものが来ても乗り換えない |
| 性格の違いが感じられない | 違うのは数字だけで、撮り方の型・巡り方・反応の仕方が同じ |
| 空が単調 | 空での動きは「島の上を高度を変えながら回る」1種類だけ |

## 2. 新しい土台：3つの層

### 層1　注目（いま何が面白いか）

生きものの固定の優先度をやめ、その場の状況から「面白さ」を毎回計算する。

- **見えやすさ**：画面のどこに、どれくらいの大きさで映るか。近くを横切るもの、画面の中央に入ってくるものほど高い
- **めずらしさ**：その海での実際の多さ（よくいる＜まれ）と、今日もう何回見たか（見るほど下がる＝飽き）
- **いま何をしているか**：狩り、息継ぎ、食事、求愛、群れの渦、跳躍など「出来事」は高く、休んでいるだけなら低い
- **時間帯**：朝夕は狩り、夜は夜行性のもの、昼は群れ、など

### 層2　撮り方の型（ショットの語彙）

カメラワークを「型」の組み合わせにする。大型の生きものですでに好評だった型を一般化して、増やす。

- 水中：回り込み、並走、真下から見上げ、正面で迎える、待ち伏せて通過させる、岩の上へ上がると現れる、背後からついて行く、寄って細部（目・模様・口）、群れの中へ入る
- 水面：水面すれすれを滑る、水面の上と下を半分ずつ（スプリット）、浮上してくるものを真上から待つ
- 空：低空で波頭をかすめる、鳥の群れを追う、水面で休む鳥にそっと寄る、跳ねるトビウオを追う、高く上がって俯瞰、夕日・星空で止まる
- 出来事：跳躍（ブリーチ）を待って捉える。深くから一気に上がってきて、水面を割って跳び、着水で大きな水しぶきと泡が渦巻く

### 層3　性格（何を好み、どう撮り、どう巡るか）

性格は数字ではなく、次の4つの「くせ」の組み合わせとして定義する。

1. **好み**：層1のどの面白さを重く見るか（出来事好き、めずらしさ好き、大物好き、群れ好き、など）
2. **撮り方**：層2のどの型をよく使うか、ひとつのものをどれだけ眺めるか
3. **巡り方**：リーフの縁沿い、砂地の上、中層を漂う、壁沿いに深く、水面近く、など
4. **気の移りやすさ**：撮影中に別の面白いものが来たとき乗り換えるか、最後まで見届けるか

あわせて、性格によらない共通の仕組みとして次の2つを入れる。

- **飽き**：同じ種類を続けて撮らない。今日すでに何度も見たものは、よほどの出来事がない限り後回し
- **知らせ**：撮らずに通り過ぎた気になるもの（魚群、大物、出来事）は、画面の端にそっと「左に○○の群れ」と出す。タップすると見に行く（「解説」がオンのとき）

## 3. 性格の案（6つ）

いまの5つ（おだやか、せわしない、サメ好き、空好き、おせっかい）を、見ていて違いがはっきり分かるように作り直す案。

| 性格 | 好み | 撮り方 | 巡り方 | 気の移りやすさ |
|---|---|---|---|---|
| **おだやか** | 休んでいる・食べている生きもの、光 | 待ち伏せて通過させる、遠すぎない定点、長く眺める | 中層をゆっくり漂う | ほぼ乗り換えない |
| **好奇心**（いまの「せわしない」） | 目の前を横切るもの何でも、群れ | 背後からついて行く、群れの中へ、短く次々 | 寄り道だらけ | すぐ乗り換える |
| **狩人**（いまの「サメ好き」） | 捕食者、狩り、夕方の群れ | 並走、低い位置から見上げ、望遠ぎみ | 群れの近くで待つ、朝夕は特に | 狩りが始まれば即乗り換え |
| **水面と空**（いまの「空好き」） | 鳥、トビウオ、浮上・跳躍、マンタ | 水面すれすれ、上下スプリット、空の型すべて | 水面近く、空との行き来が多い | 出来事なら乗り換え |
| **博物学者**（いまの「おせっかい」） | まだ図鑑にいないもの、めずらしいもの | 寄って細部、解説を詳しく | リーフをくまなく | 新種なら乗り換え |
| **深場**（新） | ウツボ、洞窟、壁、夜の生きもの | 壁沿い、ライトで照らす、岩陰をのぞく | 壁沿いに深く | ほぼ乗り換えない |

「海だけ」は性格と組み合わせられる設定として、すでに入れた（このコミットで実装済み）。

## 4. 進め方（3段階）

1. **土台**：注目の計算（見えやすさ・めずらしさ・飽き）、撮影中の乗り換え、通り過ぎたものの知らせ。いまの性格のまま入れても、タコばかり・カメばかりはここで解消する
2. **撮り方と性格**：撮り方の型を増やし、6つの性格を「くせ」で定義し直す。水中の型から
3. **空と出来事**：空の型（低空滑空、鳥を追う、休む鳥、トビウオ）と、跳躍。跳躍は、深くから上がってくる動き、水面を割るしぶき、着水の泡と白波、音まで含めて作る。トビウオが跳んで滑空する動きもここで作る

## 5. 決めてほしいこと

- 性格は6つでよいか。減らす・増やす・名前を変えるなど
- 「知らせ」の出し方（画面端の小さな文字＋タップで見に行く、でよいか）
- 跳躍させる生きもの：ザトウクジラ（冬の宮古）に加えて、マンタ、ジンベエザメ（実際にはほぼ跳ばないので入れない案）、イルカ（まだいない）など、どこまでやるか
- 進め方の順番（1→2→3でよいか、空と跳躍を先にしたいか）
