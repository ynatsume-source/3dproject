# 低い月と夕日の照り返しが白く飛ぶ（自然班、2026-10-25）

視聴者設計班の依頼（docs/proposals/viewer-design-2026-10-16/glare/、ブランチ ccr-5b43830d-xlbydx）への答え。

- 低い満月（12/25 06:45）：照り返しが、水平線の上下に大きな白い楕円になる。
- 夕日（12/21 17:35）：照り返しが、空まで伸びる白い縦の帯になる。

## 何が起きていたか

- 白いかたまりは、月や太陽そのものではない。水平線の、海が照り返す所が中心。
- 海面のきらめき（`src/ocean/air.ts` の seaTop）は `D·F/(4·nv)` で、波の陰で隠れる分（幾何の項 G）がなかった。
  - 水平線をかすめて見るほど `nv` は小さくなり（下限 0.02）、きらめきは際限なく明るくなった。月や太陽が低いほど、照り返す所は水平線に近づく。
- その明るすぎる光を、後処理のにじみ（bloom、`render/post.ts`）が空へ広げた。
  - 夜は灯りや焚き火を光らせるため、にじみの上限はほぼない（`uCap` 1e4）。
  - そのため夜明けの月で特に大きくなった。

## 直したこと（`src/ocean/air.ts` の seaTop、きらめきの1行だけ）

- きらめきに Smith の陰の項（Schlick の形、`k = sqrt(rough · 2/π)`）を掛けた。目の側と光の側の両方。
  - 水平線をかすめる所では、光に向いた波の面の多くが手前の波の陰になる。そこが暗くなり、きらめきは波で割れた光の道として残る。
  - 正面から見下ろす所（`nv`・`nl` が十分大きい）は、G はほぼ 1 で変わらない。
- にじみの強さ・上限は変えていない（夜の灯りの見え方はそのまま）。

## 見た目・重さ・保存

- 見た目：
  - 月や太陽が低く、水平線近くで照り返す場面だけ、白く飛ばなくなる（S5b の満月の明け方、S2 の夕方の干潮）。
  - 昼の海はほぼ変わらない。
- 重さ：海面の画素で、平方根 1 回と割り算 2 回が増える（月と太陽の 2 つ分）。
- 保存：変わらない。世界・住民・時計には触れていない。
