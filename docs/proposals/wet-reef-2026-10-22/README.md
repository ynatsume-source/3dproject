# 干潮のリーフ：濡れた礁の見た目（自然班、2026-10-22）

ADR 0009 の 4（濡れたリーフ・水が引いた跡などの見た目）。潮が入る前に、本体の試験用のつまみ `?sealevel=`（PR #95）で先に作った。
干潮で顔を出すサンゴの頭（平均海面近くの −0.9 m 付近、本体の依頼）を含む。

## 何が起きていたか

`?sealevel=-1.04`（1年で最も低い潮）で、水から出た礁・サンゴ・岩・海底は、水中の光（`shade()`：水を通った光の 1.6 倍とコースティクス）のまま描かれていた。水がないので吸収もなく、白く飛んでいた（`before-noon.jpg`）。

## 足したもの

- `src/render/reef-lit.ts`（新規）`reefLit(alb, wp, n, causAmt)`：
  - その場の水面（`uSeaH`）より下は前と同じ `shade()`。
  - 上は島と同じ外の光（`airLit`）にする。コースティクスはつけない。色は水中と同じくらいの明るさ（×2.0）にする。
  - 濡れているほど暗く（×0.7）、色が深くなり、空と日が映る（フレネル）。
  - 日の映り込みは、凹凸が画素より細かいところでは消す（細いサンゴの枝・遠くで点滅させない）。
  - 水際の境目は 3 cm でなめらかにつなぐ。
- 乾き方（`reefWet`）：
  - 波が洗う水面から 4〜12 cm は濡れたまま。
  - その上は、水が引いてからの時間で乾く。いまの海面で濡れたまま、`uWetH`（45 分前までにいちばん高かった海面）で乾く。
  - 水面から 0.3〜0.6 m までは少し湿り気が残る。
- `src/ocean/wet.ts`（新規）：`wetLine(ms, site)` は `seaLevel()` を今と 5 分ごと 45 分前まで引き、そのいちばん高い値を返す。時刻だけで決まる。保存も乱数もない。読み直しや時間の飛びでも同じ礁になる。
  - 試験用：`?wetfrom=`（`?sealevel=` で海を止めたとき、45 分前にいた高さ）。ないときは止めた海面そのもの（波の洗う所だけが濡れる）。
- `src/render/airlit.ts`（新規）：`airLit` を `ocean/shore.ts` から移した（中身は同じ）。サンゴ・岩の描画から使えるようにするため。二重に取り込んでも重ならないよう、ガードをつけた。`shore.ts` からも今まで通り使える。
- `reefLit` を使うところ：
  - 海底（`build.ts` の floor）
  - 海底の小石・ナマコなど（litter）
  - 岩
  - 洞窟の壁
  - サンゴ（`models.ts` の `coralMaterial`）
  - 生き物は今まで通り。
- 本体のファイル：
  - `src/main.ts` に 1 行（`setWetLine(SEA_TEST, clock.ms, cur?.loc)`、`setSeaLevel` の次）。
  - `src/render/common.ts` に `uWetH` を足した。
- `tools/lab/wet-reef.cjs`（新規）：水から 3〜35 cm 出たサンゴか岩を探して撮る。撮った位置を `flicker.cjs` の `POSE` の形で出す。

  - 水中の岩（今回変えていない所）にも増減が出ているので、一部は測定の揺れ。

## 見た目・重さ・保存

- 見た目：
  - 潮が入るまでの今の海（0 m）では、ほぼ変わらない。水から出ている岩とサンゴの上の部分だけが、外の光で濡れた見た目になる。
  - 潮が入ると、干潮で出た礁が濡れて見え、時間とともに乾く。
- 重さ：
  - 礁・サンゴ・岩の画素で、水から出ているときだけ外の光の計算が加わる（分岐。中でテクスチャを読まない）。
  - 水中の画素は `fwidth` 1 回だけ増える。
  - CPU は 1 フレームに `seaLevel()` を 10 回（いまは定数 0）。
- 保存：変わらない（何も保存しない）。

## 本体へ

- 気づいたこと（自然班では直していない）：
  - 数 cm のごく浅い水の上は、海面の描き方で白くぼやけて見える（`after-noon.jpg` の左手前）。
  - 満潮（+0.91 m）のときは、水に沈んだ浜（航空写真の部分、`LAND_ONLY` と `dry = smoothstep(-0.1, 0.06, y)`）が水中の見た目にならない。今回は干潮の側だけ。
- 潮が入ったら：`wetLine` は `seaLevel()` をそのまま読むので、つなぎ直しは要らない。干潮の昼・夕で撮り直す。
