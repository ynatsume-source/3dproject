  - 月の光の道と、濡れた礁・潮だまりに映る月を見せるには、礁の上から島の方を向く視点か、島の東側の浜が要る（本体・視聴者設計班で検討してほしい）。
- 濡れた礁のつやは、いまは太陽の照り返しだけ。月の照り返しはない。自然班で足す（別の作業）。

## 撮り方

- `tools/lab/tide-view.cjs`（新規）。`SEAS` で海面を並べ、`TIME` か `DATE`（日本時間、ページの時計をずらすので月の満ち欠けも変わる）で時刻を決める。
- `AT`（向かう礁の点）、`FWD`、`H`、`TURN`、`MOON=1`（月の方を向く）、`POSE`。
- ソフトウェア描画（SwiftShader）で撮った。本物の GPU では、夜の明るさが少し違うことがある（実機のリハーサルで見る）。
