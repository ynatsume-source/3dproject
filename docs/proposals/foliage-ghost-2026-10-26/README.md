# 邪魔な植物を1本ごと半透明に（自然班、2026-10-26）

視聴者設計班の D27（`docs/proposals/viewer-design-2026-10-16/screens/CAMERA.md` §3）。オーナーの選択は案1「なめらかに透かす」。

- いまは、カメラと住人のあいだの葉を筒の形にくり抜いている（`cutSight`）。葉が筒の縁でギザギザに切れ、切れ端が宙に浮く。
- これを、邪魔な植物を1本（1株）ごと半透明にする描き方に置き換える。

## 作ったもの

### `src/ocean/ghost.ts`（新規）：見え方
- 透かした植物は、幹も葉も **3割ほどの濃さ**。色を少し抜き、わずかに青みに寄せる。
- 時間：透かし始め 0.4 秒、戻し 0.8 秒。
- 描き方：
  - MSAA が効くとき（`uA2C`）は、アルファ・トゥ・カバレッジでなめらかに透ける。
  - MSAA が効かない軽い画質では、4×4 の決まった細かい模様で間引く（案2の見え方）。
- テクスチャの読み取りは足していない。

### `src/ocean/ghost.ts`：どの植物を透かすか
- カメラから住人の頭・体の中ほど・足もとへの線にかかる植物を、0.3 秒ごとに選び直す。
- カメラから 1.2 m 以内の植物も同じに扱う（カメラの前の面で切れて、断面が見えるのを防ぐ）。
- 葉の一部だけを消すことはしない。
- 植物1本ごとの透かし具合は、その植物のインスタンスの色（`instanceColor` の赤）に乗せる。
  - 形のデータ（共有のジオメトリ）には何も足さない。
  - 住人が倒す木、畑の若いモクマオウなど、同じ材質でもこの網を通らないものは透けない。

### 対象
- 透かすもの：浜の植物（アダン・クサトベラ・モンパノキ・モクマオウ、`shore.ts`）と、近くの林の木・若木・茂み（`forest.ts`）。
- 透かさないもの：流木・岩。
- 影はそのまま残る（世界は変わっていない）。

### 筒のくり抜き
- 植物（`shore.ts`・`forest.ts`）からは外した。
- 航空写真を貼った林の屋根は1枚の面で、1本ずつに分けられない。そのため、真上を開けるいまのくり抜き（`uCut`）のまま。
- `common.ts` の `cutSight` は、どこからも使われなくなった（消すかは本体の判断）。

### 本体のファイル
- `src/main.ts` に1か所：住人を見守っているあいだ、植物の選び直しを呼ぶ（点は選び直すときだけ `residents.sense(r).eye` から作る）。
- カメラの撮り方（D27 §1 の A〜F）には触れていない。

### 試験
- `tools/lab/ghost-look.cjs`：住人のいちばん近い浜の植物の向こうから住人を見て、透かした画と透かさない画を撮る。
- `T.ghosts.lab(点)` で、点を手で固定できる（LAB）。

## 見た目・重さ・保存
- 見た目：見守りのあいだ、カメラと住人のあいだの植物が1本ごと淡くなる。葉が筒の縁で切れて浮くことはなくなる。
- 重さ：
  - CPU：0.3 秒ごとに、近くの植物の円柱と3本の線の交わりを調べる。透けている植物は、毎フレーム値を書き換える。
  - GPU：植物の画素で、計算が少し増える。
- 保存：変わらない。植物は動かさず、消さない。
