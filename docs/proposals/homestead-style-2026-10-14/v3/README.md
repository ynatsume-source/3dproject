# 若いモクマオウの枝葉を局所的に見直す

PR16の初回1654ec4、第2案18ad2bfを保持し、若木の葉geometryだけを再調整した。家具・地面・配置・当たり判定・保存・生活の変更はない。枝葉の独立した風アニメーションも追加していない。

背景の丸い低草・下草は承認済みの目標表現ではない。低いクサトベラの復元は独立したPR17に保全しており、この試作へ混ぜない。画像に残る既存の草を、今回の採用提案として扱わない。

## PR14の確認と移せる要素

PR14のHEAD e754ce36ce0a1e0f7a93e7a5f267fd35ec23fc3dにある実画像（close/normal）と生成コード、GLBを確認した。参照GLBは1メッシュ・3,326三角形、roughness約0.95が記録されている。ただしstandalone viewerは独自のmatte shaderを使っており、このPBR値で実島の見え方を保証するものではない。確認した画像とリポジトリ内の画像はSHA256が一致し、参照ファイルに未コミット変更はない。[記録](evidence/pr14-reference.json)。

独立ステージの枝先に束を重ねる構成、丸い肩から垂れる輪郭、光沢を抑えた素材感を参考にした。一方、PR14も細葉を省略した大きめの束であり、照明・背景・サイズが違う。実島で同じ品質になる保証として扱わず、初めは形の特徴を手続き的に近似したが、実画像で目標から外れたため、最終案ではGLBの枝葉形状だけを取り出して移植した。

## 実島での局所試行

1. 350fa1c：既存の各葉メッシュ内で3束×7本の円断面の枝葉にした。[実画像](evidence/first-attempt/desktop-home-near-day.png)では大きい板葉はなくなったが、太く長い紐の房に見えたため、この形を完成とはしなかった。
2. cf0e7f2：3束×15本へ細分化し、太さ・長さ・曲がり方を変えた。[実画像](evidence/second-attempt/desktop-home-near-day.png)では紐の太さは減ったが、疎い棒が並ぶ印象になったため、この形も採用しなかった。
3. e6e43a3：重なる束と短い下縁を組み合わせた。[実画像](evidence/third-attempt/desktop-home-near-day.png)でも小さな房の塊に見え、採用しなかった。
4. 000859b：PR14のGLBから枝葉の33閉面パーツ（2,838三角形）を抽出し、既存の4葉メッシュに9/8/8/8パーツずつ分配。材質やObject3Dを追加せず、法線と頂点色を使用した。根元は既存位置のまま、高さ方向3.2・水平方向2.7で小木へ合わせ、既存メッシュの内部オフセットをgeometry側で相殺した。既存幹・pivot・切株はそのまま。GLBの幹と枝は取り込んでいない。

移植直後の[暗い画像](evidence/transfer-before-colour-fix/desktop-home-near-day.png)から、PR14 viewerが線形色をsRGB出力へ変換する一方、本体は`ColorManagement.enabled=false`で表示色を直接扱う差を確認した。GLBの頂点色を表示色へ変換してから既存の葉材質へ合わせる修正を行った。島全体の照明・色空間は変更していない。最終の全頂点について表示色域とmatte条件を検査している。

参照データの抽出は`tools/lab/extract-pr14-crown.py SOURCE.glb OUTPUT.json`で再現できる。生成したJSONは167,022 bytes。外部asset取得、Blender新規導入、runtime GLB読込はない。手続き的な途中案の最大14,400三角形/本に比べ、最終案の葉は2,838三角形/本。第2案は2,320三角形/本だった。移植時に先端の明るい頂点で光沢を戻す条件が残ることを検査で発見し、全頂点がmatte条件を満たす色倍率へ修正した。修正前の撮影は中止し、採用画像には使っていない。

## 検証条件と限界

静止画は初回・第2案と同じ人工保存、昼12:00、1280×720 high、近景カメラ。同期フレーム時間は共有CPU上のSwiftShader各3サンプルであり、実機FPSや性能回帰の確定値ではない。

微小移動の数値は同条件の画像差分診断として記録する。輪郭・色・影の変化が混ざるため、ちらつきの実測値や合否へ読み替えない。短い動画もオフライン・低フレームレートであり、実機の滑らかさの判定には使用しない。

形状の閉面・外向き・有限値・乱数不消費、typecheck、production build、薪状態5件を再検証。世界配置・衝突・60秒の生活履歴・保存・乱数・成木と若木の伐採後状態が第2案のfingerprintと完全一致した。材質shaderは第2案のまま。撮影の実WebGL経路でもエラーを収集する。

夕／夜／phoneとスマホの小さな移動は[追加検証](extra/README.md)へ記録した。実機GPU、実スマホ、長時間配信は未評価。main統合・公開・自動マージは行わない。


## 実画像での判断

[初回・第2案・改善案の同じ近景](evidence/three-way-comparison.png) ／ [改善案の原画像](evidence/desktop-home-near-day.png)

第2案の硬い大葉、途中案の太い紐・疎い棒より、枝葉の束が連続して樹冠を作る点は改善したと判断した。色変換後は暗い塊ではなく、光沢を抑えた枝葉の色が読める。ただし、丸い房の量感・面の角・枝葉の継ぎ目は残る。細枝一本一本の表現はPR14同様に省略されており、樹種らしさの完成や全島展開に十分とは判定しない。樹冠が広がったため、家具はこの同じ画角ではさらに隠れる部分がある。家具の改善成果としては扱わない。

[第2案（左）／改善案（右）の比較動画](evidence/motion-comparison.mp4) ／ [0・5・11番フレームの抜き出し](evidence/motion-contact-sheet.png)。各640×360 high、12フレーム、8fps、1.5秒。フレーム間補間は行っていない。

同じ保存・時刻・入力で6cmのカメラ移動を与えた。全12フレームでカメラ位置・時計・乱数が一致し、終了時の保存SHAも一致。入力と初期の投影行列も比較検査を通過した。既存の画角の移行やHUDの読み込みも映像に含まれるため、純粋な平行移動だけの映像やちらつき計測として扱わない。
