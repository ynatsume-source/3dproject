## 状態・動作検証

同じ乱数seedの新規世界で以下が変更前後完全一致：世界配置・100m内の衝突一覧・起動時乱数・60秒後の乱数・生活履歴SHA・保存SHA・fixture SHA・成木伐採直後と片付け後の状態・若木伐採後の保存と乱数。

若木は実際のchopアクションで立木→倒木→切株に移行する検査を追加。同じgeometry参照を維持し、保存trees[0]=1を確認した。**この動作検査だけはchopの前提である流木小屋完成を設定する。スクリーンショットfixtureには反映していない。**

形の単体検査：乱数消費なし、属性有限、葉束と板の閉じた面・外向き巻順、板の外寸、石の頂点位置不変。既存の薪状態テスト5件、fell、nav、本体typecheck/build成功。個別ログと前後fingerprintはevidenceに保存。
