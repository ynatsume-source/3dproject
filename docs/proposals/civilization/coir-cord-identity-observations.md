# B：切れない縄のIDと観察チャンネル

A（交代・部分精算）とは別の固定commit。PR25-C1/C2を扱い、科学の傷み・強度・収支・判定式は変更しない。main・受入済みPR25・Aのブランチを変更しない。

## C1：同じ物のIDを保つ

荷重で切れない場合、日なた/日陰の曝露、擦れでは、元のlotIdのまま隠れた傷みの累積だけを更新する。材料・重量・長さ・初期強さ・場所・来歴は維持する。切れたときだけ元のIDを廃止し、新しい2つのlotIdを返す。子片はその後の切れない出来事でも各自のIDを保つ。

既存process-runnerのcommitと検査は変更しない。私有コピーのtransaction内で既存commitを実行し、切れなければその一時生成ロットを元のIDへ置き換えてから台帳へ反映する。一時IDは在庫や返却結果に露出しない。seqは単調に進むので欠番はありうる。JavaScriptオブジェクトの参照同一性は保証せず、本体はlotIdで参照する。

host-4では履歴を最新チェックポイントと直近64件の再送receiptへまとめる。入力スナップショットと完了runをイベントごとに残さない。[保存上限と/3移行](coir-cord-load-checkpoints.md)を参照。同じIDの連続更新は、直前の隠れた性質・時計と照合してから最新のスナップショットに進む。同じコマンドIDの内容違いと、過去の曝露の重複は引き続き拒否する。全履歴の出力を現存ロットと比較せず、最後の現存状態だけを比較する。後続工程で消費して現存しないロットは許す。

切れた元IDは廃止済みとして、入力や生成先・現存ロットへの復活を拒否する。過去の「切れなかった」イベントを再送しても過去のreceiptを返すだけで、後で切れた縄を復活させない。

## C2：言葉と感覚をそろえる

readCordWorkerObservationsは既存の見た目の文をそのままsightとして返す。新しい触覚を創作せず、touchのラベルを外す。観察を受けられる担当期間・実作業の確認条件はAから変えない。強さ・重量・乱数・数値を観察へ含めない。B1修正済みの失敗文も変更しない。
