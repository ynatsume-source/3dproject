# 壊れた器の破片 9c3b611：確認結果

2026-10-07 JST。対象は科学側 `9c3b611f7a3a88b71450aca9532484a6b81c6a1e` の
`potSherdsQuality` と破片のquality。前回対象外だった部分だけを確認した。

**A/B/Cの追加指摘なし。本体の破損時処理へ接続してよい。**
関数は壁の水・タール・素地の吸水率・来歴を保持する。同じ質量で戻す限り、破片化による追加の丸めはない。

## 質量とppmの読み戻し

関数自体はmgをppmへ計算し直さず、組み立て時の写しにある **既存の整数ppmをそのままコピー** する。
本体は元のamountをそのまま使って `pot_sherds` を作るため、破片の成分を次の規則で読むと、元の器ロットを読んだmgと一致する。

```text
タール mg = floor(ロット全体の mg × x_wood_tar_ppm / 1,000,000)
壁の水 mg = floor(ロット全体の mg × x_water_ppm / 1,000,000)
素地 mg   = ロット全体の mg − タール mg − 壁の水 mg
```

分母は水・タールを含むロット全体。乾量基準に読み替えない。
0 ppmはフィールドごと省略される場合があるが、欠落を0として読めば同じ値になる。
`history_complete:0` は省略されず0のまま。1も保持し、元に来歴がなければ新しく1を作らない。
吸水率0も保持する。

器の工程がmgから整数ppmを書き出した段階の丸めは、破片化では取り戻せない。
例えば塗布後の615,000 mgの器は、既に `x_wood_tar_ppm:24390`、タール読み戻し14,999 mgになっている。
破片も14,999 mgであり、破片化でさらに1 mg減ることはない。

## 実際の工程と本体をつないだ確認

器の生成には再確認済みの科学側355de03を使用。この版の `potSherdsQuality` は9c3b611と関数本文が同一。
本体は取得したmain **a58a1a0** の本物の `POT_ASSEMBLY`・`assemble`・`disassemble` を使用した。
診断内だけで表のコピーに `brokenMaterial`・`brokenQuality` を付け、組み立て→condition 0→JSON保存・復元→破片化を実行した。

| 破片化する元の器 | 全体 mg | タール mg | 壁の水 mg | 来歴 |
|---|---:|---:|---:|---|
| 未塗布・乾いた試験器 | 600,000 | 0 | 0 | 未記録のまま |
| タールを15 g塗った器 | 615,000 | 14,999 | 0 | 1 |
| 水試験から返った未塗布の器 | 672,001 | 0 | 72,000 | 1 |
| 水試験から返った塗布済みの器 | 646,692 | 14,998 | 31,691 | 1 |
| その器を追加のタール5 gで封止 | 651,692 | 19,997 | 31,690 | 1 |
| 既知→欠測で戻した塗布済みの器 | 627,470 | 14,998 | 12,469 | 0 |
| 湿った封止器に不完全な来歴を設定→組み立て→傷み0.9で戻す | 651,692 | 19,997 | 31,690 | 0 |

全7経路で、破片の成分mgは元の器ロットの読み戻しと一致した。
元のqualityと設備内の写しは書き換えず、設備を除いて破片ロットを1つだけ作る。
同じ設備をもう一度戻しても二重に破片を作らず、破片を器として再組み立てする要求も拒否した。
`capacity_ml`・`coverage_ppm`・`sealed`・`airtight_known`・`air_leak_tau_min`・`crack_ppm` は破片に残らない。
素地の吸水率を保持することは、元の器と同じ透水・気密性能を破片へ与えることではない。

## 検証範囲と本体への申し送り

- [診断](review/science-review-sherds-9c3b611.repro.mjs)：218確認、失敗0。上記7経路に加え、168条件で整数ppmとmgの境界を照合。
  1/13 mgの端、1,000,000 mgをまたぐ量、成分ppm合計1,000,000、ゼロ・欠落、来歴0/1/欠落を含む。
  BigIntの整数除算を独立の参照として、既存の `readPot` と一致することも確認。
- 非整数・負・NaN・Infinity・合計超過の組成5条件は、本体の組み立て時に拒否され、設備内の写しへ入らない。
  `potSherdsQuality` 自体は入力検査器ではなく、検査済みの器の写しを受け取る関数。
- 9c3b611の器検査35件、本体a58a1a0の既存組み立て検査が成功。診断の器生成結果は検査器違反0。
- a58a1a0では破片の接続はまだ保留されている。本体で表へ
  **`brokenMaterial: 'pot_sherds'` / `brokenQuality: potSherdsQuality`** を追加し、元の写しのamountをそのまま使う。
  既存の組み立て検査の「壊れた設備は残る」を、実際に湿った・タール付き・来歴0の器から破片へ戻す検査へ更新するとよい。
- 破片を乾燥・粉砕・粘土へ混ぜる工程はまだない。この確認は将来の破片利用工程の検証ではない。
  設備として使う間に壁の水・タールそのものを増減させる工程を追加する場合は、その変化を元の写しとどう精算するか別途決める必要がある。
