## A1：気象欠測による終了を、熱い壺を開けたことにしている

対象：`src/science/step/charcoal.ts:102–104,161–178,232–234`。

標準の詰めもの2 kg・薪12 kg（水分は双方15%）、28 °C、器4000 J/K・UA 2.5 W/K・熱の取り分0.35。
中火で0→2時間進めると、器461.9816 °C、炭成分661,506.9056 mg。
次の2→3時間を `environment.source:'unknown'`、**actionsなし、stopなし**で送る。

- 計算時刻は2時間のままなのに、炭成分 **346,604 mg** を燃やす。
- この燃焼による熱 **10,398,120 J** を追加。O2も、外の薪の燃焼分に加えて **844,559 mg** 取り込む。
- 返る炭ロットは **331,902 mg**。住人への観察に「開けたとたん、炭が赤くなって燃え出した」が入る。
- 同じ2時間時点の状態から、既知の天気で `put_out` → 閉じたまま冷却 → 6時間で `open` なら **678,506 mg** が返る。
  これは欠測中の正解を推定する対照ではなく、密閉のままなら開放燃焼が必須ではないことの対照。

原因は `ending = !known || ...` のすべてで、開放時の `burnChar` を計算すること。
「operator停止は開ける」という既知の操作規約まで否定していない。**天気が分からないことは、開ける操作や壺の破損を知ったことにはならない。**
`history_complete:0` を付けても、確定した質量損失・発熱・観察を作ったことは解消しない。

欠測による計算終了と、実際の開放を分けてほしい。明示の `open`、開放を意味すると合意した停止、既知の破損は別に扱える。
未知の区間を勝手に冷やして精算する修正も避け、最後に分かっている閉じた状態／不完全な回収物としてどう引き継ぐかを明示する。
回帰は「unknownでstopped・不完全」だけでなく、開放なしでは余分なO2・炭の燃焼・その観察を作らないことを検査する。

診断JSON：`findings.A1`。現在の検査器には通るため、収支が閉じるだけでは検出できないA。

## B1：弱火の回収物を焼き直せない

対象：`charcoal.ts:29,67–73,201–203`。

最初から弱火、250分で `put_out`、360分で `open`。既存の検査にもある通常の失敗体験である。
回収物は `charcoal` **1,658,746 mg**、`x_wood_dry_ppm:969403`、`x_char_ppm:20347`、`x_ash_ppm:10248`。
最高温度256 °C、観察も「茶色い木のかけらのまま。ほとんど炭になっていない」。

**この回収ロットと、同じrunが返した薪をそのまま次のrunへ渡すと failed**。
入口は `firewood / coconut_shell / coconut_husk` だけを受け付けるため、ほんの少し分解しただけで焼き直せなくなる。
「分解0なら薪として返して再投入できる」という現在の検査は、こちらを通らない。

未反応の木と既にできた炭を保持した回収物を再処理できるようにしてほしい。
全量を新しい木へ付け替えると、炭成分を木へ戻すので不可。混合物として読むか、未完成部分を識別して返す等、成分を保つ設計にする。
実際の弱火回収物 → 再投入 → 炭化が進む、までの回帰が必要。
FAOの操作手引きにも未炭化の木を次の仕込みへ戻す記述があり、再挑戦は不自然な端の操作ではない。

診断：`findings.B1`。

## B2：持ち越しの共通丸め — 小さな試験片でも焼成へ進めない

対象：`src/science/step/common.ts:166–194`、特に成分mgの個別四捨五入とppmへの個別四捨五入。
詳細・独立した再現条件は [共通丸めレビュー](CODEX_TILE_ROUNDING_REVIEW_5555989.md)。

45.001 gの `prepared_clay`、水分20%、乾燥分のカオリナイトと石英が各500,000 ppm。
**成形 → 120時間乾燥**は成功し、36,773 mgの乾燥試験片が返る。
ところが焼成で、水772 mgを引いた乾燥分36,001 mgの半分ずつを各18,001 mgへ丸め、合計36,002 mgとして拒否する。
45.000 gの対照は焼成まで成功する。大きな試験片では、焼成自身が書いた組成を浸漬が読めない例も確認した。

成分合計を保つ読み書きと、成形・乾燥・焼成・浸漬の出力を再投入する回帰が必要。
既存の検査は余りの不活性成分が十分ある組成なので、丸め超過を吸収してしまう。
本体へ統合済みの共通処理なので、炭の修正とは別の小さな変更として扱える。

## C1・C2：ホストからの不整合入力（非保留）

**C1** — `charcoal.ts:89–99`。
前回のヤシ油C1と同じ形が、新しい炭工程にもある。1時間後、停止通知なしで設備を空にするか、別ID・熱の取り分0の器へ差し替えても、保存した設備値でrunningになる。
これはホストが予約を破り、正しい喪失通知を送らない条件なので、合意どおりC。
「継続時は設備ID・指紋を検査する」か「本体が予約の不変性を保証する」かを、ヤシ油も含めて整理してほしい。
正しい `equipment-lost` では保存値で `interval.to` まで計算する現設計を維持する。この経路は今回もoperator停止と一致した。

**C2** — `charcoal.ts:67–73`。
2 kgと1 kgの薪を**両方とも同じ壺内**に置いても、先頭を詰めもの、残りを外で燃やす薪として受け付ける。
配列順を逆にすると、標準の操作列で炭が990,705 → 337,069 mgに変わる。
外の燃料がない不正配置なので、通常の有効入力の非決定性とは区別しCとする。
詰めものがちょうど1つ、燃料のlocationがその器以外、を検査して拒否できる。
**有効な「1つは壺内、1つは外」の配列順入れ替えは完全一致**した。

locationをequipmentIdで表す方式自体は、文字列の所在を使う現契約の範囲で成立する。
本体側も器を所在として解決できること、予約時に詰めものを実際にその所在へ置くことが前提。
二重の壺を1設備としているので、受け壺の液体も同じ所在へ返す現在の集約を本体の在庫表示へ引き継ぐ。

## 通った検証と、その限界

- 科学側：炭28・既存回帰108・試験片の一周16、すべて成功。型検査成功。
  Viteビルド・OGページ・journalページ生成も成功。
  `npm run build` はVite後のtsx CLIが、この環境のIPCソケット禁止で止まるため、後処理を `node --import tsx --import ./scripts/node-assets.mjs` で実行した。ソース変更なし。
- 追加の炭診断は **479,415呼出し、validateResult違反0**。共通丸め診断の結果も検査器違反0。
- 詰めもの1 / 2 / 7 / 100 / 45,000 / 2,000,000 mg、水分0 / 15 / 100%、終了1 ms / 2時間の36条件で、
  `消費 + drawn O2 = 生成 + 放出` が整数mgで閉じた。整数J、`used = lost + stored`、終了時の累計stored=0、精算済み燃料からの熱の上限も通った。
  炭を含む熱の上限は、返却組成のppm量子化を含む保守的な上限。元素すべての厳密一致を保証する検査とはしない。
- 燃料水分0 / 15 / 50 / 95 / 100%でも総質量は閉じ、95 / 100%では使用熱0。
- `CH0.4O0.09 + 1.055 O2 → CO2 + 0.2 H2O` の係数は釣り合う。
  炭1 / 2 / 7 / 17 / 346,604 / 1,000,000 mgの燃焼では総mgが閉じ、C/H/O各元素の丸め差は1 mg未満。
  **熱分解ガス・木タールはformulaがnullなので、熱分解全体は総質量の保証であり、元素収支を検証済みとは言えない。**
- 最初の60秒はstored **+68,328 J**。2時間から消火して10分冷却する区間は **−556,900 J**、追加used=0。終了時は残った顕熱を精算する。
- `look` を17.013秒＋毎分で追加しても物理結果は同一。住人向け観察に温度等の数値は渡さない。A1の誤った言葉は別問題。
- 30秒・10分・1時間・0.25秒の要求は、開始1007 ms、格子外の火力変更を含めても最終状態・精算・累計Jまで同一。
  JSONで状態を往復しても同じ。world-pause後に同じ島時計で継続する場合も一致。
- `clock:island` と単一の `scienceStep` 入口への登録を確認。科学側は世界時計との換算をしていない。
  本体は区間・操作・気象の時刻を同じ島時計で送る。島時刻6時間を現実の6時間と表示しない。
- 詰めもの・燃料のいずれかが不完全なら、炭・タール・木酢液も `history_complete:0`。

## 本物らしさと資料の照合

本文を取得できた4件を `data/science/sources.json` に追記した。既存24件は変更なし。
保存したのは必要な事実の転記JSON。SHA-256は**転記JSONのハッシュ**で、原典HTML/PDFのバイト列のハッシュではない。
全件 `calibrationEligible:false`。資料の条件とゲームの二重壺の条件が違うため、モデル定数の置換はしていない。

| 資料 | 確認できた範囲 |
|---|---|
| [FAO Industrial charcoal making (1985), ch.2](https://www.fao.org/4/x5555e/x5555e03.htm) | 低温の炭と十分炭化した炭では収率が違う。乾燥木基準で約400 °C以下の42%、500 °Cの33%という記述。外熱式の工程全体を比べるときは外で燃やす木も分母に入れる。 |
| [FAO Simple technologies (1983・1987再版), ch.7](https://www.fao.org/4/x5328e/x5328e08.htm) | 白い煙から青・透明へ進む、冷却前の開放で燃える、未炭化の木は再投入する、という操作の筋。煉瓦窯の手引きであり、小壺の温度閾値・所要時間の校正ではない。 |
| [Browne & Brenden, USDA FPL 19 (1964)](https://www.govinfo.gov/content/pkg/GOVPUB-A13-PURL-gpo186517/pdf/GOVPUB-A13-PURL-gpo186517.pdf) | 松の試料、窒素中の熱分解、熱量計による実験を本文で確認。分解熱を省く説明は燃焼エネルギーの差し引き計算の近似。瞬間の反応熱が0という測定ではない。 |
| [Zhang et al., BioResources (2015)](https://bioresources.cnr.ncsu.edu/resources/preparation-and-characteristics-of-biomass-char/) | 主に松のおがくず、粒径>1.2 mm、密閉るつぼ・マッフル炉、昇温10 °C/min。本文の600 °Cで21.11%、900 °Cで16.73%を確認。分母は原料質量、初期水分約5%。ログ状の薪・壺へそのまま当てはめない。 |

**約4割は、低温で揮発分を多く残す炭なら桁としてありうる。しかし「標準壺で確認済みの収率」ではない。**
標準結果は炭ロット678.506 g（灰17 gを含む）。詰めた木の無水質量1.700 kgを分母にすれば **39.91%**。
外で実際に使った薪2.666667 kgの無水分2.266667 kgも含むと、全工程では **17.10%**。
予約した12 kg全部を消費した扱いにしない。炭成分のみ／灰込み、無灰乾燥木／灰込み乾燥木も混ぜない。
この区別をせず、伝統的な窯より高効率な装置だと説明するのは避けたい。

現在の収率が高めに残る原因も追えた。
中火200分で消火した場合の最高486 °Cと、そこからさらに強火200分を加えた最高947 °Cとで、
炭 **678,506 mg**、回収タール **121,175 mg**、木酢液 **201,959 mg** は同一になる。
`charYield(tMid)` が効くのは木が最初に分解するときだけで、生成済みの炭はその後さらに加熱しても揮発分を失わないため。
この仮定では、形成温度と最高到達温度を同じ意味に使えない。
今の未校正モデルに追加の精度要件を押し付けて保留を増やすものではないが、**二次的な脱揮発も省いている**ことを手順書に明記してほしい。
今後温度と炭の質・量の関係を研究させるなら、今回取得した実験条件に合わせた比較と、この部分の見直しを先に行う。

分解熱0は試作の近似として明示されている。J台帳が閉じることと、温度曲線の正しさは別。
USDA資料で「燃焼熱に比べて小さい」ことから省くのは、燃焼生成物の熱量を推算する場面である。
外から器へ届く熱は燃料全体の一部なので、その議論だけで分解中の温度・所要時間への影響まで小さいとは言えない。
今後の校正では、発熱・吸熱の段階、温度分布、木の太さ、タールの二次反応を分けて検討する。

煙の白→青という筋と、熱いうちの開放で損失が起こる筋は手引きに合う。
黄色の段階、300 °Cでの着火、一度の開放で20〜60%燃える式までは照合できていない。
火力が高いほど際限なく温度が上がる線形UAと、壺が割れない前提も試験器の仮定。
標準の中火は器への正味入熱が約1.15 kW、UAによる平衡温度が約488 °Cとなるため、486 °C近くまで上がる計算上の理由は説明できる。
冷却の終盤は時定数が約31分なので数時間待つ設計にも内部の整合性はあるが、実器で検証した時間ではない。
時間や炭の量が実体験と合わなければ、熱の取り分・UAだけで合わせず、二次脱揮発と試料の太さ・含水率を先に切り分けたい。

探索したUSDA FPL 82の配信先には到達できず、別のFPL 19を公的保存先で取得した。両者は取り違えていない。
熱帯材4種の研究（DOI `10.1007/s13399-024-05366-y`）は今回、再利用できる実験本文・数表を取得できた資料に数えていない。
原料・装置をそろえた二重壺の反復時系列、液体回収率、炭着火・消失速度の校正データは未取得。
