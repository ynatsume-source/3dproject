# 手作業の殻：完了記録の上限

手作業の科学モデルと30秒の確定方法は変えない。
完了・片付けの決着後、実行中の台帳 runs から作業を外す。
manualHuskRecords（civ-world.manual-husk-records/1）には直近64件の結果・観察・
開始要求の一致確認だけを残し、全フレームや科学モデルの確認区間は残さない。
完了した作業の区間の再送は直近64件の正確な要求を比較する。
保管窓から外れたものは未知・期限切れとして拒否し、精算をやり直さない。
材料ロット・予約の解放・IDの連番はこの圧縮で変えない。

段取りは civ-world.manual-husk-arrangement/3。
jobs は進行中だけ、finished と receipts はそれぞれ直近64件。
古い記録を落とした時刻を持ち、過去の意図を新しい作業として受け付けない。
作業場と住人の観察は完了要約からも従来の感覚・事実だけを返す。
古い /2 の段取りは全証拠を旧規則で確かめた後に変換する。
科学側の作業状態 /2 は同じ形のまま。予約中の作業・端数・交代は保持する。

専用検査は manual-husk-records-check。
旧 /2 の進行中・完了保存の変換、再送、改変・名前だけの版変更の拒否、
300回の決着後の64件上限と保存量の頭打ちを検査する。
物として増えた繊維・殻・水は在庫なので、保存量測定では別に除く。
進行中の未完作業の在席・交代・手仕事の証拠はここでは圧縮しない。
