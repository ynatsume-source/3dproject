# 縄・帆の作業場：終了記録の検査を読み取り間で再利用する

科学班の島の通し検査 `soak/2026-10-21-island-3d3e78f/prof78-summary.txt` では、
住人の update の25.9%が `readCordWorksite`、4.4%が `readSailWorksite` だった。
どちらも表示を読むたびに、上限64件の終了記録を全件検査していた。
基準は main `3d3e78fb4fadeab3bf22ddc70c55f031df8ff2da`。

## 再利用するもの

読み取り専用のキャッシュに、終了記録と受領控えを検査した印だけを持つ。
表示の言葉、作業の進み、在席、時刻ごとの表示結果はキャッシュしない。
WeakMapは保存JSONに含まれず、工程版・状態版・保存形式・科学モデルも変えない。

台帳そのもの、段取りのオブジェクト、世界IDとepoch、段取りのrevision・確認時刻・失効下限、
配列の参照・長さ・各行の参照を照合する。変われば全件を検査し直す。
各行の参照比較は上限64件の軽い比較で、本文の検査やハッシュ計算ではない。
世界全体のworldVersionを無効化の条件にはしない。
別の正規の取引が段取り全体を複製して差し替えた場合も、初回の読み取りで検査し直す。

## 残す検査と所有の境界

書き込みと保存からの復帰は、従来の全件検査を通す。
新しいLedgerは、同じ段取りの参照を持っていても検査済みとはみなさない。
全件検査で失敗した印は再利用しない。

進行中の状態・予約材料の指紋を引き続き検査する。
縄では操作の確認時刻・受領控えとの対応・担当者と作業場の二重予約の検査も残す。
選んだ終了記録は表示を返す前に検査し、縄ではそのチェックサムも確かめる。
返す表示は従来どおりコピーで、呼び出し元の編集を保存や次の表示へ持ち込まない。

終了記録の本文は世界側が所有する確定済みの履歴であり、外部の保存JSONや呼び出し元が
作業中の台帳へ本文だけを直接上書きする入口は設けない。
外部の保存は復帰入口か新しいLedgerで読む。
本文を変更する正式な処理を追加する場合は、段取りの版や参照も更新して検査を通す必要がある。

## 検査

既存の `coir-cord-work-check` と `sail-work-check` に回帰検査を足す。
実際の工程で64件の終了記録を作り、繰り返した読み取りが無関係な本文へ触れないことを
アクセス回数で確かめる。機械の負荷に依存する厳しいms上限は追加しない。

冷たい読み取りと温まった読み取りの表示、読んだ前後のJSON、時刻が1msずれた作業中表示、
返した表示を編集した場合、保存復帰、状態・材料・終了記録の破損、キャッシュを無効化する
変更を確認する。既存の収支・分割・保存・再送の検査もそのまま残す。
