# 乾かしたヤシ殻繊維から灯芯へ：水・髄の扱い案

2026-10-15。**科学班の判断待ち。未実装**。PR20・PR21の隔離モデルの受入と、灯芯の科学仕様・本体接続・住人運用は分ける。

## 現状の問題

PR20の標準殻からの束は繊維乾物72,000 mg・付着髄乾物14,400 mg・水115,200 mg。PR21の乾燥と篩い後は繊維72,000・髄7,200・水7,920 mg、合計87,120 mgである。乾物の10%の水が残り、水0の芯ではない。

mainの `src/robots/residents.ts` のmakeWickは汎用coconut_huskから同じ湿重量のlamp_wickへ改名し、水と髄を読まない。`src/science/step/oil-lamp.ts` のp40xは芯全量を乾燥木相当として燃やす。

新しい束をこのまま流すと、水も燃える乾物になる。真の乾物79,200 mgではなく87,120 mgを燃やすため、**芯由来**の燃焼量・熱を約10%過大計上する。油を含む灯り全体の発熱が10%増えるという比較ではない。残水を黙って消す処理にもできない。

## 推奨案

芯も繊維乾物・付着髄乾物・水を別の非負整数mgで持つ。束から芯と余りへ各成分を保存して切り分け、量・組成は世界の内部値とする。住人は見た目・手ざわりと、実際の秤量で得た重さだけを知る。

p40xの工程版と保存状態の版を上げ、次を保証する案：

- 燃えるのは繊維と髄の乾物だけ。O2・CO2・発熱はその乾物から計算する。
- 最初の範囲は、篩い後の束（髄が繊維乾物の10%以下）とする。
- 髄を乾燥木と同じ反応・発熱で扱うなら、明示的な「仮定（キメ値）」とする。実測した燃焼性という主張はしない。
- 水は独立に保持し、蒸発分だけwater_vapourを空気へ記帳する。水を燃料や燃焼で生成した水へ数えない。
- 蒸発の熱を計上する場合、同じ熱を放熱と蒸発に二重に支出しない。
- 残る芯・切った先にも三成分を残し、次runでそのまま読める。返却時に新品の乾いた芯へ戻さない。
- 既存の乾いた芯は水0として読み、同条件の結果が変わらないことを比較する。旧runを新しい版へ付け替えず、中止・予約解放か旧版保持を別途決める。

## 科学班に決めてもらいたいこと

以下は選択肢であり、今回係数や閾値を勝手に確定しない。

| 項目 | 候補 | 判断する内容 |
|---|---|---|
| 水を飛ばす段階 | 点火前に火のそばで乾かす／点火後に芯先で飛ばす | 最初の成果に含める範囲 |
| 蒸発の熱 | 既存の水の蒸発潜熱／灯芯向けの有効熱というキメ値 | 温度・顕熱・潜熱の範囲。資料値の利用は芯の実測校正とは呼ばない |
| 速度 | 熱の供給で制限／燃える芯の進みに比例／事前乾燥の待ち時間を固定 | 速度係数・時間、途中の水をどこに残すか |
| 点火 | 乾物比10%まで点火可／湿りの閾値／事前乾燥必須 | 火が育たない・弱い等の扱いと言葉 |
| 髄 | v1は乾燥木相当だけ／吸油・すす・焦げにも影響 | 最初にどこまで扱うか。係数はキメ値の版で固定 |

p40xを変えない代案は、別の明示的な工程で残水を0まで飛ばしてから乾いた芯を作ること。ただし屋根下3日の乾燥では0にならない。放出水と必要な手間・熱を記帳し、同量改名で済ませない。
