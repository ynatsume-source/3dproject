このモデルでは加熱中の蒸発、保持中の追加放熱、平衡含水率、収縮・割れ・焼結・鉱物反応を省略する。
自由水ゼロはモデル上の終点であり、現実の「完全乾燥」「焼成可能」「耐火」「防水」を認定しない。
全エネルギーが足りることと、現実にその時間で乾くことは別の検証である。

## 材料・熱の収支

乾燥は化学反応式を置かず、混合物中の自由水の移動として扱う。固体の質量は不変。

- 初期自由水 = 残る自由水 + 大気へ出た水蒸気（整数mg）
- 熱源からの使用 = 試料内の顕熱 + 蒸気の持ち出すエンタルピー + 変換損失 + 冷却による放熱
- 蒸気の持ち出す量 = 蒸発の潜熱 + 20°C基準で加熱済みの水が持っていた顕熱
- 成形の機械仕事・秤の電力は、このfixtureでは最終的に周囲へ散逸する熱として記帳

蒸発で試料の熱容量が減る分を持ち出し側にも入れ、顕熱を消したり二重計上したりしない。
源の出力上限と有限のJ、温度上限、実際の時間のすべてを検査する。熱量はアイテムへ生成しない。

手計算の対照：100 gの模擬固体と20 gの自由水を20→60°Cに上げて蒸発させると、
`[(0.1×800 + 0.02×4186)×40 + 0.02×2340000] / 0.8 = 66,686 J`。
試験の乾燥工程はこれと一致し、その後3,200 Jの顕熱を冷却して戻す。
