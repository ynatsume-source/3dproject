## A1：sealは実際に計算した時刻までのものだけ適用する

対象：101行、107行、130–136行。`req.actions.length` だけで、時間を進める前に `d.seal=true` にしている。

器600 g＋タール15 g、20 Wの均等な申し出、`[0, 1時間)` に20分時点のsealを置く。
15分で完了した返却物は `sealed:1, coverage_ppm:421361, air_leak_tau_min:207`。
同じ供給を15分までで区切ると、その時点ではsealはまだなく、
`sealed:0, coverage_ppm:559839, air_leak_tau_min:0` で完了する。どちらも手の仕事は13,500 J。
将来の操作が5 gの塗布先と完成品を変えている。検査器は両方を通す。

`endAt` までに実行された操作だけを適用し、区間の終端と同時の操作の規則もそろえる。
完了後の操作を持つ大きな要求／完了直前・直後で分ける要求を回帰にする。
`seal` が時刻付き操作ではなく開始時のレシピ選択なら、actionsとは別の契約にする必要がある。

## A3：回収した湿った器は、自由水がなくても乾ける必要がある

対象：214行、224–225行、243–247行、272–274行。

既存と同じ3日試験から返った器をそのまま次のrunへ渡す。
読み戻した壁の水は71,999 mg。水ロットを追加せず、33 °C・RH40%・風2 m/s・日なたに7日置くと、
蒸気0 mg・環境熱0 J。壁水は内部では全く減らず、返却ppmをもう一度読むと71,998 mgになるだけ。
その1 mgは乾燥ではなく、組成の丸めで素地へ移った分である。6日目の言葉は「外側は乾いている」。

原因は全蒸発が `waterIn>0` の内側にあり、`wall` を減らす経路がないこと。
精算も `max(0,wallAdded)` で増加しか許さない。水を全部捨てて器を乾かす、という普通の連鎖が成立しない。
外側の乾きと内部含水は本来別だが、現在はその区別のモデルもなく、単に自由水0で乾いたと言っている。

壁の水→外気への蒸発と潜熱、壁への補給を扱い、初期の壁水も含めて精算する。
湿った返却器→水なしで乾燥→再度注水、の連鎖でmg・J・観察を検査してほしい。
既存の再利用検査は毎回新しい水450 gを足すため、吸った水が乾く経路を試していない。

## A4：submergeはlookとは異なり、試料に作用する試験

対象：227–230行。現在は気密性の内部値を、泡の文章に直接変換している。

- 開いた乾いた器だけを渡してsubmergeすると「口から空気が出て、水が入ってくる」。
  返る器は依然600,000 mg・水0 mg、自由水もなく、周囲からの取り込みも0。
- 栓だけした器の0・24・48時間のsubmergeは、いずれも「細かい泡が続けて出る」。
  空気量、内外圧、浸す深さ・時間、水の侵入、試験による変化は状態にない。

## air_leak_tau_min の接続定義案

これは次の自作気圧計に向けた提案。現在の基準2時間が実測で裏付けられたという意味ではない。

**一定温度・一定容積・一定外気圧の閉じた器で、小さい圧力差ΔPが初期値の1/eになる時間**と定義する。
完全な空気の入れ替わり時間、温度が追いつく時間、泡が止まる時間とは区別する。
基準はオーナー決定の500 mL、例えば28 °C、乾燥した壁、栓込み、と明示する。

線形の漏れを仮定すると、圧力差に対するモル流量係数Gについて、

```text
dn/dt = −G (Pb − Pa)                       [G: mol/(s Pa)]
G = Vref / (R Tref τref)                   [τrefは秒へ変換]
(Pa + 2ρg x)(V0 + A x) = n R Tb           [現行の釣り合い式の右辺をnで持つ]
```

とすればつながる。容積と温度が固定なら `dΔP/dt=−ΔP/τref` に戻る。
U字管では水柱が動いて容積も変わるため、目盛りxを単純に同じτで0へ戻す式とは一致しない。
固定Pa・Tbでも有効な圧力の容量は `V + Pb A/(2ρg)` となる。
温度由来の時定数 `bulbTauS` とは別名・別状態で扱う。

今の `airLeakTauMin` は容量・壁厚・湿りを引数に取らず、吸水率とcoverageだけで決まる。
吸水できる容量と気体の通りやすさは別の量なので、全素材共通の測定則にはできない。
当面500 mLの試験器専用の仮定として保持するのは可能。
係数を本体の隠れた物性として渡すことと、住人が測定でそれを知ることは分離する。
`sealed:0`の0は「利用不可」、分母の下限が作る最大1,200,000分は「完全気密」ではないことも換算表に書く。
