# A：殻と縄の交代・部分精算

対象はPR25の受入済み c923781ff876243dd60e2056d7eae2fd9e7952a7 からのAだけ。科学班が示したキメを実装する。B（非切断時のlotId維持と観察チャンネル）はこのcommitへ入れない。main・受入済みPR21/22/25のブランチ・src/robots・接続仕様・process-runner・PR20の科学中核/配分表は変更しない。隔離したDraftレビュー用であり、住人運用の承認ではない。

## 交代

殻はapplyHuskIntent、縄はapplyCordIntentにkind:takeoverを追加。新しいactorId・atWorldMs・presenceを渡す。stopまたは保存復帰で中断している作業だけを別の担当者が引き継げる。同じ担当者はresumeを使い、作業中は拒否する。屋根下乾燥は担当者を拘束しない待機なのでtakeoverを拒否する。

元のspecと入力は書き換えない。履歴は各担当者と交代時刻を残し、Run.operatorと現在の担当者だけを切り替える。交代後に前の担当者の区間を送っても実働へ加算しない。交代をまたぐ作業区間は本体が分ける。30秒未満の確認済み実働は物に付随する端数として次の担当者へ引き継ぐ。科学に渡す区間にも当時実際に作業した担当者を残す。

殻と縄をまたいで担当者の二重手作業・作業場の二重予約を検査する。引き継いだだけでは、前の担当者の手ざわりの知識を新しい担当者へ渡さない。元の担当者が戻った場合も、その担当期間に実作業の確認が必要。

## やめて片付ける

kind:abandonを追加。現在の担当者が中断中の作業にだけ使える。作業中なら先にstopする。意図が受け付けられると、確定済み30秒の累積だけで一度精算し、runはstopped、表示はabandoned、予約を解放する。同じ意図ID・内容の再送は変更なし、別の精算・再開・後続の新しい作業区間は拒否する。30秒未満の端数は生成量に使わず、監査用の事実は履歴へ残す。

- 殻：ほぐれた繊維束、残りのpartially_separated_coconut_husk、husk_drainage_waterを返す。端数しかなくても新品の殻へ戻さず、既存の入口へ新品として再投入できない。
- 振るう：その時点で落ちたcoir_pithと残りの繊維束を返す。
- 撚る：できた1mm以上の撚り糸と残りの繊維を返す。強さは元のrun開始時に決まった値を保ち、引継ぎや片付けで引き直さない。繊維のない髄だけの端はcoir_pithとして返す。
- 縒り合わせる：2mm以上の縄と各糸の残りを返す。糸の余りへ元の強さ・傷みを引き継ぐ。2mm未満の中間品はほどいて元の3本を全量返し、質量を消さない。この最小単位の扱いを明示的な実装上のキメとする。
- 乾燥：屋根から取り出した時点の水分の束を返し、確認済み区間で抜けた水だけをairへ記帳する。ロードや未報告の時間から水を抜かない。

途中までの品を返すのは、科学モデルの明示的なprojectForAbandon(state)だけ。通常のproject(state)はこれまでどおり途中のpiece/bundleを返さず、表示を在庫加算と取り違えない。projectForAbandonも在庫は変更せず、部分の進捗statusはpartialのまま。本体の終端transactionで既存commitを通じて消費・生成・予約解除する。整数で読み戻せない極端な入力は精算を拒否し、中断した材料を残す。

表示と観察は「途中までほぐした殻を脇に置いた」などの事実だけ。強さや配分、重量、時刻、次に作るための正解を返さない。Bで修正するtouch/sightの扱いは本commitでは未変更。
