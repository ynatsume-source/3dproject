## −60〜70 °C を保証の根拠にできるか

**「この工程が扱う世界の気温は、欠測中も −60〜70 °C の範囲内」という仕様なら、できる。**
気候についての経験則ではなく、モデルの適用範囲としての条件付き保証である。

器のモデルは `dT/dt=(Ta−T)/τ`。解は、直前の温度とその後の外気温の正の重み付き平均になる。
したがって、実際の `Ta` が区間内にあり、直前の器の温度が保存した幅に入っていれば、上下端をそれぞれ下限・上限へ緩和した幅は真のモデル温度を含む。
`AIR_RANGE_C` を既知気温の判定と未知区間の緩和で共有する今回の変更は、この前提と整合する。

ただし、**入力の範囲検査だけで、欠測中の現実の気温まで保証したことにはならない**。
本体の説明は「適用範囲内での包含保証」とする。範囲外の実測値を `unknown` に置き換えるだけでこの保証を延長しない。
適用範囲外と判明した run は、適用範囲内の計測として扱わず、置き直すか対象範囲を改版する。この点は適用条件の申し送りであり、今回の範囲内での反例や新しい統合保留ではない。
実測が保存されている区間は、その記録を送る。欠測を推測値で埋める必要はない。
