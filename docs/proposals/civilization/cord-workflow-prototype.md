# 縄づくり：暮らしと並行する工程案と隔離試作

2026-10-14。最初の設計レビュー用。公開・main統合・未校正モデルの本番採用はしない。

## 推奨する体験

「浸けた住人を、その場に長時間立たせない」。容器・材料は作業場に残り、住人は食事、採集、別の研究へ移れる。戻ったときに何をしていたか分かり、手作業は一束ずつ続けられる。見せるために自然の処理を完了扱いにしない。

```mermaid
flowchart LR
  A[副産物の殻を用意] --> B[容器で浸す・住人は別の暮らしへ]
  B --> C[戻って取り出し確認]
  C --> D[小束を叩き・ほぐす]
  D --> E[洗浄・選別して乾かす・住人は解放]
  E --> F[小束を撚り、継ぎ足す]
  F --> G[試験して使える縄を確認]
  G --> H[道具の柄の結束・建物の結び目に現れる]
```

Cで未分離なら条件を見直す。Eは乾燥の科学結果と実際の観察で判断する。F/Gで強度・長さが不足すれば未完成の束として残す。最後の結び目は、使用した縄のlotと量が確定した後の派生表示にする。既製品を置いて成功扱いにはしない。

最初に見せる用途の推奨は**道具の柄の結束見本**。使った縄が画面で読み取れ、現在の建築を止めずに比較できる。これは次段階の見本の提案であり、今回その道具や縄を生成していない。

## 根拠と5項目の推奨

一次の事業報告として[FAO/CFC Coir Processing Technologies §3.1](https://www.fao.org/4/y3612e/y3612e04.htm)と[同事業の序文](https://www.fao.org/4/y3612e/y3612e01.htm)を2026-10-14に確認した。前者は浸漬後の叩き出し、洗浄・乾燥等を説明し、短い処理例を機械・特定の生物処理と区別する。手作業で普遍的に短時間で済むという根拠にはならない。資料は工程の分離を支持するために使い、速度・温度係数・収率・手作業時間の校正には使わない。

| 項目 | 推奨案 | 根拠・今回の境界 |
|---|---|---|
| 原料 | 最初は既存ミルク工程の`coconut_husk`一種類。一束ずつ扱い、後で成熟度・繊維品質を区別する | 既存副産物を活用できる。漂着殻の成熟度から白色繊維品質などを推定しない。アダンと同じ工程・同じ収率にしない |
| 水 | 次の比較対象は由来を追える雨水系の水を第一候補とする。使用水は加工用に予約し、飲用・他工程へ無条件返却しない | 現行台帳は一般的な`process_water`。海水、塩分、汚水の扱いが未定義なので海水可とは採択しない。今回もPR12の`unclassified-test-water`であり、清浄さを保証しない |
| 設備 | 定位置の浸漬容器・叩く台と道具・乾燥置場を分ける。待機中も容器と材料の予約は保持、住人だけ解放 | 作業場所を見失わず、同じ容器の二重利用を防ぐ。今回は既存の試験basinだけ。量保存とは別に、実容積・漏れ・道具摩耗の校正が必要 |
| 時間と分業 | 浸漬/乾燥は島時計、叩く/撚るは現実時計の独立した手作業工程。短い小束単位で手を離せる | 表示アニメーションは確定した仕事の進行を描く。再生速度・画面の閲覧回数は仕事量や自然処理を増やさない。短縮した自然時間は採択しない |
| 欠測と判定 | PR12の欠測時進行停止・履歴不完全を継続。画面は「確認予定」と「処理完了」を区別する | 予定時刻を過ぎても物理的な完成は保証しない。住人は自分の操作と実行済みの観察だけを覚える。内部温度・閾値・真の進捗を覚えない |

技術値をユーザーに決めてもらう段階ではない。上記で設計と隔離検証を進められる。将来、現実に即した処理が体験上長すぎると分かった時点で、自然時間自体を変える世界設定を望むのか、複数バッチと暮らしを並行して見せるのかだけを、実測の比較画面と理由付きで相談する。現時点では後者を推奨し、前者は採択しない。

## 作業・保存・並行性

`src/world/prototypes/cord-workflow.ts`の新しい隔離sessionは、既存Ledgerと小さな作業メタデータを一緒に保存する。単一writerへの単調なsequenceを要求し、同じ命令の再送・古い画面からの命令を拒否する。失敗した命令は複製上で破棄され、台帳・記憶は変わらない。

| 状態 | 住人 | 材料と設備 | 次の操作 |
|---|---|---|---|
| 浸して待つ | 解放。別の仕事を選べる | runが予約し続ける | 島時計で進行。設定した確認予定後に候補を出す |
| 確認候補 | 解放。自動的に住人を呼び戻さない | 予約継続 | 本人が作業を選んだ時だけ短いleaseを取る |
| 回収の手作業 | 1住人につき1つのlease。他の住人は別バッチを作業可能 | 予約継続 | 現実時計の小区間を積算。一区切りで自動解放 |
| 手作業の中断 | 即解放。積算した仕事は残す | 予約継続 | 同じ住人でも別の住人でも残りから再開 |
| 回収反映待ち | 解放 | 半開区間の次の科学更新で精算 | PR12の回収actionを保存。取消で先行回収を上書きしない |
| 回収済み | 解放 | 科学結果のlotを一度だけ台帳へ | 縄完成ではない。未分離の殻なら再検討、試験繊維なら次の未実装工程へ |
| 取りやめ | 解放 | PR12のoperator stopが返却・解放 | 次回は返却lotから新規run。失われた材料を補填しない |

- 住人の休息・別仕事への移動は**手作業のinterrupt**であり、自然に進む浸漬runのoperator stopではない。取りやめは別操作。
- `restoreCordSession`は保存済み手作業量を保ち、開いていたleaseを解放する。停止中に住人が働いていたと推定しない。未実行のlook予約は破棄し、不在中に見たことにしない。欠けた自然時間はunknown環境で送る。再開前の命令はsequence更新で無効化する。
- tickは確定世界時計の更新だけ。複数の手作業leaseがある場合、それぞれの実作業区間だけを積算する。一区切り終了後は、次のtickが遅くても追加の仕事を積まない。
- 科学には30秒セルごとの環境を渡す。既存advanceの400区間上限を複数回呼び、日以内の要求を追いつかせる。1回で1日を超える世界時間や上限超過は拒否する。より長い復帰には外部writerによる区切りが必要。
- 観察は明示look命令を科学が実行した時だけ記憶になる。準備・作業開始・中断は本人の行為の記録。作業終了の記録も「結果はまだ確認していない」であり、完成知識や天気の隠れた値を作らない。
- 試作は既存台帳の形式を持つJSONを前提に、自身のplan/lease/sequence等を検査する。一般の不正Ledger全体を検証する新しい保存移行器ではない。実ユーザーの保存には触れない。

## 読み取り専用の表示案と具体例

`projectCordWorkflow`は保存済みの公開用メタデータだけを値として返す。時計を読まず、物理計算も`sense`/`optionsFor`も呼ばず、観察や記憶を追加しない。真の有効時間・温度・品質・完成閾値を返さない。環境記録の取得状況だけはworld側の運用情報として保持し、欠測があれば視聴者には「環境記録が不足（完了保証なし）」と表示する。これを住人の観察記憶には渡さない。住人用入力とは分け、`cordResidentMemory`は本人に紐づく行為と実行済み観察だけを返す。

画面の一例：

> **浸して待つ**　担当者は別の暮らしへ移れる  
> 確認予定まで：島時計の目安／試験計画、完成保証なし  
> 容器と殻はこの場所で予約中

> **回収の手作業を中断**　担当者は解放済み  
> 残りの手作業：試験用の仕事量／現実時計  
> 次：小分けで再開。続きの材料は残っている

> **回収済み・縄は未完成**  
> 試験繊維なら「乾燥・撚りは未実装」  
> 殻が返ったなら「未分離で戻った。条件を見直す」

実行検査の例（現実の工程速度ではない）：浸漬の確認予定と有効時間に島時計60秒、回収の仕事に現実時計12秒、最大作業単位に5秒を置く。2秒働いて中断し、100秒後に保存復元しても仕事は2秒のまま。5秒＋5秒の再開で12秒となり、PR12に回収を要求する。**100秒の不在もアニメーションの再生も手作業を進めない**。欠測しかなかった別例では同じ作業をしても繊維を作れず、殻が戻る。

上記の仕事量はスケジューリングの試験値で、叩き出しの仕事率・必要エネルギー・収率を校正したものではない。PR12の回収も未モデル化の試験分離のまま。新たな叩き工程、乾燥工程、撚り工程、縄の長さ・強度・消費を実装したとは扱わない。

将来の表示は「今の工程／次の確認予定（時計の区別付き）／手を離せる状態／停止理由／次工程」の5点を常時読めるようにする。束のほぐれ・撚り・結び目は、後に科学または確定作業が供給する可視形状状態を描く。今回3Dモデルやアニメーションは変更していない。

## 検証と次の最小ステップ

未検証：科学的校正、実住人の選択・移動・休息との接続、作業場の3D表示、視聴者の離脱・理解度、縄の長さ/強度、乾燥・叩き/撚りの科学モデル、既存建物への材料消費、設備消失時の実行役との全面接続。これらは本番で動いたとは報告しない。
