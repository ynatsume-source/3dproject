## A1 — 火がつかなかった試験片を「焼成品」に変えてしまい、再挑戦もできない

影響 **A（世界の材料状態が事実と違う）**。
該当: `src/science/step/wood-fire.ts:144,160,185–186`、呼び出される `kiln-ware.ts` の `const fired = o.done || d.maxWareC > 300`。

今回追加した `wont_burn` が `cool → done` となり、`settleWare` に `done:true` を渡すと、
試行が終了しただけで材料が `test_tile_fired`（カタログでは「焼成した試験片」）になります。

再現は通常の30秒区間です。標準の試験片37,037 mg・試験用薪窯・28°C・通常の橙の計画を使い、
薪60 kgの `water_ppm` を950000にします。`stop` は渡しません。

| 観測項目 | 451ea82 の結果 |
|---|---|
| 入力試験片 | `test_tile_dry` |
| 区間 / 結果 | `[0,30000) ms` / `completed`, `outcome:wont_burn` |
| 薪の燃焼 / エネルギー | 0 mg / `energy:[]` |
| 試験片の最高温度 / 焼結 | 28°C / 0 |
| 出力試験片 | `test_tile_fired`, 37,035 mg |
| 検査器 | 違反0 |
| 返却試験片＋通常の乾いた薪で新規run | `failed: expected one unfired test tile lot and one firewood lot` |

水だけ・灰だけの入力でも同じ結果です。質量の2 mg差そのものは今回の指摘ではなく、未焼成品を焼成品に分類する点を指摘しています。
1 ms停止の理論上の端ではなく、新しく設けた「火が育たなかった」の通常終了で起こります。

**修正依頼:** `wont_burn` で加熱していない試験片は未焼成の材料種を保ち、返却品を新しい薪で再試行できるようにしてください。
`completed` が「試行の終了」を表すこと自体は問題ありません。試行の終了と材料の焼成を分けてください。
既存の `fire(q)` 回帰は薪の返却量・熱・観察だけを確認しているため、
**返却試験片の材料種 → その試験片と新しい薪による再試行**まで検査をつなぐと、この不具合を検出できます。

## C1 — 薪専用検査の工程版の追随漏れ（非阻止）

影響 **C（今回の統合を止めない検査保守）**。

本体の工程実行の例外としては扱いません。

一時コピーで工程版だけを0.1.3へ変更した場合は32件成功しました（コピー先に合わせたimportの絶対パス化を含む）。
次の全面レビュー向けの検査保守として、工程版の更新と失敗結果を扱う箇所の保守を記録します。lab側では元ファイルを編集していません。
