# 設計案：器を形づくり、乾かし、焼く（鍋・桶・灯皿・二重の壺）

2026-10-07 / ブランチ `codex/civilization-simulation` / **相談用の設計案**（実装の前に、オーナーと本体に決めてほしいことがある）

本体の依頼（science-requests-2026-10-06.md の1・2）への答え。いま島で工程が動かないのは、桶・鍋・二重の壺がすべて「試験用の既製品」だから。住人が自分で器を作れるようにして、試験用の道具を置き換える。
技術の地図では「成形・乾燥・素焼き」は初点灯に**致命的**（器・るつぼ・窯のもと）。ここが島の科学の本当の入口になる。

## 1. 住人に見えること

| 試すこと | 住人に見えること | 世界の中で起きていること |
|---|---|---|
| 粘土を紐にして積み、器の形にする | 手の跡、厚い・薄い | 壁の厚さと大きさが決まる。厚いほど丈夫だが、乾きにくく割れやすい |
| 日陰でゆっくり乾かす | 色が薄くなる、軽くなる、縁から乾く | 縁と底で乾き方が違う。日なた・風で急ぐと、縁にひびが入る |
| 焚き火の脇であぶってから焼く（野焼き） | 煙が白い → 透明、器が赤くなる | 残った水が抜ける。あぶらずに火に入れると、水が蒸気になって器がはじける |
| 薪で囲んで焼き、灰の中でゆっくり冷ます | 叩くと高い音／鈍い音、ひび | 600〜800 °C で素焼きになる。風で片側だけ熱いと割れる。急に冷やすと割れる |
| 砂や貝殻の粉を混ぜる | 割れにくくなる。貝殻は、焼いた後に白い粒がはじけることがある | 混ぜ物が割れを止める。貝殻（炭酸カルシウム）は熱で生石灰になり、後で水を吸ってふくらむ（考古学で知られた現象） |
| 湿った薪で焼く | 煙ばかりで赤くならない | 生木は燃えても温度が上がらない（今の焚き火の式に足す） |

## 2. 工程の案（3つ、1つの run は1つの時計）

```
prepared_clay（＋任意で砂・貝殻の粉）
  → p11y 器を形づくる（世界の時計・手の仕事）→ green_pot（形・大きさ・壁の厚さ）
  → p12y 器を乾かす（島の時計・待つ）→ dry_pot（割れの有無）
  → p13y 野焼きで焼く（島の時計・火の番）→ fired_pot（吸水率・焼き締まり・ひび） ／ 割れたら pot_sherds
  → 本体が組み立て（換算表）→ 鍋・桶・灯皿・二重の壺の設備
```

- **p11y 器を形づくる**：`prepared_clay` から、`shape`（鍋・桶・灯皿・壺）と容量を指定して作る。壁の厚さは大きさから標準値を決め、指定もできる。紐積みの手間は質量に比例。今の `p11_pottery_shape`（試験用、既製の台）は残す。
- **p12y 器を乾かす**：試験片の乾燥（p12x、統合済み）の式を、器の形（壁の厚さ・縁と底）に広げる。厚い器ほど割れやすい仕組みは同じ。湿った器はつぶれる・持てないので、「革のかたさ」までは動かせない、などの言葉も試験片と同じ。
- **p13y 野焼きで焼く**：薪で焼く工程（p13w、統合済み）と、焼き物の物理（`kiln-ware.ts`：壁の厚さに応じた温度の遅れ、蒸気の破裂、冷めるときの割れ、焼き締まり）を、器に使う。野焼き特有のこととして、風による片焼け、火の勢いのむら、生木で温度が上がらないこと、を足す。割れて分かれた器は、元と同じ質量の `pot_sherds` になる（破片の quality は確認済みの `potSherdsQuality` と同じ形）。

## 3. 決めてほしいこと

### ① 焼き方（オーナー）

| 案 | 中身 | よいところ | 気になるところ |
|---|---|---|---|
| **A（おすすめ）野焼きから** | 地面で器を薪で囲んで焼く。600〜800 °C、焼き締まりは弱い（吸水 10〜15%） | 島の今の道具（焚き火・薪）だけで始められる。世界中の最初の土器と同じ | 割れやすく、焼きむらがある。高い温度は出ない |
| B 窯から | 粘土と石で囲った窯を先に作る | 割れにくく、温度も上がる | 窯そのものを作るのに器と同じ技術が要る（順番が逆） |

おすすめは **A → 後で窯**（技術の地図の「窯（1000 °C を超える）」は金属とガラスに必要なので、別の段階で作る）。

### ② 難しさ（オーナー）

本物の最初の野焼きは、かなりの割合で割れる。住人が覚えるべき工夫は、どれも観察から気づける：よく乾かす、あぶってから焼く、風のない日を選ぶ、灰の中でゆっくり冷ます、砂を混ぜる。

| 案 | 最初の器が割れる割合の目安（工夫なし → 工夫あり） |
|---|---|
| **A（おすすめ）本物に近い** | 半分近く → 1割ほど。工夫を覚える過程が見どころになる |
| B やさしめ | 2割ほど → ほぼ割れない |

### ③ 形と大きさ（オーナー・本体）

| 器 | 容量の案 | 壁の厚さ | 置き換える試験用の道具 |
|---|---|---|---|
| 鍋 | 3〜5 L | 7〜9 mm | `fixture_cook_pot`（ヤシ油を煮る） |
| 灯皿 | 50〜100 mL | 6 mm | （油の灯り、これから） |
| 壺（二重の壺の上下、気密の器） | 0.5〜8 L | 8〜10 mm | `fixture_tar_retort`、`fired_pot_test` |
| 桶 | 20〜40 L | 12〜15 mm | `fixture_clay_tub`（粘土を浸す） |

**桶だけ相談**：40 L の焼き物は、野焼きでは大きすぎて割れやすい（本物でも大きな甕は難しい）。代わりに、**地面に掘った穴を粘土で塗り固めた「粘土の池」**（焼かない）や、竹で編んで粘土で目止めした桶もありうる。おすすめは「最初は粘土の池、後で大きな甕」。

### ④ 名前と、気密の器とのつながり（本体と科学）

- 焼いた器の材料名を `fired_pot`（形 `shape`・容量・壁の厚さ・吸水率を持つ）にし、試験用の `fired_pot_test` と同じ quality の鍵をそろえる。気密の器（p16x・p17x）と組み立ての換算表が、どちらも読めるようにする（版を上げる）。
- 換算表は器の組み立てと同じ形で、**形ごとに設備の値を出す**：

| 設備 | 焼いた器から決める値（式は仮定） |
|---|---|
| 鍋 | 容量、熱容量（質量 × 0.85 J/(g K)）、熱の逃げ（表面積から）、火の熱が鍋に入る割合（かまどの形で、本体が決める） |
| 二重の壺 | 上下2つの器から：容量、熱容量、熱の逃げ、下の壺に落ちる割合 |
| 灯皿 | 容量（油の灯りの工程で使う） |
| 桶 | 容量、水面の面積、壁からしみる水（吸水率から。素焼きの桶は少しずつ水が減る） |

- 竹・木・石の道具（ヤシの実を割る石と杭・刷毛・器の台・薪の屋根）は物理の値がほとんど効かないので、**材料の一覧（何を何 g）だけ科学側が出し、本体が材料から作る**（params は固定値）。

### ⑤ 生木の焚き火（科学側から提案）

今の焚き火の式は、湿った薪でも正味の熱が残れば同じように燃える（熱が減るだけ）。野焼きでは「生木では温度が上がらない」が大事なので、**薪の水分で炎の温度と燃える速さが下がる**ようにしたい。薪で焼く工程（p13w、統合済み）も版を上げることになる。

## 4. 数値の扱い（予定）

すべて仮定から始め、Codex に一次資料（野焼きの温度の記録、民族誌の野焼きの割れ率、貝殻混ぜ物の石灰化の考古学、壁の厚さと乾燥割れ）での照合を頼む。これまでの学び（見ても変わらない・格子の間の look はその時刻の状態・分からない天気は計算しない・その後は観察しない・返したものが次で読める・整数 ppm の切り捨て・設備の指紋のキー順・風の欠測は分からない扱い）は最初から入れる。
