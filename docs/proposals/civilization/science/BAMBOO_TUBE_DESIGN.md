# 設計案：竹の管と「天気の壺」型の自作気圧計

**オーナーの決定（2026-10-10、すべておすすめどおり）**：竹の管を作る。形は A「天気の壺」型（まっすぐな竹の管を栓に通し、壺の中の水に差し込む）。乾かす棚は科学側の変更なし（本体が1つの棚に器3個まで、乾かす run を同時に置く）。

本体の質問（2026-10-10）：島で封じた壺はできた（空気を保つ時間 705 分）が、気圧計にする管が島にない。竹は南の島（小浜島）から持ち帰れる（`bamboo`）。

## 形：「天気の壺」型

- 竹の節と節の間（30〜40 cm）を両端で切って、まっすぐな管にする。節を抜かない・曲げない。
- 封じた壺の底に水を入れ、管を栓に通して下端を水に差し込む。壺の中の空気が水面を押し、外の気圧が下がる（または壺が温まる）と、管の水が上がる。
- 釣り合いは今の m03x と同じ：(Pa + ρg·h)(V0 − 壺の水) = 空気の量 × Tb。壺の中の水面は管の断面よりずっと広いので、管の水が上がっても壺の水面はほとんど下がらない（下がる分も式に入れる）。
- 管の上端からあふれる・下端が水から出て泡が入る、の2つの端は今のあふれと同じ扱い。

## 工程（案）

1. **竹から管を作る**（新規、世界の時計、手の仕事）：`bamboo` から節の間を選んで切る。乾かす間に割れることがある（仮定）。内径はわずかに先細り。できた管 `bamboo_tube` は内径・長さ・割れを持つ。
2. **封じる（p16x）**：`bamboo_tube` も栓に通せる。竹は外側が不ぞろいなので、継ぎ目の漏れが試験用の管より大きい（仮定）。管の水は試験用と同じく別のロット。
3. **気圧計（m03x）**：「天気の壺」型の形を足す。目盛りは住人の記録の上で相対的に読む（先細りの分、目盛りの間隔は均一でない）。
