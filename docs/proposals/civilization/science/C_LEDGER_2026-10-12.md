# 非保留の C の棚卸しと整理（2026-10-12）

ブランチ `codex/civilization-simulation` / オーナー了承（2026-10-12：「提案どおり進めよう」）。新しい技術に進む前に、たまった非保留の C（統合を止めない指摘）をまとめて片付ける。出どころ：Codex の carryover/status.json（7f4d1e3 と 475c7ff の棚卸し）、各最終レビュー依頼の「次の全面レビューへ」、475c7ff の BW-C1・BW-C2・U 字の言葉。

## 残すもの（理由つき）

| ID | 内容 | 残す理由 |
|---|---|---|
| FX-C1 | 灯りのすすの炭素熱の控除と、整数 mg のすすの数 J の残差 | 最大約 4 J。熱の合計の誤差の範囲で、住人の結果は変わらない |
| FX-C3 | 手書きの大きな灯皿で吸着油が 1 kg を越える端 | 通常の灯皿の上限（728,640 mg）では起きない |
| VF-C1・VF-C2 | 乾燥の最大流束の ppm が極端な条件で上限 1e9 を越える、整数の上限 | 65 °C・RH0・風 80 m/s などの人工的な端。直すと p12y の版が上がり、本体の乾燥中の run がすべて中止になるので、次に p12y を変えるときに一緒に直す |
| VF-C3・VF-C4 | `surface_cm2` は片面の薄壁の有効面積、漏れの係数は仮定 | モデルの意味の説明。校正の資料がまだない |
| DRY-PEAK（相談） | 乾燥の最大流束を持ち続けるのは強すぎうる | 試験片と一緒にモデルを見直す相談（POTTERY_CRACK_MODEL_CONSULTATION） |
| BARO-C2 | m02x の格子外のあふれの最初の検出時刻と言葉 | 読みの値は正しく、時刻の言い方だけ |
| BARO-GAP（相談） | 気圧と器温の極値を同じ時刻で組にする改善 | 今の幅は安全側（広め）。改善は相談 |
| C-V1 | 日なたでタールがやわらぐとき、継ぎ目の覆いは変わらない | 気圧計は日陰に置く決定。水の試験（p17x）の日なたでだけ起きる |
| C-M1 | 大きな瞬間の気圧変化での流出量と余水の所在（U 字） | 1 秒ごとの調べ方の範囲。天気の壺には当てはまらない |
| 幾何の近似 | 天気の壺の水面は球の最大断面で一定とする（厳密な球冠の水深ではない）。管の中の水の二重計上で V0 が約 0.5% 変わる | 手順書に「最大断面一定の近似」と明記。詳しい形を採るときに整理する |
| 竹の割れ | 青い竹 35% は切り出し時の一度の判定（後で乾いて割れることは計算しない） | 手順書に明記 |
| 他工程の旧 C 13 件 | Codex が今回再確認していないもの | 次にその工程を変えるときの全面レビューで |
