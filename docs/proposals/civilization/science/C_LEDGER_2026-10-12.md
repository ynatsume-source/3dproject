ブランチ `codex/civilization-simulation` / オーナー了承（2026-10-12：「提案どおり進めよう」）。新しい技術に進む前に、たまった非保留の C（統合を止めない指摘）をまとめて片付ける。出どころ：Codex の carryover/status.json（7f4d1e3 と 475c7ff の棚卸し）、各最終レビュー依頼の「次の全面レビューへ」、475c7ff の BW-C1・BW-C2・U 字の言葉。

## 残すもの（理由つき）

| ID | 内容 | 残す理由 |
|---|---|---|
| FX-C1 | 灯りのすすの炭素熱の控除と、整数 mg のすすの数 J の残差 | 前回の診断で最大約 4.34 J。前回確認した通常の条件では、住人の結果への影響を検出していない（すべての閾値での証明ではない。今回は再診断していない）（CS-LEDGER-C2） |
| FX-C3 | 手書きの大きな灯皿で吸着油が 1 kg を越える端 | 通常の灯皿の上限（728,640 mg）では起きない |
| VF-C1・VF-C2 | 「上限 1e9 の入力に戻せない」件は p12y 0.1.2 で解消済み。残るのは、8.8e8 ppm の見積もりが風の高さ 10 m だけの条件であること（高さ 1 m なら約 1.44e9 ppm）と、MAX_SAFE_INTEGER の人工的な端での ppm の往復 +1（CS-LEDGER-C1） | 通常の生成値の数百万倍の人工的な端。直すと p12y の版が上がり、本体の乾燥中の run がすべて中止になるので、次に p12y を変えるときに一緒に扱う |
| VF-C3・VF-C4 | `surface_cm2` は片面の薄壁の有効面積、漏れの係数は仮定 | モデルの意味の説明。校正の資料がまだない |
| DRY-PEAK（相談） | 乾燥の最大流束を持ち続けるのは強すぎうる | 試験片と一緒にモデルを見直す相談（POTTERY_CRACK_MODEL_CONSULTATION） |
| BARO-C2 | m02x の格子外のあふれの最初の検出時刻と言葉 | 読みの値は正しく、時刻の言い方だけ |
| CS-SAMPLE-C1（新） | セルの頭ちょうどの読みは、頭の標本を調べない（28 °C・20 hPa/h の低下・U 管 200 mm で、5,400,000 ms に 20 目盛り、1 ms 後に「あふれて減ったまま」、1 ms で止めると 8 mg 流出）。0.2.1 も同じ | 整数の読み（端の 20）とは合っている時刻の端。BARO-C2・C-M1 に近い制約として残す（隠して解消扱いにしない） |
| 油灯の保存 C2 | 灯りの壊れた保存状態の構造の検査 | 今回の `stateShapeOk` は m02x・m03x だけに使った。灯りは未変更（次に灯りを変えるときに） |
| BARO-GAP（相談） | 気圧と器温の極値を同じ時刻で組にする改善 | 今の幅は安全側（広め）。改善は相談 |

| C-M1 | 大きな瞬間の気圧変化での流出量と余水の所在（U 字） | 1 秒ごとの調べ方の範囲。天気の壺には当てはまらない |
