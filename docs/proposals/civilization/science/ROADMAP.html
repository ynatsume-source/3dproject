5. 石灰とれんがで建てる2027年1月〜3月 消石灰のモルタル、焼いたれんが、小さな壁や作業場。創作（建築）側とつながる。

6. 金属を取り出す2027年春〜夏 鉱石を見分け、耐火の器と炉で還元し、使える鉄・銅にする。島の外へ広がる段階。

流れ

鉱石の探索・評価 → 耐火材 → るつぼ → 炉（送風・温度・雰囲気）→ 木炭で還元 → 粗い金属 → 精製 → 加工
  • 木炭づくり（炭化）
  • 耐火粘土の評価、るつぼの成形・焼成
  • 送風（ふいご）と炉：1000 °C を超える熱と、還元する雰囲気
  • 鉄・銅の還元と精製、スラグ
  • 島外の資源と輸送（地域・運搬・時間の記録、本体の G6 とつなぐ）

リスク

7. 電線・磁石・ガラス2027年後半 銅を細い線にして絶縁する。磁石を作る。透明なガラスを溶かす。どれも難所。

流れ

銅の線引き → 焼きなまし → 絶縁（樹脂・布）→ 巻線
鉄系の磁性材 → 熱処理 → 磁化（最初の磁化をどうするか）
珪砂＋融剤 → 溶融 → 徐冷 → 薄い外殻
  • 線引きの工具（硬い鉄・穴の精度）と、断線・抵抗の評価
  • 電気の計測器を自分たちで作る（測れないものは測れないまま）
  • 磁化の出発点：外部の磁石なしにどう始めるか（循環依存を隠さない）
  • ガラスの組成・溶融・徐冷・割れ

担当：科学 ClaudeCodex（資料）

8. 発電して、初めて灯す2028年〜 風で回し、自作の発電機で電気を起こし、自作の灯体を灯す。長期目標。

流れ

風車 → 軸・軸受 → 発電機（巻線＋磁石）→ 配線 → 炭素フィラメント → 排気（真空ポンプ）→ 封止 → 定置灯が灯る
  • 風車と発電機：風があるときだけ回る、出力は風しだい
  • 真空ポンプと、ガラスと金属の封止（漏れ・寿命）
  • フィラメントの炭化と寿命
  • W（電力）と Wh（電力量）、蓄電の有無（夜に灯すには蓄えが要る）
  • 初点灯の判定：原料の来歴をすべて遡れること。既製の電材やロボットの電池は数えない

担当：科学 ClaudeCodex本体

ずっと守ること

  • 住民の言葉（AI）では結果を決めない。材料・熱・時間の規則で世界が決める。
  • 住民は、見た目・音・自分の計器でしか知らない。
  • 確認していない値は「仮定」と書く。嘉弥真島の資源を勝手に追加しない。
  • 既製の部品やロボットの電池で、初点灯を代替しない。
  • 本体へは小さな単位で、レビューの後に統合する。
