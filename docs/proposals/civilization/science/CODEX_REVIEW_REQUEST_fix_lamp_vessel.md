## 住人の気密の器：換算表 civ-sci.fired-pot-assembly/1 → /2（VF-A1）

`readFired` は素地をロットからタールと壁の水（`x_*_ppm`）を除いて読む。重さ・熱容量は素地だけ。灯皿が油を吸える割合＝吸水率 ×（1 − 覆い）− 壁の水 / 素地。裸の器は /1 と同じ。

回帰（`scripts/science-fired-pot-assembly-check.ts` 26件、6節）：成形 → 乾燥 → 野焼きの本物の灯皿 → 水の試験で濡れて返る → `lampDishParams` → 純油を 1 時間置く：素地の重さは同じ、吸う油は 8.2 g → 0 g（増えない）。鍋の熱容量も素地の分。
