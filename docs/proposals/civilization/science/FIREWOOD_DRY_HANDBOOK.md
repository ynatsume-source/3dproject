# 手順書：薪を積んで乾かす（p15x_firewood_dry 0.1.1）

2026-10-06 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

本体の依頼（science-requests-2026-10-06.md の3）への答え。切ったばかりの薪（水 45%）を積んで乾かす。島の時計、接続仕様 0.2.x のみ（屋根のない山にしみこむ雨を `drawn` で空気から取るため）。

## 1. 世界側が用意するもの

| もの | 中身 |
|---|---|
| `firewood` | 本体の薪のロット（`water_ppm` 450,000：切ったばかり）。任意で `piece_mm`（割った太さ、既定 60 mm） |
| `firewood_stack` | 積む場所。`covered`（1=葉で葺いた屋根の下・日陰、0=屋根なし）は必須。`sunExposure` 0〜1（屋根なしのとき）、`topAreaM2`（雨を受ける上面、既定 0.2 m²） |
| 天気 | 気温・湿度・風（風がないことは明示の 0。欠けていれば分からない扱い）。屋根なしのときは雨量 `rainMmH` も。分からない区間は計算しない |

操作：`look`（持つ・切り口を見る。物理に触れない）、`take_out`（下ろす＝終わり）。`stop` operator / equipment-lost でも終わる。

## 2. 住人が試して分かること（試算、4 kg の薪）

| やり方 | 結果 |
|---|---|
| 屋根の下・日陰（28 °C・湿度75%・風 2 m/s） | 島の時計で約4か月（現実の約9日）で水 13% の乾いた薪に。最初は「湿って重い」、途中で「ひびが出て少し軽い」、最後は「乾いて軽く、打ち合わせると乾いた音」 |
| 屋根なし・日なた（30 °C・60%・風 3 m/s） | 40日で水 8%（屋根の下は 20%）。ただし雨に当たると戻る |
| 太さ 12 cm（割らない） | 40日で水 39%（6 cm は 24%）。割ると早く乾く |
| 乾いた薪（15%）を屋根なしで雨の1日（8 mm/h） | 雨を約 1.5 kg 吸って水 38% に戻る。屋根の下なら乾いたまま |
| 乾かした薪を燃やす | 1 kg あたりの正味の熱が 8.7 → 15.1 MJ に（薪で焼く工程・炭焼き・器を温める火がそのまま読む） |

## 3. 物理（すべて仮定、`params.ts`）

- 含水率 MC（乾いた木あたり）が平衡含水率 EMC へ近づく：`dMC/dt = −(MC − EMC)/τ`。
- EMC は USDA Wood Handbook の Hailwood–Horrobin 式（28 °C・75% で約 14%）。係数と表 361 点は Codex が照合済み（29521cb レビュー）。式を使うのは表の範囲（木の温度 −1.1〜98.9 °C）だけで、外では計算しない（来歴が不完全）。原典の表（Table 4-2）の相対湿度は 5〜95%。湿度 98% を超えると、式に h = 0.98 を代入した値に固定する：これは原典の表の値ではなく、この工程独自の仮定（5% 未満と 95〜98% も表の外で、式をそのまま使っている）。水は 0 より下がらない。木の温度は気温＋日射の上乗せ（15 K × 日なた）で、日なたの山はそのぶん乾いた空気を感じる。
- τ = 30 日 ×（太さ/6 cm）² ÷（風の効き × 温度の効き）。風は棚と同じ高さ換算（10 m の風 × 0.6）、温度は 15 K ごとに2倍。
- 屋根なしの山：上面に降る雨の 3 割がしみこみ、含水率 0.6 まで（残りは流れ落ちる）。雨は `drawn: rain_water`（空気から）。
- 乾く水の熱は `src:env-heat:`（潜熱、蒸気の整数 mg から）。

扱わないもの：平衡より乾いた木が湿った空気から水を取り戻すこと、カビ・腐れ・虫、山の中と外の乾き方の違い、木の種類の違い、雨水が蒸発で冷やす効果。

## 4. 本体へ

- 屋根（`covered: 1`）は本体が材料（竹・葉）から作る場所の性質として渡す。薪の山そのものは作る道具ではない。
- 返す薪は `water_ppm` を整数にしない（薪で焼く工程の 0.1.2 と同じく、比を丸めない）。次の乾燥・薪で焼く・炭焼き・器を温める火がそのまま読む。
- 焚き火の式は、まだ「生木は火がつきにくい・煙が多い・温度が上がりにくい」を表していない（正味の発熱が下がるだけ）。器を焼く工程の設計で一緒に見直す。
