| R1 区間の分割で使用 J・温度が変わる（石灰・焼成） | 積分を30秒の格子点でしか進めず、端数の区間の申し出を捨てていた | 各要求は自分の区間の終わりまで正確に積分する（格子点と区間の境界で刻む）。使うのはその区間の申し出だけ。窯・炉の制御（出力・段階の切り替え）は格子点で決めて次の格子点まで保持する。申し出からの J は切り捨てで報告するので、区間の上限を超えない。乾燥・消化にも同じ方式を適用した | 炉：30秒一括 = 1秒×30 = 29秒+1秒 = 120000 J（以前は 4000 J）。窯：66666 J と 66666 J（以前は 15000 J）。格子の上で区切る場合は結果が完全に一致し、格子から外れる場合も離散化の許容差内 |
