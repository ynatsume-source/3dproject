# 設計案：油の灯り（灯皿・ヤシ油・灯芯）

2026-10-09 / ブランチ `codex/civilization-simulation` / **相談用の設計案**（実装の前に、オーナーと本体に決めてほしいことがある）

ランタンの大義は「夜に明かりを灯す」（火 → 油 → 電気）。島にはもう、住人が焼いた灯皿（`fired_pot` の形3、`lampDishParams`）と、住人が煮たヤシ油（`coconut_oil`）がある。灯芯を足せば、焚き火ではない最初の明かりが灯せる。技術の地図では「油の灯り」は初点灯への途中の段で、夜の航海の灯りにもつながる。

## 1. 住人に見えること

| 試すこと | 住人に見えること | 世界の中で起きていること |
|---|---|---|
| 灯皿に油を入れ、繊維をよって灯芯にして火をつける | 小さな炎、まわりが少し明るい | 灯芯が毛細管で油を吸い上げ、先で油が気化して燃える |
| 初めて使う灯皿に油を注ぐ | 油が皿にしみて減る、皿の外がにじむ | 素焼きの皿は油を吸う（吸水率から。最初の一回は皿が油を吸い込む） |
| 灯芯を長く出す／短くする | 長いと炎が大きく、黒い煙とすす。短いと暗く、消えやすい | 芯の出しろで燃える速さと明るさが変わる。出しすぎると燃え残りの炭素がすすになる |
| 芯の材料を変える（アダンの繊維・ヤシの実の繊維・葦の髄など） | よく灯るもの、すぐ焦げて消えるもの | 繊維の太さとすき間で、油を吸い上げる速さが違う |
| 長く灯す | だんだん暗くなる、芯の先が黒く固まる | 芯の先が炭になり（灯芯の炭化）、吸い上げが落ちる。切りそろえると戻る |
| 風のある場所で灯す | 炎がゆれて消える | 風で炎が吹き消される。風よけ（壁・覆い）が要る |
| 涼しい夜に灯す | 油が白く固まって、火がつかない・すぐ消える | **ヤシ油は 24 °C 前後で固まる**（実際の性質）。温めるか、暖かい場所に置くと戻る |

最後の「涼しい夜に油が固まる」は、八重山の冬の夜（15〜20 °C）で実際に起きる。住人が観察から気づける、本物らしい発見になる。

## 2. 工程の案（1つ）

```
lamp_dish（設備：灯皿）＋ coconut_oil ＋ 灯芯の材料（pandanus_fiber など）
  → p40x 油の灯り（灯す・芯を切る・消す）
  → 残った油・燃え残った芯・すす（皿に）、CO2 と水蒸気（空気へ）、O2 は drawn
  → 明るさの記録（世界が数える）
```

- 操作：`light`（火をつける。火種が要る：焚き火から）、`trim`（芯の先を切る）、`wick_out`（芯の出しろ 0〜2）、`put_out`（消す）、`look`。
- 明るさは世界が決める値として持ち、住人には「まわりがどこまで見えるか」の言葉で返す（数値は渡さない）。ランタンの報酬「夜を照らす範囲」の元になる。
- 質量は今までの約束どおり閉じる（油 + O2 = CO2 + 水 + すす）。

## 3. 決めてほしいこと

### ① 時計（オーナー・本体）

| 案 | 中身 |
|---|---|
| **A（おすすめ）世界の時計** | 夜の明暗は現実と同じなので、灯りも現実の時間で燃える。見ている人の夜に、ランタンの灯りが数時間ともる |
| B 島の時計 | 待つだけの工程と同じ約13倍。灯りが数十分で燃え尽きてしまい、夜の長さと合わない |

### ② 難しさ（オーナー）

| 案 | 中身 |
|---|---|
| **A（おすすめ）本物に近い** | 芯の材料・出しろ・切りそろえ・風よけ・冷えた油を、住人が一つずつ覚える。最初は暗く、すすだらけで、すぐ消える |
| B やさしめ | 芯は何でも灯る、油は固まらない。最初からそこそこ明るい |

### ③ 灯芯の材料（オーナー・本体）

島にあるものから選ぶ。おすすめは、**アダンの繊維・ヤシの実の繊維（コイア）・葦の髄の3つを試せる**ようにすること。違いがあるので、試す楽しみが生まれる（どれがよいかは世界が決め、住人は試して知る）。どの材料を島のどこで手に入れるかは本体側で決める。

### ④ 明るさをどう使うか（オーナー・本体）

明るさは世界が数える。それを、ランタンの「夜を照らす範囲」の報酬にするか、カメの子どもを迷わせる人工の光の決まりにもつなげるか（ロードマップ A6 の「灯りとカメの利害」）。おすすめは、**まず報酬だけ**にし、カメとの利害は灯りが島に広がってから。

## 4. 数値の扱い（予定）

すべて仮定から始め、Codex に一次資料での照合を頼む：ヤシ油の融点（約 24 °C）と燃焼熱、昔の油の灯りが燃やす油の量と明るさ（ろうそく1本の数分の1〜1本ほど、要確認）、植物繊維の灯芯の吸い上げ、すすの出方、素焼きが油を吸う量。これまでの学び（見ても変わらない・格子の間の look はその時刻の状態・分からない天気は計算しない・風の欠測は分からない扱い・返したものが次で読める・整数 ppm の切り捨て）は最初から入れる。
