# 設計案：気密の器（焼いた器＋木タールの封じ）

2026-10-05 / ブランチ `codex/civilization-simulation` / **相談用の設計案**（実装の前に、オーナーと本体に決めてほしいことがある）

ランタンの発明の順番の4つ目。**自作の気圧計**の「空気を閉じ込める器」と、**油の灯り**の油を入れておく器の土台になる。ここで初めて**漏れ**を扱う。

## 1. 何を確かめられるようにするか

住人が自分の目と手で確かめられる範囲で：

| 試すこと | 住人に見えること | 世界の中で起きていること |
|---|---|---|
| 素焼きの器に水を入れて待つ | 外側がしっとり濡れる、水が少しずつ減る | 焼き締まりの足りない壁の細かい穴を水が通り、外で蒸発する |
| 温めた器の内側にタールを塗る | 塗った面が黒く光る、冷めると固い | 温かいタールが穴に入り、冷えて固まる。塗る量と器の温度で、ふさがる割合が決まる |
| 塗った器に水を入れて待つ | 外側が乾いたまま、水が減らない | ふさがった割合に応じて、しみ出しが減る |
| 口をタールで封じ、水に沈める | 泡が出る／出ない | 壁と封じからの空気の漏れ。漏れが少なければ気圧計の器に使える |
| 日なたに置く | 封じがやわらかくなる、ひびが入る | タールは温まるとやわらかく、冷えると脆い（割れると漏れが戻る） |

## 2. 工程の案（3つ、1つの run は1つの時計）

```
（器を焼く） → p16x タールを塗って封じる（世界の時計・手の仕事） → p17x 漏れを試す・寝かせる（島の時計・待つ）
```

- **p16x タールを塗って封じる**（世界の時計）：焼いた器のロット＋`wood_tar`。焚き火のそばで器を温め（燃料は薪）、内側に塗り、口に栓をしてタールで封じる。出てくるもの：塗った器（quality：ふさがった割合、塗ったタールの量、封じの有無）。タールの使った分は器に移る（質量は器のロットに入る）。
- **p17x 漏れを試す**（島の時計）：器のロット（＋入れる水か、閉じ込める空気）。待つ間に、壁からしみ出す水（外で蒸発）、封じと壁から抜ける空気、日なたでやわらかくなる・夜に冷えてひびが入るタール、を計算する。操作：水に沈めて泡を見る、外側を触る、中の水を量る（秤量の工程で）。
- **自作の気圧計**（次の工程）は、この器の「空気の漏れやすさ」を受け取って、今の試験用の気圧計の式に漏れを足す（読みがだんだんずれる → 住人は「ときどき開けて合わせ直す」を学ぶ）。

## 3. 決めてほしいこと

### ① 器をどこから用意するか（オーナー）

成形（`p11_pottery_shape` → `unfired_pot`）はあるが、**器を乾かす・焼く工程はまだない**（今あるのは試験片の乾燥・焼成だけ）。

| 案 | 中身 | よいところ | 気になるところ |
|---|---|---|---|
| **A（おすすめ）試験用の焼いた器から始める** | 試験用の `fired_pot_test`（吸水率・容量・壁の厚さを quality に持つ）を世界側が置く。気圧計・ヤシ油と同じ「既製の対照設備」の考え方 | タールで封じる・漏れを試す、という新しい科学（漏れ）にすぐ入れる。灯りまでの道が早く見える | 器そのものは住人が作っていない（後で置き換える） |
| B 器の乾燥・焼成を先に作る | 試験片の乾燥・焼成の仕組み（`kiln-ware`）を器に広げる。新しい工程として作り、統合済みの乾燥は触らない | 住人が作った器で最初から試せる | 器の形（厚い底・口）で割れ方・乾き方が試験片と違い、新しく決めることが多い。気密の器までが遠くなる |

おすすめは **A → 後で B**。A で「タールで封じると漏れない」という知識の筋を先に通し、B ができたら試験用の器を住人の器に置き換える（試験片のときと同じ順番）。

### ② ロットから設備へ（本体）

気圧計の器・油の壺は、工程の中では**設備**（`equipment`）として使う。ところが工程が作れるのは**ロット**（`produced`）だけで、設備は作れない（接続仕様どおり）。

提案：**ロットを設備にするのは本体の仕事**（「組み立て」）。科学側は、ロットの quality から設備の params を決める**換算表**を出す（例：塗った器の「ふさがった割合」→ 気圧計の器の「空気の漏れやすさ」）。接続仕様は変えない。

本体に決めてほしいこと：組み立てのしかた（いつ・誰が・何を消費して設備にするか）、設備を壊したとき・使い終わったときにロットへ戻すか。

### ③ 大きさ（オーナー）

- 気圧計の器：今の試験用と同じ 500 mL でよいか。
- 油の壺：灯り1つ分の油（数日分、数百 mL）でよいか。

## 4. 数値の扱い（予定）

すべて仮定から始め、Codex に一次資料（素焼きの透水、タールの軟化点・脆さ、土器の封じの民族誌的な記録など）での照合を頼む。これまでのレビューで学んだこと（見ても変わらない、細かい固定の格子、蓄えた熱、設備の喪失は区間の終わり、返したものが次で読める、ppm の切り捨て、天気が分からない区間は勝手に進めない）は、最初から入れる。

## 5. 決まったら

①が A なら：試験用の焼いた器 → p16x → p17x の順に作り、まとめて Codex の全面レビューへ。②の換算表は手順書に書き、本体の組み立ての設計に合わせて直す。
