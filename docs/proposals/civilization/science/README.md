## 何ができたか

少量の粘土を練って試験片にし、乾かし、焼いて冷まし、水に浸けて吸水と割れを確かめる。その結果から次の焼き方を決める。この研究の一周が、TypeScript の独立したコアと試験用 adapter で動く。

- 記録の画面：[runs/clay-loop-v0.html](runs/clay-loop-v0.html)（ダウンロードしてブラウザで開く）／元データ：[runs/clay-loop-v0.json](runs/clay-loop-v0.json)
- 実行：`npx tsx scripts/science-clay-report.ts`（2回実行してもバイト単位で同じ出力）
- 検査：`npx tsx scripts/science-clay-check.ts`（50項目）

### 試験世界での結果（規則だけ、実AIなし）

| 試験片 | 条件 | 世界の判定 | 住民が知ったこと |
|---|---|---|---|
| T1 | 焚き火、薪20 kg | 燃料が尽き、炉内は最高621 °C。脱水95%・焼結0%。冷えるときに573 °Cを急に通過し、割れが一本貫通した（危険比2.9、確率0.46の抽選） | 火の色は「ごく暗い赤」、割れて分かれている、量った吸水率14.4% |
| T2 | 試験用の小窯、橙、30分保持 | 980 °C、焼結28% | 澄まない音、吸水率11.5% |
| T3 | 焼かない対照 | 脱水0%：水中で崩れ、泥水のロットになった（粘土に戻せる） | 崩れた |
| T4・T5 | 小窯、橙、90分保持、別々の焼成2回 | 焼結54% | 澄んだ音、どちらも吸水率8.8% → 作り方が「再現済み」になる |

拒否されたもの：計画だけのれんが窯、燃料を予約していない窯、暮らし用の水と煮炊き用の薪（保護資源）。薪は4回の焼成で合計111 kg を使った。大気へは CO2 172 kg と水蒸気 67 kg が出て、大気から O2 129 kg を取り込んだ。熱は「放出＝排気＋壁＋試験片＋反応＋炉体の蓄熱」で毎ステップ閉じる。試験片に入る熱は放出熱の1万分の1以下。

## 最小範囲をこう決めた

設計資料のS2「器素地の焼成」をそのまま実装すると、窯（p17）・れんが（p16）・初期焼成の校正（カタログ外の能力）が循環する。そこで一周に必要な部分だけを切り出した。

| 入れた | 理由 |
|---|---|
| 練る（p10）、試験片の成形（p11x：器ではなく 50×50×10 mm の試料）、乾燥（p12x）、焼成と冷却（p13x）、冷水浸漬（m01）、目視とはじく音 | 「成形→乾燥→焼成→冷却→評価→見直し」に必要な最小の工程 |
| 化学種：カオリナイト→メタカオリン＋水、方解石→CaO＋CO2、有機炭素＋O2→CO2、木の燃焼 | 純物質として元素収支を取れる反応だけ。それ以外の鉱物は「反応させない混合物」として質量だけ保つ |
| 設備：日陰の棚、日なたの台、地面の焚き火、試験用の小窯（既製の対照設備）、浸漬桶、0.1 g のはかり | 全て `test-fixture`。原料自作の達成には数えない |

| 入れていない（次以降） | 理由 |
|---|---|
| 石灰系の結合材・れんが・窯の組立 | 別系統。粘土の一周を先に固める |
| 煮沸法の吸水試験 | 燃料が必要。v0 は冷水24時間で、煮沸値の0.8倍と仮定 |
| ライムポップ（残った CaO が湿気を吸って弾ける）、還元焼成の色、イライト等の脱水 | 組成・条件の根拠が未確認 |
| ロットごとのばらつき | 同じ条件では同じ結果（T4とT5が一致）。割れだけが種つき抽選 |
| 事故（Incident） | 消費は常に予約の範囲内。予約外の被害はまだ起こさない |

## 守ったこと（検査で確認済み）

- **同じ入力なら同じ結果**：時刻・環境・seed は command で渡す。コアに `Date.now`、`Math.random`、ネットワーク、DOM、Three.js がないことも検査した。
- **重複しない**：
  - 全ての command を同じ内容で再送しても世界は変わらない（89件）。同じ ID で内容が違う command は拒否する。
  - 全 command の後で保存→読込を挟んでも、最終状態のハッシュが同一になる。
  - `advance` を1時間ずつ進めても、7.3＋0.2＋22.5時間に区切っても、結果は同じ。
  - 古い版を元にした提案は確定時に拒否する。
- **収支**：
  - 質量は整数 mg で、毎回の確定時に完全に一致する。
  - C・H・O・Al・Si・Ca の元素収支の誤差は、試験全体で各1 mg 未満。
  - 灰は燃やした薪の灰分と一致する。
  - 未使用の予約燃料は焼成の終了時に解放する。
- **設備と供給は別**：
  - 窯が存在していても、その回の燃料を予約していなければ焼成できない。
  - 予約した燃料が足りなければ、目標の色に届かず冷める。
  - 焚き火（覆いなし）は、薪を140 kg予約しても最高712 °Cで止まり、橙に届かない。
- **運用停止と世界内の失敗は別**：
  - 焼成中に止まった場合は `halted_operational` とし、熱履歴が不明な試料は根拠から外す。
  - 燃料切れは世界内の結果として扱う。
  - 乾燥中の停止区間は、天候を作らずに記録だけする。
- **住民の知識**：
  - 計器のない値は色・音・様子として渡す。数値の観察は、はかり・時計・束の数え上げからだけ。
  - 他の住民の観察を自分の試作として引用できない。
  - 習得手順は「試した（1回成功）」と「再現済み（別々の焼成で2回成功）」を分ける。
  - 手順には、住民が操作できる条件（狙う色・速さ・保持時間・置き場所・日数）だけを書く。
- **条件が効く**：厚さ15 mm の試験片を日なたで乾かすと20 seed 中16回割れた。日陰では0回だった（危険比 4.03 と 0.91）。

## 設計資料のレビューで見つけた点

1. **最初の加熱設備の循環**：p13（器の焼成）は窯と `early_ceramic_firing_calibration` を要し、窯（p17）は焼成れんが（p16）を要し、れんがの焼成には p13 の成立が要る。v0 の試験世界では、地面の焚き火を「れんが不要の出発点」として扱った。ただし到達温度が低く、低温焼成品しかできないことがモデルから出る。原料自作の本世界では、焚き火→低温焼成のれんが→窯、という段階を足す必要がある。
2. **測定工程が足りない**：カタログには吸水試験や割れの検査がない。`m01_cold_soak_absorption` と、目視・打音の inspect を追加した。
3. **試験片と製品の区別**：p11（器）・p14（れんが）とは別に、比較用の試料を作る p11x を置いた。研究の単位は「試料」で、製品ではない。
4. **温度を制御する手段**：計器がなければ、住民は温度の数値を指定できない。焼成の計画を「速さ・狙う火の色・保持・冷まし方」で受け取り、世界側で制御則に変換した。色と温度の対応は資料によって最大約200 K 食い違うため、区分は粗くした。
5. **予約と事故の境界**：ADVERSITY の「通常の試作失敗では事故枠を使わない」を、「消費は予約の範囲内、保護資源は予約不可」として実装した。予約外の被害は未実装。

## 科学の根拠：何が確かで何が仮定か

**原典の本文は今回も取得できなかった。** WebFetch による取得の試行18件と、curl による接続確認は、すべてネットワークの遮断（EGRESS_BLOCKED）で失敗した。検索結果の要約だけは見えたが、ページの本文は読めていない。そのため、どの数値も「原典照合済み」にはしていない。各数値の状態は [`params.ts`](../../../src/science/params.ts) と画面の表にある。

| 区分 | 該当するもの |
|---|---|
| 化学量論として確か（計算） | 反応式と分子量から出る量：カオリナイト脱水の質量減13.96%、CaCO3→CaO＋CO2、燃焼の O2 と CO2。元素収支は検査で閉じる |
| 検索要約と一致する範囲に合わせた校正値（未照合） | 脱水 450〜600 °C、炭酸塩の分解 700〜900 °C、石英転移 573 °C、収縮の止まる含水約13%、乾燥収縮4〜6%、吸水率（850 °Cで約18% → 1200 °Cで約5%）、薪窯の熱効率12〜22% |
| 仮定（根拠なし、または未確認の一般値） | 割れの許容値、蒸発係数、炉の熱容量・熱損失、窯に入る燃焼熱の割合、冷水と煮沸の比0.8、粘土Aの組成、薪の含水率15%・灰1%、反応の吸熱量、Magnus 式 |
| 現地の事実 | **なし**。嘉弥真島の粘土・燃料・水は確認していない。試験粘土Aは仮想の材料 |

出典カードは [`sources.ts`](../../../src/science/sources.ts)（取得の状態つき）にある。照合する人は、カードの「確認先の候補」を、遮断のない環境で読んでほしい。
