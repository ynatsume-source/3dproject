## 特に見てほしいところ

1. **本物らしさ**（方針の観点）：湿った粘土は崩れにくく、干してから浸すと早い。早くこすと塊が残る。早く上澄みを捨てると濁って少ししか取れない。日陰の桶で約9日、日なたで3日足らず。これらの筋と桁は現実の水簸（すいひ）の感覚と合うか。一次資料が取れれば照合してほしい。
2. **質量**：入れたもの（粘土＋水）＝ 練る前の粘土＋布に残ったもの＋捨てた水＋蒸発、を整数 mg で閉じている。こす・捨てるは、その時点で整数にしている。蒸発は浮動小数で積み、終わりに切り捨て。丸めで負や過不足が出る道はないか。
3. **区切り**：30秒・1時間・3時間で、格子外の時刻の操作も含めて結果が完全一致（検査3）。蒸発は水が多い間は区間内で線形。乾きが進んで係数が下がる領域（含水比 0.13 未満）で、格子外の操作の誤差がどう出るかは未測定。
4. **島の時計と世界の時計**：待つ工程と手の仕事を別の run に分けた。練る工程は天気を使わない（どの source でも受け付ける）。この切り分けで、ADR 0006 の「1つの run は1つの時計」が守れているか。
5. **`raw_clay` の組成の読み方**：`xd_`（乾いた部分）と `xc_`（そのうち粗いもの）。`xc_inert_mineral_ppm` を許す。丸めで `xc` が `xd` をわずかに超える場合は、2 mg まで許してその化学種を全部粗いものにする。こす前に取り出したときに戻す `raw_clay` は、同じ読み方で読み直せる（検査2）。
6. **住人が知り得ないこと**：観察は言葉だけ（布に残ったもの・上澄みの濁り・手ざわり）。重さは秤量の工程で量る。診断（`diagnostics`）の含水比などは住人に渡さない約束。
7. **前回の学び**（気圧計の A1）：設備の喪失は `interval.to` で起き、それまでの蒸発は数える。桶の寸法は状態に保つ。練る工程も、止める区間で働いた分は数える。
8. **拒否**：組成なし、粗いものが超過、知らない化学種、水不足、桶に入らない、桶なし、エネルギーの申し出（浸す工程）、知らない操作、ロットの変化、区間の抜け、布の残りを練る、組成のない粘土を練る。

## 扱っていないもの

捨てる水と一緒に出る細かい粒、雨が桶に入ること（屋根の下の前提）、塩類・有機物の腐り、沈みの温度依存、練っている間の水の出入り・気泡・練りむら、布の残りを浸し直す工程。
