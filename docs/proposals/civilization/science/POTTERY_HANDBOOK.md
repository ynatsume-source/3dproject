# 手順書：器を形づくる・乾かす（p11y・p12y 0.1.0）

2026-10-07 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

設計案 [POT_FIRING_DESIGN.md](POT_FIRING_DESIGN.md) の1つ目。住人が自分で器を作る。野焼き（p13y）は次に別の工程で。

```
prepared_clay → p11y 器を形づくる（世界の時計・手）→ green_pot → p12y 器を乾かす（島の時計・待つ）→ dry_pot →（野焼き、これから）
```

## 1. 形づくる（p11y_pot_shape）

- 入れるもの：`prepared_clay` のロット1つ（下ごしらえの工程の返すもの）。道具は使わない（手だけ）。手の仕事 `mechanical` 15 W 以上。
- 最初の依頼の `interval.from` に `plan` を1回だけ：`form`（1 鍋・2 壺・3 灯皿）、`capacityMl`、`wallMm`（省くと標準）。開始時のレシピで、時刻つきの操作ではない（気密の器 A1 の学び）。後の依頼に操作があれば断る。
- 使う粘土は形から決まり、残りは同じ粘土として戻る。

| 器 | 容量の幅 | 標準の壁 | 例：使う粘土 | 手間 |
|---|---|---|---|---|
| 鍋 | 0.3〜8 L | 8 mm | 4 L で 1.7 kg | 約1時間半 |
| 壺 | 0.1〜10 L | 9 mm | 500 mL で 625 g（試験用の器 600 g とほぼ同じ） | 45分 |
| 灯皿 | 20〜300 mL | 6 mm | 80 mL で 98 g | 24分 |

形にならないとき（粘土はそのまま戻る、何も作られない）：含水比 0.32 より湿っている「壁がつぶれた」、0.17 より乾いている「紐がひび割れてつながらない」、壁が 3 + 1.5·∛(容量 L) mm より薄い「重みでたわんで崩れた」。

## 2. 乾かす（p12y_pot_dry）

- 入れるもの：`green_pot` 1つと `drying_rack`（`sunExposure`、任意で `covered`：葉で覆う）。天気は気温・湿度・風（欠けたら分からない、明示の 0 は無風）。
- 操作：`look`（色を見る）、`take_off`（下ろす）。乾ききったら `dry_pot`、まだ湿っていれば `green_pot` のまま戻り、次の run で続きを乾かせる。

| やり方（4 L の鍋） | 結果 |
|---|---|
| 日陰 | 約5日で乾く。「やわらかく色が濃い」→「縁が先に白っぽい（革のかたさ）」→「全体が白っぽく乾いて軽い」。割れない |
| 日陰で葉で覆う | 約2週間。割れない |
| 暑い日なた・風 6 m/s・湿度55% | 半日で乾くが、20個中12個がひび、9個が割れて分かれる |
| 灯皿（壁 6 mm） | 鍋より早く乾く |

## 3. 物理（すべて仮定、`params.ts`）

- 試験片の乾燥の式（physics.ts `dryPhysics`）を、器の面に使う。面積は片面 ×（1 + 内側の効き 0.5）。
- 革のかたさを過ぎると、壁の中の水が出てくるのが遅い：試験片の 10 倍 ×（壁 / 8 mm）²。これがないと 4 L の鍋が日陰で1日で乾ききってしまう（本物は数日〜1週間）。値は仮定で、照合が要る。
- 縁が先に乾く器（鍋・壺）は、割れやすさの比を 1.3 倍。葉で覆うと乾く速さ 0.4 倍。
- 割れ方は試験片と同じ（革のかたさを越えるときの乾く速さの比で、run の seed から引く）。
- `dryPhysics` に任意の入力（`areaM2`・`fluxFactor`・`crackFactor`・`fallingSlow`）を足した。試験片は使わないので、タイルの結果は変わらない（タイル・粘土の検査で確認）。

扱わないもの：砂・貝殻の混ぜ物（野焼きと一緒に）、底と縁を別々の部分として持つこと、乾く途中でつぶれること、割れた生の器を粘土に戻すこと、乾いた器が湿った空気で水を取り戻すこと。

## 4. 本体へ

- 手で作る器は道具が要らないので、島で `prepared_clay` があればすぐ動く。乾かす棚は試験片と同じ `drying_rack`（`covered` は葉で覆う、任意）。
- 割れて分かれた器（crack 2）は、野焼きで断る予定。
