# 竹の筒 0.1.1：残竹の質量と保存互換性

p18x_bamboo_tube は、筒を切ったあとに返す竹の絶対量を更新する。
元の質量 M、残量 R に対し、水 W' = floor(W × R / M)、乾物 D' = R − W'、
長さ L' = floor(L × R / M)。掛け算から BigInt を使う。
乾物と水の配分の誤差は 1 mg 未満で、端数は乾物へ残す。
元の乾物が正なら残量の乾物も正になり、帆の readPlantMass が読める。
history_complete・sail_codec など元のキーは保ち、新しい品質キーは追加しない。

絶対量の品質がある場合は、乾物・水・長さを安全な整数として検査し、
乾物＋水と入力の質量が一致しなければ消費せず拒否する。
品質のない旧竹と空の品質は、成功時の残竹にも品質を追加しない。
旧竹の質量・管の形・乱数・手間・観察は従来どおり。
割れた場合と作業中止は入力を丸ごと返し、既存の品質値も変えない。空の品質は省略する。
water_ppm からの管の水分・割れやすさの計算はこの修正では変えない。

工程版と評価器は 0.1.1。作業状態 civ-sci.bamboo-tube/1 は変えない。
0.1.0 の要求と JSON 保存状態も読み、残竹の修正を適用して継続できる。
本体の保存読み込みにはカタログの明示的な resumeVersions を使い、
竹の 0.1.0 だけを互換版に指定する。他の工程の版一致規則は変わらない。
住人の行動・記憶・表示は変更せず、保存復帰の版チェックだけを対応させる。

検査は scripts/sail-lots-check.ts に追加した。
品質付き・旧変換の3キー・品質なしの竹、筒→残竹→マスト、繰り返し切断、
安全整数上限付近と乾物1 mg、旧状態の JSON 再開・再送、割れ・中止、
不正な絶対量を確かめる。
旧版の結果は main db1a160 の凍結コピーと384条件（完了と中止）で比較する。
比較では評価器の版と、空の品質を省略する意図した変更だけを除外する。
