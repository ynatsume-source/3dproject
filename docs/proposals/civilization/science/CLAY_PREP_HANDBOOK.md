# 手順書：生の粘土の下ごしらえ（浸す・こす・沈める → 練る）

2026-10-05 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

ドットが近くの島から運んだ `raw_clay` を、成形が受け取る `prepared_clay` にする。2つの工程に分けた。1つの run は1つの時計で動く約束のため。

```
秤量 → p10x_clay_slake（島の時計）→ p10y_clay_knead（世界の時計）→ 成形 → 乾燥 → 焼成
```

## 1. 世界側が用意するもの

| もの | 中身 |
|---|---|
| `raw_clay` のロット | 量は整数の mg（10 kg = `10000000`）。quality：`water_ppm`、乾いた部分の `xd_<化学種>_ppm`、そのうち粗いもの（小石・砂・根）の `xc_<化学種>_ppm`。**掘った場所ごとに固定の値**にする（同じ場所の粘土は同じ性質） |
| `process_water` のロット | 乾いた土の 1.5 倍以上。全部を桶に入れる。捨てた上澄みとして戻った水も使える（来歴を引き継ぐ） |
| `fixture_clay_tub` | params：`capacityMl`（容量）、`surfaceCm2`（水面の面積）、`sunExposure` 0〜1（小屋の屋根の下なら 0） |
| `fixture_bench` | 練る台（成形と同じ台）。練るときは params を見ない |
| 手の仕事の申し出 | 練る工程に `mechanical` を1つ。20 W 以上が区間に均等に届くこと |

試験値の例（本書の検査で使った値。島の粘土の分析ではない）：

```json
{ "water_ppm": 200000, "xd_kaolinite_ppm": 450000, "xd_quartz_ppm": 350000, "xd_organic_c_ppm": 10000,
  "xc_quartz_ppm": 150000, "xc_inert_mineral_ppm": 50000, "xc_organic_c_ppm": 5000 }
```

## 2. p10x_clay_slake（浸す・こす・沈める）— 島の時計

- 最初の要求で、粘土と水が桶に入る。その後は待つだけ。
- 操作（区間の中の時刻、何もしない区間があってよい）：
  - `sieve`（1回）：こし布でこす。粗いものと、まだほぐれていない塊が布に残る。泥が濃すぎると通らない（言葉で返り、何も起きない）。
  - `decant`（こした後、何回でも）：沈んだ泥の上の水を捨てる。早すぎると濁っていて少ししか捨てられない。
  - `take_out`：終わり。ここで一度だけ精算する。
- 精算：`raw_clay`・`process_water` を消費 → `settled_clay`（細かい部分と水）、`clay_sieve_residue`、捨てた水（`process_water`）、蒸発した水（`water_vapour`、空気へ）。こす前に取り出すと、湿った `raw_clay`（同じ組成）が戻る。
- 天気：気温・湿度・風で水面から水が飛ぶ。天気が分からない区間は蒸発を計算しない（来歴が不完全）。ほぐれと沈みは天気によらない。
- `stop`：`operator`・`equipment-lost` は `interval.to` で中身を返して終わる（その区間の蒸発は数える）。`world-pause`・`shutdown` は続きから。
- エネルギーの申し出は要らない（あれば拒否）。蒸発の熱は `src:env-heat:` で報告する（乾燥棚と同じ）。

### 住人が試して分かること（検査の試験天気：28 °C・湿度 75%・風 3 m/s、日陰）

| やり方 | 結果 |
|---|---|
| 湿ったまま浸す（含水比 0.25） | 2時間で 3割ほどしかほぐれない。日に干してから浸すと 8割近く |
| 浸して 10 分でこす | 布に塊が多く残る（7.8 kg）。1日待つと粗いものだけ（1.7 kg） |
| こして 30 分で上澄みを捨てる | 濁っていて 0.8 kg。2日待つと澄んで 8.8 kg |
| 1日でこし、上澄みを捨て、日陰で約9日 | 手につかず、よくまとまる（含水比 0.26） |
| 日なたの桶 | ずっと早く水が飛ぶ（3日で乾きすぎるほど） |

## 3. p10y_clay_knead（練る）— 世界の時計

- `settled_clay` / `prepared_clay` を1ロット以上と、任意で `process_water` 1ロット。全部を1つの `prepared_clay` に練り合わせる。
- 練る時間は 1 kg あたり 5 分（仮定）。手の仕事 20 W が届く区間だけ進む。届かない区間は何も起きない（`needs-input`）。
- 操作はない。時間が働かれたら完了し、そこで一度だけ精算する。途中で止めたら精算しない（ロットはそのまま、働いた分の J だけ報告）。
- やわらかすぎる粘土はここでは乾かない。`settled_clay` / `prepared_clay` のまま `p10x_clay_slake` の桶へ戻して待ち直す（水は要らない、こす必要もない。上澄みを捨て、水を飛ばして取り出すと `settled_clay`）。固すぎれば水を練り込める。
- 返る観察：手ざわり（「手につかず、よくまとまる」など）。

## 4. 成形へ

`prepared_clay` は `water_ppm` と `xd_` を持つので、`p11x_test_tile_shape`（fixture-4）がそのまま受け取る（検査で確認）。成形は1ロットを丸ごと1枚にするので、**ロットを試験片の大きさに分けるのは世界側**（在庫の分割）。

## 5. 本体側で決めること

1. `raw_clay` の組成：掘る場所ごとの値。試験値のままでよいか、場所で変えるか。
2. 桶：試験用の `fixture_clay_tub` の寸法。住民が作る器（焼いた甕など）は後の段階。
3. 粘土を掘る・運ぶ量の単位（10 kg）と、真水の元（雨水など）。
4. 下ごしらえの間、住民がそばにいる必要があるか（待つ工程なので不要、を提案）。

## 6. 値の扱い

すべて仮定（`params.ts`）：ほぐれの時定数、浸すのに要る水、こせる濃さ、沈んだ泥の含水比、沈む時定数、布に残る水、練る時間・仕事率。蒸発は乾燥棚の式と係数（校正値）。島の粘土の組成は試験値。一次資料の候補：陶芸の水簸（すいひ）の手引き、粘土の沈降の資料。

## 7. 0.1.1 の変更（Codex のレビュー dd781fc への対応）

- こし布の観察は、実際に残ったもの（小石や砂・根や草・塊）から作る。何も残らなければ「何も残らなかった」。
- 捨てた上澄みの水は、その run の来歴（`history_complete`）を引き継ぐ。
- 組成は整数 ppm の切り捨てで書き、切り捨てで読む。返したロット（こす前の `raw_clay` など）は次の run でそのまま読める。
- すぐこして水を捨てると桶が空になる。これも有効な結果として精算する。
- 湿りすぎて取り出した粘土は、桶へ戻して待ち直せる（§3）。

## 追記（2026-10-07）：手でさわって確かめる（p10x 0.1.3）

本体の報告：池に9日置いたら、沈めた粘土が水 3.6% まで乾いた（本物の天気で）。住人が「ちょうどよいとき」に取り出せるよう、`look` を足した。

- `look`（区間の中の時刻、何回でも）：桶・池の粘土を手でさわった感じが、その時刻の状態で返る（格子の間はコピーを進めて読む。見ても物理は変わらない）。
- 言葉：「どろどろで、すくうと流れ落ちる」→「やわらかく、手にべったりつく」→「少しやわらかいが、なんとかまとまる」→**「手につかず、よくまとまる」（取り出しどき）**→「固く、曲げるとひびが入る」→「乾いて固まっている」。こす前は「こす前の泥。」が前につく。
- 天気が分からない区間がある run（来歴が不完全）では、その後は何も言わない。
- 検査の天気（28 °C・75%・風 3 m/s、日陰）では、こして水を捨てた後、8.5 日ほどで「手につかず、よくまとまる」になる。乾きすぎても、練る工程で水を足せば戻る（本体が水を分けている今のやり方でよい）。
- 状態の形は同じ（/2）。0.1.2 の run は版で拒否（本体が取り消して中身を返す）。

## 島の粘土の組成（表 civ-sci.island-clay/1、仮定）

`src/science/island-clay.ts` の `islandClay('south-near')`。値は本体がいま使っている `RAW_CLAY_SOUTH`（本書の検査の例）と同じで、**科学側の表として持つ**ことにした。状態は「仮定」：砂の多いカオリン質の土器用粘土に、草や根が少し（有機炭素 1%）。石灰（貝殻・石灰岩のかけら）は入れていない。本物の島の地質を述べたものではない。資料（八重山の土壌、昔の土器）での照合は Codex に頼む。値を変えるときは表の版を上げる。掘った粘土のロットは、掘ったときの値を持ち続ける。
