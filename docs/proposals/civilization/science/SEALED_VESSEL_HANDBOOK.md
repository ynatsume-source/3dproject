2026-10-05 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

設計案 [SEALED_VESSEL_DESIGN.md](SEALED_VESSEL_DESIGN.md) のオーナーの決定（2026-10-05）：① 試験用の焼いた器から始める（器の乾燥・焼成は後で置き換え）、② ロットを設備にするのは本体の「組み立て」、科学側は換算表を出す、③ 気圧計の器 500 mL、油の壺は数百 mL。

```
試験用の焼いた器 → p16x タールを塗って封じる（世界の時計） → p17x 漏れを試す（島の時計） → 本体が組み立て（気圧計の器・油の壺）
```

## 1. 世界側が用意するもの

| もの | 中身 |
|---|---|
| `fired_pot_test` | 試験用の焼いた器。quality `capacity_ml`・`absorption_ppm`（例 500・120000）。質量は素地（例 600 g） |
| `wood_tar` | 炭焼きの下の壺から（全部を塗る。封じるときは 5 g が栓に） |
| `firewood` | 任意。焚き火で器とタールを温める（300 g 燃やす） |
| `fixture_tar_brush` | 刷毛と栓。温めるときは `open_fire_pit` も |
| `fixture_vessel_stand` | 漏れを試す台。`sunExposure` 0〜1 |
| 手の仕事 | タールを塗る工程に `mechanical` 15 W 以上、15分 |

## 2. 住人が試して分かること（試験の値、28 °C・湿度75%・日陰、500 mL の器に水 450 g、3日）

| やり方 | 結果 |
|---|---|
| 何も塗らない | 外側がしっとり冷たい。水がはっきり減る（216 g：壁が吸う分＋しみ出して乾く分） |
| 冷たいままタールを塗る（15 g） | 「表面に乗っているだけ」。ふさがり 56 %、水は 95 g 減る |
| 器とタールを温めて塗る（15 g） | 「しみこみ、黒く光る」。ふさがり 94 %、水は 14 g しか減らない |
| 口だけ封じて水に沈める | 細かい泡が続けて出る（壁から抜ける） |
| 温めて1回塗って封じる | しばらくすると小さな泡がときどき出る |
| 温めて2回塗って封じる | 泡は出ない |
| 日なた（33 °C の日に器が 48 °C） | タールがやわらかく垂れて、ふさがりが減る |
| 湿った無風の日 | しみ出しが遅い |

## 3. 本体への換算表（ロット → 設備）

組み立ては本体の仕事。科学側の値はすべて仮定で、Codex の照合の後に直すことがある。

| 設備（今の試験用） | params | 器のロットから |
|---|---|---|
| 気圧計の器（`fixture_air_barometer` の後継、自作の気圧計で使う） | `bulbVolumeMl` | `capacity_ml` |
| 〃 | 空気の漏れの時定数（自作の気圧計で新設） | `air_leak_tau_min`（`sealed` が 1 のときだけ。0 は使えない） |
| 油の壺（油の灯りで使う） | 容量・しみ出し | `capacity_ml`・`coverage_ppm`・`absorption_ppm`（油のしみ出しは灯りの工程で） |

決めてほしいこと（本体）：組み立てのしかた（いつ・誰が・何を消費するか）、設備を壊したとき・使い終わったときにロットへ戻すか。

## 4. 値の扱い

すべて仮定（`params.ts`）：タールがふさぐ割合の基準（温め 150・冷たい 500 g/m²）、封じのタール 5 g、温める薪 300 g、手間、しみ出しの基準 40 g/日、空気の時定数の基準 2 時間、壁が吸う時定数、タールが垂れる温度 45 °C と速さ、器の形（球＋2割）。扱わないもの：冷えた夜のタールのひび、タールが日にちをかけて深くしみる、器そのもののひび、油を入れたとき。
