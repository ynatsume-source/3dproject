# 手順書：気密の器（試験用の焼いた器＋木タール）

2026-10-05 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

設計案 [SEALED_VESSEL_DESIGN.md](SEALED_VESSEL_DESIGN.md) のオーナーの決定（2026-10-05）：① 試験用の焼いた器から始める（器の乾燥・焼成は後で置き換え）、② ロットを設備にするのは本体の「組み立て」、科学側は換算表を出す、③ 気圧計の器 500 mL、油の壺は数百 mL。

```
試験用の焼いた器 → p16x タールを塗って封じる（世界の時計） → p17x 漏れを試す（島の時計） → 本体が組み立て（気圧計の器・油の壺）
```

## 2. 住人が試して分かること（試験の値、28 °C・湿度75%・日陰、500 mL の器に水 450 g、3日）

| やり方 | 結果 |
|---|---|
| 何も塗らない | 外側がしっとり冷たい。水がはっきり減る（216 g：壁が吸う分＋しみ出して乾く分） |
| 冷たいままタールを塗る（15 g） | 「表面に乗っているだけ」。ふさがり 56 %、水は 95 g 減る |
| 器とタールを温めて塗る（15 g） | 「しみこみ、黒く光る」。ふさがり 94 %、水は 14 g しか減らない |
| 水を捨てた湿った器を日なたに置く（33 °C・湿度40%） | 空けてすぐは外側がしっとり。壁の水 72 g が乾いて、6日目には乾いている |
| 封じた器 | 水は入れられない。空気を保つ時間 `air_leak_tau_min` は世界の隠れた値（口だけ 120 分、温めて1回 743 分、2回 11458 分：住人が読む値ではない） |

水に沈めて泡を見る（`submerge`）は**保留**（Codex A4）：泡が何を語るかは、器の中の空気の量・内外の圧力・浸す深さと時間・入ってくる水で変わり、今のモデルはそれを持たない。気密性の内部値を泡の言葉に直すことはしない。空気を閉じ込めた試験は、圧力を扱う自作の気圧計の工程で行う。

天気が分からない区間があった run では、その後は何も観察しない（帳簿が世界より遅れているので、減った量を事実として言わない：A5）。もう一度見るには、器を下ろして新しい run で置き直す。
| 日なた（33 °C の日に器が 48 °C） | タールがやわらかく垂れて、ふさがりが減る |
| 湿った無風の日 | しみ出しが遅い |

## 3. 組み立て（本体の決まり ADR 0006 と、科学側の換算表）

本体の決まり：組み立ては必要なときだけ、ランタンが棚の前で、器のロット1つをまるごと設備にする。設備はそのときのロットの写しを持つ。使い終わっても設備のまま残し、試し直すと決めたときだけロットに戻す。壊れたら、かけらの材料ができるまで使えない設備として残す。

科学側の決定（本体の4つの問いへの答え）：

| 問い | 決定 |
|---|---|
| ① 設備の kind・catalogEntry | `assembled_pot`（両方とも）。気圧計の器にも油の壺にも同じ kind を使い、どう使うかは使う工程が決める |
| ② 換算表の版 | `civ-sci.pot-assembly/2`（`vessel.ts` の `POT_ASSEMBLY_TABLE`）。本体は組み立てた設備にこの版を記録する。/1 は傷んだ器の `sealed` を外していた（下の③、Codex A6） |
| ③ 傷んだ器（condition < 1）をロットに戻すときの品質 | **傷みは開栓ではない**（/2、Codex A6）。栓が口にあるかという物理の状態（`sealed`）と、空気を保つと分かっているか（`airtight_known`）を分ける。封じた器は `sealed: 1` のまま、`airtight_known: 0` を付け、`air_leak_tau_min` を外す。開いた器は開いたまま。ひびの損傷指数 `crack_ppm` に今回の傷み (1 − condition) × 1,000,000 を**足す**（上限 1,000,000）。condition が 1 なら写しのまま戻す |
| ④ かけらの材料 | 目録に入れる：`pot_sherds`。本体の決まりで、壊れた器は元と同じ質量の `pot_sherds` のロットに戻す。quality は `potSherdsQuality`（素地の吸水率・ついていたタール・壁の水）。使う工程はまだない（砕いて粘土に混ぜる、など後の候補） |

破片の quality（`potSherdsQuality`）は Codex の確認済み（lab e2a4147、2026-10-07）：壁の水・タール・吸水率・来歴を保ち、同じ質量で戻す限り丸めは増えない。

本体はこの2つの関数をそのまま呼べる（画面・保存・乱数を持たない）：

| 関数 | 中身 |
|---|---|
| `potToEquipmentParams(lot)` | 器のロット → 設備の params：`capacityMl`・`absorptionPpm`・`coveragePpm`・`sealed`・`airtightKnown`・`crackPpm`・`airLeakTauMin`（0 = 気圧計の器には使えない：開いている、または `airtightKnown` 0） |
| `potQualityOnReturn(copy, condition)` | 組み立てたときのロットの写し（前回戻した quality ではない）＋設備の condition → 戻すロットの quality |
| `potSherdsQuality(copy)` | 壊れたとき：写し → `pot_sherds` の quality（元と同じ質量で本体が作る。素地の吸水率・ついていたタール・壁の水） |

使う工程（予定）：自作の気圧計は `capacityMl`（器の容積）と `airLeakTauMin`、油の灯りは `capacityMl` と漏れ（油のしみ出しは灯りの工程で）。

**`airtight_known: 0` の器の扱い**：口は封じたまま。水は入れられず、内側も塗り直せない（どちらも封じたままなので拒否）。気圧計の器に組み立てない（`airLeakTauMin` 0）。気密性を確かめ直す圧力の試験と、栓を開ける工程はまだない。開ける工程（栓とタールをどう外し、どこへ行くか）ができたら、開けた器として塗り直し・封じ直しへ進める。それまでは棚に置いておく。

**ひびの扱い（C2）**：本体は組み立てるたびに condition を 1 にするので、1 − condition はその設備として使った間の傷み。写しのひびを残して今回の分を足す：

```text
crack_after = min(1,000,000, round(crack_before + (1 − condition) × 1,000,000))
```

将来 condition を器の一生の健康度にするなら、同じ傷みを二重に足すことになるので、この式を見直す。
`crack_ppm` は**試験用の損傷指数**で、ひびの幅・面積・割れた質量の割合ではない（係数 20 と condition との線形の対応は未校正）。住人に「ひびの割合」として渡さない。
ひびの項も壁の項と同じく蒸気圧差に掛かる「細かい通り道を経た蒸発」で、湿度 100 % なら水は減らない。底まで貫いて水が**滴る**割れ、ひびの幾何（幅・長さ）は扱っていない（扱うときは水頭と液体の流出を別に入れ、校正する）。p16x は内側を塗るだけで、割れを接ぐ・補強する工程ではないので、塗ってもひびは消えない（あらゆる微細なひびがタールでふさがらない、という材料の法則ではない）。

**`air_leak_tau_min` の定義（Codex 提案、e6668fb レビュー）**：一定温度・一定容積・一定外気圧の閉じた器で、小さい圧力差 ΔP が初期値の 1/e になる時間。完全な空気の入れ替わり・温度が追いつく時間・泡が止まる時間とは別。基準は 500 mL・28 °C・乾いた壁・栓込みで 2 時間（仮定、実測の裏付けなし）。0 は「使えない」、分母の下限による最大 1,200,000 分は「完全な気密」ではない。今の式は吸水率と coverage（とひび）だけで決まり、容量・壁厚・湿りを見ないので、500 mL の試験器専用の仮定。自作の気圧計では、線形の漏れ `dn/dt = −G(Pb − Pa)`、`G = Vref / (R Tref τref)` として、水柱の動きで容積が変わる釣り合い式に入れる（温度の時定数 `bulbTauS` とは別の名前・別の状態）。

## 4. 値の扱い

すべて仮定（`params.ts`）：タールがふさぐ割合の基準（温め 150・冷たい 500 g/m²）、封じのタール 5 g、温める薪 300 g、手間、しみ出しの基準 40 g/日、空気の時定数の基準 2 時間、壁が吸う時定数、タールが垂れる温度 45 °C と速さ、器の形（球＋2割）。壁が乾く速さ（中の水がなくなったら、湿っている割合に比例）も仮定。扱わないもの：冷えた夜のタールのひび、タールが日にちをかけて深くしみる、ひびの幾何と滴る漏れ、外側の乾きと壁の奥の水の区別、蒸発で器が冷えること（表面は「気温＋日射 15 K」のままなので、蒸発とタールの軟化を高めに見積もりうる）、水に沈めて泡を見る試験（保留）、封じた器を開ける工程、油を入れたとき。「ひんやりする」は温度の計算ではなく、しみ出す量のラベル。タールは濃縮した（常温で固い）ものを前提にする（採ったばかりの液状のタールは同じ物性ではない）。

## 追記（2026-10-09）：住人の焼いた器も気密の器に（p16x 0.1.2・p17x 0.1.3・換算表 /3）

自作の気圧計への下準備。野焼きでできた住人の器（`fired_pot`）を、試験用の器（`fired_pot_test`）と同じように封じ、水の試験をし、気圧計の器に組み立てられるようにした。

- 受け付ける器：`fired_pot_test` と `fired_pot`。返すときは同じ材料名で、`fired_pot` の形・壁の厚さ・表面積・焼いた組成・ひびの印（`form`・`wall_mm`・`surface_cm2`・`xd_*`・`sinter_ppm`・`crack` など）をそのまま持って返る。
- 壁の面積：`fired_pot` は自分の表面積（`surface_cm2`）を使う。試験用の器は今までどおりの仮定の形。
- `fired_pot` の素地そのものの水（`water_ppm`）は 0 であること（焼いた器）。壁が吸った水は今までどおり `x_water_ppm`。
- 換算表 `civ-sci.pot-assembly/3`：`fired_pot` も組み立てられる。傷んで戻ると、ひびの印 `crack` も 1 になる（もう鍋・二重の壺には組み立てられない）。
- 試験用の器の結果は前の版と完全に同じ（封じる 40 通り・水の試験 100 通りの比較。状態の器に `areaM2` が増えただけ）。古い版の run は版で拒否。
- 例（検査）：住人の 2 L の壺にタール 40 g を冷たいまま塗って栓をすると、空気を保つ時間は約 215 分。気圧計の器には足りないので、温めて塗る・タールを増やす工夫が要る（どこまで要るかは自作の気圧計の設計で決める）。
