# 手順書：ヤシ油（ミルクを搾る → 煮て油を取る）

2026-10-05 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

灯りの燃料（油の灯り：焼いた灯皿＋ヤシ油＋アダンの灯芯）への最初の一歩。2つの工程に分けた（1つの run は1つの時計）。

```
浜のヤシの実 → p30x_coconut_milk（世界の時計、手の仕事）→ p31x_coconut_oil_boil（島の時計、火の番）→ ヤシ油
```

## 1. 世界側が用意するもの

| もの | 中身 |
|---|---|
| `coconut` のロット | 漂着したヤシの実。量は mg（1個 約1.3 kg）、quality `count`（実の数）。外皮・殻・果肉の割合は任意（なければ仮定値） |
| `process_water` | 任意。果肉と同じ重さまで足すほど脂が多く出る |
| `fixture_coconut_tools` | 試験用の道具一式（杭・石・削る道具・布）。params なし |
| 手の仕事の申し出 | `mechanical` 1つ。30 W 以上が区間に均等に届くこと。1個 20 分 |
| `firewood` | 煮る工程の燃料（薪で焼く工程と同じ書き方） |
| `fixture_cook_pot` | 試験用の鍋：`heatCapJPerK`・`uaWPerK`・`heatShare`・`capacityMl`（例 1800・3・0.2・5000） |
| `open_fire_pit` | `maxBurnKgPerH` だけ使う |

## 2. p30x_coconut_milk（世界の時計）

- 4個（5.2 kg）と水 1.56 kg で 80 分。出るもの：外皮 1.8 kg、殻 0.7 kg（半分の殻 8 個）、ヤシの水 1.1 kg、ミルク 2.4 kg、搾りかす 0.7 kg。
- 水を足すと薄いミルクで脂が多く出る（366 g）。足さないと濃いミルク、かすが脂っぽい（261 g）。
- 外皮と殻は薪と同じ書き方（`water_ppm`・`ash_dry_ppm`）。殻は椀・燃料・炭・封じた器の候補。

## 3. p31x_coconut_oil_boil（島の時計、接続仕様 0.2.x）

- 操作：`fire_level`（0 弱・1 中・2 強、いつでも）、`look`（音・色・におい）、`take_off`（下ろす＝終わり）。
- 水が残る間は 100 °C で煮立つ。水が尽きると鍋はすぐ熱くなる（中火で 1分に十数度）。かすが金色→茶色になり、澄んだ油が浮く。強い火のまま・目を離すと焦げる。
- 精算：ミルク・薪を消費 → `coconut_oil`（`scorch_ppm`）、`coconut_latik`、薪の残り、灰、蒸気と CO2（空気へ）、O2 を取り込む（`drawn`）。水が残るうちに下ろすと、濃くなった `coconut_milk`（煮直せる）。
- 見ていない区間（天気 `unknown`）は火が落ちて止まる（薪で焼く工程と同じ）。

### 住人が試して分かること（試験の天気 28 °C、上の鍋、4個分のミルク）

| やり方 | 結果 |
|---|---|
| 中火で煮る、1分ごとに見る | 約3.2時間ぐつぐつ → ぱちぱちに変わる |
| ぱちぱちで弱火にし、色づいて10分で下ろす | 澄んだ淡い油 約280 g（脂 366 g の約4分の3） |
| 中火のまま、10分ごとにしか見ない | 気づいたときには油が色づいている（焦げ 4〜5 倍） |
| 強火のまま | 茶色く焦げ臭い油 |
| 1時間で下ろす | まだミルク（濃くなっただけ） |
| 最初から弱火 | 6時間たっても水が多い |
| 薪が足りない | 火が尽きて冷める |

## 4. 本体側で決めること

1. ヤシの実のロット：漂着物の `coconut` を、拾ったときに何 mg・何個のロットにするか。腐った実・芽の出た実の扱い（v0 では扱わない）。
2. 鍋：試験用の `fixture_cook_pot` の値。住民が焼いた鍋（素焼きは油を吸う）は後の段階。
3. 火の番：煮ている間、住人がそばにいる必要があるか（look の間隔が結果を変える）。
4. 真水の元（ミルクに足す水）。

## 5. 値の扱い

すべて仮定（`params.ts`）：実の部分の割合、果肉の水・脂（食品成分表の生の果肉の値に近いが未照合）、搾りで出る割合、手間、鍋に入る火の熱の割合、色づき・焦げの速さ、油の分かれる割合。水の蒸発熱は出典あり。ヤシ油が約24 °C より冷えると固まることは、今の工程では扱わない（灯りの工程で必要になる）。

## 6. 0.1.1 の変更（Codex のレビュー eaa2a84 への対応）

- 見る（`look`）は鍋に触れない。何度見ても油の量は変わらない。
- 鍋は run の始まりからの 0.25 秒の格子で計算する。要求の区切り方（30秒・10分・1時間・格子外）によらず、油の量は 1 mg 以内で同じ。0.1.0 は 30 秒刻みで、油を2割ほど多く見積もっていた。
- 鍋と中身が持つ熱を `storedJ` で報告する（温まると正、冷えると負、終わりに 0 に戻る）。
- 油が分かれる前に下ろすと、入れたものと同じ material が戻る（濃くなったミルク、色づきの度合いつき）。もう一度火にかければ続きから。色づきの途中で下ろしたかす（`coconut_latik`）も火に戻せて、残りの油が取れる。
- 状態は `civ-sci.coconut-boil/2`。0.1.0 の run（`/1`）は拒否するので、本体は run を中止して予約を解放する（ミルクと薪は消費されていない）。
