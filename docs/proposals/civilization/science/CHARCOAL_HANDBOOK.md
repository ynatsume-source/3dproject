# 手順書：炭と木タール（二重の壺）

2026-10-05 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

ランタンの発明の順番の3つ目。**木タール**は気密の器・自作の気圧計の封じに、**炭**は後の金属の入口になる。最初は少量で両方が取れる**二重の壺**にした（たくさん炭を作る土の窯は後で）。

```
上の壺（底に穴、薪やヤシの殻を詰めて口を下に）
下の壺（地面に埋める：落ちてくるタールと木酢液を受ける）
まわりで焚き火 → 中は空気がないので燃えず、乾いて、分解して炭になる
```

## 1. 世界側が用意するもの

| もの | 中身 |
|---|---|
| 詰めるもの | `firewood` / `coconut_shell` / `coconut_husk`、または焼き残りの `charcoal` のロット。**location をレトルトの equipmentId にする**（中に入っている印）。レトルトの中のロットはちょうど1つ |
| 燃料 | `firewood` のロット（レトルトの外。中にあると拒否） |
| `fixture_tar_retort` | `heatCapJPerK`・`uaWPerK`・`heatShare`・`capacityMl`・`collectShare`（例 4000・2.5・0.35・8000・0.6） |
| `open_fire_pit` | `maxBurnKgPerH` |

接続仕様 0.2.x のみ（火が O2 を取り込む）。島の時計。

## 2. 操作と結果

- `fire_level`（0 弱・1 中・2 強）、`put_out`（火を止める。器はその場で冷える）、`look`、`open`（取り出す＝終わり、ここで一度だけ精算）。
- 精算：詰めたもの・燃料を消費 → `charcoal`（`charred_c`＝最高温度）、`wood_tar`、`wood_vinegar`、燃料の残り、灰。煙（タール）・ガス・水蒸気・CO2 は空気へ、O2 を取り込む。
- 何も分解しないうちに開けると、詰めたものがそのまま（乾いた分だけ軽く）戻り、次の run にそのまま使える。

### 住人が試して分かること（試験の値、薪 2 kg を詰める、28 °C）

| やり方 | 結果 |
|---|---|
| 中火 → 200分で火を止め → 冷ましてから開ける | 炭 約680 g（乾いた木の4割）・タール 約120 g・木酢液 約200 g。「黒く軽い炭。打つと澄んだ音」 |
| 煙を見る | 白い湯気 → 黄色っぽい濃い煙 → 細く青っぽい煙（できた合図） |
| 火を止めて10分で開ける | 開けたとたん炭が燃え出し、3割ほど失う |
| 弱火のまま | 器が熱くならず、茶色い木のかけらのまま |
| 強火 | 熱くなりすぎ、炭が少し減る |
| ヤシの殻（8個分 676 g） | 炭 約240 g |

## 3. 本体側で決めること

1. 詰めるロットを「レトルトの中」に置く表し方（location ＝ equipmentId）でよいか。
2. 二重の壺：試験用 `fixture_tar_retort` の値。住民が焼いた壺で作るのは、壺の焼成ができてから。
3. 火の番（`look` の間隔で、開けどき・火を止めどきが分かる）。
4. タールと木酢液の置き場所（下の壺ごと）。

## 4. 値の扱い

すべて仮定（`params.ts`）：分解の速さ、炭・タール・水の割合と温度による変化、下の壺に落ちる割合、器に入る火の熱の割合、炭が燃え出す温度、炭の発熱量。炭の組成は CH0.4O0.09（400〜500 °C の炭に近い組成近似）。扱わないもの：分解そのものの熱、ひびからの空気、高温でのタールの分解、木の太さ、木酢液の酸、壺が割れること。

## 5. 0.1.1 の変更（Codex のレビュー 5555989 への対応）

- 炭が空気に触れるのは、開けたとき（`open`）、人が取り出したとき（`stop: operator`）、レトルトを失ったとき（`equipment-lost`）だけ。天気が分からない区間（だれも見ていない）は、壺を閉じたまま run が止まる：中身は最後に分かっている状態のまま、何も燃えない、来歴は不完全、中身の観察も返さない（だれも開けていない）。
- 弱火で残った茶色い炭（`charcoal`、木が残っている）は、そのまま詰め直せる。できている炭はそのまま持ち越し、残りの木が炭になる。
- レトルトの中にロットが2つあると拒否（どちらが燃料か分からない）。燃料はレトルトの外。
- run の途中でレトルトや炉が変わったら `changed-input`（失ったときは `equipment-lost` を送る）。
- 状態は `civ-sci.charcoal-retort/2`。0.1.0 の run（`/1`）は拒否するので、本体は run を中止して予約を解放する（詰めものと燃料は未消費）。

### モデルの限界（Codex の照合から）

- **炭の収率は、木が最初に分解したときの温度で決まる。** 一度できた炭を後で強く熱しても減らない（二次的な揮発を扱わない）。だから「最高温度」と「炭のでき方」は同じ意味ではない。
- 約4割（標準の結果、詰めた乾いた木あたり 39.9 %）は、400 °C 前後の低温の炭なら桁としてありうる（FAO：400 °C 以下で約42 %、500 °C で約33 %）。ただし二重の壺で確かめた値ではない。外で燃やした薪の乾いた分も分母に入れると、工程全体では 17.1 %。
- 分解そのものの熱は 0 とした（燃焼熱に比べて小さいという近似。分解中の温度や時間への影響までは確かめていない）。白い煙から青い煙へ、熱いうちに開けると燃える、焼き残りは詰め直す、は FAO の手引きと合う。黄色の段階、300 °C で燃え出す、開けたときに燃える割合は照合していない。
