# 手順書：器を野焼きで焼く（p13y_pot_pit_fire 0.1.1）

2026-10-07 / ブランチ `codex/civilization-simulation` / **未採択の提案**（Codex の全面レビューと本体の最終レビューの後に統合）

設計案 [POT_FIRING_DESIGN.md](POT_FIRING_DESIGN.md) の2つ目。形づくって乾かした器（[POTTERY_HANDBOOK.md](POTTERY_HANDBOOK.md)）を、地面で薪に囲んで焼く。島の時計、接続仕様 0.2.x のみ（火が O2 を取り込む）。

## 1. 入れるもの・決めること

- ロット：器1つ（`dry_pot`、乾ききっていない `green_pot` も可：蒸気で割れやすい）と `firewood` 1つ。割れて分かれた器は断る。
- 設備：`open_fire_pit`（場所）。器を囲んで積む火の値は科学側の仮定（`pit*`、料理の焚き火の値は使わない）。
- 天気：気温・湿度・風・雨（どれかが欠けたら火を起こさない／途中なら止める。明示の 0 は有効）。
- 最初の依頼の `interval.from` に `fire_plan` を1回：`preheatMin`（あぶる時間）、`pace`（0 ゆっくり・1 ふつう・2 速く）、`targetGlow`（0 暗い赤〜3 黄）、`holdMin`、`forcedCooling`（0 灰の中で冷ます・1 引き出す）。操作 `look` でその時刻の火と器を見る（物理に触れない）。

## 2. 住人が試して分かること（4 L の鍋、日陰で8日乾かした器、乾いた薪 40 kg、28 °C）

| やり方 | 結果 |
|---|---|
| 1時間あぶる・ゆっくり盛り上げる・桜色で30分・灰の中で冷ます、風 1 m/s | 島の時計で約8時間、薪 約32 kg。焼けた鍋（吸水 約14%）。割れたのは 20個中1個 |
| あぶらない・速く・引き出して冷ます | 20個中15個が割れ、10個はかけらに（冷めるときの石英の転移） |
| 気をつけても風 6 m/s | 20個中6個が割れる（片焼け） |
| 1日しか乾かしていない湿った器を速い火へ | 20個中13個が蒸気で割れる。3時間あぶれば1個 |
| 切ったばかりの薪（水 45%） | 煙ばかりで炎が弱く、約 440 °C まで。器は焼けず、土のまま（「水に入れると崩れる」） |
| 強い雨（8 mm/h） | 約 410 °C までしか上がらない |

住人が覚える工夫：よく乾かす・あぶる・乾いた薪を使う・風のない日を選ぶ・灰の中でゆっくり冷ます。どれも観察から気づける。

## 3. 物理（すべて仮定、`params.ts`）

- 火と器は「薪で焼く」工程（p13w）と焼き物の共通の物理（`kiln-ware.ts`）をそのまま使う：壁の厚さに応じた遅れ、乾き切らない水の蒸気、573 °C の石英の転移、脱水、焼き締まり。
- 野焼きの火：熱容量 30 kJ/K、熱の逃げ 25 W/K、燃えた熱のうち器のまわりに残る割合 0.35、燃やせる速さ 40 kg/h。盛り上げ 300/600/1200 K/h。あぶりは 60 K/h で 150 °C まで上げて保つ。
- 湿った薪：薪の水が湿った重さの 2 割を超えると、1 割ごとに器に届く熱が 25% 減る（下限 1 割）。
- 風：地上 10 m の風が 3 m/s を超えると、その比で片焼けの割れやすさ。
- 雨：器に届く熱 ÷（1 + 雨 mm/h ÷ 2）。
- 手で積んだ器の見えない欠陥：どれだけ気をつけても 8% が割れる（半分は細いひび、半分はかけら）。
- 冷まし方：灰の中なら熱の逃げ 0.3 倍、引き出すと 3 倍。
- 焼けたかどうか：300 °C を超えて熱くなれば割れは起こりうる。粘土の鉱物が水を手放す（脱水）まで焼けて初めて `fired_pot`。足りなければ器のまま（`dry_pot`）。
- 割れは run の seed と器ごとに決まる（区切り方で変わらない）。割れて分かれた器は、焼いた後の質量の `pot_sherds`（`potSherdsQuality` の形）。
- 吸水率：試験片の浸す工程と同じ式（焼き締まりから、冷たい水に浸したとき）。

扱わないもの：砂・貝殻の混ぜ物（貝殻の石灰化を含む）、煙で黒くなること、器をいくつも一緒に焼くこと、器そのものの強さと壁の厚さの関係、薪で焼く工程（p13w）への湿った薪の炎（同じ式を入れるなら版を上げる）。

## 5. 0.1.1 の変更（島の粘土は草や根を含む）

0.1.0 は粘土に有機物（`xd_organic_c_ppm`）があると拒否していた。島の粘土は 1% 含むので、このままでは焼けない。

- 有機物は野焼きの火の中で燃えて抜ける（400 °C あたりから）。燃やす O2 は空気から取り込み（`drawn`）、CO2 として出す。質量は閉じる。
- 燃え残ったまま冷めた器は「割ると、器の芯が黒い（土の中の草や根が燃え残っている）」と言う。
- 生木で火が育たなかった場合、有機物は抜けても、器は素焼きにならない（`dry_pot` に戻る。割れたら `pot_sherds`）。
- 共通の焼き物の物理（`kiln-ware.ts` の `advanceWare`）に、有機物を燃やすかどうかの選択（`burnOrganic`）を足した。指定しなければ今までと同じなので、試験片と電気の試験窯の結果は変わらない（試験片の検査 32・52・18・24・47 件で確認）。
- 状態の形は同じ。0.1.0 の run は版で拒否（本体が取り消して中身を返す）。
