## 実際の回収物で確認したこと

前回と同じ実4個＋加水1.56 kgのミルクを、標準条件で中火加熱。
下表の時刻に下ろし、そこで生成されたミルク／かすと、そのrunが返した薪を次へ渡した。
品質の色の値を検査用に作り込まず、各回収物を弱火で5分煮直して確認した。

| 最初に下ろした時刻 | 回収物のbrown / scorch（ppm） | 煮直し後の観察 |
|---|---:|---|
| 189分 | 0 / 0 | かすはまだ白く、澄んだ油はほとんど分かれていない |
| 195分 | 312638 / 13817 | かすが色づき始めたが、澄んだ油はまだ分かれていない |
| 200分 | 1000000 / 132615 | かすは茶色く、もう油は出てこない |
| 205分 | 1000000 / 755792 | かすは黒く焦げていて、もう油は出てこない |

4条件とも追加の油は0 mg、褐変・焦げの品質は煮直し前の値を維持し、言葉がそれに対応した。
特にA3の「205分のかす＋返却薪→弱火5分」は、焦げたままなのに白いという観察を返さなくなった。

修正前24b8ad4と修正後b033ef7へ同じ入力を送り、各初回・煮直しの結果を比較した。
観察とevidenceを除く全結果（状態・時刻・status・消費／生成／放出／取り込み・J・設備消耗・diagnostics）が一致した。
