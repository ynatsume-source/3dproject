## 明示的に選ぶ仮定

必須ID：`owner-assumption/coir-cord/2026-10-15/v1`。生成APIはID省略・未知のIDを拒否し、黙ってこの値へ切り替えない。共有の `COIR_CORD_RULES` はfreezeし、`evidence: owner-assumption-not-calibrated` を付ける。係数、時計、配分や丸め規則を変えるならIDの版を上げる。種類名を「校正済み」としない。

| 項目 | 仮定（キメ値） |
|---|---|
| 乾燥 | 屋根の下・島時計3日。水の終点は元の全乾物の1/10（整数mgで切捨て）、もともと少ない水は増やさない |
| 篩い | 世界時計、繊維乾物72,000 mgにつき60,000 ms。髄は繊維乾物の1/10まで落とす |
| 撚り糸 | 世界時計、1 mmにつき乾物5 mg、手作業120 ms。要求長は正の整数mm |
| 縄 | 三本の最短長の9/10（整数mm切捨て）、1 mmにつき手作業60 ms |
| 糸の切れる重さ | 基準40,000 gf。髄/繊維が1/10以下は100%、1/10〜2/10で100%から70%へ直線 |
| 撚りの出来 | 各runの32bit seedから固定した整数係数850,000〜1,150,000 ppm。呼出しごとに振り直さない |
| 縄の切れる重さ | 使用する三本の**現在の強さ**の最小値 × 255/100、整数gf切捨て |

| 擦れ | 本体が確定した使用回数1回につき0.99倍。質量の削り屑はv1でモデル化しない |
| 濡れ・海水 | v1では濡れ/海水による強度劣化を計算しない。吸水や排水を勝手に増減する工程ではない |
| 見た目 | 1年相当の曝露で色あせ、擦れ1回以上で擦れ跡という観察用の仮定 |

未指定部分への追加の仮定：
- 「同じくらいの長さ」は `最大長−最短長 ≤ max(1 mm, floor(最短長/10))`。最短3 mm未満は縒り合わせを拒否し、完成縄は最低2 mmになる。
- 髄が繊維乾物の20%を超える束は、撚り糸にする前に篩う。20%を超える強度曲線を勝手に外挿しない。篩い自体は湿っていても受け付ける。
- 整数mmでは1 mm片を正長の2本へ分けられない。1 mm片への再破断試験、または比例配分で片側の繊維が0 mgになる破断は、物と状態を変えず明示拒否する。0 mm片や、長さ・質量の複製で帳尻を合わせない。通常の数mの材料を止める条件ではない。
- 手間の比例縮尺はmsへ切上げ、配分は整数の累積から算出。seed係数は有限個なので、異なるseedが同じ係数になる場合はある。
- 仕掛かりは同じrunの保存で続ける。途中の配分snapshotを独立の新品ロットとして再投入しない。

## 材料と水の収支

`CoirBundle` は `lotId, fiberDryMg, pithDryMg, waterMg`。水と付着髄を繊維に改名して消さない。PR20の分離した繊維乾物・付着髄乾物と、両方の保持水の和を明示的に渡す。未分離殻、PR12で仮分割済みの出力、汎用の原料を自動変換するadapterはない。

### 1. 乾かす

屋根があると本体が確認した島時計の区間だけを積算する。雨にさらす入力は拒否する。元の水から終点まで、3日の累積時間に比例して失う水を切捨て算出し、`releasedWaterMg`へ記帳する。抜けた水は空気へ出た水蒸気。3日後は配分を固定し、乾物は変えない。すでに終点以下の束はそのまま完了する。

温湿度・風・水分平衡の測定値を予測するモデルではなく、屋根下の3日というv1の仮定である。

### 2. 髄を振るい落とす

`ceil(60000 × 繊維乾物mg / 72000)` ms。すでに髄が繊維の1/10以下なら手間0・材料変化なし。取り除く髄の累積mgは元入力と確定手作業の累積から算出する。

残束水は `floor(元の水 × 残乾物 / 元乾物)`、差を落ちた髄の水として保つ。`fallenPith` は髄乾物とその水を持つ出力であり、蒸発・廃棄ではない。この丸めにより、乾いた束の余りだけが湿りすぎて次へ進めなくなる問題を避ける。

### 3. 撚り糸

入力水が全乾物の10%を超えれば「湿っていて撚れない」として拒否。材料の必要乾物は `要求mm × 5 mg`、不足なら何も消費しない。進捗mmは `min(要求mm, floor(累積手作業ms / 120))`。

製品の繊維乾物を `ceil(使用乾物 × 元繊維 / 元乾物)`、残りを製品の付着髄とし、元入力からそれぞれ引いた量を残束へ置く。残束水は上記と同じく残乾物への比例切捨て、差が糸の水。このため小さな製品には1 mg未満の丸めに相当する水が多めに付く場合がある。水を乾物へ変えず、糸・縄はその実量を持ち続ける。湿り判定は新しく撚る**繊維束**に適用し、糸の水を捨てて合わせない。

整数配分で残束の髄/繊維比が元より高くなる場合がある。例：繊維9・髄1 mgから1 mmを撚ると、余りは繊維4・髄1 mgとなり、直接の再撚りは髄比25%のため拒否される。余りは捨てず、必要なら再度篩ってから使う。

強度は元束の髄比とseedからrun開始時に一度決まる。途中の描画・読み・保存・刻みで変わらない。

### 4. 三本を縒り合わせる

別のlotIdを持つ三本の撚り糸を受け付ける。完成時には各糸を最短長だけ使い、長い糸の残りを元の強さ・傷みを保つ糸として返す。長さの縮みは質量損失ではない。

途中の縄長は `floor(累積手作業ms / 60)`。使う各糸の長さは最短長を進捗縄長/完成縄長で比例切捨てし、完成時に最短長まで正確に使う。各糸の使用乾物は使用長に比例して切捨て、成分・水は上記の配分規則で製品と残りへ分ける。残りが0 mmなら製品ロットとして返さない。

新しい縄の初期強度は三本の現在強度の最弱値から決め、その後の傷みを新しく積算する。古い糸の見た目の色あせ/擦れ跡は `inheritedWear` に残す。傷んだ糸を縒り直して新品の強さや見た目に戻さない。

## 時間・保存・再送

`createCoirCordModel(input, assumptionId, context)` のcontextはworldId・worldEpoch・runId・seed・clock・openedAtMs。乾燥だけisland、ほかはworld。同じrunの入力・ID・係数・contextを保存bindingへ含める。

`commit`が受け付けるのは完了済みの本体確認区間のみ。乾燥は `host-confirmed-roofed-wait`、手作業は `host-confirmed-manual-work` と在席・actorIdが必要。休みや不在の空白は積算せず、逆行・重複・ID競合・別run/世界/時計・未完了の確認を拒否する。同じID・同じ確認は後続区間後やJSON復元後も無変化。

`project`は世界の検証用の**累積snapshot**。毎回在庫へ足すdeltaではない。製品の `piece` / `bundle` は完了時だけ返す。途中の `product` や `leftovers` も仕掛かりの配分であり、在庫へ反映しない。製品・余り・落ちた髄・放出水の一括精算は `status === 'completed'` のときだけ行う。本体は元入力の排他予約、単一writer、一度だけの在庫置換と保存を担当する。これは本体にまだ接続していない。

一致の対象は同じ入力・runの**時間区間の分割**。材料を別ロット・別seedのrunへ分けると、作業配分・整数丸め・撚りの出来が変わる。

## 傷み・荷重・切断

`createCordDamageModel(piece, assumptionId, context)` は、元pieceと、world/island双方の開始時刻を明示したcontextを保持する。本体が既存の時計換算と出来事の順序を確定し、曝露はisland、擦れと荷重はworldのイベントとして渡す。モデルは両時計の換算を発明しない。

傷みの隠れた現在強度：

`floor(初期gf × 2^(-(日なたms/年ms + 日陰ms/(10×年ms))) × 0.99^擦れ回数)`

毎回前の整数gfへ掛ける方式にはせず、累積時間と累積回数から計算する。曝露の空白を勝手に足さない。擦れ・曝露・濡れで強さを回復させない。

荷重gfが現在強度を**超えたとき**だけ切れる。同じ値なら切れない。切断位置は正の整数で元長より短い位置。指定なしは `floor(元長/2)` と残り。各成分は位置比による切捨てと差に配分し、二片の長さ・繊維・髄・水の和を元に一致させる。二片は元の初期強度と累積傷みをともに引き継ぎ、その時点の強さも等しい。

同じ破断イベントの再送は無変化。破断後に新しいイベントを足すことは拒否し、以後は二片をそれぞれ新しいrunで扱う。破断後の片をもう一度使っても傷みを消さない。

## 住人へ渡すもの

`project`・保存state・材料の隠れた強度は世界側だけが扱う。`observe`は見た目/手ざわりの短い言葉のみ。毛羽、太さの見た目、湿り、色あせ、擦れ跡、実際に切れた事実を返す。強度gf、seed、ぶれ、配分表、係数、未計量の重さは返さない。

長さの数値は、本体が実際の巻尺測定を確認した `host-confirmed-length-measurement` を渡した場合だけ製造モデルの観察へ追加する。重さは別の秤量工程の責任。強さは世界の荷重試験の破断有無としてしか住人へ知らせない。

現在のmainの原料 `coconut_husk → lamp_wick` は水・髄を読まず同量の乾いた芯にするため、この湿繊維を直結しない。今回の乾燥終点にも水が残る。油の灯りへ渡す芯の水・髄の扱いは別の接続レビューで決め、今回「灯った」とは扱わない。

## 標準殻の計算例

PR20の殻1個：入力900,000 mg。分離後は繊維72,000・付着髄14,400・保持水115,200 mgの束と、残留殻518,400 mg・排水180,000 mg。

| 工程 | 残る製品 | 別に出るもの |
|---|---|---|
| 屋根下3日 | 繊維72,000＋髄14,400＋水8,640 mg | 水蒸気106,560 mg |
| 篩い1分 | 繊維72,000＋髄7,200＋水7,920 mg | 髄7,200＋水720 mg |
| 撚り糸 | 5,280 mmを3本（糸の合計15.84 m） | この例では余りなし |
| 縄 | 4,752 mm、乾物79,200＋水7,920 mg | 糸長の余りなし |

`縄87,120 + 落ちた髄7,920 + 蒸発106,560 = 元の束201,600 mg`。残留殻と分離時の排水まで合わせれば900,000 mgで閉じる。手作業は篩い1分＋糸31分40.8秒＋縒り4分45.12秒＝37分25.92秒、PR20の打ち分け4分を含めると41分25.92秒。島時計3日の待ち時間は別。

「72 gなら約14 m」は繊維だけなら14.4 mという目安。v1では篩い後の付着髄7.2 gも糸の乾物に含めるため15.84 mとなる。縄は1個で約4〜5 m、10〜20個で数十mという桁は保つ。これは実測校正ではない。
