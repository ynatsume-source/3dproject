# 科学チームへの依頼：住処の材料（2026-10-08）

本体（main）から科学チームへ。住処のテーマ（`docs/proposals/sumika-2026-10-07.md`）で、ドットの家・石垣・ラッコの休み場まで島で動くようになった。ただし、縄・土壁・石の材料は、いまは本体の仮の決まり（帳簿の数字だけ）で動いている。科学の工程にしてほしいものを3つ挙げる。急ぎではない。器を焼く工程と二重の壺（AS-A1）のあとでよい。

## いま本体で動いているもの（仮の決まり）

| もの | 本体の今の決まり | 足りないところ |
|---|---|---|
| 縄 | ドットが作業台でアダンの気根の繊維をよる。1回（60〜90秒）で10 m。家の工程ごとに使う（桁3 m、筋交い・垂木2 m、茅4 m、壁下地4 m、床4 m）。帳簿は `village.house.rope`（m）だけ | 繊維を取り出す手間（浸す日数）がない。強さ・濡れての傷みがない。1回で10 mは速すぎるはず |
| 土壁 | 南の島（sopunu）の粘土を筏で運び、壁1面に150 kg塗る。塗ったらすぐ「家」になる | 配合（粘土・砂・すさ・水）、乾く時間、ひび、雨で削れる速さがない。科学側の粘土の値（`island-clay` の south-near）とつながっていない |
| 石垣 | サンゴ石24個の空積み（モルタルなし）。ラッコが海の底から運び、ドットが積む。石は数だけ | 石の重さ・大きさがない。漆喰（石灰）で固める段階がない |

## お願いしたいこと

### 1. 縄（アダンの気根・ヤシ殻の繊維）
- **繊維を取る工程**：気根やヤシ殻を水（海水・雨水）に浸して柔らかくし、たたいて繊維を取り出す。日数は島の時計で、水温（記録の気温）次第。入力は `pandanus_root` / `coconut_husk` のロット（いま島にはない。本体が浜や林から集める決まりを作る）、出力は `plant_fiber`。
- **縄をなう工程**：繊維から縄をなう。1時間あたりの長さ、太さ、1 mあたりの質量。出力は `rope`（`quality` に長さ・太さ・強さ）。
- **使うときと傷み**：家の結び目に使った縄の強さと、濡れて乾いてを繰り返したときの傷み。台風で結び目が切れる確率につなげたい（本体は、茅が飛ぶ判定にこの値を足す）。
- 本体が欲しい値：1 mあたりの繊維の量、なう速さ、切れる強さ、濡れたときの傷み方。

### 2. 土壁（粘土・砂・すさ）
- **土を練る工程**：粘土に砂と切った草（すさ。茅の残りを使う）と水を混ぜる。配合の幅と、配合で何が変わるか（ひびの出やすさ、乾く速さ、強さ）。粘土の下ごしらえ（p10x・p10y）と同じ形で、出力は `daub` のロット。
- **壁で乾かす工程**：塗った壁が乾くまで（島の時計、記録の気温・湿度・風）。乾く前の雨で流れる量。乾いたあとのひび。壁は設備でなく家の一部なので、本体は壁1面を1つのロット（`daub_wall`）として扱い、乾きを進める形を考えている。形の案があれば教えてほしい。
- **雨で削れる速さ**：乾いた土壁が、雨量と風（横から当たる雨）でどれだけ薄くなるか。本体はこれを家の手入れ（塗り直し）の作業につなぐ。
- 本体が欲しい値：配合の表、乾く時間、雨で削れる速さ、塗り直しに要る量。

### 3. サンゴの石灰（漆喰）
- **石を焼く工程**：海の底のサンゴ石（炭酸カルシウム）を薪で焼いて生石灰にする。どのくらいの温度と時間が要るか、野焼きや穴の窯で届くか、薪が何 kg 要るか、どれだけ取れるか。入力は `coral_rubble`（ラッコが運ぶ石。重さ・すき間の割合）と `firewood`、出力は `quicklime`。
- **石灰を水でならす工程**：生石灰に水を加えて消石灰にする（熱が出る）。出力は `slaked_lime`。
- **使い道**：石垣の目地や家の土壁の上塗り（漆喰）。漆喰を塗ると雨で削れにくくなるか（2とつながる）。石垣を固めると台風での崩れ方が変わるか。
- 危ないところ：生石灰は水で熱を出し、ロボットの関節を傷めるかもしれない。傷みの決まり（本体）につなぐ値があれば。
- 本体が欲しい値：焼く温度・時間・薪の量・取れる量、ならす水の量、漆喰の配合と乾き方。

## 順番の案
本体からの案は、1 縄 → 2 土壁 → 3 石灰。縄は家のどの工程でも使い、いちばん頻繁に出てくる。土壁は家の手入れになる。石灰は新しい工程なので最後にした。科学側の都合で入れ替えてよい。

## 本体で先に用意できること
- 気根・ヤシ殻・サンゴ石を集めてロットにする決まり（どこで、1回にどれだけ）。
- 壁1面を1つのロットとして扱う帳簿の形（2の形が決まってから）。
- 台風で結び目が切れる判定、壁の塗り直しの作業（値が届いてから）。
