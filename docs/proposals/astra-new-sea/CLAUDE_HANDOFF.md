## 提案の中心

Point Lobos / Bluefish Cove を題材にした温帯Macrocystis林。岩と砂の専用地形、地面の三角形に沿う付着器、曲がる茎と高さの異なる茎、水面天蓋を一体で比較してほしい。地名は実在するが、測深・岸線・植生被度・写真を照合した復元ではない。先行Monterey案と併設する既定海域の追加ではなく、どちらを基礎にするかの比較候補。

新しい森の基礎に今回の地形・接地・茎・高低・天蓋を、葉の細さと模式地図には先行案の一部を検討できる。種の細部と負荷は採用前に確認する。既存Claude作業の上書きや基盤の組み替えは避け、必要な差分だけ最新mainへ移す。

## 最新mainへ持ち込むときの競合

比較担当が `4219cb0` のmainとのmerge-treeで **`src/ocean/build.ts` の内容競合**を確認した。この試作ブランチは共通基点のまま保ち、rebaseしていない。

最新mainではサンゴ配置が `coralAt(...)` 関数へ抽出されている。試作の `if (!(tot > 0)) continue;` は、移す先の `coralAt` 内では **`return`** に変える必要がある。これは競合印のない箇所でも必要な意味上の適応である。`coralAt` / `grow` / `ZONE` 周辺を最新構造に合わせる。競合箇所だけ解決して完了としない。

`main.ts`、`models.ts`、`minimap.ts`、`locations.ts`もClaude側で編集されやすい共有部。最新mainに必要なhunkを移し、cherry-pickを使う場合も全ファイル置換に頼らず内容を確認する。既存の新海域・沈没船・住民・地形変更の意図を維持する。

## 海域切替の修正について

見ていない海の生態系は停止するため、古い海の被写体の `live()` が真のまま残り、PiPや捕食通知が別海に現れる不具合があった。異なる海へ入るときだけ、PiP、巡航被写体、観察キャプション、通知キュー、捕食ロック、一時マーカーと各表示タイマーを消す。

保存済みの `seaglass.log.*` や `seaglass.seen` は消さない。既存コードではコメント末尾に入り込んで実行されていなかった `U.uFire.value.w = 0` を独立文にし、入海時の `U.uCamCave.value = 1` も明示した。これはケルプだけの表示変更ではなく、既存海域にも効く修正なので個別にレビューする。

軽量画質のレビューでは宮古島へ永続する仮のPiP被写体・旧海通知を注入し、fire/cave値を変更した後で戻った。通常往復と合わせて成功し、最終結果を `browser-low.json` の `runtime.crossSeaCleanup` に記録した。`pip` がJSONにないのは被写体が `undefined` のため。`toast` は非表示要素に残るテキストも読むため、表示中の通知一覧ではない。
