# 科学チームへの依頼：ヤシ油の灯り（2026-10-09）

本体（main）から科学チームへ。「焼いた鍋でヤシ油を煮る」が住人の手で通った（oil-chain-check：ミルク 281.5 g から油 67.8 g）。次の使い道として、灯皿でヤシ油を燃やす灯りを工程にしてほしい。急ぎではない。縄・土壁・石灰の依頼（2026-10-08）と並べて、順番は科学側の都合で決めてよい。

## 島にもうあるもの
- `coconut_oil` のロット（p31x の生成物）。
- 灯皿：`fired_pot` の form 3 から `lampDishParams(lot)`（容量・吸水・質量）。本体では、ひびのない form 3 の器を灯皿の設備にできる（組み立ての表の形は鍋と同じにする予定）。
- 芯の材料の候補：アダンの繊維（縄の依頼と同じもの）、ヤシ殻の繊維、竹の細い割り。
- 火：焚き火（open_fire_pit）からの種火。

## お願いしたいこと
1. **灯す工程**：灯皿に油を入れ、芯を立てて燃やす。島の時計で、油の減る速さ（g/時）、明るさ（だいたいの光の量。ランタンの星の観察の邪魔になるか、手元が見えるか、の判断に使う）、煤、芯の燃え進み。風で消えるか（風速と覆いの有無）。
2. **油の質の影響**：p31x の油の質（水分・焦げ・固形分）で、燃え方や煙が変わるか。
3. **灯皿の吸い込み**：素焼きの灯皿が油を吸う量（吸水の値からの換算）。最初の一回は皿に吸われる、など。
4. **芯の材料**：アダンの繊維・ヤシ殻の繊維など、どれが燃えやすいか、どれだけもつか。

## 本体で使う場面
- ランタンは夜に星を観察し、気圧計を読む。灯りがあれば、手帖に書く・目盛りを読むのが楽になる。逆に、明るすぎると星が見えにくくなる。
- 家の中の灯り（夜の作業、台風の夜）。
- 本体は、油の在庫・灯皿・芯の材料から、灯せる時間を世界の帳簿として数える予定。
