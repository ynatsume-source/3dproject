# 殻と縄の見た目 その1：繊維の束（湿っている／乾いている）（自然班、2026-10-17）

本体の依頼（オーナー決定 10/17：殻と縄の作業は配信の必須）への1つ目。基点は PR #33 の先頭 `9e5f19f`（`src/world/worksite-look.ts`、main d6a6d03 の上）。

## 足したもの

- `src/robots/coir-look.ts`（新規）：作業場ごとの見た目の一覧（`WorksiteLook`）を受けて描く。
  - いまは繊維の束（`fiber-bundle`）の `wet` と `dry` だけ描く。それ以外の種類と見た目は読み飛ばす（次の段で足す）。
  - 型は本体の `src/world/worksite-look.ts`（PR #33）から読む。
  - 見た目の根拠は、種類と見た目の状態だけ。強さ・水の量・重さ・個数などの値は読まない。
- `src/ocean/build.ts`：住人を作ったあとに `oc.coirLook` を作る。試験用のつまみで、ドットの家の前の砂に試験用の作業場を置く：`?coirlook=wet` / `dry` は本体の試験用の値 `WORKSITE_LOOK_FIXTURES['fiber-wet']` / `['fiber-dry']`（`partial-husk` はまだ描かない）、`?coirlook=both` は湿り2・乾き2を並べた比較用。
- `tools/lab/coir-look.cjs`：試験用の作業場を、近く（しゃがんだ目線）と見守りの高さから撮る。

### 本体がつなぐ所

`cur.coirLook.set(looks, where)`：

- `looks` は `WorksiteLook[]`。
- `where(siteId)` は作業場の地面の位置と向き `{ x, z, face }` を返す。知らない作業場は `null` で、その作業場は描かない。
- 状態が変わるたびに呼ぶだけでよい。物は作り直さず、置き直しだけ（インスタンスの行列と数）。

## 見た目

| | 湿っている | 乾いている |
|---|---|---|
| 色 | 栗色、少しつや（2026-10-18 に少し明るく：0x3a271a → 0x5c3d24） | 明るい黄褐色、つやなし |
| 形 | 寄り集まって低く寝ている | 真ん中はまとまり、両端が開いて少し浮く。1本ずつ軽く波打つ |

- 長さ約 30〜38 cm の束。繊維 72 本の細い帯。点々や穴の模様は使っていない（集合体恐怖症への配慮）。
- 束ごとの向き・大きさ・並びの小さな違いは、物の id を種にした見た目専用の乱数（`science/rng.ts` の `draw`）で決める。
- 遠く（カメラから 3.5 m 以上）では、同じ形を太い 14 本で描く。細い繊維は配信の距離では画素より細く、カメラが動くとちらつくため。近いか遠いかは束ごとに頂点シェーダーで決める（毎フレームの CPU 処理なし。分岐の中でテクスチャは読まない）。
- 光は住人の物と同じ（陸の光 `airLit`、砂からの照り返し）。夜は main の夜の明るさ（`nightFill`）がそのまま効く。

## 乱数と物の数

three.js は物を作るたびに `Math.random` を引く。この見た目の物は全部 `quiet()` の中で作り、そのあいだだけ見た目専用の乱数を three.js に貸す。世界の `Math.random` は引かれない。

確認（PR #9 の `tools/lab/firewood-fixture.ts`）：変更前と変更後で `fingerprint.json` がバイト単位で一致した。

- 島を作った直後の乱数の回数 598832・ハッシュ 3879708679。
- 60 秒動かしたあと 599248・ハッシュ 3677529292。
- 住人の行動の SHA と保存データの SHA も一致。

## その2：浸けた殻・打ったあとの殻（2026-10-17）

- `wet-husk`（浸けた殻）と `partial-husk`（打ったあとの殻）を、それぞれ `wet` と `dry` で描く。
  - 浸けた殻：殻を割った一片（長さ約 26 cm）。外の皮を上にして寝ている。湿っていると濃い茶色で少しつや、乾くと灰色がかった茶色。
  - 打ったあとの殻：薄くなった一片を、内側を上にして置く。内側に、繊維を打ち出した筋が縦に入る（科学側の観察「残った殻に筋がついている」）。両端からほぐれた繊維が少し垂れる。湿っていると赤茶、乾くと明るい黄褐色。
  - 筋は縦長のやわらかい帯で、画素より細くなる所では消える。点々や穴の模様は使っていない。
  - 垂れる繊維は近く（3.5 m 未満）だけで描く（繊維の束と同じ切り替え）。
- 並べ方：作業場の中で横一列。種類ごとの幅で間を空ける。物ごとの向きと大きさの違いは id から。
- 試験用のつまみ `?coirlook=all`：浸けた殻・打った殻・繊維の束を、湿り・乾きで1つずつ。
- 画像：`husks.jpg`（昼の近く、夜の近く、昼の見守りの高さ）。
- 確認：

  - typecheck、build。
- まだ：

## その3：撚り糸・縄（2026-10-17）

- `yarn`（撚り糸）：`fuzzy`（毛羽が多い）と `smooth`（なめらか）。`cord`（縄）：`smooth`、`frayed`（ほつれ）、`broken`（切れた）。
- 形：
  - 地面にゆるく巻いて置いた輪。長さは世界の隠れた値なので、どの糸・縄も同じ大きさの輪で描き、輪の大きさで長さを表さない。
  - 縄は撚り糸のおよそ2倍の太さ。撚り合わせた筋（縄は3本、撚り糸は2本）がらせんの帯で見える。帯は画素より細くなる所で消える。
  - 毛羽が多い撚り糸とほつれた縄：短い繊維の先が立つ。
  - 切れた縄：輪の途中が切れて、両方の端が開く。
  - 繊維の先は近く（3.5 m 未満）だけで描く。
- 色：撚り糸は明るい黄褐色（なめらかなものは少し濃く、少しつや）。縄は茶色（ほつれ・切れたものは少し明るく、つやなし）。
- 試験用のつまみ `?coirlook=cord`：撚り糸2種と縄3種を並べる。
- 画像：`cords.jpg`（昼の近く、夜の近く、昼の見守りの高さ）。
- 確認：指紋は PR #33 の先頭とバイト単位で一致。shader-check（PR #32 版）12 件 PASS。typecheck、build。
- まだ：ちらつきの測定（細い糸）、灯りの下、実機、湿った撚り糸・縄の見た目（窓口から来たら足す）。

## その4：打つ台・干し場（2026-10-17、PR #33 425c1f6 の `fixtures`）

- 窓口の `fixtures` に入っているものだけ描く（世界がそこに置いたあとだけ）。`bare-site` では何も描かない。
- 打つ台（`beat-board`）：風雨にさらされた厚い板（約 60 × 28 cm、厚さ約 7 cm）を砂に少し埋めて置く。上面は少し丸くすり減り、木目が縦に通る。
- 干し場（`drying-rack`）：二股の枝2本に竿を渡したもの（長さ約 1.1 m、高さ約 0.85 m）。枝は砂に刺さる。枝の傾きは id から。

- 干している繊維を竿に掛けては描かない。窓口に「どの品物がどの設備の上にあるか」がないため（下の提案）。
- 試験用のつまみ：`?coirlook=wet`（`fiber-wet`：打つ台、濡れた繊維、打った殻）、`?coirlook=dry`（`fiber-dry`：干し場、乾いた繊維）、`?coirlook=bare`（`bare-site`）。
- 画像：`fixtures.jpg`（昼の近く、夜の近く、見守りの高さ）。
- 確認：指紋は PR #33 の先頭（425c1f6）とバイト単位で一致。shader-check（PR #32 版、仕上げなし・あり）12 件 PASS。typecheck、build。
- 本体への提案：品物に `on?: fixtureId`（その設備の上・掛けてある）があれば、干している繊維を竿に掛けて、打っている殻を台の上に描ける。

## その6：設備の上の物（`on`、PR #40）・ちらつき・夜の灯り（2026-10-18、main 5c34c28 の上）

### 設備の上の物

- 品物の `on` が、その作業場にある設備の id を指すときだけ、設備の上に描く。
  - 打つ台（`beat-board`）：殻（浸けた殻・打った殻）と繊維の束を、台の上面に台の向きで寝かせる。複数あれば台の長さ方向に並べる。
  - 干し場（`drying-rack`）：繊維の束を竿に二つ折りで掛ける（新しい形 `hungGeo`）。湿った束は重く、まっすぐ近くに垂れる。乾いた束は軽く、先が開いて少し外へ浮く。複数あれば竿に沿って並べる（間は最大 15 cm）。遠く（3.5 m 以上）は、地面の束と同じく太い 14 本で描く。
- 次のときは、これまでどおり地面の列に置く：`on` がない、指す設備がその作業場にない、その設備に載らない種類（例：竿に掛かった縄）。
- 試験用のつまみ `?coirlook=on`：打った殻を台の上に、湿った束を台のそばに、乾いた束3つと湿った束1つを竿に掛ける。
