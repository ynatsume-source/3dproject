# wall-check case 2 の診断（自然班、2026-10-12。scratch の成果を保全）

- 原因：住人の判断と three.js の id が同じ `Math.random` を使う。09a9990（海岸を元の形へ）で作る物が減り、ビルド後の乱数回数が main 598,832 → 598,796 にずれた。海岸の当たりや置き物が変わったため、岩の配置などで選び直す回数も変わり、main と完全にはそろわない。
- case 2 はカメマルが陸から始まり（`fed()` で空腹も眠気もない）、水に入るかが3〜4回の乱数で決まっていた。
- 案：テストで本当に海中から始める（`wall-check-case2.patch`。調べるためのログ行入り。清書は本体）。main・合わせたもの、どちらも合格した（`case2-*.log`）。根本の直し方は、住人用の乱数列を別にすること（未実装）。
- `draws-fingerprint.ts.txt`：ビルドの途中ごとの乱数回数を数える。`scripts/` に `.ts` で置いて `npx tsx --import ./scripts/node-assets.mjs` で実行する。
