# 遠くの林（航空写真の面）との境目：画像と直し方の案（自然班、2026-10-10）

本体の依頼 §3.2 への答え。**まだ手を付けていない。** 案を選んでほしい。

## 画像

`seam.jpg`：ドットの家から少し上がった所（高さ約 16 m）から、林のいちばん深い方向を見た。撮影は `tools/lab/island.cjs` の `seam`、昼 12:00、晴れ。

- 手前から中ほど：近くの木。丸い塊が、明るい黄緑と深い緑の2色で並ぶ。木が描かれるのは、カメラから約 85 m まで（`forest.update` の `near`）。
- その奥（画像の上の帯）：航空写真を貼った樹冠の面。暗いオリーブ色で、写真の細かい明暗がある。
- 境目が帯になって見える。原因は3つ。
  - 明るさ：近くの木のほうが明るく、黄色寄り。
  - 色：遠くの面は写真そのままで、くすんで暗い。
  - 手触り：近くは大きい丸い塊。遠くは写真の細かい粒。

前（丸くする前）も境目はあったが、前の近くの木は暗い葉の塊で、写真の色に近かった。今回、近くの木を明るく丸くしたぶん、差が目立つようになった。

## 直し方の案

どれも、ライト・テクスチャ・描画の呼び出しを増やさない。地面の色（`LAND_FLOOR`）は触らない。

### 案 A：遠くの面の色を近くの木の色に寄せる（`shore.ts` の canopy のシェーダーだけ）

- 写真の明るさは残す。そのうえで、色合いを近くの木の2色（上が明るい黄緑、下が深い緑）に寄せる。
  - 写真の明るさで2色を混ぜ、写真の色とも少し混ぜる。
- 面の起伏（法線）で、上を向いた所を明るくする。丸い樹冠が並ぶように見える。
- 良い点：遠くから見た島全体が、近くの木と同じ雰囲気になる。
- 気になる点：
  - 空から見た島の色が変わる。写真の「実在の島」らしさが少し薄まる。
  - 写真の、木の種類による色の違いは残る（混ぜる割合で調整）。

### 案 B：境目のあたりで、近くの木の色を写真の色に寄せる（`forest.ts` の `treeMat` だけ）

- カメラからの距離が `near` の 6〜10 割の木を、写真の色へ少しずつ寄せる。写真の色は、木の位置で頂点シェーダーが写真のテクスチャから読む。
  - 分岐の外で読む。Windows の決まりは守る。
- 遠くの面はそのまま。
- 良い点：
  - 遠くから見た島は、今の写真のまま。
  - 境目は「だんだん写真になる」ので、帯にならない。
- 気になる点：
  - 近くの木の色が距離で変わる。
  - ドローンで動くと、木の色が少しずつ変わるのが見えるかもしれない（変わる幅が 40 m あるので、目立ちにくいはず）。

### 案 C：A と B を少しずつ（おすすめ）

- 遠くの面は、写真の色を半分ほど2色の緑に寄せる（A を弱く）。
- 近くの木は、境目の手前で写真の色に3割ほど寄せる（B を弱く）。
- 両側から寄せるので、どちらも大きく変えずに、境目の帯が消える。

## 確かめ方（選んでもらった案で）

- `seam` の位置で前後を撮る。高い所からの1枚（空からの島）も撮る。
- `shader-check`（陸のある海：planet・kayama）。
- フレーム時間：`tools/lab/frame-ms.cjs`。頂点でテクスチャを1回読む分。
