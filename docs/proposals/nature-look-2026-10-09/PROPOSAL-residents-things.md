# 案：住人が作るものも丸っこく（自然班 → 本体、2026-10-09）

本体の依頼 §3.4 への案。**まだ手を付けていない。** 進めるかどうかと順番を決めてほしい。

## 守ること（本体の約束）

- 部品の数と順番は変えない（家は工程ごとに1部品で `HOUSE_N`、小屋は流木24本の `HUT`）。
  - 変えるのは、各部品の Mesh／Group が使う形と色だけ。置き場所・向き・`visible` の切り替えは本体のまま。
- 当たりの大きさは変えない（`house.ts` の `posts`／`wallDots`／`door`、小屋の柱、焚き火の石、薪棚）。
  - 見た目は今の外形の中に収める。はみ出す場合は、数字を出して相談する。
- 帳簿の値は読むだけにする。見た目の色や形に使うが、書き換えない。どの値を使うかは、本体の一覧に合わせる。
- 前回と同じ：ライトとテクスチャは足さない。形は決まった乱数で作る。`Math.random` を新しく呼ばない。三角形数は今の2倍まで。

## やること（丸っこさの共通のやり方）

- 棒・丸太（柱、梁、垂木、小屋の流木、薪、作業台の脚）
  - 今は `CylinderGeometry` の 6〜7 角柱。これを、断面が丸く端の丸い管にする。拾える流木と同じ作り（`items.ts` の `lathe`）で、ゆるい曲がり、太さのむら、白っぽい流木色。
  - 柱は足もとを少し太くする。
- 茅葺き
  - 8 段の帯は、段数も順番もそのまま。
  - 各段の下端の切り口を丸くし、帯を少しふくらませる。
  - 色は2色：日の当たる上が明るい麦わら色、軒下が影の茶。
- 土壁
  - 箱（`BoxGeometry`）を、角を丸めた板（角の丸い直方体）にする。
  - 塗り立ては濃く湿った土色で、乾くと明るい黄土色に寄せる（帳簿に乾きの値があれば）。
- 焚き火の石・積み石（ケルン）
  - 拾える石と同じ、なめらかで平たい小石の形にする。大きさは今のまま。
- 器・灯皿
  - ろくろ（回転体）の断面で、口と縁を丸く、厚みを見せる。
  - 焼き色は野焼きの温度から決める（低い→赤茶、高い→明るい肌色に黒い焦げのむら）。
  - ひびは細い暗い線を1〜2本。点々や穴の模様は使わない（オーナーの集合体恐怖症への配慮）。
  - 灯皿の油の量は、油の面の高さで見せる。
- 薪棚
  - 薪を丸い断面の短い丸太にする。乾きの値で色を変える（生木→濃い茶・少し緑、乾いた→明るい灰茶）。
