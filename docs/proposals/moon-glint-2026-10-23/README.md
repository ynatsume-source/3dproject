# 濡れた礁に月が映る（自然班、2026-10-23）

視聴者設計班の TIDE_SCENES.md の S5（満月の干潮の礁、夜）。濡れた礁のつやは太陽の照り返しだけで、月は映っていなかった（docs/proposals/tide-views-2026-10-23）。

## 直したこと（`src/render/reef-lit.ts` の `reefLit` だけ）

- 水から出た濡れた礁に、月の照り返しを足した。
  - 明るさは月の満ち欠けと高さ（`uMoonI`）。雲で弱まり、月が沈んでいるときはない。
  - 濡れているほど強い（乾いた礁には出ない）。
- 照り返しは、凹凸を水平に寄せた面から、ゆるい広がりで出す。礁の上に一本の光の道としてのる。
  - 最初の形（凹凸のままの面、鋭い広がり）は、さざ波ごとに小さな光の点が散った（`first-try-flecks.jpg`）。点の模様になり、ちらつきの元にもなるのでやめた。
  - 太陽の照り返しは、細かい凹凸では消している（`sharp`）。月はもとから凹凸を寄せているので、その消し方を通さない。通すと 2×2 画素の暗いかたまりが光の中に出た。
- テクスチャの読み取りは分岐の外のまま。

## S5b：満月の明け方、S1 から光の道が見えるか（視聴者設計班の依頼）

- `s5b-s1-dawn-moon.jpg`：12/25 6:00、S1 の位置（`34.9235,4.7,-86.0062`）から月の方を向いて（向き 1.2713、S1 の向き 2.7254 から約 83° 振る）。海面は 0 m（潮はまだ入っていない）。
- **見える**。月は西の海の上にあり、海に光の道が映る。
- ただし S1 の向きのままでは、月は画面の外。向きを約 83° 振れば、同じ位置から撮れる。潮が入ったら、その時刻の海面で撮り直す。

## S1 の向きを振ったとき（視聴者設計班の依頼）

- 殻の潮だまり（`site:husk-pool`）は S1 から 29 m、S1 の向きから約 100° 横。画面の横の視野は ±51°（縦 70°、16:9）。
  - `s1-turn+0.9.jpg`（TURN +0.9 rad）：左の端に、殻の潮だまりのあたりの浅い緑の所と岩が入る。
  - `s1-turn-0.9.jpg`（TURN −0.9 rad）：右は礁と林。潮だまりは入らない。
