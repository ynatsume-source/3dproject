# 経験から次の一歩を選ぶ、小さな試作

ランタンの性格・初期関心と、使える行動を用意します。その範囲で、経験・現在の条件・未完成の作品から次の目的を選びます。初回の試作は星の観察に絞っています。

## 一回の循環

1. 世界が、本人の時刻・電池・雲量・行ける場所・そばの仲間を組み立てる。
2. 制作途中の問いと、最近の本人の記憶を使って、次の行動を選ぶ。
3. `residents.ts` の既存の歩行・作業を実行する。
4. 到着と作業時間を確認して結果を確定する。中断・道の失敗・天候変化は成功にしない。
5. 観察、描き直し、完成、共有などの結果を記憶し、関心を少し更新する。

通常の判断は規則によるもの。AIを有効にした場合は、同じ候補と本人の情報を渡し、候補ID、短い選択理由、関心、問い、任意の作品用の文章を提案させます。既存の作品が途中ならその問いを引き継ぎます。APIの返答を待たずに暮らしを続け、返答は次の判断の機会に現状と照合して使います。

行動は観察40秒・描画55秒・探索30秒・休息45秒・共有20秒、判断の間隔は最低90秒です。これらは試作の設計値で、心理学や生理の実測値ではありません。睡眠・運搬・共同作業などによって開始が遅れます。作品完成後は10分間、新しい作品を始めるまで間を置きます。

## 記憶と作品

問いは作品の完了まで持ち越し、二度の観察と二度の描画で完成します。再読み込みで「描いたこと」にせず、途中の実行を止めて、既に得た観察と下書きから次の判断をします。新しい描画は未記録の星や存在しない場所を作りません。

関心は成功した経験から少しずつ増え、既に作った題材の履歴も次の選択に使います。規則による関心更新であり、LLMの重みの学習ではありません。3つの関心と5つの行動からなる初期の範囲です。新しい研究分野や制作道具の発明まで委ねていません。

観察は既存 `public/stars.bin` の20恒星から、その時刻・緯度経度で地平線より上の計算位置を選びます。元データは [d3-celestial](https://github.com/ofrohn/d3-celestial) の stars.6.json、Yale Bright Star Catalogueほか（Copyright (c) 2015, Olaf Frohn, BSD-3-Clause）。既存READMEの素材出典に沿っています。新しい外部素材や通信先は追加していません。

雲量のしきい値0.65と太陽高度−6度は、試作の観察を始める条件です。実際の星ごとの視認判定ではありません。出力には雲量の出典、作中の記録、計算の限界、創作の文章であることを分けて記します。古い時刻の星と新しい時刻の星を一つの図に重ねず、最後の有効な観察で星図を作ります。

## 実際に確かめた範囲

ルールによる複数夜の継続、行動の完了条件、保存、実島の移動・描画、模擬APIでの失敗・制限・遅延を検証しました。実モデルの提案の質・多様性・長期の性格変化は未評価です。作品の観察内容が正しいことと、芸術としての完成度は別の評価軸です。

次にClaudeと確認したいのは、実APIで1体を限定的に動かしたとき、記憶が選択に使われるか、理由と実行が一致するか、関心の反復と変化の釣り合いがよいか、作品を見返したくなるか、です。その結果から行動や題材を増やすのが適しています。
