# 夜の浜のカニ：見た目の受け渡し（自然班 → 生態系の側、2026-10-19）

分け方（本体の答え、2026-10-19）：暮らし（いつ出るか、灯りから逃げる、寒い夜は少ない）は生態系の側、形と動きは自然班。
巣穴を出入り口にして「現れる・消える」にしてよい（オーナー決定）。

見た目は `src/ocean/crab.ts`（ブランチ `nature/night-sights`）。いまは試験用のつまみ `?crablook` の後ろにしかない。

## 見た目が受け取るもの

- `makeCrabLook(group, cap = 16)` → `{ show(poses: CrabPose[]) }`：毎フレーム、いまいるカニの一覧を渡す。種類ごとに `cap` 匹まで。
- `makeBurrowLook(group, cap = 16)` → `{ show(burrows: BurrowPose[]) }`：いまある巣穴の口の一覧。

### CrabPose

| 項目 | 意味 |
|---|---|
| `kind` | `'ghost'`（ツノメガニ）か `'coconut'`（ヤシガニ） |
| `id` | そのカニの変わらない id。大きさと色の違いはここから決まる（見た目専用の乱数。世界の乱数は使わない） |
| `x`, `z`, `y` | 足もとの位置。`y` は地面の高さ（`loc.f(x, z)`） |
| `head` | 頭の向き（ヨー、rad）。ツノメガニは横（自分の x）に走り、ヤシガニは前（自分の z）に歩く |
| `phase` | 歩きの位相（rad）。脚が左右互い違いに動く。目安：ツノメガニは 1 周で約 6 cm 進む（`phase += v / 0.06 × 2π × dt`）、ヤシガニは約 12 cm |
| `run` | 速さ 0..1。0 で止まり、1 でいちばん速い（体が少し浮き、脚が大きく動く）。目安：ツノメガニの 1 は約 1.5 m/s の逃げ足、ふだんは 0.2〜0.4。ヤシガニの 1 は約 0.2 m/s |
| `sunk` | 0..1。0 で砂の上、1 で巣穴の中（ツノメガニは 6 cm 下、砂が隠す）。出るときは巣穴の口の上で 1 → 0、入るときは 0 → 1 |
| `eyes` | 0..1。0 で眼柄を前の縁に倒す（休んでいる）、1 で立てる（警戒・動いている） |
| `on` | 任意。立っている物（幹）にしがみつくとき：表面から外への向き `n` と、頭の向き `fwd`（単位ベクトル）。ないときは砂の上 |

### BurrowPose

| 項目 | 意味 |
|---|---|
| `id`, `x`, `z`, `y` | 巣穴の口の位置。`id` で大きさが少し変わる |
| `dir` | 掘り出した砂が広がる向き（ヨー、rad） |

## 見た目の決まり（自然班で守っている）

- 遠く（5 m 以上）では、脚をたたみ、触角を短くする（ちらつき対策）。巣穴の口は 9〜14 m で消える。
- 巣穴は 1 匹に 1 つ。穴を並べない（集合体恐怖症への配慮）。
- 世界の `Math.random` と島の乱数は引かない（`quiet()`）。指紋は main と一致。

## 生態系の側に決めてほしいこと

1. いつ出るか：日没後から夜明けまで。寒い夜（気温・砂の温度）は少ない。月が明るい夜、雨の夜。
2. どこに巣穴があるか：ツノメガニは満潮線より上の乾いた砂。巣穴は世界の事実として残る（カニが中にいても、昼でも口が見える）。
3. 灯りから逃げる：住人の灯り（`residents.ts` の `uLights` の位置）とドローンの灯りが近づくと、横に走って巣穴へ入る。
4. ヤシガニのすみか：ヤシガニは砂の巣穴ではなく、岩のすき間・木の根元の穴にこもる。そこを出入り口にしてよいか（オーナーの決定は「カニの巣穴」。ヤシガニにも広げてよいか確認が要る）。だめなら「見えない所から歩いて入る」（`eco/unseen.ts`）。
5. 数：配信の画面で、灯りの輪に 1〜3 匹入るくらいが見どころ。

## 自然班がこのあとやること

- 幹に登るヤシガニ：住人が通れない物の登録（`robots/solids.ts`）の幹は、足もとの直立した円柱で、描いている幹（傾いている）とずれる。登る位置を出すには、描いている幹の線（足もとと傾き）を返す問い合わせが要る。自然班が `forest.ts`・`shore.ts` の側に作る。
- 灯りの輪の中で撮ること、見守りの高さのちらつき。
