# 見どころ 1 の前提：海面が潮で上下する（自然班の調べ、2026-10-19）

見どころ 1（夕方の大潮の干潮に、干上がったリーフを灯りで歩く）には、海面が潮で下がる必要がある。
いまの描画の海には潮がない（`src/ocean/air.ts`、`src/ocean/water.ts` 9 行目、`src/ocean/build.ts` の `CORAL_CEIL` の注記）。
潮の模型（`time/astro.ts` の `tide`）は、ドローンの深さの表示（`main.ts` の `s.tideH`）と潮の流れにだけ使われている。

## 海面を潮で動かすと変わる所（main db1a160 で調べた）

| 所 | いま | 潮で動かすと |
|---|---|---|
| 海面の描画（GPU の `seaK`、`ocean/air.ts`） | 平均海面 y=0 で固定 | 潮の高さ（例：`uSeaH`）だけ上下 |
| 海面の高さ（CPU の `surfaceAt`/`swellAt`） | 同上。鳥・トビウオ・ラッコ・訪問者・`main.ts` が使う | 同じ値を足す（GPU と CPU が同じ答え） |
| 水域の区分（`ocean/water.ts`） | 平均海面で、海・ラグーン・潮だまり・陸を一度決める | 区分はそのまま。「いま水の下か」は、海とラグーンでは潮の高さで決める。潮だまりは海から切れているので、水面は動かない |
| 住人が水に入る所（`robots/residents.ts`） | 区分と海面 | 同じ関数を使う。干潮では、リーフの上を歩ける |
| 経路（`robots/solids.ts`、nav） | 水と陸 | 潮が満ちる前に戻る（世界の決まり） |
| サンゴの上端（`CORAL_CEIL` = −0.35 m、`scripts/coral-depth-check.ts`） | 平均海面の下 | −0.8 m の干潮では、背の高い群体の頭が水から出る。現実のリーフでもそうなる。そのままにするか、決めが要る |
| 浅場の魚（`eco/`） | 平均海面の下を泳ぐ | 干潮で水がなくなる所に残さない（深い所へ移る） |
| 水中かどうかの判定（カメラ、ドローン、霧、音） | `s.tideH` を一部で使う | 全部を同じ海面に揃える |

## 段取りの案

1. 決める（本体・オーナー、ADR）：世界の海面＝潮の高さ（嘉弥真で ±0.8 m）。住人と生き物は、この海面で暮らす。
2. 基盤（1 回の作業）：海面の高さを 1 つの関数にまとめ、GPU と CPU が同じ値を使う。見た目では、海面が上下するだけ。
   - 確認：`water-check`（潮だまりの水面が動かないこと、外海は潮で上下すること）、`coral-depth-check`、`nav-check`、shader-check `--all`、乱数の指紋。
3. 暮らし（本体）：干潮の夕方にリーフへ出る・満ちる前に戻る。見つけた物は本当に見た物だけ。
4. 見た目（自然班）：濡れたリーフと砂のつや（月・灯り）、潮だまりの映り込み、水が引いた跡。
