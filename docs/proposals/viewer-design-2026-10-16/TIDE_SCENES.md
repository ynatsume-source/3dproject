# 潮が入ったときに、視聴者に見せたい場面（本体・自然班へ、2026-10-23）

科学班からの依頼（2026-10-23）への答え。オーナーの決定で、潮（ADR 0009 の第2段・第3段）は12月の本番に間に合わせる。海と礁湖が潮で上下し、干潮では礁が水から出る。潮だまりと内陸の水は平均海面のまま。

- この文書は**見せ方の希望**。世界で何が起きるか（住人が礁へ出るか、何を見つけるか）は本体、形と光は自然班、科学の中身と潮の模型は科学班が決める。
- 映すのは**本当に起きたこと**だけにする。干潮に住人が礁へ出なければ、出ていない礁を映す。

## 3. 壊れて見えるのを避けたいこと

潮が動くようになると、次のことが起きうる。見る側から先に挙げる。

1. **カメラが水面をまたぐ**：付き添いのカメラが水際の住人を追うと、画の半分が水中になる。潮で水際が動くので、起きる場所が増える。水面の上か下か、どちらかに保ちたい（本体）。
2. **定点が満潮で水に沈む**（S1。高さを決めるとき）。
3. **驚かせる距離のある生き物に近づきすぎる**：干潮では、息つぎ中のウミガメなどが浜の近くの浅い所にいることがある。カメラを変えるときは #94 の決まりを壊さない（`turtle-view-check`）。
4. **干潮で、水のなくなった所に魚が残る**（自然班の TIDE.md：浅場の魚は深い所へ移る）。
5. **潮だまりの水面が、海と一緒に上下する**（`water-check` で確かめる約束）。
6. **満潮で作業場・材料が水に入る**（ADR 0009 の確認）。
7. **状態の1行と画が合わない**：礁へ「向かっている」のに画では水の中、など。言葉は実際の状態から（CLAUDE.md の決まり）。

## 4. 画面の言葉と、前もって伝えること（科学班の答え 2026-10-23 を入れた）

- 潮の高さの**数字は出さない**。時刻も「あと○分」も出さない。
- 言葉は出してよい（科学として問題なし）。本体は、潮を入れる PR（11/13〜16）のあとに入れる。以下が、この担当の案（2026-10-23）。

**出す言葉**（4つ）

| 言葉 | 英語の画面 | 出すとき |
|---|---|---|
| 満潮 | High tide | 描いている潮が、いちばん高くなる時刻の前後40分 |
| 潮が引いていく | Tide going out | それ以外で、海面が下がっているとき |
| 干潮 | Low tide | いちばん低くなる時刻の前後40分 |
| 潮が満ちてくる | Tide coming in | それ以外で、海面が上がっているとき |

- 「満ち潮」「引き潮」は使わない。満潮・干潮の意味でも使われる言葉で、どちらのことか迷わせるため。動きは「〜ていく」「〜てくる」で言う。
- 決め方：**描いている海の高さ**（科学班）の潮の式から、前後の「いちばん高い・低い」の時刻を求め、いまがその前後40分かで決める。40分は、海面の変化が20分で数 cm 以下になり、目では止まって見えるころ。小潮で差が小さい日も同じ決め方でよい。
- 海を止めて描いているとき（`?sealevel=` など）は、動きが決まらないので何も出さない。
- 「大潮」などの潮の名前は、いまは出さない（文字を増やさない。D22）。

**出す場所と形**

- **S1 の定点と、巡回の 13（海と浜）を映している間だけ**。付き添いの 01〜04 には出さない（住人の状態の1行が主役のため）。
- 左下の視点の行に、番号のあとに続けて：`05 DORON ・ 潮が引いていく`（英語は `05 DORON · tide going out`）。大きさは s1（22px）、明朝、薄い白（ink2）。視点の行の番号と同じ高さにそろえる。
- 映している間に言葉が変わるときは、ほかの文字と同じく 0.6 秒で静かに入れ替える。
- 定点の名前（`SHIOMI` など）は付けない。番号と DORON だけにそろえる（ほかの視点と同じ形）。
- YouTube の字幕（CC）には流さない。
- 潮を住人の科学（住人が潮を観察して仮説を立てる、など）で扱う予定は、12月の時点ではない。将来の題材として、科学班がオーナーと相談する。
- **SNS やダイジェストの説明で、潮の日時を前もって伝えてよい**（科学班）。島の潮は時刻だけで決まる（乱数なし）ので、出した日時のとおりになる。決まり：
  - 必ず「**島の潮**」と書く。実際の潮の予報と受け取られないため。本物の潮見表とは、時刻が最大で1時間ほど、高さも少しずれる。
  - 日時は `tide-dates.mts` と同じ関数（`time/astro.ts` の `tide`）から出す。手で写さない。
  - 時刻は「ごろ」を付けて分単位まで。高さの数字は出さない（画面と同じ）。
  - **住人が礁へ出るとは書かない**（住人の行動は予告できない）。
  - 島だよりには書かない（島だよりは住人のメディア。運営の告知は載せない）。
  - 例：`今夜19時35分ごろ、島の潮が、この1年でいちばん低くなります。満月です。（島の潮は、この星の月と太陽から計算したもので、現実の潮見表とは少し違います）`
