# 夜の構成：海をメインに、起きている住人を小窓に（2026-10-25）

本体からの依頼（main 7c8214e）への答え。オーナーの案（リハーサルの試運転 10/25 23:30 の所見、R-004）をもとに、画面の構成を決める。作るのはリハーサルのあと、本体。

- **いま**：夜はランタンしか起きていないので、画面がずっとランタンの歩きだけになる。
- **オーナーの案**：
  - メインのカメラは、島のまわりの海を巡航して、自然と生き物を映す（utsushiyo の巡航）
  - 右下の小窓（HUNT の小窓の仕組み）で、ランタンを映し続ける
  - ランタンの見どころが来そうなら、メインをランタンへ戻す
  - 眠っている住人も、30〜60分に1回、10〜15秒映す
- モック：`live-screens.html#nightsea`（`&rh` でリハーサルの時計も）。画像は `screen-7-nightsea.jpg`。
  - メインの画は、満月の明け方の海をソフトウェア描画で撮った仮の画。
  - 小窓の中は、オーナーの試運転の画（本物の GPU、R-001 の画像）からランタンの所を切り出したもの。
- これまでの夜の巡回（`../README.md` §3-1 の「夜（起きているのがランタンだけ）」と「全員が眠っている」の行）は、この構成で置き換える（D24）。

## 1. 夜の構成に切り替える条件

| | 条件 |
|---|---|
| **入る** | **日が沈んでいて**（太陽の高さ −6° より下）、**起きている住人が1人以下**の状態が **3分続いた**とき。焚き火の会（18:54〜21:00）の間は入らない（会の間は会に留まる。§3-1） |
| **出る** | 起きている住人が **2人以上**になって1分続いた、または太陽の高さが −6° を超えた（夜明け） |
| 全員が眠っている | メインは海のまま、**小窓は閉じる**。眠っている住人を映す間隔を短くする（5） |

- 時刻はすべて島の時刻（＝現実の時刻）。日の出・日の入りは世界の太陽の計算から。
- 「起きている・眠っている」の読み方は本体が決める（状態の文か体の状態。§3-1 と同じ）。
- 小窓に入るのは「起きている1人」。ふつうはランタンだが、ランタンに決め打ちしない。
- 切り替えはフェードで 1.5 秒。小窓は 0.6 秒で静かに出入りする。
- 3分・1分の待ちは、出たり入ったりをくり返さないため。

## 2. メインをランタン（起きている1人）へ戻す見どころ

世界の事実（状態の文・出来事・字幕・札）を読むだけ。住人には何も返さない。

| 見どころ | きっかけ | メインに出す長さ |
|---|---|---|
| **節目の札**（島で初めて） | 節目の出来事 | 札が消えるまで ＋ 1分 |
| **灯りをともす・灯りの番** | 状態の文（灯す） | 灯るまで ＋ 2分 |
| **星を見る** | 状態の文（「丘の上で星を見て考えごとをしている」など） | 4分。続いていれば、次に戻るときもう一度 |
| **手帖に記録する** | 記録の字幕・出来事 | 字幕が終わるまで ＋ 30秒 |
| **ほかの住人と会う・話す**（誰かが起きてきた） | 字幕、頼む・渡す・教えるの出来事 | 話が終わるまで |
| **地図に新しい場所** | 地図の出来事 | 1分 |
| **気圧計を読む** | 状態の文 | 1分 |

**R-006（地図のあとのランタンの夜の仕事）**：科学班の順番（2026-10-25、science/reviews b2897e6 の `specs/night-work-r006.md`）。決まって本体が入れたら、上の表に足す。
| 順 | 仕事 | 時期 | 見せ方 |
|---|---|---|---|
| ① | **星と月の観測**（月齢・月の出・北極星の高さを指の幅で測る） | 先に | 「星を見る」と同じ扱い（4分）。月の出は、月が昇る瞬間に合わせて戻せるとよい |
| ① | **気圧計の夜の読み** | 先に | 1分の場面（上の表の「気圧計を読む」） |
| ② | **灯りの改良**（段階を世界の事実にする） | 12/1 以降 | 「灯りをともす」と同じ扱い。段階が上がったときは節目の札と一緒に |
| ③ | **潮の記録**（刻みの杭を灯りで読む。月の記録と並べて大潮に気づく） | 2027年1月以降 | 水際の灯りの場面として1〜2分。画面には刻みの数も時刻も出さない（言葉だけ。科学班 10/25） |
- 季節の星座は使わない（島の暦は13倍速、空は実際の日付のため。科学班）。
- 日記・島だよりに、住人が自分の単位（「刻み2つ」など）で書くのはよい。住人が自分で測った値だから。画面には出さない。

- **戻さないもの**：歩いているだけ、ひと休み、「回り道を探している」（R-001 のように止まっている所）。小窓のままにする。
- 見どころが終わったら（状態の文が変わったら）、海へ戻る。メインに出したら**最低1分**は戻さない。節目と会話のほかは、**5分に1回まで**（行ったり来たりしないため）。
- **字幕は、小窓が開いている間は出さない**。話すときは、先にメインを話し手へ戻して小窓を閉じ、それから字幕を出す（字幕と小窓が画面の下で重ならないため）。
- 節目の札は、メインを戻すのと同時に出す（札は画面の上の中央なので、小窓とは重ならない）。

## 3. 小窓の位置と大きさ（1920×1080）

| | 決め方 |
|---|---|
| 大きさ | **512×288**（16:9、横幅の約27%） |
| 位置 | **右 96px（5%）・下 136px**（下の端が y=944） |
| 枠 | 1px の細い線（白 32%）と柔らかい影。角は丸めない |
| 文字 | **小窓の外、すぐ上**に、左をそろえて：`04` ＋ 島の文字の名前 ＋ ランタン ＋ 色の線（s1）。**画の上には文字を載せない**（足もとが隠れるため）。状態の1行は、左上の4人の一覧（R-008、`LAYOUT.md` §2）の明るい行に出るので、小窓の上には出さない（2026-10-25 改め） |
| 中のカメラ | 付き添いと同じ向きで、**少し近く**（3.5 m 前後）。小さな窓でも姿が分かる大きさに |

- **右下の JST の時計**（`?rehearsal` のときだけ、右 96px・下 86px）は、小窓の下 28px にあって重ならない。
- **左下の文の帯**（左 96px から右へ最大約 800px）とは離れている。
- **字幕**とは、上の 2 の決まりで重ならない。
- スマホを横にした全画面（幅 844px）では、小窓は約 225×127px、状態の1行は約 11px。姿と灯りは分かる大きさ。
- YouTube の操作バーとの重なりは、限定公開での撮影（README §13-1）で確かめる。小窓の下の端は画面の高さの87%。
- **重さ**：小窓はもう一度島を描くので、GPU の負担が増える。小窓は自分の大きさ（512×288）で描き、必要なら 15 fps に落とす。リハーサルの記録（毎秒のフレーム）で、夜の時間帯の重さを確かめる。

## 4. 海を映している間の、左下の帯

**帯はメインの画のことだけ、小窓の文字は小窓のことだけを言う。**

| 行 | 出すもの |
|---|---|
| 1行目 | `13 DORON`。潮が入ったら ` ・ 潮が引いていく` などの言葉（`../TIDE_SCENES.md` §4。13 は潮の言葉を出す視点） |
| 2行目 | ふだんは「**島のまわりの海**」。巡航が生き物を見ているときは、**その生き物の名前**（例：アオウミガメ）に替える |

- 生き物は**名前だけ**。何をしているかの文は作らない（世界が持っている言葉がないため。言葉は実際の状態からという決まり）。
- ランタンの状態は帯には出さない（小窓の上の文字に出ている）。
- 英語の画面：`The sea round the island`、生き物の名前は英名。

**海の巡航そのもの**（本体・自然班、見る側からの希望）
- 月の明るい夜は、海の上の画（月の光の道・星・島の影）を多めに。月のない夜は、ドローンの灯りで海の中（光るマリンスノー・オキクラゲ）を多めに。
- 生き物に近づくときは、驚かせる距離の決まり（#94、`turtle-view-check`）と「無から出ない」の決まりを守る。
- 夜の明るさ（暗すぎないか）は、リハーサルと試験配信で見る。

## 5. 眠っている住人の映し方

| | 決め方 |
|---|---|
| 間隔 | **40分に1回**（ドット → ラッコ → カメマル の順に1人ずつ）。全員が眠っているときは **20分に1回** |
| 長さ | **12秒**（フェードの 1.5 秒ずつを含めない） |
| どこに | **メイン**に出す。小窓は起きている1人のまま |
| カメラ | **動かさない**（静かな1枚の絵として） |
| 帯 | `0X DORON` ＋ 名前 ＋ 状態の1行（実際の状態の文。「眠っている」など） |

**住人ごとの撮る位置**

| 住人 | 位置 |
|---|---|
| ドット | 家（小屋）の開いた側から 2.5〜3 m、目の高さより少し上から、少し見下ろす |
| ラッコ | 水に浮いて眠る姿を、横から 3 m。カメラは水面より 0.5 m 以上上に置き、水面をまたがない。月の夜は、光の道が背景に入る向きを選べるとよい |
| カメマル | 岩棚の寝場所を、海の側から低く 3 m |

- その住人が本当に眠っていない（状態の文が違う）ときは、飛ばして次の住人へ。
- メインに見どころ（2）を出している間は、待って後にする。
- 灯りのない所で真っ暗になる場合は、飛ばす（暗いだけの画は出さない）。

## 6. 本体にお願いしたいこと（まとめ）

1. 夜の構成の切り替え（1）と、戻す見どころ（2）を、表示の側だけで読む形で。
2. 小窓の位置・大きさ・文字の置き方（3）。小窓は自分の大きさで描き、重さを記録で確かめる。
3. 海の巡航中の帯（4）。生き物の名前は、世界の生き物のデータから。
4. 眠っている住人の映し方（5）。
5. リハーサルの記録から、夜にランタンしか起きていない時間の長さ（本体が出してくれる）を受け取ったら、この担当が長さと間隔を見直す。
