- **オーナーの案**：
  - 画面の右上（日付と「住人はAIです」の下）に「ランタンの地図」を出す
  - ランタンが歩いた所だけ、霧が晴れるように開く。開いた所には、実際の地形（海・浜・森・草地・岩）を描く

- 色づかいと記号のデザインは、自然班に見てもらう。この文書は、位置・大きさ・出すとき・数字の扱い。

## 2. いつ出すか

| とき | 出す？ |
|---|---|
| **夜の構成**（`NIGHT.md`） | **出す**。夜はランタンが地図を広げる時間で、霧が少しずつ晴れていくのが、夜の静かな見どころになる |
| 昼、メインがランタン（04）のとき | **出す** |
| 昼、ほかの住人や 13 のとき | 出さない（その住人の画に、関係のない地図を重ねない） |
| 字幕が出ている間 | そのまま（字幕は下、地図は上で重ならない） |
| 節目の札が出ている間 | そのまま |

- 出入りは、ほかの文字と同じく 0.6 秒で静かに。
- **地図が広がった瞬間**（新しいマスが開いたとき）：そのマスの霧が **2秒かけて晴れ**、その所が少しだけ明るく光って消える。**地図を大きくはしない**（画面の割り付けが動くと、世界から目がそれるため。D22）。
- **記号が加わった瞬間**（小屋ができた、など）：記号が 1 秒でふっと現れる。大きな節目なら、節目の札が別に出る。
- ランタンの灯り：いまいる所に小さく、ゆっくり明滅（2〜3秒で一回り、強さの差は小さく）。

## 3. 割合（%）を数字で出すか → **出さない**

- **霧の開き方そのものが、どれだけ歩いたかを見せている**。数字を足すと、文字が増える（D22）。
- **「%」はゲームの進み具合の表示に見える**。「100% になったら終わり？」と受け取られやすい。この配信は、根拠のない進捗の％を出さない決まり（README の決まりごと）。地図の割合は世界が測った値なので根拠はあるが、**100% の基準（320 マス）は世界の側の決めごとで、ランタン自身が知っていることではない**。
- 数字を見せたいときは、住人自身の言葉（日記・島だより）に任せる。世界が「地図が半分を超えた」といった節目を出すなら、節目の札に載せてよい（札の文は世界の出来事の文のまま）。
- 科学班の「数字は出さない」の方針（潮の高さ）とも、そろう。

## 4. 見た目（自然班と相談）

この担当からの希望だけ書く。色と記号の形は自然班が決める。

- **霧**：夜の海の色（ライブ画面の暗い青緑）。点々や粒の模様にしない（集合体恐怖症への配慮。雲のような、やわらかいむら）。
- **開いた所**：実際の地形を、彩度を落として静かに。マスの角が見えないよう、縁を半マスほどぼかす（霧が晴れたように見える）。
- **記号**：砂の金（`#e9cf98`、ライブ画面の強調の色）の細い線で。小屋・家・桟橋・畑・棚・石積み・筏。地図が 240px でも形が分かる大きさ（線の太さは 1080p で 2px 前後）。
- **ランタンの灯り**：暖かい灯りの色の小さな点と、ぼんやりした輪。
- ちらつき：霧のむらと縁のぼかしは、画面の動きで細かくちらつかないように（`flicker.cjs` の考え方）。

## 5. 本体にお願いしたいこと

1. 位置と大きさ（§1）と、出すとき（§2）。
2. 地図は表示の側だけで、世界の記録（歩いたマス・作った物）を読むだけにする。住人には何も返さない。
3. 割合の数字は出さない（§3）。
4. 見た目は、自然班と相談して決める（§4）。
5. 重さ：地図は、マスが開いたとき・記号が加わったときだけ描き直す（毎フレームは描かない）。
