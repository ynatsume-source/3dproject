## 1. R-011 ランタンの考えごと（独り言）

> 2026-10-26：同じ作りを、ドット・ラッコ・カメマルの「決めるときの考え」にも使う（D29、`VOICE.md` §4）。

**オーナーの所見**：ランタンの「考えごとをしている」は、いまは中身のない「フリ」で、視聴者はしらける。D11 でランタンが AI を持ったら、考えごとの間に本当に考え、その中身を独り言として見せたい。30〜60分かけて、ゆっくり紡がれていく文。

- モック：`live-screens.html#nightsea&ctx&think&tate`
  - `screen-9-think.jpg`：縦書き、おすすめ
  - `screen-9-think-yoko.jpg`：横書きの場合
- 文は見本。実際はランタン自身の考え（AI の答えを検査したもの）。

### 決め方

| | 決め方 |
|---|---|
| **位置** | 左の中ほど。左 96px・上 372px から（4人の状態の下）。横幅は最大 420px（節目の札とぶつからない幅）。高さは、下の文の帯の上の端の 32px 上まで（夜の海の画では約 400px、昼にランタンを映しているときは約 300px） |
| **書き方** | **縦書き**（日本語の画面）。右の行から左へ書き進む。英語の画面は横書きの斜体（Cormorant Garamond の italic） |
| **大きさと濃さ** | s2（26px）、行の間を広く（1.9）、薄い白（ink2）。見出しに「ランタンの考えごと」（s1、ink3）とランタンの色の短い線 |
| **島の文字** | 付けない（声に出していない「考え」なので。声に出したら、それは字幕になる） |
| **紡ぐ速さ** | 1文を、**1秒に3字**ずつ書いていく（30字の文で約10秒、手で書くくらいの速さ）。次の文までは、考えごとの長さを文の数で割った間をあける（**最短でも1分半**）。1回の考えごとに出た文が、その考えごとの間（30〜60分）に行きわたる |
| **残し方** | 見えるのは新しい4文まで。いちばん新しい文と、その前の文はふつうの濃さ。その前は 55%、さらに前は 30%。それより古い文は静かに消える |
| **出すとき** | ランタンが**本当に考えごとをしている間だけ**（AI の考えごとの区切り。状態の文と世界の事実から読む）。かつ、ランタンが画面にいるとき（メイン、または夜の構成の小窓） |
| **出さないとき** | ランタンが画面にいない（4人の状態の一覧で「考えごとをしている」と分かる）。考えの中身がない（AI が答えなかった・予算が尽きた） |
| **終わったとき** | 考えごとが終わったら、最後の文が書き終わってから2分そのまま残し、2秒かけて消える（読み終えられるように） |

### 字幕（会話）との違い

| | 字幕（会話） | 考えごと（独り言） |
|---|---|---|
| 場所 | 下の中央 | 左の中ほど |
| 向き | 横書き | **縦書き** |
| 大きさ | s5（46px） | s2（26px） |
| 島の文字 | あり（声に出した言葉） | なし（頭の中の言葉） |
| 出方 | 話している間だけ、まとめて出る | 1字ずつ書かれ、ゆっくり積もる |

- **字幕が出ている間**：考えごとの文は書くのを止め、40% の濃さに下げる。字幕が終わったら戻る（いま声に出している方を先に読ませる）。
- **節目の札が出ている間**：同じく 40% に下げる。

### 割り付けの中で

- 「ときどき」出るもの（`LAYOUT.md` §1）の1つに数える。
- 夜の構成のとき：右の列（地図と小窓）と、左の考えごと。これで「ときどき」は2つ。道のりは、考えごとが終わってから出す。
- 出る順の強さ：節目の札 ＞ 字幕 ＞ 考えごと ＞ 道のり。

### 中身について（本体・科学班へ）

- **独り言に出すのは、実際に頭へ渡した世界の事実と、確かめた結論だけ**（科学班 2026-10-26）。考えている「フリ」の文は作らない。
- **答えを待つ間の表示は、頭に渡した材料の言葉だけ**（例「月のこと・北の星のこと」）。材料の言葉は、渡した世界の事実の種類から作る（`VOICE.md` §4）。

- 文はランタン自身の考え（AI の答え）を、ほかの言葉と同じく検査してから出す。表示の側で足したり直したりしない。
- 隠れた科学の値は書かない。ランタンが自分で測った値（自分の単位）は、ランタンの言葉としてよい（日記と同じ）。
- 考えごとのための AI の呼び出しは、いまの節目の呼び出しの中で（増やすなら予算と相談）。答えがないときは、考えごとの文を出さない（作り話の文で埋めない）。

## 2. R-013 星を見るときの構図

**オーナーの案**：ランタンが星を見ているときは、星空を主役にした構図にしたい。
- 構図：ランタンが見上げる姿を、画面の下の手前に小さく。画面の7割ほどを星空に（低い位置から見上げる、広い画角）。
- 組み合わせ：R-012（星を見る場所を、空の開けた浜にする案）。

- 見取り図：`stars-plan.jpg`（`stars-plan.html`）。**位置関係だけの図**で、星・線・月の位置は見本。

### 構図

| | 決め方 |
|---|---|
| 場所と向き | 科学班の決定（R-012、1fbfa75）：星を見る場所は、**北の水平線の開けた浜**（北向き 15° より上が隠れない所）。北極星の高さを測るので、**北を向いて、海の水平線の上の空**を撮る。方角は「北」が画面の中ほどに来る。のちに丘の上の見晴らし台（ランタンの道のりで「星と月の手帖」の次）ができたら、そこからも |
| カメラ | 地面から 0.4 m、ランタンの斜め後ろ 4〜6 m。ランタンが見ている方の空を、同じ向きに見上げる（25〜30°）。画角はいつもより広く（縦 80〜85°） |
| ランタン | **画面の右下の3分の1あたり**（左下は文の帯なので避ける）。高さは画面の1割ほど。灯りの輪が見える |
| 空 | 画面の約7割。水平線は下から約22%。水平線は傾けない |
| 長さ | 星を見る見どころ（`NIGHT.md` §2、4分）の間ずっと。途中で動かさない（ゆっくり 1〜2° だけ流れるのはよい） |
| 隠れない | ランタンと空のあいだに木が入らない位置だけ（`CAMERA.md` §1）。R-012 の開けた浜なら入りにくい |
| 撮り方の表との関係 | `CAMERA.md` の「E 見上げ」の、星を見るとき専用の長い版 |

### 重ねる情報（量・濃さ・時間）

| もの | 量と濃さ | 出す時間 |
|---|---|---|
| **方角**（東西南北と、その間の8方位） | 水平線のすぐ下に小さく（s1、白 55%）。画面に入っている方角だけ | 星を見る間ずっと |
| **星座の線と名前** | 線は細く（1px、白 25〜30%）。名前は s1、薄い白（ink3）。**北の空の星座だけ**を5つまで。<br>・**こぐま座と北極星**：いつも付けてよい（一晩中沈まない）。<br>・**北斗七星（おおぐま座）・カシオペヤ座・ケフェウス座・りゅう座**：線を結ぶ星が**全部、水平線（と地形）より上に見えているときだけ**。一部でも沈んでいる・隠れているときは、線も名前も付けない（途中で切れた形を見せない）。<br>季節の星座（オリオン座・さそり座など）と季節の言葉は出さない（下の注） | **始めの8秒は何も重ねない**（まず空そのものを見せる）。それから 45秒、ふわっと出して、ふわっと消す。4分続くなら、半分のころにもう一度 20秒 |
| **月・惑星・天の川の名前** | 名前だけ、s1、薄い白。月と、見えている明るい惑星（いくつでも）と、天の川（見えているとき） | 星座と同じ時間 |
| ランタンがいま見ているもの | 世界がそれを持っているときだけ（月・北極星など。R-006 の観測の対象）、その名前を少し明るく（ink2） | 星座と同じ時間 |

- 空は本物の星（実際の日付と場所の空）なので、星座は実際の空と合う。名前は日本語のふつうの呼び名（英語の画面は英名）。
- **季節の言葉と季節の星座を、同じ画に並べない**（科学班の指摘、2026-10-26）。画面の右上にはいつも島暦の日付（例「島暦1年 6月1日」）が出ている。島の暦は13倍速で、空は実際の日付なので、「6月なのにオリオン座」のように食い違って見える。
  - 星を見る場所は北の水平線の開けた浜（R-012）で、画は北の空が主になる。一晩中沈まず、季節を感じさせないのは**こぐま座と北極星だけ**（科学班の訂正、2026-10-26）。
    - 嘉弥真（北緯24°）で一晩中沈まないのは、赤緯 +66° より北の星だけ。こぐま座はその中。
    - 北斗七星・カシオペヤ座（赤緯 +50〜+63°）は、季節で北の水平線の下に入る（10月の夜、北斗七星は水平線の近くか下）。ケフェウス座・りゅう座も一部が沈む。
    - これらは、空に見えているときだけ名前を付ける。見え隠れは実際の空どおりなので、季節の言葉を添えなければ食い違いにはならない。
  - 南や東西の空が画に入っても、そこの星座には名前も線も付けない。
  - 重ねる文字に「夏」「冬」などの季節の言葉を使わない（夏の大三角・冬のダイヤモンドも使わない）。
- **独り言（R-011）との重なり**：考えごとの文がある所（左の中ほどの四角）には、星座の線と名前を描かない。その中に入る星座は飛ばす。
- **文の帯との重なり**：帯の上には方角を出さない。
- **節目の札**が出ている間は、札の四角の中の線と名前を消す。
- 夜の構成の地図（右上）の四角にも、線と名前を描かない。
- 字の数が増えすぎないよう、同時に出る名前は、方角を除いて8つまで。
