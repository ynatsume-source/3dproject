# 会話を、話している住人の頭の上の吹き出しで（R-024、2026-10-26）

本体からの依頼（main 32638a3）への答え。オーナーの希望：会話を、画面下の字幕の帯でなく、話している住人の頭の上の吹き出しで出したい。見本は焚き火の会のデモ（https://claude.ai/artifact/2FErGtpuYdFGbn3fmtbZYs）。

v2 §4 の「吹き出しの代わりに下の字幕」を改める（`README.md` §4 も直した）。

- モック：`live-screens.html`
  - `#fire`（焚き火の会、夜）→ `screen-10-fire.jpg`：カメマルの桟橋の提案（薄く残したもの）と、いま返事をしているラッコ。ラッコの吹き出しは、カメマルの吹き出しとドットの頭をよけて横にずれ、尾は自分の頭を指す。台詞は `PROGRAM.md` §6 の言い方に直したもの
  - `#bubble`（昼、2人の会話）→ `screen-11-bubble.jpg`：ラッコの申し出（R-023 で消えなかった台詞）。ドットの頭をよけている
  - `#bubble&en`（英語の画面）→ `screen-11-bubble-en.jpg`
- 背景は main 32638a3 のビルドをソフトウェア描画で撮った画（アプリの表示を消したもの）。住人の位置はモックのために焚き火の席に置いたもの。頭の点は、その画のカメラで実際に写した位置。台詞は `islandlang.ts`・`lumau/frames.ts` の文。

## 0. 考え方

- **吹き出しは、四隅の決まり（D26）の例外**。住人に付いた言葉として、話している間だけ、画面の真ん中にも出てよい。
- **下の字幕は残す**。吹き出しを出せないとき（話し手の頭が画面にない・岩などに隠れている）だけ、いまの字幕を出す（§3）。
- **1行の途中で、吹き出しと字幕を切り替えない**。話し始めに決める。
- 見本の作り（話す1人に1つ、名前・島の文字・点線・訳、尾は住人を指す、端では吹き出しだけ内側へ、声のあいだだけ、住人の色の影）は、そのまま使う。違うのは、大きさ（配信の画面に合わせる）・書体（ライブ画面の明朝）・夜の地の明るさ（§8）。

## 1. 大きさ（1920×1080）

| もの | 1080p | スマホ横の全画面（高さ約 390px） |
|---|---|---|
| 吹き出しの幅 | 中身に合わせて 220〜690px（訳の行は最大 630px、日本語で15字） | 約 80〜250px |
| 余白 | 上下 18px・左右 26px | — |
| 角の丸み | 24px | — |
| 名前 | s1（22px）、太め、字間 0.1em | 約 8px |
| 島の文字 | 高さ 30px（いまの字幕と同じ）。長いときは幅に合わせて縮める（最小 22px） | 約 11px |
| 点線 | 1.5px、上下に 10px あける | — |
| 訳 | **s4（40px）**、行の高さ 1.45、3行まで | 約 14px |
| 尾 | 幅 32px・高さ 16px | — |
| 全体の高さ | 訳が1行で約 180px、2行で約 240px | — |

- 訳は、いまの字幕（s5、46px）より1段小さい。
  - 吹き出しは明るい地に濃い字なので、景色の上の白い字より読みやすい。
  - s5 のままだと、2行の吹き出しが 270px を超え、景色を隠しすぎる。
  - スマホ横で約 14px は、状態の1行と同じ大きさ。
- 訳の改行：1行15字まで。超えるときは「、」「。」の後で分ける（`wrapStatus` と同じ考え方）。分けられないときは字の切れ目で。
- 遠くても近くても、**吹き出しの大きさは変えない**（いつも読める大きさ）。

## 2. 置き場所

| | 決め方 |
|---|---|
| 基準の点 | 頭のてっぺんの 12cm 上を画面に写した点（見本と同じ）。尾の先がここ。吹き出しの下の端は、この点の 16px 上 |
| 追い方 | 頭の位置を、なめらかに追う（0.2秒ほど遅れて）。歩く・波に揺れるなどの小さな上下は伝えない（縦は 0.6 秒ほどかけてゆっくり動く）。字が揺れると読めないため |
| 画面の端 | 左右と上は、画面の端から 96px の内側（四隅の文字と同じ余白）。端では**吹き出しだけ**内側へ寄せ、尾の先は頭を指したまま。尾の付け根は、吹き出しの角から 28px 以上内側 |
| 上に入らないとき | 頭が画面の上のほうにある（手元の撮り方 C など）ときは、頭の横（空いている側）に置き、尾を横から出す |
| 避けるもの | 四隅のかたまり（左上のブランドと4人の一覧、右上の日付と地図、右下の JST の時計）、節目の札、考えごとの欄、ほかの住人の頭のまわり。避けるときは、まず横へずらす（尾は頭を指したまま） |
| 避けきれないとき | 下の字幕に戻す（§3） |
| 下の帯 | 帯は退かない（§5）。吹き出しが帯に重なるときだけ、帯を 30% に薄くする |

- カメラ（`CAMERA.md` §1 に足した）：話が始まる前の構図（F 正面側か、2人が入る横からの画）では、話し手の頭の上に、吹き出しの入る空き（約 260px）を残す。

## 3. 遠いとき・画面の外・後ろ姿

| 場合 | 出し方 |
|---|---|
| 遠い（小さく映っている） | 吹き出し。大きさは変えない。尾が頭を指す |
| 後ろ姿・横顔 | 吹き出し。顔の向きには関係なく、頭の上 |
| 植物の陰 | 吹き出し（植物は1本ごと透かすので、D27） |
| 岩・地形・小屋に頭が隠れている | **下の字幕** |
| 画面の外・カメラの後ろ | **下の字幕**。端に寄せた吹き出しでは、誰が言ったか分からないため |
| 話している途中で、画面の外へ出た | その行が終わるまで、吹き出しを画面の端（96px の内側）に寄せたまま。尾は出た方を指す。次の行から字幕 |
| 夜の構成で、小窓が開いている | `NIGHT.md` のとおり。先にメインを話し手に戻して小窓を閉じ、それから吹き出し。小窓の中には吹き出しを出さない |

- 「頭が見えている」の判定は、カメラの「隠れない位置」（`CAMERA.md` §1）の頭の点と同じものを使う。
- 下の字幕に戻ったときは、いまと同じく帯が退く。

## 4. 2人が続けて話すとき（会話・焚き火の会）

- 吹き出しは、**いま話している1人に1つ**。
- 次の人が話し始めたら、前の吹き出しは**薄く残す**：
  - 濃さ 55%、影なし、少し小さく（92%）。
  - 読み終わる目安（§6）まで残し、それから 0.4秒で消える。
  - 早口のやりとりでも、前の台詞を読み終えられるように。
- 同時に見える吹き出しは**2つまで**（いまの1つと、前の薄い1つ）。3人目が話し始めたら、いちばん古いものはすぐ消す。
- 前の吹き出しといまの吹き出しが重なるときは、**いまの吹き出しを横へずらして**よける（尾は自分の頭を指したまま。`screen-10-fire.jpg`）。よけられないときは、前のものをすぐ消す。
- 焚き火の会も同じ。輪を映す構図で、話す人の頭の上に順に出る（`screen-10-fire.jpg`）。
- 「ときどき」の数え方（D26）：吹き出しは、薄いものも含めて**1つ**に数える（字幕と同じ枠）。

## 5. 状態の1行（帯）との関係

- **吹き出しのときは、帯は退かない**。いま帯が退くのは、字幕が下の中央に出て帯と並ぶため。吹き出しは下に出ないので、退く理由がない。
- 帯の状態の1行は「〇〇と話している」のまま。**誰と話しているかは帯、何を言ったかは吹き出し**（同じことを2か所で言わない）。
- 吹き出しが帯に重なるときだけ、帯を 30% に薄くする。
- 節目のひとこと（②の2、`VOICE.md` §3）は、吹き出しが出ている間は出さない。吹き出しが消えてから出る。出る順の強さ：節目の札 ＞ 吹き出し・字幕 ＞ 考えごと ＞ 道のり。
- 考えごとの欄は、いまの字幕のときと同じく、書くのを止めて 40% に（`THINK.md`）。

## 6. 出す時間（R-023 の、会話の外のひとことも）

| | 決め方 |
|---|---|
| **読む目安** | 本体の案のとおり **4秒＋訳1字ごとに 0.15秒、最大 10秒**（20字で7秒）。英語の画面でも、同じ行の日本語の訳の字数で数える（どの画面でも同じ時間にするため） |
| 会話の台詞 | 声が始まったら出し、声が終わって 0.4秒で消す（見本と同じ）。ただし、読む目安より短くはしない |
| 会話の外のひとこと（申し出・知らせ・返事・心づもりを伝える） | 読む目安の時間だけ出して消す。声があるときは、声の終わり（＋0.4秒）と長いほう |
| 出方・消え方 | 0.25秒で、6px 下から浮かびながら出る。消えるときも 0.25秒（見本と同じ） |

- 会話の外のひとことが消えないこと（R-023）は、世界の側で直った（main 4ecedd7、PR #147：`sayUntil`＝4秒＋1字0.15秒、最大10秒）。画面は世界に従い、`saying` が消えたら吹き出しも消す。会話の台詞では、読む目安を下限に使う。

## 7. 英語の画面と YouTube の字幕

- **英語の画面（`?lang=en`）**
  - 名前は英名。訳は英語の文（`sayEn`）を Cormorant Garamond の 44px（s4＋4px、欧文は大きめにする決まり）で。
  - 1行は約30字まで、3行まで。超えるときは文の切れ目、なければ語の切れ目で分ける。
  - 英語の文がないときは、島の文字だけの吹き出し（いまの字幕と同じ扱い）。
- **YouTube の字幕（`?captions`）は変えない**
  - 1行ごとに、話し手の名前つきで送る（いまの `captions.send` のまま）。日本語の画面には英語の字幕（v2 §6）。
  - 吹き出しを出したときも、下の字幕に戻したときも、同じように送る。
  - YouTube の字幕は、視聴者がオンにしたときだけプレイヤーの下に出る。下の帯と重なることがあるが、視聴者が選んだ表示なので、こちらでは避けない。

## 9. 本体にお願いしたいこと

1. 吹き出し（§1・§2・§8）。下の字幕は、§3 のときだけにする。
2. 遠いとき・画面の外・隠れたときの出し分け（§3）。1行の途中で切り替えない。
3. 2人が続けて話すとき（§4）。前の吹き出しを薄く残す、2つまで。
4. 吹き出しのときは帯を退かせない（§5）。
5. 出す時間（§6）。会話の外のひとことは、R-023 の直し（`sayUntil`）のまま。会話の台詞に、読む目安の下限を足す。
6. 英語の画面と YouTube の字幕（§7）。
7. 確かめ方：`tools/layout/overlap.cjs` に吹き出しを足す（HUD を変えたら通す決まり）。
   - 7サイズで、焚き火の会と2人の会話の場面。
   - 吹き出しが四隅のかたまり・節目の札・考えごと・ほかの住人の頭と重ならないこと、画面の外に出ないこと。
   - 吹き出しの揺れ（1秒あたりの動き）も測れるとよい。
8. 入れるのは**試し回しの4回目（11/5 ごろ）**（`docs/rehearsal/CYCLES.md`）。3回目は、考えの見せ方と目的・結果のひとこと（R-030）、カメラ、章に使うので、画面の作りの入れ替え（吹き出し）は別の回にして、どちらが効いたかを分けて見る。
