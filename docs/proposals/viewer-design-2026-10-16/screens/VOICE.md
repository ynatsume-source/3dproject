# 「なぜ今これをしているか」を、住人自身に語らせる（R-017・R-021、2026-10-26）

本体からの依頼（main ebdb843）への答え。オーナーの昼の試運転の所見 R-017（何を見させられているのか分からない）と R-021（考えている様子が見えない）。

## 1. 原則：本体の3段の案（2026-10-26、オーナー決定）

- **画面の外の語り手は、説明しない**。「ドットは今、小屋を作るために…」のような三人称の解説文は出さない。
- **住人自身が語る・示す**。画面に出る言葉は、次の3つだけにする。
  1. 世界が言う、短い「いまの動き」（状態の1行）
  2. 住人の声（独り言・会話）
  3. 住人の道のり（数秒）
- オーナーが本体の3段の案で決めた（main 41ed981）。この担当は、3段をこう組み立てる（いつも出すのは①だけ。ほかは時間を区切る）。

| 段 | いつ | 何を | 声 |
|---|---|---|---|
| ① 状態の1行 | **いつも** | 目的を込めた「いまの動き」 | 世界（主語なし、短く） |
| ② 考えごと | 考えている間と、答えが出た直後 | 考えた中身 | 住人 |
| ② の2 節目のひとこと | 映り替わったときと、心づもりが変わったとき（節目）に **20秒** | 住人が自分で言った、いまの心づもり（かぎかっこ） | 住人 |
| ③ 道のり | 映り替わったときと、段階が進んだときに **12秒** | 大きな目標までの段階 | （ラベルだけ） |

## 2. ① 状態の1行の言い換え：語調の決まり

**決まり**
1. **主語を書かない**。「〜ている」で終える（いまの形のまま）。
2. **目的を、動きの中に込める**：「〜を探して」「〜を集めに」「〜を確かめに」「〜にそなえて」「〜を温めて」。「〜のため」で終えない（説明に聞こえる）。
3. **世界にある具体的な物と場所**で言う（流木・部材・潮だまり・岩棚・日なた）。
4. **体の理由は、ふつうの体の言葉で**（冷えた・おなかがすいた・眠い・電池が減った）。体の状態が本当にそうなっているときだけ（`body.ts`、電池）。
5. **20字まで**（帯の1行。長いときは画面の側で整える）。
6. **使わない言葉**：散歩・ひと休み・休憩・作業・活動・用事など、目的を持たない言い方。気持ちの言葉（楽しそうに・のんびり）も、世界が持っていないので使わない。
7. **いちばん大事**：言い換えてよいのは、**世界の中に本当の理由があるとき**だけ。理由がない行動（ただの「散歩」）は、言葉で目的を付けるのでなく、**行動の方に理由を持たせる**か、その行動をなくす（本体・科学班）。言葉は実際の状態から（CLAUDE.md の決まり）。

**言い換えの例**（中身と理由は、本体・科学班が世界と照らして決める）

| いま | 言い換えの例 | 世界にあってほしい理由 |
|---|---|---|
| 散歩している（ドット） | 流木を探して、浜を見て回っている／まだ歩いていない浜を見に行っている | 流木・貝殻を本当に探している、または地図の空白を埋めている。どちらでもなければ、散歩はやめる |
| ひと休みしている（ドット） | 日なたで、電池をためている | 電池が減っている（`voyageHour` などが見ている値） |
| 仰向けに浮いたまま昼寝している（ラッコ） | 眠くなって、波の上で眠っている | 眠気が強い（`body.ts`） |
| 浜で甲羅干しをしている（カメマル） | 冷えた甲羅を、日に当てて温めている | 体が冷えている（R-019） |
| 水面で毛づくろいしている（ラッコ） | 毛に空気を入れて、体を冷やさないようにしている | 冷え（いまある「冷えた体を、水面で毛づくろいして温めている」はこの形でよい） |
| 海を眺めている | 流木が打ち上がるのを、浜で待っている | いまある括弧の中身を、そのまま本文にする |
| 丘のふもとで夜を待っている（ランタン） | 星が出るまで、丘のふもとで待っている | 夜の観測の前 |
| 気になる場所へ歩いている | まだ測っていない岩場へ歩いている | 行き先の本当の理由（地図・測量・頼まれごと） |
| どうするか考えている | 道がふさがった。次にどうするか考えている | 考えるきっかけ（`report` の結果：done・no way・blocked など）を、ふつうの言葉で |

## 3. ② の2 節目のひとこと（R-009 ① を、住人の声に改める）

D26 の「何のための1行」（「― 小屋の部材にするため」）は、三人称の説明に聞こえるおそれがある。**住人自身が言った言葉**に改める。

| | 決め方 |
|---|---|
| 中身 | その住人が自分で言った、いまの心づもり。例：朝の集まりで言ったこと（「今日は小屋の部材を集める」）、AI の目的の文（R-016 の内部の名前を除いたもの） |
| 形 | 状態の1行の下に、かぎかっこで小さく1行（s2、ink2）。例：「部材は、あと少しで足りる」 |
| 出すとき | 映り替わったとき（道のりの12秒が終わってから）と、心づもりが変わったときに、**20秒**。そのあと消える |
| 出さないとき | 住人が自分で言った言葉がないとき（作らない） |

## 4. ② 考えごと：R-011 の形を4人みんなに

R-011（`THINK.md` §1）の画面の作りを、ドット・ラッコ・カメマルにも使う。左の中ほどに縦書き、見出しは「（名前）の考えごと」とその住人の色の線。

**考えごとは2種類**

| | 長い考えごと | 決めるときの考え |
|---|---|---|
| 誰が | おもにランタン（夜、30〜60分） | 4人とも（AI の節目。数秒〜数十秒） |
| 答えを待つ間 | — | 見出しと、ゆっくり増える「……」だけ（1秒に1つ、3つまで、くり返し）。**作り話の文は出さない** |
| 文の出し方 | 1秒に3字。次の文まで最短1分半。新しい4文まで | 答えが来たら（検査のあと）、1秒に6字で書く。2文（50字ほど）まで |
| 残し方 | 終わってから2分 | 書き終わってから30秒。次の考えが来たら入れ替える |

- **同時に考えたとき**：出すのは、画面にいる住人（メイン、夜は小窓も）の考えごとだけ。画面にいない住人の考えごとは出さない（左上の4人の一覧で「考えている」と分かる）。考えごとのためだけにカメラを替えない。
- **語調**（AI への頼み方。本体・科学班）：一人称、短い文、具体的な物と場所。内部の名前・英語を書かない（R-016）。世界の隠れた値は書かない。
- 字幕・節目の札が出ている間は、書くのを止めて 40% に（R-011 と同じ）。

## 5. R-021 考えている間の様子

オーナー：考える時間に上限は要らない。問題は、考えている様子が見えず、止まって見えること。

| | 決め方 |
|---|---|
| **しぐさ**（本体・自然班） | 止まらず、小さく動き続ける。ドット：手を止めてうつむく、4秒ほどごとに首を少しかしげる。ラッコ：仰向けで前足をお腹の上で合わせ、ゆっくり回る。カメマル：首をもたげ、ゆっくりまばたきして首を回す。ランタン：灯りがゆっくり明滅する（3秒で一回り、明るさの差は小さく） |
| **カメラ** | 考え始めたら、正面側（`CAMERA.md` の F）へゆっくり回り、少しずつ寄る（1秒に 5〜10 cm、1.5 m まで）。答えが来たら止まる |
| **状態の1行** | 「（きっかけ）。次にどうするか考えている」（§2 の例）。きっかけが分からないときは「次にどうするか考えている」 |
| **考えごとの欄** | 見出しと「……」（§4）。答えが来たら文を書く |
| **長さ** | 上限なし（オーナー）。通信が切れたときだけ、習慣に戻る（本体の R-015 の扱い）。習慣に戻ったときは、「……」を静かに消す |

## 6. ③ 道のりの頻度

D26 のまま：映り替わったときと、段階が進んだときに12秒。夜の小窓で何時間も同じ住人のときは、メインに戻した見どころの始めに出る。これ以上は増やさない（説明しすぎない）。

## 7. まとめ：一度に見える言葉の量

いつも見えるのは、状態の1行（①）と、左上の4人の一覧だけ。映り替わった直後の約30秒は、次の順に重ならずに出る。
1. 道のり（12秒）
2. 節目のひとこと（20秒）

考えごとは、考えている間だけ出る。三人称の解説は、どこにも出さない。

## 8. 本体・科学班にお願いしたいこと

1. 状態の文の言い換え（§2）。言い換えは世界に本当の理由がある行動だけ。理由のない行動（散歩など）は、行動の方を直す。
2. 節目のひとこと（§3、②の一部）：住人が自分で言った心づもりを、映り替わりと変化のときに20秒。R-009 ① の「何のための1行」は、これに置き換える。
3. 考えごと（§4）を4人に。決めるときの考えは、答えを待つ間「……」、答えが来たら1秒に6字で2文まで。
4. 考えている間のしぐさとカメラ（§5）。上限はなく、通信が切れたときだけ習慣に戻る。
