## 1. 考え方：文字は四隅に、真ん中は世界に

D22（文字は控えめに、世界観が先）のまま、情報を足しても次を守る。

- **文字と小窓は、画面の四隅だけ**。画面の真ん中（横の中央60%・縦の中央50%）には、節目の札のほかは何も置かない。
- **いつも出すもの**は、四隅に1かたまりずつ。そのほかは、**ときどき・数秒だけ**。
- 大きさは土台の6段（s1〜s6）の中で。新しい物は s1・s2 の小さい段を使い、いちばん大きい文字は、いま映している住人の状態の1行（s4）のまま。
- 同じことを2か所で言わない。

## 2. R-008 4人の状態（左上）

| | 決め方 |
|---|---|
| 出すとき | **いつも**（昼も夜も）。夜に「なぜランタンだけなのか」が、これで分かる |
| 1行の形 | 住人の色の短い線 ＋ 名前 ＋ 状態の1行（世界の状態の文を、帯と同じ整え方で） |
| 目立たせ方 | **映している住人**（夜の構成ではメインか小窓に映っている住人）は、明るい白と長い色の線。ほかは薄い白（ink3）と短い線 |
| 長さ | 1行は最大18字ほど。長いときは最初の「、」までにする |
| 島の文字 | 一覧には入れない（横に長くなるため。島の文字は帯と小窓の上で出ている） |

**進み具合は、% にも棒にもしない。言葉の数え方にする**
- 例：「帆を編んでいる（3枚目）」「小屋に部材を取りつけている（9本目）」。世界が数えている数（作った物の数）を、何枚目・何本目という**順番の言葉**で出す。
- 「（3/8）」のような分数・「●%」・進み具合の棒は出さない。
  - % や棒は、ゲームの進み具合の表示に見える。「いつ 100% になる？」と受け取られやすい。
  - 終わりの数（8枚など）が住人自身の計画でない限り、それは世界の側の決めごと。
  - 潮の高さと地図の割合を数字で出さない決まり（科学班・D25）とそろう。
- どの作業に何の数え方（枚・本・個・回）を付けるかは、本体と科学班が決める。数のない作業は、数を付けない。
- 夜の構成では、小窓の上は「04 ＋ 島の文字 ＋ ランタン」だけにし、状態の1行は出さない。左上の一覧の、明るい行に出ているため（同じことを2か所で言わない）。

## 3. R-009 何のため・道のり

### ① 何のための1行（帯の状態の1行の下）

| | 決め方 |
|---|---|
| 出すとき | **いつも**（その住人を映している間）。たまたま開いた人が、最初の数秒で「何を見ているのか」分かるように |
| 形 | 状態の1行の下に、小さく1行（s2、薄い白 ink2）。例：「流木を拾っている」の下に「― 小屋の部材にするため」 |
| 変わるとき | 状態の1行と同じく、0.6秒で静かに入れ替える。**比べるのは画面に出す文**（PR #121 のコメントの、点滅の件と同じ） |
| 出さないとき | 目的がないとき（眠っている・ひと休み）、目的が状態の1行と同じことを言うとき |
| 長さ | 最大22字ほど。長いときは本体と科学班で短い言い方を持つ |
| 言葉 | 世界が持っている、いまの目的（住人の計画・頼まれた仕事など）から。表示の側で作らない |

### ② 道のり（大きな目標までの段階）

| | 決め方 |
|---|---|
| 出すとき | ① ドロンがその住人に**映り替わったとき**、帯が出てから12秒。② その住人の**段階が進んだとき**、12秒（節目の札が出るなら、札が終わってから） |
| 場所 | 文の帯の中の、縄づくりの段階と同じ段（名前の下）。**同じ見た目の言葉**で、ラベルだけ「道のり」にする |
| 形 | `道のり　小屋・家・筏・帆で島の外へ`。済んだ段階は「済んだ」の色、いまの段階は砂の金に下線、次からは薄く。5段階より多いときは、済んだものを前から省く |
| 縄づくりの段階との関係 | 道のりの12秒が終わったら、作業中なら縄づくりの段階に戻る。同時には出さない |
| 出さない所 | 4人の一覧（1行が長くなるため）、地図の近く（地図はランタンだけのため）、小窓の中（小さいため） |

- 道のりがあれば、ただ歩いている画も「大きな目標の途中」に見える。いつも出すと帯が重くなるので、映り替わったとき（見る人が「これは誰で、何を目指しているのか」を知りたいとき）だけにする。
- 道のりの段階と言葉は、科学班と本体が決める。
