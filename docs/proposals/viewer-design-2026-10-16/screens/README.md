## 1. 考え方：ドロンの「観測の窓」

見る人は、住人には見えないドロンの記録画面をのぞいている。画面の文字は、ドロンが添える**控えめな注記**であって、島の主役ではない。

| 原則 | 中身 |
|---|---|
| **世界が主役** | 文字は四隅に寄せ、画面の中央の広い部分は空けておく。文字の下の暗さは、文字のある角からやわらかく落とすだけ。箱・枠線・丸いボタンの形は使わない |
| **暗さは景色しだい** | 文字の下の「くもりガラス」（背景をぼかして暗くする）の濃さは、背後の明るさで変える。明るい砂浜では濃く、夜はほとんど無し。アプリが文字の場所の明るさを1秒に1回ほど測って決める（描画だけの処理で、世界には触れない） |
| **語り手を書体で分ける** | 世界の事実（状態・出来事・節目）と住人の言葉の訳は**明朝**。ドロンの記録（番号・DORON の文字）は**英字の小型大文字と等幅の数字**。住人自身の言葉は**島の文字**（ルマウ）で、その下に訳 |
| **島の文字を見せる** | 住人の名前は島の文字＋カタカナで添える。会話は島の文字の行と訳の行を重ねる。島に独自の言葉と文字があることが、説明なしで伝わる |
| **色は一つだけ** | 白（少し温かい白 `#f4f1ea`）が基本。強調は**砂の金**（`#ebcb8b`、波打ち際＝ルマウの色）だけ：今の段階、節目。住人の色（ドット黄・ランタン水色・カメマル緑・ラッコ橙）は名前の横の短い線にだけ使う |
| **動きは静かに** | 視点の切り替えはフェード。文字は0.6秒ほどでふわっと出て、消えるときも同じ。点滅・跳ねる・横から滑り込む動きはしない |

## 4. 部品

**下の帯（付き添いの視点 01〜04）**：細い縦線（白 60%）の右に、上から `01 DORON ・ 付き添い` → 島の文字の名前 ＋ カタカナの名前 ＋ 住人の色の短い線 → 状態の1行。

**下の帯（島をめぐる視点 13）**：`13 DORON ・ 島をめぐる` → 4人の名前（島の文字・カタカナ・色の線。眠っている住人は薄く）→ 1行：直近の出来事の文（例「焚き火の会が始まった」。10分以内の出来事がなければ出さない）。

**縄づくりの段階**：名前と状態の1行の間に1行。今の段階は砂の金の太字に下線、済んだ段階は淡い青緑、まだの段階は白、省いた段階は取り消し線。残り時間や％は出さない（§3-6）。

**会話の字幕**：話している間、**下の帯は退いて**（話している言葉そのものが「今していること」なので）、下の中央に字幕を出す。上から、話し手（色の線 ＋ 名前）→ 島の文字の行 → 訳。訳が20字を超えるときは最初の「。」で改行する。いまのアプリの吹き出し（住人の頭の上）は、ライブでは小さすぎて読めないので、ライブだけこの字幕にする案。

**節目の札**：上の中央寄りに、砂の金の細い線ではさんで「島で初めて」→ 出来事の文（最初の「。」まで）→ 島暦の日付と時刻。約8秒出してフェードで消す。札の間も下の帯はそのまま。

**島の時刻**：`島暦1年 6月14日 ｜ 19:06`。「今」とは書かない（配信の遅延があるため）。

## 5. 読みやすさ（測った値）

文字を消した画（`&notext`）で、文字の下の明るさ（明るいほうから1割の位置）と、文字の白との明るさの比を測った。目安は 4.5 以上。

| 場面 | 状態の1行 | 名前 | ドロンの番号 | 島の時刻 | AI の表記 |
|---|---|---|---|---|---|
| 昼の明るい砂浜（`#day`） | 10.0 | 11.3 | 9.9 | 11.7 | 12.3 |
| 昼・縄づくり（`#rope`） | 10.0 | 10.9 | 10.1 | 11.7 | 12.3 |
| 夕方・島をめぐる（`#isle`） | 16.4 | 15.5〜16.5 | 12.8 | 12.3 | 12.4 |
| 夜（`#night`・`#talk`・`#milestone`） | 17.6 | 17.7 | 17.4 | 17.0 | 16.7 |

- いちばん明るい場面（白い砂浜の真昼）でも目安を大きく超える。くもりガラスは、明るい場面では文字の角を中心にはっきり暗くなる。夜はほとんど見えない。
- 試しに画面の下全体や上全体を帯で暗くする案も作ったが、空や浜まで夜のように暗くなって島が台無しになったのでやめた。

## 7. 決めてほしいこと（オーナー）

1. **書体**：明朝（世界観が強い、おすすめ）か、ゴシック（案A、情報として読みやすい）か
2. **島の文字を画面に出すか**（名前と会話）。出すと島の言葉があることが伝わるが、初めての人には模様に見える
3. **会話を下の中央の字幕にするか**（ライブだけ）。アプリの吹き出しはそのまま
4. **ブランドの表記**：`UTSUSHIYO / ドットたちの島` でよいか（チャンネル名と合わせる：`../CHANNEL_COPY.md`）

## 8. 作るときのメモ（main 向け）

- ライブモードの画面だけに入れる。地球の海の画面は変えない。
- くもりガラスは `backdrop-filter: blur() brightness()` と、端をぼかす `mask-image`。濃さは、文字のある場所の明るさを小さく縮めた画（例 64×36）で1秒に1回ほど測り、明るいほど濃くする（0.2〜0.6）。描画だけの処理で、世界・住人には触れない。
- 島の文字は `islandlang.ts` の `glyphs()` をそのまま使う（モックはその写し）。
- 文字の出入りは 0.6 秒のフェード。視点の切り替えは §3-1 のとおり 1〜1.5 秒のフェード。

## 9. 自然班への依頼（見た目）

- 灯りの光：夜の引きの画で、灯りの届く範囲が見えること（モックでは描き足した）。
- 夜の明るさ：今回撮った夜（22:30、曇り）は、島の輪郭がほとんど見えないほど暗かった。曇りで月のない夜でも、浜と森の輪郭が分かる程度の明るさがほしい（`../TEST_REVIEW.md` の N1）。

## 10. 確かめていないこと

- 実際の GPU で描いた画の上での見え方、動き（フェード）、配信の圧縮のあとの文字のにじみ。
- YouTube のプレーヤーの表示との重なり（試験配信で撮る）。
