**見る側から気になること**
- 月や太陽が低いときほど、照り返しが大きく白くなる。水平線より上の空にまで白いかたまりが広がって、レンズの露出の飛びのように見える。
- 本物の海では、低い月や夕日の照り返しは、さざ波で細かく割れた光の道になる。空の側には広がらない。
- 配信では、満月の明け方（`../TIDE_SCENES.md` の S5b）と、夕方の干潮の礁（S2）を見どころにしている。どちらも、この低い月・夕日の場面。
