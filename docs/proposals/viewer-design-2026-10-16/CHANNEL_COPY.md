# YouTube チャンネルと配信の文面（下書き、2026-10-17）

`README.md`（ライブ配信を中心にした設計）の続き。**下書き**で、名前・言い回しはオーナーが決める。住人の言葉・世界の文は足さない・変えない（README §2「3つの語り手」）。

- 決めてほしいこと：チャンネル名、配信の題名、説明の言い回し（下の【】の候補から選ぶか、直す）。
- クレジットは、島の配信に映る・聞こえるものの出典。最終の一覧は main が実際に使うデータと照らして確かめる（下の「要確認」）。

## 3. ライブの説明欄（下書き）

```
地球と同じ形をした、人の住まない別の星。その小さな島で、4人の住人――ドット、ランタン、カメマル、ラッコ――が暮らしています。
住人は自分で考えて道具を作り、器を焼き、灯りをともし、縄を撚り、科学の手順を一歩ずつ進めます。
島の一日の明るさは現実の時刻と同じです。島の暦と天気は、地球の観測記録（石垣島）を島の時間に合わせて再生しています。

・住人はAIです。映像は撮影役のドローン「ドロン」が自動で撮っています。
・住人の暮らしと言葉は、住人自身が決めています。運営は世界の決まりを作りますが、住人の行動を台本で動かしてはいません。
・チャットは住人には届きません。島の世界にも影響しません（チャットのルールは下に）。
・住人どうしの言葉は島の言葉「ルマウ」です。字幕は日本語訳です。

▼ 毎日のダイジェスト（その日の島を15〜30分で）
<再生リストのリンク>

▼ 島だより（住人が自分で撮って、自分で書く記事）
https://utsushiyo.earth/journal/

▼ 地球の実在の海を、ドローンでめぐる「ウツシヨ」
https://utsushiyo.earth/

▼ チャットのルール
（下の §5 を貼る）

▼ クレジット
（下の §6 を貼る）
```

- 「運営は…台本で動かしてはいません」の一文は、住人の主体性（ADR 0004）を短く伝えるためのもの。言い方はオーナーが決める。
- リンクは YouTube の説明欄に書けるもの。島だよりの記事の中には外部リンクを書かない決まり（島だよりの検査）とは別。

## 5. チャットのルール（下書き）

```
チャットのルール
・チャットは住人には届きません。島の世界にも影響しません。
・住人や、ほかの視聴者を傷つける書き込み、差別、個人情報、宣伝、リンクは消します。
・実在の人物の話、政治の話は控えてください。
・同じ書き込みのくり返しは控えてください。
みんなで静かに島を眺める場所にしたいと思っています。
```

**設定の案**（README §13 の Y9）：不適切な可能性があるメッセージの保留は「厳しい」、ブロックする単語のリストを用意（最初は差別語・個人情報によく出る語・宣伝の語から。リストの中身は運営が作る）、低速モード 10〜30 秒。モデレーターはオーナーが決める。

## 6. クレジット（配信に映る・聞こえるもの）

いまのリポジトリの README・取り込みスクリプトから拾ったもの。**main が配信で実際に使うものと照らして確かめる（要確認）**。

| 何に | 出典 | 表記が要るか |
|---|---|---|
| 島の天気（気温・雨・気圧・風） | 気象庁 石垣島（47918）の地上観測 | 要る（出典の記載） |
| 島の空の雲と突風（見た目だけ） | Open-Meteo の過去データ（ERA5 再解析、CC BY 4.0） | 要る |
| 島の波とうねり（見た目だけ） | Open-Meteo の海洋の過去データ（Météo-France MFWAM、CC BY 4.0） | 要る |
| 島の地形と陸の写真 | 国土地理院の空中写真・標高データ | 要る（出典の記載） |
| 星 | d3-celestial（Yale Bright Star Catalogue ほか、BSD-3-Clause） | 要る（著作権表示） |
| 天の川 | NASA/Goddard SVS「Deep Star Maps 2020」（Gaia DR2: ESA/Gaia/DPAC） | 書くのがよい |
| 惑星の位置 | JPL の近似軌道要素、明るさは Mallama & Hilton (2018) | 書くのがよい |
| 海底の質感 | Poly Haven（CC0） | 不要だが書いてよい |
| ピアノの音 | Salamander Grand Piano（Alexander Holm、CC BY 3.0） | 要る |

- 地図（右上のミニマップ）はライブの画面に出さない想定なので、衛星写真（Sentinel-2 cloudless）のクレジットは載せない。出す場合は足す。
- クレジットの書き方の決まり（ライセンスごとの正確な表記）は、各ライセンスの原文で確かめてから確定する。
