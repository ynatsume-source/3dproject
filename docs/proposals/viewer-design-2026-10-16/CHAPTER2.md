## 1. 第2章の芯

- **持ち帰った粘土で、何をするか**。第1章の答え（南の島から持ち帰った）の続きが、そのまま第2章の問いになる。
- **夜の画が変わる**。灯りがともるまで、夜はランタンひとりの暗い浜。ともったあとは、毎晩そこに灯りがある。章の終わりで夜の画そのものが変わるので、見る人にとっていちばん分かりやすい「進んだ」になる。ランタンの名前とも重なる。
- **懸かっているものは本物**。野焼きで器が割れることがある（`quality.crack`）。最初の試しで灯らないことがある（科学班）。雨の日は野焼きができず、薪も乾かない。何日目に、何度めでともるかは、島ごとに変わる。
- **第1章の反省を生かす**（`CHAPTER1_END.md`）。どの島でも同じになる競争は約束しない。期限や量の競争は置かず、荷の行も出さない（粘土は第2章のうちに尽きない）。

### 道のりの「済んだ」（世界の事実。名前と境は本体・科学班が決める）

| 段階 | 「済んだ」になる世界の事実 |
|---|---|
| 薪 | 野焼き1回ぶんの、乾いた薪がそろった（乾きの境は科学班の `SEASONED_PPM`、量は野焼きの選択肢の前提と同じ） |
| 器 | 焼けた器が初めてできた（§2-1-1 の「器」と同じ。`firsts` の `fired-pot`） |
| 灯皿 | 灯皿が初めて焼けた（割れていないもの。`dishForLamp` と同じ条件） |
| 油 | ヤシ油が初めてとれた（`coconut_oil` の lot が初めてできた） |
| 灯り | 灯りが初めてともった（§2-1-1 の「灯り」と同じ。`firsts` の `light`）。これが章の終わり |

- 「薪」を置くのは、1.3日目から4.5日目までの約3日、道のりが一つも動かないのを避けるため。木を切る・積む・乾くのを待つは、画にもなる。世界の事実で決められないときは、道のりを `器 ・ 灯皿 ・ 油 ・ 灯り` の4つにする。
