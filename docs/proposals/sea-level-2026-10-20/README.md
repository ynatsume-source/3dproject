# 海面 `seaLevel(t)`：第一段と、第二段（潮）で直す所（本体、2026-10-20）

ADR 0009 の順番の 1 と 2。第一段はこの PR、第二段はこの一覧を片づけてから潮を入れる。

## 第一段（この PR）：1つの値と、それを読む道

- `src/time/sea-level.ts`：`seaLevel(ms, site)`（いまは常に 0）と `waterTop(kind, level)`（潮だまり・内陸の水は 0 のまま）。時刻だけで決まり、保存しない。乱数を引かない。
- GPU：`U.uSeaH`（`render/common.ts`）。水の色（`waterCol`）・吸収（`absorb`・`absorbSeen`）・霞（`hazeCol`）・空から見た水（`fogAir`）・霧の切り替え（`fogIt`）・コースティクス（`caus2`）が 0 の代わりに `uSeaH` を読む。
- 描かれる海面：空から見た海面（`ocean/air.ts` の `seaTop` と `abyss`）と、水中から見た海面（`ocean/scenery.ts` の `surface`）が `uSeaH` の高さに置かれる。星・雨・空のドーム・光の筋（`scenery.ts`・`render/post.ts` の体積光）・水際の分割画面（`render/split.ts`）も同じ値を使う。
- CPU：`swellAt`・`surfaceAt`（`ocean/air.ts`）が `seaLevel` に波を足した値を返す。`setSeaLevel` が GPU と CPU に同じ値を入れる（`main.ts` が毎フレーム呼ぶ）。
- 確かめたこと：
  - `scripts/sea-level-check.ts`（fast）。
  - 乱数の指紋が main と同じ（b4c20fab…、598832/599248）。
  - fast 76 件。
  - shader-check `--all`。

## 第二段（潮）の前に直す所

調べた結果、y = 0 を海面と決めている所は次のとおり。

### 1. 潮で動かさない（平均海面のまま）

- 水の分類（`ocean/water.ts`）。
- サンゴの上端 `CORAL_CEIL` と、海底に置く物の深さ（ADR 0009 §4）。
- 砂と草の境（`shore.ts` 80–81）。
- 作業場を選ぶ高さ（`residents.ts` の `beach`・`open`・`spot`・`pierAt`）。これは満潮 +0.8 m と比べて確かめる（科学班のチェック 4）。

### 2. 第二段で `seaLevel(t)` を読むようにする

- **潮のマスク**：海面は1枚の円盤なので、そのまま上げると潮だまりと内陸の水も一緒に上がる。`uSeaK` と同じ作りで「潮が届く量」（海・礁湖は 1、潮だまり・内陸は 0）を持たせる。
- **ドローンとカメラ**：`main.ts` で 0 と比べている所（およそ 50 か所）。
  - 水面を抜ける所（1065–1095）
  - 波に乗る所（1105–1110）
  - 空気と水の状態（3596。`swellAt` 経由なので第一段で済んでいる）
  - 露出（3503）、灯り（3506）、白の合わせ（3655）、水際の画（3656）
  - `director.ts` の画づくり、`ocean/start.ts`
- **HUD の深さ**：`main.ts` 1794 は `-y + tideH`（いまも潮を足している）。第二段では `seaLevel(t) - y` に替える（二重に足さない）。
- **生き物の上限**：魚の群れ −0.8、1匹 −0.5、カメの息つぎ、イルカ・アシカ・トビウオ・海鳥の水面。干潮（−1.04 m）で空中に出ないように、`seaLevel(t)` からの深さにする。
- **住人**：
  - 泳ぐ・歩くの境（`residents.ts` 2830–2978 の `G` 0.1/0.2/0.3）。`placeY` の浮かぶ高さ（3074–3080）、目の高さ（1376、3641–3643）。
  - 道の計算を覚えている所は、潮で古くならないようにする。
- **浜の見た目**：濡れた砂と波の線（`shore.ts` 117–120）は潮の高さから。陸と海底の見た目の境（`build.ts` 310）は自然班の「濡れたリーフ」と一緒に。
- **しぶき・泡**：`ocean/splash.ts`、`residents.ts` 125、`flyingfish.ts` 86（空中か水中か）。
- **「いま水の下か」**：これを答える関数がまだない。`underWater(x, z, y, t)` を足す。海・礁湖は `seaLevel(t)`、潮だまりは 0 と比べる。

## 先に測ったこと（チェック 4 の下調べ、2026-10-20）

1年の潮（嘉弥真、`tide` に日周の分を入れたもの、10分ごと）の幅は、**最高 +0.91 m、最低 −1.04 m**。ADR 0009 に書いた「満潮 +0.8 m」は大潮の目安で、1年の最高はこれより 0.11 m 高い。

作業場の地面の高さ（`worksiteSpots()`、main の島。筏はまだないので入っていない）：

| 作業場 | 高さ |
|---|---|
| site:husk-pool | 1.31 m（2 m 以内の最も低い所 1.13 m） |
| site:husk-work | 1.71 m |
| site:cord-dry | 1.77 m |
| site:cord-work | 1.69 m |
| site:cord-hang | 1.73 m |
| site:sail-tree-0 | 1.13 m |
| site:sail-tree-1 | 1.40 m |
| site:sail-dry | 1.82 m |
| site:sail-work | 1.67 m |

- どれも1年の最高潮（+0.91 m）より上にある。いちばん低い所でも 0.22 m 上。
- 波の打ち上げを入れると、sail-tree-0 と husk-pool のまわりは近くなる。

**科学班に相談したいこと：`site:husk-pool` の水。**
- 作業場の点そのものは乾いた砂（1.31 m）にある。
- 近くの水は、6 m 先にある**海**（`water.ts` の分類では `sea`）で、潮だまり（`pool`）ではない。
- 作業場を選ぶ `shore`（`residents.ts` 1257）は「浜で、9 m 以内に `L.h < 0` がある所」。そのため、浸ける水は海の縁になる。
- 潮を入れると、干潮（−1.04 m）で水際が遠のく。
- 決め方の案は2つ：
  - (a) 浸けの水は「平均海面の水たまり」とみなし、潮を読まない（ADR 0009 §3 のとおり。見た目だけが動く）。
  - (b) 本当の潮だまり（`pool`）のそばへ移す。
- 第二段の前に決めたい。本体のおすすめは (a)。浸けの工程と lot は変えず、見た目の水際だけが動く。
