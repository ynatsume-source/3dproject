# クサトベラとモンパノキの真ん中の「丸いもの」をやめる（自然班、2026-10-26）

オーナーの指摘：植物の中央に、なぞの丸いものが見える。

- 正体は、ずんぐりした形にした作業（48febd6、nature-look 段階2）で足した「葉の芯」のドーム（`shore.ts` の `dome()`）。
  - クサトベラ（`shrubGeo(false)`）：地面に低いドーム。
  - モンパノキ（`shrubGeo(true)`）：樹冠の真ん中に、下を閉じたドーム。
- ロゼットのすき間から砂や空が透けないように置いたもの。だが、なめらかで暗い面なので、葉の塊ではなく丸い玉に見えていた。

## 直したこと（オーナーの選択：案1、`src/ocean/shore.ts` だけ）
- ドームをやめた。代わりに、外のロゼットの内側の殻に、小さなロゼットを並べた。
  - クサトベラ 34 個、モンパノキ 15〜16 個。
  - 外向きで、陰になった少し暗い緑。モンパノキは樹冠の下側まで回る。
  - すき間は葉で埋まり、砂や空は透けない。
- ほかの植物の形は変えていない。
  - 植物の形は自分の乱数で作る（`fineGeos()`）。
  - 旧ドームの乱数は今までどおり引き、形は捨てる。そのため、あとに作るモンパノキ・流木・岩の乱数は前と同じ。
  - 新しい葉は、さらに自分の乱数で作る。
  - 島の乱数（`Math.random`・世界の乱数）には触れていない。
- 形のハッシュ（`tools/lab/shrub-look.cjs`）：変わったのはクサトベラ（頂点 3656 → 4232）とモンパノキ（8852 → 10100）だけ。モクマオウ・アダン・流木・岩は main と同じ。
