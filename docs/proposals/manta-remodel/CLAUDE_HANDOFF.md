## 部分採用

造形のみなら `manta.ts` と `models.ts` の再exportが最小単位。旧呼び出しの `mantaMaterial()` と `uFeed` でも動きます。模様の種差を使うなら通常生成・群れ・跳躍・図鑑の引数も適用します。

動作側は新しい `uMouth` / `uBank` / `uAir` を参照します。旧マテリアルのまま動作コードだけを移すと未定義uniformへアクセスするため、互換処理を設けるかモデルと一組で適用してください。

## 最新mainとの関係

この試作は基準コミットからの独立した分岐です。制作中にmainが進んでいるため、現在のmainのカルナティック号や海域の改良をこのブランチの古い状態で置き換えないでください。採用時の最新mainに対して差分を確認し、今回のマンタ関連の変更を移植してください。

2026-10-02の確認時点では、main `d3e2e899b0a885be3244dfd44156179737867525`（Point Lobos追加）と実装コミット `c9a6c715938f8243664bd0a0e40d610c8374215b` の `git merge-tree --write-tree` は内容競合なしでした。`models.ts` の温帯魚追加、`build.ts` のケルプと沈船の改善は今回の差分と別の場所です。これは内容競合の確認であり、統合後アプリの動作検証ではありません。

このブランチの実装コミットと、その後の頭鰭の厚み修正を合わせて取り込んでください。最後の資料コミットだけではモデルは揃いません。
