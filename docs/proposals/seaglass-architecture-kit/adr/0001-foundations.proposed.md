# ADR 0001｜最小の永続世界から育てる

状態：Proposed（未採択）  
日付：2026-09-30

## 背景

海中の3D観賞アプリが既にあり、将来はAI住民・オープンワールド・訪問者・配信へ広げたい。本人は技術専門家ではなく、AIと反復的に開発する。趣味としての楽しさを重視し、商用化は未確定。

## 提案する判断

1. 現在のTypeScript/Vite/Three.jsを継続し、全面移行しない。
2. 世界状態と描画を徐々に分け、最初は単一アプリで運用する。
3. 永続ID・正式時間・保存形式を、最初の名前付き住民で導入する。
4. 住民の行動はルールから始め、LLMを交換可能な補助的判断として追加する。
5. 24時間・複数人の共有が必要になった時点で常駐サーバーを追加する。
6. 既存の観賞用の時間操作と、永続世界の履歴を区別する。
7. 商用機能はIDと権限の接続点だけを残し、現時点では実装しない。

## 理由

既存の表現を活かし、楽しさを維持したまま、保存・同一性・AIの誤作動への対処を小さく検証するため。

## 代償

一時的に旧構造と新構造が共存する。全魚群が最初から永続化されるわけではない。サーバー化にも別途作業が必要。綺麗なフォルダ構造へ一度で揃えるより、段階的な対応表の維持が必要になる。

## 再検討する条件

実測で現エンジンの制約が主要ボトルネックになったとき。多人数による同じ世界への参加が不可欠になったとき。異なる計算機での運用や、重い物理シミュレーションが必要になったとき。

## 採択方法

本人が採用する範囲を指定し、正式ADRへ移す。未採択のままAIが全方針を実装しない。
