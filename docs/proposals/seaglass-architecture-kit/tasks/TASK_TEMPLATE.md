# Task｜タイトル

状態：Draft / Ready / In progress / Done  
対象コミット：  
依頼者が承認した範囲：

## 目的
どんな体験・不具合を改善するか。

## 変更する範囲
対象領域・ファイル。未確認の場合は最初に特定する。

## 変更しない範囲
時計、保存形式、住民ID、他魚種、依存関係等、今回は触らないもの。

## 参照する仕様
正式採択済みの文書と、その版。

## 振る舞い
入力条件／期待する結果／例外時の結果。

## 合格条件
ユーザー視点の成功条件と、機械で確認する条件を分けて書く。

## 性能
比較する端末・シーン・解像度・設定。許容する変化。

## 保存と互換性
変更の有無。変更がある場合は移行・バックアップ・復元方法。

## 検証
変更前／変更後に実行した内容と結果。未実行の理由。

## 戻し方
変更の取り消し方法。新しいデータを作った場合の扱い。

## 完了メモ
実装済み／未実装／次の候補。推測を事実として記録しない。
