# 00｜現状確認と設計の前提

状態：2026年9月30日に確認した公開mainの部分調査。完全なコード監査ではない。

## 1. ユーザーの構想として置く前提

海中の風景と生態系を磨きながら、陸・空・天候へ世界を広げる。継続した個性と記憶を持つAIキャラクターを住まわせ、本人や訪問者が観察し、将来は遊びに参加できるようにする。

主目的は趣味として作り続ける楽しさ。YouTube配信、広告、グッズ、課金による関与、住所・土地の販売は将来の可能性であり、初期開発の必須要件にしない。映画品質のCGや地球全体の精密物理再現も初期要件ではない。

ここでの「自我」は、工学上は「同一個体として続く記憶・好み・目標・関係・行動の一貫性」として扱う。主観的意識の有無を実装の合否条件にしない。

## 3. まだ断定していないこと

世界全体の永続化、サーバー権威、住民LLM、既存のテスト網、保存の互換性、シミュレーションとThree.jsの完全分離については、部分調査だけで「ある／ない」を断定しない。

READMEの記述と実装・公開版の動作が一致することも未検証。実際のFPS、VRAM使用量、最大生物数、最適なPC構成は測定していない。

したがって、この設計に書かれた機能を「既に実装済み」と説明したり、本体を読まずに同名機能を追加したりしない。

## 4. 文書で区別する4つの状態

- **Confirmed**：根拠を確認した現状。
- **Proposed**：このキットの推奨設計。採用前。
- **Accepted**：本人が採択し、正式な設計記録に残したもの。
- **Deferred**：将来構想。現時点では作らない。

以降の設計は、特記がない限りProposed。提案と現行コードの差は、不具合そのものではない。
