# ADR 0008｜帆を進める時計：島時計

状態：採択（2026-10-20、オーナー）
関係：ADR 0006（島の時間）、ADR 0007（二つの世界）、科学班の仕様 `specs/sail-api-v2` §9.1（science/reviews ブランチ）

## 決定

帆の航海で、筏が進む距離・帆走時間・縄の擦れ（帆走1時間に1回）・漕いで進む距離は、**島時計**で数える。

- 科学側の定数 `SAIL_MOTION_CLOCK` は `'island'` のまま（`src/science/prototypes/sail-raft-rules.ts`）。コードの変更はない。
- 仮定の ID は `owner-assumption/sail-raft/2026-10-18/v2-island`。時計を切り替えると ID も変わるので、前の保存と混ざらない（混ざるものは拒否される）。
- 帆の日焼けと雨は、どちらの時計を選んでも島時計で数える。

## 前提（時計の説明の訂正、2026-10-18）

本体はいったん「島の1日は現実の約1.8時間」と説明したが、これは誤りだった。正しくは次のとおり。

- **島の時刻（朝・昼・夜）は、現実の時刻と同じ**。
- 速く進むのは**島暦の日付**と、待つだけの変化（季節・乾燥・作物）で、約13倍（`ISLAND_RATE`）。

オーナーは、この訂正を聞いたうえで島時計に決めた。

## 何が起きるか

- セルは世界時計の30秒ごとに確定し、島の区間はその約13倍（約6.5分）になる。島時計で進むので、筏は現実の時間でも短く渡り終える。
- 「日のあるうちに戻る」は、島の時刻が現実と同じなので、どちらの時計でも成り立つ。引き返しの見積もりは、`sailMotionClock(sailAssumptionId())` を見て換算する（`src/robots/sail-voyage-host.ts`）。
- 漕ぐ速さ `PADDLE_MM_S = 556`（島時計で約2 km/h）は、帆のない今までの渡航と同じ速さ。

## 見送った案

- **世界時計**：現実の時間どおりに進む。島の時刻は現実と同じなので、日暮れまでに戻る判断は成り立つ。ただ、渡航に現実の何時間もかかり、帆のない今までの渡航（島時計）とも速さがそろわない。

## 変えるとき

切り替えるときは `SAIL_MOTION_CLOCK` の1か所を変える。仮定の ID が変わるので、そのとき海に出ている航海は読み込みのときに決着する（`interrupted`）。
