# ADR 0007｜二つの世界：ウツシヨの自然と、ドットたちの星

状態：採択（2026-10-05、オーナー）
関係：ADR 0006（大義と報酬、島の時間、別の星、島の言葉）

## 決定

ウツシヨには世界が二つある。話をするときも、作るときも、はっきり区別する。

| | ウツシヨの自然の世界（ネイチャー担当） | ドットたちの世界 |
|---|---|---|
| 星 | 地球（現実） | 地球と同じ形をした、人の住まない別の星 |
| 嘉弥真島 | 実在の嘉弥真島。住人はいない、手つかずの島と海 | 同じ形の島。ドット・ランタン・カメマル・ラッコが暮らす |
| 時間 | 現実の時間・現実の季節 | 一日の明暗は現実と同じ。季節と待つだけの変化は約13倍（ADR 0006） |
| 天気 | 現実 | 地球の過去の観測記録を、島の暦に合わせて再生 |
| 物 | 現実どおり | 人工物は流れ着かない。小屋・桟橋・畑など住人が作った物はこちらだけ |
| 言葉・科学・発信 | なし | 島の言葉ルマウ、ランタンの科学（科学チーム）、島だより |
| 担当 | 自然チーム | 本体（住人）・科学チーム |

**嘉弥真島は二つになる。** 形（地形・海岸線・植生・海の地形）は共有し、中身（時間・天気・住人・作った物・保存データ）は別々にする。

## 共有と分離

- **共有するもの**：地形のデータ、海と生き物の仕組み（コード）。ドットたちの世界は、自然の世界の仕組みを複製せずに借りる。
- **分けるもの**：時計と暦、天気の出どころ、住人と作った物、保存データ（`localStorage` のキー、日誌の島の記憶）、画面への入口。
- 海と生き物の仕組みは、時計・季節・天気を世界から受け取る（`src/time/clock.ts`・`weather.ts` を通す）。自然の世界は現実の値を渡す。ドットたちの世界は島の時計と再生した天気を渡す。

## 今のコードからの移行

1. 嘉弥真島の場所（`src/data/locations.ts` の `kayama`）は自然の世界のものとし、住人を外す（`residents: true` をやめる）。手つかずの島に戻る。
2. ドットたちの世界を別の場所として作る。地形は同じデータを使い、住人・島の時計・天気の再生・保存データを持つ。今の住人の保存データ（`seaglass.residents.v1`、日誌の `journal-data`）はこちらに引き継ぐ。
3. 画面の入口を分ける。地球儀（現実の地球）からは自然の世界に入る。ドットたちの世界への入口は別に設ける（見せ方は後で決める）。
4. 島だよりと科学の工程は、ドットたちの世界だけのもの。

## 取り消し

ADR 0006 の「他チームとの調整」にあった、自然チームへの依頼（嘉弥真島の海の季節の生き物と台風を島の暦に合わせる）は取り消す。自然チームの嘉弥真島は、現実の時間・季節のままでよい。代わりに、海の仕組みが時計・季節・天気を外から受け取れるようにすることを依頼する。

## 追記（2026-10-05、オーナー決定）：自然の世界の調整は、ずっとドットたちの世界にも反映する

自然チームが地球の嘉弥真島で進める描写や海の調整は、基本的にすべてドットたちの世界にも反映する。今後もずっと続ける。仕組みは次のとおり。

- ドットたちの世界の場所（`DOTWORLD`、`src/data/locations.ts`）は、地球の嘉弥真島（`kayama`）を**継承**して作る（`Object.create(kayama)`）。自分で上書きするのは、`world: 'planet'`・住人・名前・説明だけ。それ以外（地形、水の色、光、海の生き物、図鑑、`f()` など）は、読むたびに地球の嘉弥真島の値が使われる。あとから地球の嘉弥真島の値を変えても、そのまま反映される。
- `id` は両方とも `'kayama'`。id で引くもの（地形 `landOf`、ミニマップ、場所、出来事、生き物の追加 `add('kayama', …)`）は、自動で両方の世界に効く。
- 画面の入口：地球儀のピンは地球の嘉弥真島だけ。ドットたちの世界は、地球の海の後に「もうひとつの星」として並ぶ一枚のカードと、URL `#planet` から入る。

**自然チームへのお願い（反映が途切れないように）**
1. 嘉弥真島の調整は、`kayama` の値を変えるか、`loc.id === 'kayama'` で分ける形で入れる。どちらもドットたちの世界に届く。
2. 場所のオブジェクトを複製しない（`{ ...loc }` や `structuredClone(loc)`）。継承した値が落ちる。複製が必要なときは、本体に相談する。
3. 地球だけ・ドットたちの世界だけにしたい調整は、`loc.world`（ドットたちの世界では `'planet'`、地球では未設定）で分ける。住人がいるかどうか（`loc.residents`）では分けない。

## 追記（2026-10-05、オーナー決定）：この星の島にあるものは使ってよい

- ドットたちの世界の島に生えている植物・いる生き物は、地球での由来（人が持ち込んだかどうか、在来種かどうか）を問わず、この星にもともとあるものとして扱い、住人が使ってよい。たとえばモクマオウは、地球では防風林として植えられた木だが、この星ではただ島に生えている木。自然の世界の島をそのまま継承する方針（上の追記）とも合う。
- 世界を成り立たせるための多少の「都合のよい要素」は許容する。作り込みすぎて進まなくなるより、筋が通っていて前に進むことを優先する。
- 島に無いもの（竹・葦など）は、ドットが別の島へ渡って見つける対象になる。

## 追記（2026-10-05、オーナー決定）：この世界を撮影している存在「ドロン」

- ドットたちの世界を撮影しているのは、**ドロン**という名のドローン。見た目は今のドローンのモデル（`src/ocean/drone.ts`、全長 0.46 m）のまま。
- ドロンは普段、**姿と音を透過**させている。住人にも生き物にも見えず、聞こえない。住人の記録・考える部分・報酬には現れない。島の言葉にドロンを指す語はない。
- ドロンは島に**複数体**いる。4人それぞれに1体ずつ付いて見守るもの（4体）と、島の重要な場所を定点で見守るものがいる。
- 世界には触れない。物を動かさない、住人に話しかけない、灯りで生き物を寄せない。
- 画面との対応：住人を「見守る」表示はその住人に付いたドロンの視点。ドローンを画面に入れる表示では、見る人にだけドロンの姿が見える。定点の表示はこれから。
- 実装（2026-10-05）：ドットたちの世界では、魚・ウミガメ・タコがドローン（カメラ）から逃げない（`env.shy = 0`）。地球の海では今までどおり。
- これから決めること：ドロンが姿を見せることがあるか。

### 追記（2026-10-05、オーナー決定）：ドロンの番号と配置

- ドロンは**番号**で見分ける。番号は額（ドームのすぐ後ろの上面）に書く。色分けはしない（数が増えたときに分かりにくいため）。
- 配置（14体）：

| 番号 | 種類 | 見守るもの |
|---|---|---|
| 01〜04 | 付き添い | 01 ドット、02 ランタン、03 カメマル、04 ラッコ |
| 05 | 定点 | 浜と焚き火（小屋・棚） |
| 06 | 定点 | 畑 |
| 07 | 定点 | 漁礁（ドットが流木を沈めて作った、貝やウニが育つ場所） |
| 08 | 定点 | 藻場 |
| 09 | 定点 | 岩場（ラッコの食べ場） |
| 10 | 定点 | ラグーン |
| 11 | 定点 | 東の高み（ランタンの観測地） |
| 12 | 定点 | 筏の浜（渡航の出発点） |
| 13 | 巡回 | 島のまわりの海と浜を常に巡回 |
| 14 | 巡回 | 島の上空を常に巡回 |

- 実装（2026-10-05）：ドットたちの世界では、ドローンの額に番号が出る。住人を見守っているときはその住人のドロン（01〜04）、それ以外は巡回の 13。定点と 14 の表示はこれから。
