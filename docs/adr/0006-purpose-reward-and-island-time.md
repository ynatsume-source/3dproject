# ADR 0006｜大義と報酬、島の時間

状態：採択（2026-10-04、オーナー）
関係：ADR 0004（住人の主体性）とその追記（世界にない気持ちは書かない／島でも人間臭さを演出しない）、ADR 0002（科学の核と接続仕様）

## 背景

住人から性格や台詞を外した（ADR 0004 追記、2026-10-04）。残ったのは「役割」「判断の傾向」「当たり」だけだった。しかし、役割が小屋の建設や貝殻の収集のような「その日のタスク」に留まっていた。住人を前に進めるものがない。食べ物と眠気だけでは、生き物は満腹になると止まり、島の中で満足してしまう。

## 決定

### 1. 大義（マクロな役割）

| 住人 | 大義 | 報酬（世界が数える） | 段階 |
|---|---|---|---|
| ドット | 世界を広げる | 世界地図のうち、到達して確かめた範囲 | 嘉弥真島 → 見えている島々 → 太平洋の彼方 → 世界地図の完成 |
| ランタン | 科学を進める・夜に明かりを灯す | 確かめた知識の数と、夜を照らせる範囲・時間 | 火 → 油の灯り → 電気 |
| ラッコ・カメマル | なし（生き物） | 体：おなか・ねむけ・安全・労力あたりの食べ物 | — |

- **ドットだけが主人公の特性を持つ。** 「世界を広げる」は**理由の書かれていない目的**として与える。人物設定には目的だけを書き、理由は書かない。他の報酬から見れば損な行動（電池や作業時間を使う、危険を冒す）にも、この目的の報酬が出る。「合理ではないが本人にとっては報酬」を、感情を書かずに実現する。
- ドットとランタンは互いを必要とする。遠くへ行くには科学（舟の材料、夜の航海の灯り、星で位置を知る方法）が要る。科学を進めるには新しい場所（別の島の材料、緯度で変わる星）が要る。

### 2. 報酬と学習（強化学習に近い形）

- 報酬は**世界が計算する**。本人の申告は報酬にならない。
- 世界は、場所・行動・相手ごとの**価値（期待値）**を持ち、結果で更新する。遅れて来た報酬は手前の行動にも少し配る（例：話す → 情報 → 拾えた）。
- 考える部分（モデル）には「当たり」を数字で渡す（例：「岩場D 獲れた率 0.8（12回）」）。モデルは計画を出すだけで、何が報酬になったかは世界が決める。
- 報酬の抜け道には罰を合わせて決める（例：沖の最大距離は、漂流や電池切れでは数えない）。

### 3. 生き物がドットとランタンに協力する理由

生き物に大義は持たせない。代わりに次の3層を世界の仕組みとして持つ。

1. **島は楽園ではない**：季節と台風から始める（後に食べ尽くし、天敵）。
2. **見返りのある取引**：頼みごとには見返りが付き、生き物は自分の体の値と比べて得なら引き受ける。
3. **相手ごとの期待値（信頼）**：頼みを引き受けて見返りが来たかを数字で覚え、次の判断に使う（`talkUse` を相手ごとの期待値に広げる）。

最初の取引：

| 払う側 → 受け取る側 | 払うもの | 受け取る側の報酬 |
|---|---|---|
| ドット → ラッコ | 漁礁（桟橋の柱・沈めた石積みに貝やウニが付く）、貝を割る台座の石、波よけの入り江 | 食べ物・労力・台風の日の安全 |
| ラッコ → ドット | 水中の作業、沖の流木の運搬、岩場の偵察、後に舟の曳航 | 世界を広げる |
| ランタン → カメマル・ラッコ | 台風の予報（気圧の測定がランタン最初の発明） | 安全 |
| ドット → カメマル | 藻場の植え直し | 食べ物 |
| カメマル → ドット | 海流の道筋（泳いだ跡が潮の流れのデータになる） | 世界を広げる（最初の渡航の航路） |
| ドット ⇄ ランタン | 材料（粘土・石灰岩・薪、遠くの島の材料）⇄ 科学の成果（焼いた器・石灰・灯り・航海の道具） | 互いの大義 |

台風が最初の試金石になる。ランタンが予報する → 生き物が避難して損が減る → 波よけ・漁礁・藻場の植え直しで回復が早まる → 次から生き物が予報を聞きに来る。これを台詞なしに、数字と行動だけで見せる。

知られた利害の衝突も世界の決まりとして持つ。人工の光はカメの子どもを迷わせる。ランタンの灯りが広がると、カメマルの報酬が下がるところが出る。

### 4. 島の時間

- **現実と同じもの**：一日の明暗（24時間）、住人の動き（歩く・潜る・食べる・話す）、おなか・ねむけ、日誌と人間界への発信の頻度。視聴者の目の前で起きることは早送りしない。
- **島の時計（現実の約13倍）で進むもの**：暦と季節（現実の1週間で季節がひとつ、4週間で島の1年）、天気、乾燥・焼成・作物・藻場の回復など、待つだけの変化。倍率は一つに固定し、工程ごとに変えない。変えるときは全部まとめて変える。
  - 目安：薪の乾燥 約2週間 → 現実で約1日、焼成 約11時間 → 約50分、藻場の回復 30時間 → 約2時間半。
- **天気**は過去の実測を島の暦に合わせて再生する（例：石垣島の過去の気象記録から、島の暦の日にあたる日の値）。測った値なので嘘にならず、本物の台風を再生できる。現実の今の天気（live）は嘉弥真島では使わない。
- 画面と日誌には、島の日付（例「島暦 夏の12日目」）を現実の日付と並べて出す。考える部分への入力にも島の暦と季節を渡す。
- 島の暦は嘉弥真島だけに使う。ほかの海は今までどおり。

## 他チームとの調整

- **科学チーム**：
  - 科学の工程に渡す区間（`interval`）は島の時計の時刻で送る。
  - 環境の値は過去の実測の再生で、区分（`simulation` にするか、新しい区分を作るか）を決める。
  - live を許す予定の版（fixture-4）の扱い。
  - ランタンの段階表（火 → 油 → 電気）と、気圧の測定（台風の予報）を工程として用意する順番。
- **海チーム**：嘉弥真島の海の季節の生き物と台風（波・濁り）を、島の暦に合わせる。

## 実装の順序

1. 島の暦と時計（13倍）、季節と台風（過去の実測の再生）
2. 相手ごとの期待値（`talkUse` を広げる）と、場所・行動の価値の表（「当たり」を数字で渡す）
3. 取引（ラッコの漁礁、ランタンの台風予報、カメマルの藻場の植え直しから）
4. ドットの目的（理由のない目的）と世界地図の報酬、ランタンの段階表

## 追記（2026-10-04、オーナー決定）：別の星

- 嘉弥真島のプロジェクトは、**地球と全く同じ形をした、人の住まない別の星**として扱う。島のことは島のこととして独立して考える。島の暦と時計（13倍）、地球の観測記録による天気の再生、ラッコがいること、ドットの「世界地図の完成」、ランタンが科学を一からたどり直すこと、人間界への広報（別の星から地球への通信）が、この前提で筋が通る。
- **漂着物は自然のものだけ**：ヤシの実、軽石、大きな骨のかけら、モダマの種。人の作った物（瓶の手紙・歯車・浮き玉・木札）は流れ着かない。古い島に記録されていた人工物は、読み込み時に自然の漂着物へ置き換える。
- **地名**：住人は人間の地名を知らない。場所は自分たちで呼ぶ（「この島」「北の浜」、見つけた島は自分で名付ける）。地球の地名との対応（嘉弥真島・小浜島など）は、視聴者向けの画面にだけ添える。考える部分・日誌の書き手・ランタンの指示文は、この前提で書き直した。
- サイト全体の見せ方（地球儀から入る今の作りと、ほかの海＝現実の地球との区別）は、後で決める。
