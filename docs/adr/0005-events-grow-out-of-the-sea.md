# ADR 0005｜出来事は海の状態から生まれる

状態：採択（2026-10-04、オーナー）
出典：オーナーの違和感と、`docs/proposals/kayama-review/BACKLOG_2026-10-04.md` の 0 章。

## 背景

自然な海を眺めていたはずなのに、突然「演劇」が始まったように感じる。マンタのジャンプ、ベイトボール、トルネード、シュモクザメの群れなど、出来事の多くが同じ課題を持っていた。

いまの作りは次のようになっている。
- 出来事は「起こす」ところから始まる。`eco/events.ts` は10〜15分ごとに候補から一つ選び、カメラの前方に置いて始める。`eco/breach.ts` は、跳ぶ地点をカメラの前方に決めてから、マンタをそこへ向かわせる。
- 告知が先に出て、カメラが向かい、着いた頃に始まる。
- 主役は決まった周期・軌道で動く。
- 撮影監督は、出来事が始まると何をしていても飛んでいく。

## 決めたこと

1. **出来事は、海の状態から生まれる。** 起こすのではなく、条件がそろった所で起こる。小魚の密度、捕食者の空腹、時刻・潮・季節、餌の多さなど、その海に前からあった状態の延長線上で起こる。カメラの位置は、どこで起こるかを決める理由にしない。
2. **前ぶれが、海の中に先に見える。** 小魚がざわつく、群れが寄る、海鳥が集まる、大物の影が増える、など。字幕や SEA LOG は、その変化が起きてから付く。表示が出来事に先回りしない。
3. **カメラは「気づく」。** 巡航中に、近くで高まっている気配へ寄っていく。カメラの前に出来事を置かない。結果として見逃すことがあってよい。図鑑からの「見に行く」は、いま起きている（または起きかけている）所へ向かう。
4. **振る舞いは、個体の状態から。** 狙う・休む・散る・跳ぶは、その個体の空腹・疲れ・まわりの密度で決まる。決まった周期で回したり、決まった時刻に跳ばせたりしない。
5. **長さと頻度は、見ていて飽きない範囲に調整してよい。** 現実より少し多めに起こる、は許す。ただし「何もない所から始まる」「告知が先に出る」はしない。
6. **既存の決まりは変えない。** 生き物は無から出ない・その場で消えない（`src/eco/unseen.ts`、`scripts/appear-check.ts`）。重さの上限は画質の段階の中で守る。

## 進め方

1回の作業は1つの出来事。それぞれに LAB の before/after と受け入れ条件を付ける。
1. ベイトボール（小魚の大群・捕食者の個体ごとの狩り・海鳥）。ここで型を作る。
2. 捕食者の振る舞い（空腹・狙い・休み）。
3. トルネード。
4. マンタの跳躍。冬の宮古で、水面近くで餌を食べている個体が、ときどき跳ぶ。
5. ほかの出来事（シュモクザメの群れ、マンタトレイン、魚の壁、産卵、ヒートラン）。

## 見直すとき

重さが画質の段階に収まらないとき、または「何も起きない時間が長すぎて退屈」とオーナーが感じたとき。頻度の調整（5）で足りなければ、この ADR を見直す。

## 追記（2026-10-06）：通り過ぎる出来事は、見えてから知らせ、見えてから待つ

**オーナーの指摘**：ウメイロモドキの大群で、画面に何も映っていないのに「出来事発生」の知らせと定点の撮影が始まった。バグかと思って5〜10秒待つと、背後から大群が来た。

**調べたこと**（`tools/lab/rare.cjs`）：
- 魚の壁は、知らせから群れが初めて映るまで約30秒。その間、カメラは群れが通る予定の空っぽの一点を見ていた。
- マンタの群れ・シュモクザメの群れ・ヒートランは、カメラの後ろの見えない所に置かれていた。知らせと同時にカメラが振り返っていた。
- どれも、撮り手が見えないものを知っていて先回りする作りで、決めたこと2・3に反していた。

**決めたこと**（マンタの群れ・魚の壁・シュモクザメの群れ・ヒートラン）：
1. **知らせは、見ている人に見えてから**。
   - 体が画面に映ったら、そこで知らせと説明を出す。
   - 映ったとする基準：見通しの70%以内、礁に隠れていない、見えている体の見かけの合計が 15 px 以上で、そのうち1つは 6 px 以上。
   - それまでは撮影監督の候補にも入れない。
2. **撮り手は、画面より広い目で気づく**。
   - 撮り手の目（正面から左右60°）に入ったら、カメラは毎秒40°以内でそちらへ向き始める。この時点では何も表示しない。
   - ダイバーが視界の端で何かに気づいてカメラを向ける動きにあたる。
3. **待つのは見えてから**。
   - 見えたら、ドローンはその場でゆっくり止まり、本体のほうを向いて待つ。先回りして待つ場所へ移る、回り込む、はしない。
   - 本体が近づいたら（`comes`）、いつもの撮り方へつなげる。
4. **現れ方**。
   - カメラの真横より少し後ろの見通しの外（100〜125°）から、前方を横切る線で泳いでくる。
   - 誰にも見えていない間だけ、毎秒10°以内でカメラのいまの前方を横切るよう向きを直す（巡航で向きが変わっても前を通るように）。
   - 一度でも見える所に入ったら、線は固定する。
5. **前ぶれ**（本物の出来事の一部として）：
   - 魚の壁：ばらけた先頭集団が本隊より少し速く泳ぎ、先に来る。
   - マンタの群れ：追われるメスが1枚だけ、ほかより12秒以上先に来る。
   - シュモクザメの群れ：斥候の1匹が先に来る。下の礁の魚が、捕食者として身を隠す。
   - ヒートラン：見える前から、息継ぎの噴気の音が水中を遠くまで届く。

**確かめたこと**：
- `rare.cjs`（宮古・モルディブ・ガラパゴス・紅海）：
  - 知らせが初めて映る前に出たもの：0/10
  - 初めて映ってから近くを通るまで：3〜39秒
  - 待つ間、本体が画面に入っている割合：99〜100%、向きの速さは毎秒40°以内
  - 見える前に聞こえた噴気の音：3〜8回
- `scripts/appear-check.ts`（宮古・モルディブ・ガラパゴス・紅海）：マンタの群れ・魚の壁・シュモクザメの群れ・ヒートランはすべて合格。
  - 大きなベイトボールは「10分たっても終わらない」で不合格。変更前の版でも同じなので、別に調べる。
