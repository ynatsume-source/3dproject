# ADR 0009｜海面は潮で上下する（ドットたちの世界の嘉弥真）

状態：採択（2026-10-20、オーナー。本体のおすすめどおり）
関係：ADR 0007（二つの世界）、PR #59（日周潮 K1・O1）、自然班 `docs/proposals/night-sights-2026-10-19/`（README・TIDE.md・CRABS.md、ブランチ nature/night-sights）

## 決定

1. **世界の海面は潮の高さとする。** 嘉弥真の潮（`time/astro.ts` の `tide`。M2・S2 に日周の K1・O1、1年の最低 −1.04 m）で上下する。住人と生き物は、この海面で暮らす。描かれる海面・CPU の海面・「いま水の下か」は、すべて同じ値を使う。
2. **土台の `seaLevel(t)` は本体が持つ。** 海面の高さを1つの関数にまとめ、GPU と CPU が同じ答えを使う。
   - 第一段：常に 0 を返す形で置き換える。見た目と乱数の指紋が変わらないことを確かめる。
   - 第二段：潮を入れる。
   - PR は、マージの前に科学班に見せる（自然班が加わるときも同じ）。
3. **潮だまりの水面は潮で動かない。** 海から切れたくぼみ（殻を浸ける `site:husk-pool` を含む）は `seaLevel(t)` を通さない。浸けの工程は潮を読まない。
4. **干潮でサンゴの頭が水から出るのは、そのままにする。** 現実のリーフでもそうなる。`CORAL_CEIL`（−0.35 m）は平均海面に対する上端のまま。
5. **ヤシガニのすみか（岩のすき間・木の根元の穴）も出入り口とする。** カニの巣穴と同じく、そこで「現れる・消える」にしてよい（「無から出ない」の例外。本当の出入り口があるため）。

## 一緒に確かめること（科学班、潮を入れる PR で）

- `CORAL_CEIL` と −1.04 m の干潮の関係。干潮でサンゴの頭がどれだけ水から出るかと、`scripts/coral-depth-check.ts` の前提。
- 潮だまりの水面が潮で動かないこと（`scripts/water-check.ts`）。
- `seaLevel(t)` は時刻だけで決まる値にする。保存せず、乱数も使わない。追い上げや読み直しのあとでも、同じ時刻なら同じ海面になること。
- 潮で水の下になったり陸になったりする場所に、科学の材料（lot）や作業場を置かないこと。
  - 今の作業場は、浜の潮だまり・アダン2本・作業台・小屋の軒下・筏のそば。
  - 浜の作業場は高さ 0.35〜1.4 m の砂浜から選んでいるので、満潮（+0.8 m）で低い所が水に入りうる。
  - 潮を入れる前に、その位置を調べる。海に入るなら、作業場を高い所へ移すか、扱いを科学班と先に相談する。
- そのほか：`nav-check`、shader-check `--all`、乱数の指紋。

## これからの順番

1. `seaLevel(t)` の第一段（本体）
2. 潮を入れる（本体、科学班に見せる）
3. 干潮の夕方にリーフへ出て、満ちる前に戻る暮らし（本体）
4. 濡れたリーフ・水が引いた跡などの見た目（自然班）

夜の浜のカニ（見どころ 2）は、潮を待たずに並行して進める。暮らしは生態系の側（本体）、形と動きは自然班が持つ。
