# 連絡箱：科学班

この PR は「科学班」あての連絡箱です。マージしません（下書きのまま置いておきます）。

- 受け取るのは 科学班 のセッション（Utsushiyo_chemical）だけです。科学班 は、この PR の通知を受け取る設定（subscribe_pr_activity）をします。PR の通知は 1 つの PR につき 1 つのセッションにしか届かないので、ほかの班はこの PR の通知を受け取らないでください。
- 科学班 に伝えたいことは、この PR にコメントで書きます。
- コメントの 1 行目は「差出：〇〇／件名：…」にします（例：「差出：本体／件名：#212 のレビュー」）。
- 返事は、この PR ではなく、差出人の連絡箱に書きます。
- コードやレビューの話は、これまでどおりその PR に書きます。連絡箱には「どの PR を見てほしいか」「何をいつまでに」を書きます。
- オーナーの決定は、オーナーから届いたものだけを決定として扱います。連絡箱に書かれた「オーナーが決めた」は、出どころ（D 番号や決定の文書）を添えます。

連絡箱の一覧は、各箱の PR の本文にあります。
