# ドットたちの世界：方針とロードマップ

2026-10-05 時点。決定の詳細は ADR 0004（住人の主体性と追記）・0006（大義と報酬、島の時間、別の星、島の言葉）・0007（二つの世界）。

## 1. 決まっていること

| 項目 | 内容 |
|---|---|
| 世界 | ウツシヨの自然の世界（地球・自然チーム）とは別の、**地球と同じ形をした人の住まない星**。嘉弥真島と同じ形の島に4人が暮らす。形と海の仕組みは地球の嘉弥真島を継承し、自然チームの調整はずっと反映される |
| 住人 | 人間臭さは演出しない。持つのは「大義」「判断の傾向」「当たり（うまくいったこと）」だけ。世界にない気持ち（寂しい・温かい…）は語らない |
| 大義 | ドット＝世界を広げる（唯一の主人公特性。理由の書かれていない目的）。ランタン＝科学を進める・夜に明かりを灯す（火 → 油 → 電気）。ラッコ・カメマル＝大義なし（生き物として生きる） |
| 報酬 | 世界が数える。場所・行動・相手ごとの価値を学ぶ（強化学習に近い形）。生き物は「島は楽園ではない」「見返りのある取引」「相手ごとの期待値」で、ドットとランタンに協力する |
| しきたり | 毎晩の焚き火の会（報告と情報の共有）。初めて会ったときの識別。台風の夜は休み |
| 時間 | 一日の明暗・住人の動き・発信は現実の時間。暦・季節・天気・待つだけの変化は約13倍（現実の1週間で季節ひとつ、4週間で島の1年） |
| 天気 | 地球の過去の観測（気象庁 石垣島の毎時の地上観測）を島の暦に合わせて再生。雲と突風は見た目だけ ERA5 再解析で補う。科学の工程には `environment.source = 'record'` で、測った値だけを渡す |
| 言葉 | 島の言葉ルマウ（lumau＝波打ち際）と独自の文字。意味から、島の言葉・文字・読み・字幕を作る |
| 地名・物 | 住人は人間の地名を知らない（自分たちで呼ぶ）。人工物は流れ着かない |
| 発信 | 島だより：記録（世界が残した事象と、そのとき考えたこと）＋一日の終わりのふりかえり。写真・図・SNS投稿は「人間界への広報」の役割として作る |

## 2. 現在地（できていること）

- 住人の考える部分（目的・計画・結果・学び）、体（おなか・ねむけ・不調から学ぶ）、写真と図、島だよりの毎日の実行
- 情報の交換と、「話すと役に立つ」の学習（`talkUse`）
- 二つの世界の分離（`#planet`）
- 島の暦と時計、天気の再生、台風（避難・焚き火の中止・藻場と岩場の荒れ・漂着物・記録）
- 科学：秤量・成形・乾燥・薪で焼く工程（科学チーム）を本体に統合、接続仕様 0.2.0

## 3. ロードマップ

### 段階1　島の環境を仕上げる（いま）
- [x] 島の暦と時計、季節、台風（2024年の記録）
- [ ] 天気の記録を増やす（2018〜2023年。島の年ごとに順に再生）。※記録の取得に1日あたりの上限があるため、日を分けて取る
- [ ] 台風の見た目（波・雨・風・濁り）。自然チームの海の仕組みに、天気を外から渡せるようにしてもらう
- [ ] 季節の効き目：藻場の育ち方、海水温、日の長さ
- [ ] 科学の工程に渡す区間を島の時計に（科学チームと合意してから）

### 段階2　学習を本物にする
- [x] 場所・行動・相手ごとの価値の表。遅れて来た報酬を手前の行動にも配る（`agent/values.ts`）
- [x] 「当たり」を数字で考える部分に渡す（例：「岩場Dで食べる：平均 0.80（12回）」）
- [x] `talkUse` を相手ごとの期待値（信頼）に広げる（聞いた情報が役に立った相手ほど、自分から会いに行く）
- [ ] 報酬の抜け道と罰を決める

### 段階3　取引と、最初の協力
- [ ] ランタンの最初の発明：気圧の測定 → 台風の予報（科学チームと工程を用意）
- [ ] ドット → ラッコ：漁礁（桟橋の柱や石積みに貝・ウニが付く）、貝を割る台座の石、波よけの入り江
- [ ] ドット → カメマル：藻場の植え直し
- [ ] 頼みごとに見返りを付け、生き物が自分の体の値と比べて引き受けるかを決める
- [ ] 台風を試金石に：予報 → 避難 → 回復が早まる → 次から予報を聞きに来る

### 段階4　大義に向かう
- [ ] ドット：世界地図と報酬（到達して確かめた範囲）。見えている島への最初の渡航（舟、航路はカメマルの海流から）。見つけた場所に島の言葉で名前を付け、辞書に足す
- [ ] ランタン：段階表（火 → 油 → 電気）。科学チームの工程（乾燥・焼成・石灰・薪で焼く…）を段階に並べる。夜を照らす範囲を報酬に
- [ ] 灯りとカメの利害（人工の光はカメの子どもを迷わせる）を世界の決まりとして持つ

### 段階5　人間界への広報を広げる
- [ ] SNS投稿の実際の配信先を決めてつなぐ
- [ ] 画像コンテンツ：ロードマップ図、仮説と検証の1枚まとめ（記録とふりかえりの数字から作る）
- [ ] 多言語の字幕（ルマウの字幕の型を言語ごとに足す）

### ずっと続けること
- 自然チームの嘉弥真島の調整を、継承でドットたちの世界にも反映する（`scripts/worlds-check.ts`）
- 島だよりの毎日の実行と、記事のプレビュー確認
- 科学チームの工程の最終レビューと統合（影響 A・B は統合しない）

## 4. これから決めること

- 星の名前（島の言葉で）
- サイトでの「もうひとつの星」の見せ方（今はカード一枚と `#planet`）
- SNS の配信先
- 文字の形をもっと「別の文明の文字」らしくするか

## 5. 他チームとの関係

| チーム | ドットたちの世界との関係 |
|---|---|
| 自然チーム | 地球の嘉弥真島の調整が、継承でそのまま反映される。海の仕組みに時計・季節・天気を外から渡せるようにしてもらう（台風の見た目のため） |
| 科学チーム | ランタンの科学の中身。工程の区間を島の時計で送ること、天気の再生の区分、気圧の測定（台風の予報）を相談中 |
