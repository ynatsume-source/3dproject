# ドットたちの世界：方針とロードマップ

2026-10-05 時点（最終更新：同日夜）。決定の詳細は ADR 0002（共有世界と科学コア）・0004（住人の主体性と追記）・0006（大義と報酬、島の時間、別の星、島の言葉、科学との合意、地図と渡航）・0007（二つの世界）。

## 1. 決まっていること

| 項目 | 内容 |
|---|---|
| 世界 | ウツシヨの自然の世界（地球・自然チーム）とは別の、**地球と同じ形をした人の住まない星**。嘉弥真島と同じ形の島に4人が暮らす。形と海の仕組みは地球の嘉弥真島を継承し、自然チームの調整はずっと反映される。島に生えている物・いる生き物は、地球での由来を問わず使ってよい（多少の「都合のよい要素」は許容） |
| 住人 | 人間臭さは演出しない。持つのは「大義」「判断の傾向」「当たり（うまくいったこと）」だけ。世界にない気持ち（寂しい・温かい…）は語らない |
| 大義 | ドット＝世界を広げる（唯一の主人公特性。理由の書かれていない目的）。ランタン＝科学を進める・夜に明かりを灯す（火 → 油 → 電気）。ラッコ・カメマル＝大義なし（生き物として生きる） |
| 報酬 | 世界が数える。場所・行動・相手ごとの価値を学ぶ（強化学習に近い形）。生き物は「島は楽園ではない」「見返りのある取引」「相手ごとの期待値」で、ドットとランタンに協力する |
| しきたり | 毎晩の焚き火の会（報告と情報の共有）。初めて会ったときの識別。台風の夜は休み |
| 時間 | 一日の明暗・住人の動き・発信は現実の時間。暦・季節・天気・待つだけの変化は約13倍（現実の1週間で季節ひとつ、4週間で島の1年）。島暦1年は6月1日に始まった |
| 天気 | 地球の過去の観測（気象庁 石垣島の毎時の地上観測）を島の暦に合わせて再生。島の年ごとに別の年を順に再生（1年目＝2024年、2年目＝2023年、3年目＝2022年…）。雲と突風は見た目だけ |
| 科学との約束 | 待つだけの工程（乾燥・焼成・薪・浸漬・石灰・消化・気圧計）は島の時計、手を動かす工程（秤量・成形）は現実の時計で進める。天気は `environment.source = 'record'`（過去の実測の再生）として、測った値だけを渡す。風は測った高さ（`windHeightM`）と一緒に、気圧は海面気圧のまま |
| 工程を動かす場所 | ADR 0002 では材料台帳の正本は共有世界のサーバー。サーバーができるまでは、**ブラウザの島で動かす**（オーナー決定）。部品はそのままサーバーへ移せる作り |
| 言葉 | 島の言葉ルマウ（lumau＝波打ち際）と独自の文字。意味から、島の言葉・文字・読み・字幕を作る。新しく見つけた場所には同じ音の決まりで名前を付ける |
| 地名・物 | 住人は人間の地名を知らない（自分たちで呼ぶ）。地球の地名は視聴者向けの画面にだけ添える。人工物は流れ着かない |
| 撮影 | ドロン（ドローン）が姿と音を透過させて見守る。額の番号で見分ける。01〜04 は4人の付き添い、05〜12 は定点（浜と焚き火・畑・漁礁・藻場・岩場・ラグーン・東の高み・筏の浜）、13・14 は巡回（海と浜、上空）。住人と生き物には見えず、聞こえない（ADR 0007 追記） |
| 発信 | 島だより：記録（世界が残した事象と、そのとき考えたこと）＋一日の終わりのふりかえり。写真・図・SNS投稿は「人間界への広報」の役割として作る |

## 2. 現在地（できていること）

**暮らしと学習**
- 住人の考える部分（目的・計画・結果・学び）、体（おなか・ねむけ・不調から学ぶ）、写真と図、島だよりの毎日の実行
- 情報の交換と「話すと役に立つ」の学習、相手ごとの信頼、場所・行動ごとの「当たり」

**島の環境**
- 二つの世界の分離（地球の嘉弥真島と、`#planet` から入るドットたちの星）
- 島の暦と時計、天気の再生（2024・2023・2022年）、台風（避難・焚き火の中止・藻場と岩場の荒れ・漂着物・記録）

**取引**
- ドット → ラッコ：流木を沈めた漁礁。ラッコはドットへの信頼を学ぶ
- ドット → カメマル：台風で荒れた藻場の植え直し（しばらく3倍の速さで回復）

**ドットの大義（世界を広げる）**
- 浜から水平線を見渡し、見えている島5つを地図に載せる。それぞれにルマウの名前（例：南のすぐ近くの島＝sopunu、西の大きな島＝luweke）
- 部材6本で筏を組み、近くの島 sopunu（約2.6km）へ渡る。出るかどうかは世界が判断（距離・風・台風・時間帯・電池）。出ている間に台風が来たら引き返す
- 着いた島から材料を持ち帰る（粘土10kg・竹6kg・葦3kg）。小屋の脇に置かれ、世界の在庫になる

**ランタンの大義（科学）の受け皿**
- 科学チームの工程（秤量・成形・乾燥・薪で焼く）を本体に統合。接続仕様 0.2.0
- 本体側の工程の実行役：材料と道具の予約、工程ごとの時計、結果の検査と一度だけの反映、保存と復元
- 島につないだ：ランタンは起きている間、使える工程と材料が棚にあれば、棚の前で工程を始める。結果は記録に残る
- **ただし、島で使える工程はまだない**（下の「段階4」の最初の項目を参照）

## 3. ロードマップ

### 段階1　島の環境を仕上げる
- [x] 島の暦と時計、季節、台風
- [x] 待つだけの工程は島の時計で進める（科学チームと合意、ADR 0006 追記）
- [ ] 天気の記録を増やす：2024・2023・2022年は済み。2021〜2018年は取得中。雲と突風（ERA5）は1日の取得上限のため、無い年は雨と湿度から空の見た目を決める（科学に渡す測った値には影響しない）
- [ ] 台風の見た目（波・雨・風・濁り）。自然チームの海の仕組みに、天気を外から渡せるようにしてもらう
- [ ] 季節の効き目：藻場の育ち方、海水温、日の長さ

### 段階2　学習を本物にする
- [x] 場所・行動・相手ごとの価値の表。遅れて来た報酬を手前の行動にも配る
- [x] 「当たり」を数字で考える部分に渡す
- [x] 相手ごとの信頼（聞いた情報が役に立った相手ほど、自分から会いに行く）
- [ ] 報酬の抜け道と罰を決める

### 段階3　取引と、最初の協力
- [x] ドット → ラッコ：漁礁。台座の石・波よけの入り江はこれから
- [x] ドット → カメマル：藻場の植え直し
- [x] 見返りの学習：ラッコはドットの漁礁で食べると信頼を学び、頼みを引き受けやすくなる
- [ ] ランタンの最初の発明：気圧の測定 → 台風の予報。科学チームの工程の順：試験用の気圧計（Codex の確認待ち）→ ヤシ油 → 炭焼き（炭＋木タール）→ 気密の器 → 自作の気圧計 → 油の灯り。電気はその先（炭が金属の入口）
- [ ] 頼みごとに見返りを明示して付け、生き物が自分の体の値と比べて引き受けるかを決める
- [ ] 台風を試金石に：予報 → 避難 → 回復が早まる → 次から予報を聞きに来る

### 段階4　大義に向かう
- [x] ドットの世界地図と、地図が広がる報酬
- [x] 最初の渡航（筏で近くの島へ）と、材料の持ち帰り
- [x] 本体側の工程の実行役と、ランタンが棚の材料で工程を始める流れ
- [x] 科学の束を統合（2026-10-05）：接続仕様 0.2.1（島の天気 `record`）、fixture-4、粘土の下ごしらえ、ヤシ油、試験用の気圧計。島の工程表に7工程
- [ ] **島で科学の工程を実際に動かす**（次の一歩）。科学側はそろった。残りは島の側で決めること：
  - 真水の元（雨水をためる、別の島の川から運ぶ など）
  - 桶・鍋・道具を島でどう作るか（どの工程も試験用の設備 `fixture_…` を前提にしている。人工物は流れ着かない）
  - 浜のヤシの実と薪を在庫にする決まり
  - 気圧計：既製の試験用は島にない。島で作る気圧計は別の工程
- [ ] 気密の器（科学側 e6668fb、Codex 確認待ち）：器のロットを設備にする「組み立て」の決まりを決めた（ADR 0006 追記）。統合は Codex の確認の後
- [ ] 2つ目の島へ：東の平たい島（石灰岩）は筏では遠い。帆・大きな舟（ランタンの科学と材料）、航路はカメマルの海流から
- [ ] 太平洋の彼方：星で位置を知る方法（ランタン）と、夜の航海の灯り
- [ ] ランタンの段階表（火 → 油 → 電気）。夜を照らす範囲を報酬に
- [ ] 灯りとカメの利害（人工の光はカメの子どもを迷わせる）を世界の決まりとして持つ
- [ ] 共有世界のサーバー（国内 VPS）：できたら工程の実行役と在庫をそのまま移し、全員で同じ島の歴史を見るようにする

### 段階5　人間界への広報を広げる
- [x] ドロンの番号（額）。付き添い 01〜04 と巡回 13 の表示
- [ ] 定点のドロン 05〜12 と、上空を巡回する 14 の表示
- [ ] SNS投稿の実際の配信先を決めてつなぐ
- [ ] 画像コンテンツ：ロードマップ図、仮説と検証の1枚まとめ（記録とふりかえりの数字から作る）
- [x] ルマウ語の文法と約1,200語の語彙（docs/lumau/GRAMMAR.md）。語順は日本語と同じ、気持ちの言葉はなし
- [x] ルマウ語：島の全台詞に英語の訳、「〜で」を ni に、吹き出しは「名前・島の文字・訳」（訳はメニューで日本語／English／なし）、住人の声（それぞれの声で読み上げ、距離で音量、メニューで切り替え）、設定資料集の「ことば」のページ
- [x] ルマウ語：住人どうしのやり取り（頼む・引き受ける／断る・手渡す・場所を教える）を意味の枠から話す（lumau/frames.ts）
- [x] ルマウ語：考える部分（AI）が「話す」を行動の選択肢として選ぶ（天気の知らせ、これからすること）
- [ ] ルマウ語：枠をさらに増やす（手伝いの申し出、見つけたものの知らせ、焚き火の会での質問と答え）
- [ ] 多言語の字幕（ルマウの字幕の型を言語ごとに足す）

### ずっと続けること
- 自然チームの嘉弥真島の調整を、継承でドットたちの世界にも反映する
- 島だよりの毎日の実行と、記事のプレビュー確認
- 科学チームの工程の最終レビューと統合（Codex の確認の後に取り込む）

## 4. 待っていること・これから決めること

**科学チームから届くのを待っているもの**
- 試験用の気圧計（`m02x_air_barometer_test`）、fixture-4、接続仕様 0.2.1 案：Codex の全面レビュー待ち。確認が済んだら本体に統合する（統合検査の processVersion を fixture-4 に）
- 生の粘土の下ごしらえの工程と、材料の名前（`raw_clay`・`bamboo`・`reed`・`limestone`）を科学側の表記に合わせるかどうか

**オーナーが決めること**
- 星の名前（島の言葉で）
- サイトでの「もうひとつの星」の見せ方（今はカード一枚と `#planet`）
- SNS の配信先
- 共有世界のサーバーを用意する時期
- ドロンが姿を見せることがあるか
- 文字の形をもっと「別の文明の文字」らしくするか

## 5. 他チームとの関係

| チーム | ドットたちの世界との関係 |
|---|---|
| 自然チーム | 地球の嘉弥真島の調整が、継承でそのまま反映される。海の仕組みに時計・季節・天気を外から渡せるようにしてもらう（台風の見た目のため） |
| 科学チーム | ランタンの科学の中身。工程ごとの時計と天気の再生（record）は合意済み・実装済み（Codex 確認待ち）。次は気圧計、生の粘土の下ごしらえ、ヤシ油・炭焼きへ |
